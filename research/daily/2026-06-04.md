### 1️⃣

📄 **从技能到人才：将异构 Agent 组织为一家真实公司**（From Skills to Talent: Organising Heterogeneous Agents as a Real-World Company）
🔗 https://arxiv.org/abs/2604.22446

💡 **核心贡献**
提出 OneManCompany (OMC) 框架，将多智能体系统提升到"组织层"，使 Agent 团队可以像真实企业一样动态招募、自治决策与持续改进。引入"Talent Market"，支持按需招募具备不同技能的 Agent，彻底解耦"组织能力"与"个体知识"。

🔧 **技术亮点**
- 每个 Agent 封装为可移植的 **Talent 身份**，包含技能、工具与运行时配置，支持跨后端迁移
- 通过 **Explore-Execute-Review (E²R) 树搜索** 统一规划、执行与评估为单一层次循环，自顶向下分解任务、自底向上聚合结果
- E²R 提供形式化的**终止与无死锁保证**，是首个兼顾工程可靠性的多 Agent 组织框架

📊 **实验结果**
在 PRDBench 上取得 **84.67% 成功率**，超过 SOTA **15.48 个百分点**；跨域案例研究进一步证明其泛化能力。

🎯 **与 Agent/Routing 的关联**
OMC 的 Talent Market 本质上是一个 **能力感知的动态 Agent 路由层**，与 LLM Routing 研究高度互补。

### 2️⃣

📄 **AgentGym-RL：通过多轮强化学习训练 LLM Agent 进行长时程决策**（AgentGym-RL: Training LLM Agents for Long-Horizon Decision Making through Multi-Turn Reinforcement Learning）
🔗 https://arxiv.org/abs/2509.08755

💡 **核心贡献**
构建了首个模块化、解耦的多轮 RL 训练框架，专为 LLM Agent 在多样化真实场景（工具调用、网页导航、代码生成）中的长时程决策设计。提出 ScalingInter-RL 训练策略，通过训练早期跨任务探索显著提升泛化能力。

🔧 **技术亮点**
- **模块化解耦设计**：Agent 训练器、环境接口、奖励函数三者完全独立，支持任意 LLM 骨干接入
- **ScalingInter-RL**：在训练初期强化跨任务交互采样，打破单任务 RL 的过拟合瓶颈
- 支持 **多域异构环境**同时训练，覆盖 WebArena、SciWorld、ALFWorld 等主流 Agent Benchmark

📊 **实验结果**
在多个 Agent Benchmark 上显著超越 SFT 基线，跨任务泛化能力在同等参数量下超越先前所有 RL 方法；已获 ICLR 2026 Oral。

🎯 **与 Agent/Routing 的关联**
多轮 RL 训练出的 Agent 天然具备"何时调用哪个工具"的决策能力，是工具路由（Tool Routing）的重要训练范式。

### 3️⃣

📄 **UniRoute：面向高效 LLM 推理的通用模型路由**（UniRoute: Universal Model Routing for Efficient LLM Inference）
🔗 https://arxiv.org/abs/2502.08773

💡 **核心贡献**
提出 UniRoute，解决现有路由方法只能应对固定模型池的局限，支持**动态路由**——测试时接入从未见过的新 LLM 无需重新训练路由器。用代表性 prompt 集合的预测向量为每个 LLM 建立特征表示，从理论上证明其逼近最优路由规则。

🔧 **技术亮点**
- 将每个 LLM 表示为**基于代表性 prompt 预测的特征向量**，实现模型无关的通用嵌入
- 提出两种实例化：**基于聚类路由** 与 **学习聚类映射路由**，均有超额风险上界保证
- 无需访问新模型内部权重，仅需少量 prompt 推理即可完成模型注册

📊 **实验结果**
在覆盖 **30+ 未见 LLM** 的多个公开基准上验证有效性，与需要全量重训的方法性能相当，迁移成本大幅降低。

🎯 **与 Agent/Routing 的关联**
直接针对 LLM Routing 核心挑战——模型池动态更新，对生产环境的 Agent 系统尤具实用价值。

### 4️⃣

📄 **GreenServ：面向多模型 LLM 推理的能耗感知动态路由**（GreenServ: Energy-Efficient Context-Aware Dynamic Routing for Multi-Model LLM Inference）
🔗 https://arxiv.org/abs/2601.17551

💡 **核心贡献**
提出 GreenServ，首个同时优化**推理精度与能耗**的上下文感知 LLM 动态路由框架，通过轻量级特征提取 + 多臂老虎机在线学习实现无需离线标注的自适应路由策略。

🔧 **技术亮点**
- 从每个 query 提取**任务类型、语义聚类、文本复杂度**三类轻量特征，路由决策延迟极低
- 采用**多臂老虎机（MAB）** 在线学习路由策略，仅需部分反馈，天然支持新模型热插拔
- 在 **16 个开源 LLM** 构成的异构模型池上评测，覆盖 5 类任务

📊 **实验结果**
对比随机路由：精度提升 **22%**，累计能耗降低 **31%**；在 RouterBench 上平均精度 71.7%，峰值 75.7%。代码完全开源。

🎯 **与 Agent/Routing 的关联**
将能耗纳入路由目标，为 Agent 系统的绿色部署提供了理论与实践基础，是 LLM Routing 领域的重要新维度。

## 🧠 今日洞察

1. **组织化是多 Agent 系统的下一个里程碑**：从固定拓扑的 Pipeline 走向动态招募、自我改进的"AI 公司"（如 OMC），标志着多 Agent 研究从工程实现迈向组织理论，任务规划与人员路由的边界正在模糊。

2. **LLM Routing 进入"动态模型池"新阶段**：UniRoute 和 GreenServ 均指向同一趋势——路由不再绑定静态模型集合，而是要在运行时接纳新模型、响应价格与质量变化（ParetoBandit 亦如此），这与 Agent 系统对弹性基础设施的需求高度契合。

3. **强化学习成为 Agent 长时程能力的核心训练范式**：AgentGym-RL 获 ICLR 2026 Oral 印证，多轮 RL 正在替代 SFT 成为训练"会用工具、能规划"Agent 的主流方法，ScalingInter-RL 等跨任务训练策略值得重点关注。
