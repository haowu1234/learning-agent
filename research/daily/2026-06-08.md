📄 **AI Agent 如何重塑知识工作：自主性、效率与任务边界**（How AI Agents Reshape Knowledge Work: Autonomy, Efficiency, and Scope）
🔗 https://arxiv.org/abs/2606.07489
💡 核心贡献：
基于 Perplexity 的 Search 与 Computer 两款产品的真实生产数据，量化了 AI Agent 自主执行对知识工作效率的实际影响；研究发现 Agent 模式不仅加速任务，更从根本上改变了用户尝试的任务类型和认知复杂度。
🔧 技术亮点：
- 利用"初始查询近似配对"的自然实验设计，对比 Agent 模式（Computer）与搜索模式（Search）在同类任务上的差异
- Computer 模式每会话自主工作 26 分钟（vs Search 的 33 秒），任务不满意率降低 55%
- Agent 化后用户任务跨越职业边界、包含更多复合子任务，解锁了纯搜索模式下几乎不存在的工作类型
📊 实验结果：
在匹配任务对上，Computer 将完成时间从 269 分钟压缩至 36 分钟，估算时间成本降低 87%、货币成本降低 94%（相比人类+搜索）。
🎯 与 Agent/Routing 的关联：
直接证实了 Agent 自主任务分解与执行对生产力的量化价值，为 Agent 能力评估和 Routing 策略（何时升级到 Agent 模式）提供了经济视角。

📄 **像真正的研究员一样行动：评估前沿 LLM 与 Agent 框架的研究生命周期基准**（Act As a Real Researcher: A Suite of Benchmarks Evaluating Frontier LLMs and Agentic Harnesses in Research Lifecycle）
🔗 https://arxiv.org/abs/2606.07462
💡 核心贡献：
提出 AARR 基准系列，首个子基准 AARRI-Bench（研究实习生级别）专注于粒度级研究场景中的专业性、细致性和科学判断力，而非仅评估宏观执行能力；填补了现有 Agent 基准对"研究细节敏感性"评估的空白。
🔧 技术亮点：
- 设计了贴近真实研究工作流的细粒度任务，考察 Agent 能否发现"显而易见但易被忽视"的关键细节
- 评测了多个前沿模型+脚手架组合（包括 Mini-SWE-Agent + Claude Opus 4.7）
- 引入"研究行为"维度，区别于纯代码执行能力或复杂脚手架堆砌
📊 实验结果：
最佳配置（Mini-SWE-Agent + Claude Opus 4.7）成功率仅 68.3%，Agent 频繁忽视对人类研究者来说显而易见的细节。
🎯 与 Agent/Routing 的关联：
揭示了长视野 Agent 在研究类任务中的关键短板，为"何时需要人类介入"的 Routing 决策提供了 benchmark 依据。

📄 **Skill-3D：进化式场景感知技能用于 Agent 3D 空间推理**（Skill-3D: Evolving Scene-Aware Skills for Agentic 3D Spatial Reasoning）
🔗 https://arxiv.org/abs/2606.07436
💡 核心贡献：
针对 Agent 在 3D 空间推理任务中"工具使用偏差"问题（对所有场景用同一工具策略），提出 Skill-3D 框架，通过场景记忆驱动自演化技能库来实现场景自适应的工具选择与调用。
🔧 技术亮点：
- 构建 Scene Memory 记录 Agent 的工具使用轨迹，提炼成功轨迹为可复用的"场景感知技能"，附加失败案例作为 lessons
- 技能库与记忆协同演化（co-evolve），形成闭环自我改进机制
- 支持在 Gemini / Qwen3-VL 等模型上进行 agentic post-training，强化技能引导的推理轨迹
📊 实验结果：
工具正确使用率从 39% 提升至 78%（VSI-Bench）；Gemini-3-Flash 在 MMSI-Bench 上提升 67%；Qwen3-VL-8B 在 VSI-Bench 上提升 43%。
🎯 与 Agent/Routing 的关联：
本质上是一种"场景感知的工具路由机制"——根据场景特征动态决定调用哪些工具，与 LLM Routing 中的"任务-模型"匹配问题高度类似。

📄 **SETA：稀疏子空间到专家共享，用于任务无关持续学习**（Sparse Subspace-to-Expert Sharing for Task-Agnostic Continual Learning）
🔗 https://arxiv.org/abs/2606.07500
💡 核心贡献：
提出 SETA 框架，通过自适应稀疏子空间分解将知识隔离到任务专属专家与共享专家模块，以统一门控网络在推理时自动路由到正确的专家组合，解决 LLM 持续学习中的可塑性-稳定性矛盾。
🔧 技术亮点：
- 自适应弹性锚定（adaptive elastic anchoring）+ 路由感知正则化（routing-aware regularization），在权重与路由两个层面同时保护共享知识
- 统一门控网络在推理时自动检索正确专家组合，无需已知任务标识符
- 在 LLaMA-2 7B 和 Qwen3-4B 上验证，对早期任务知识保留尤为突出
📊 实验结果：
在多个领域特定基准上，SETA 达到与当前最优持续学习基线相当或更优的综合性能，早期任务保留和 backward transfer 明显改善。
🎯 与 Agent/Routing 的关联：
SETA 的门控路由机制直接对应 LLM Routing 的核心问题：如何根据任务特征自动选择最合适的模型/专家，其"稀疏路由+知识隔离"思路对 Multi-Agent 任务分配有直接借鉴价值。

## 🧠 今日洞察

1. **Agent 价值量化进入生产实证阶段**：从 Perplexity 的生产数据研究可以看出，AI Agent 的价值已不再停留于 benchmark 数字，而是开始以真实的"时间节省率"和"任务边界扩展"来度量——这对 Agent 产品化和 ROI 评估有重要参考价值。

2. **工具路由与场景自适应是 Agent 能力天花板**：Skill-3D 揭示了当前 Agent 的核心问题不是"有没有工具"，而是"能否根据场景选对工具"——这与 LLM Routing 领域的核心挑战高度同构，预计场景感知路由将成为近期研究热点。

3. **Agent 基准从"能完成"向"像人一样做"升级**：AARRI-Bench 将评估维度从宏观任务完成率精细化到研究细节判断力，代表着 Agent 评估范式的新一轮演进——关注"专业性"而非"能力"，这对 Agent 的 Routing 决策（何时信任 Agent、何时需要人工介入）具有直接的实践指导意义。
