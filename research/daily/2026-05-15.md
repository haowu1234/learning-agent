## 📄 **基于强化学习的自演化 Agent 技能策划系统 SkillOS**
（SkillOS: Learning Skill Curation for Self-Evolving Agents）

🔗 https://arxiv.org/abs/2605.06614（arXiv:2605.06614 | cs.AI | 2026-05-07）

💡 **核心贡献**
提出 SkillOS，一个通过 RL 训练让 Agent 自主学习"如何策划技能库"的框架，解决了现有方法依赖人工策划或短程启发式操作、无法从间接延迟反馈中学习复杂长程策略的痛点。SkillOS 将技能存储在外部 SkillRepo 中，由可训练的 skill curator 根据累积经验持续演化更新。

🔧 **技术亮点**
- **冻结执行器 + 可训练策划器分离设计**：agent executor 负责检索并应用技能，skill curator 单独训练，互不干扰
- **组合奖励 + 分组任务流训练**：早期轨迹更新 SkillRepo，后续相关任务评估更新效果，构成自然的学习信号闭环
- **跨 backbone 泛化**：学到的策划器可迁移到不同执行器模型和任务域，SkillRepo 中的技能自动演化为结构化 Markdown 元技能文档

📊 **实验结果**
在多轮 agentic 任务和单轮推理任务上，SkillOS 在效果与效率上均优于无记忆基线和强记忆基线；SkillRepo 技能随训练逐渐从简单操作演化为高层 meta-skill 描述。

🎯 **与 Agent/Routing 的关联**
直接回答"Agent 如何动态选择工具/技能"的核心问题，SkillOS 的策划机制本质上是一种任务级别的 skill routing 决策。

## 📄 **面向长程 Agent 记忆的统一短/长期记忆管理框架 AgeMem**
（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for LLM Agents）

🔗 https://arxiv.org/abs/2601.01885（arXiv:2601.01885 | cs.CL | 2026-01-05，v2 2026-04-30）

💡 **核心贡献**
提出 AgeMem，首个将长期记忆（LTM）和短期记忆（STM）统一纳入 Agent 策略的端到端框架；将记忆操作暴露为工具化 action，让 LLM Agent 自主决定何时存储、检索、更新、摘要或丢弃信息，避免了对启发式辅助控制器的依赖。

🔧 **技术亮点**
- **记忆操作即工具**：store / retrieve / update / summarize / discard 全部作为 action space 的一部分，Agent 可学习使用
- **三阶段渐进式 RL 训练**：循序渐进地赋予 Agent 记忆管理能力，降低稀疏奖励下的学习难度
- **Step-wise GRPO**：专为记忆操作触发的稀疏、不连续奖励设计的 policy 优化方法

📊 **实验结果**
在 5 个长程 benchmark 上一致优于强记忆增强基线；同时实现更高质量的长期记忆存储和更高效的上下文使用，多 LLM backbone 验证。

🎯 **与 Agent/Routing 的关联**
Agent 在长程任务中需要动态决定哪些信息进入哪种记忆类型，这本质上是一种 memory routing 问题，AgeMem 给出了端到端的可学习解法。

## 📄 **面向专业化 Web 环境的 Agent 长期记忆评测基准 LongMemEval-V2**
（LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues）

🔗 https://arxiv.org/abs/2605.12493（arXiv:2605.12493 | cs.CL | 2026-05-12）

💡 **核心贡献**
发布 LME-V2，第一个专为评估 Agent 在定制化 Web 环境中"积累环境经验"能力而设计的长期记忆 benchmark；同时提出两种记忆方法：基于 RAG 的 AgentRunbook-R 和基于 Coding Agent 动态取证的 AgentRunbook-C。

🔧 **技术亮点**
- **451 个人工标注问题**，覆盖五类记忆能力：静态状态召回、动态状态追踪、工作流知识、环境"陷阱"与前提意识
- **超大规模历史轨迹**：每问题关联最多 500 条轨迹，合计 115M tokens，测试记忆系统的极限
- **AgentRunbook-C**：将历史轨迹存为文件，召唤 Coding Agent 在增强沙箱中动态检索证据，兼顾精度与灵活性

📊 **实验结果**
AgentRunbook-C 达到 **72.5%** 平均准确率，远超最强 RAG 基线（48.5%）和 off-the-shelf Coding Agent 基线（69.3%）；但编码类方法延迟较高，精度-延迟 Pareto 边界仍有改进空间。

🎯 **与 Agent/Routing 的关联**
LME-V2 将记忆能力的评估精细化到"工作流知识"与"环境状态追踪"层面，为构建更精准的 memory routing 机制提供了评测标尺。

## 📄 **多 LLM 动态路由与级联推理综述**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/abs/2603.04445（arXiv:2603.04445 | cs.NI+cs.CL | 2026-02-23，v2 2026-04-21）

💡 **核心贡献**
首个系统梳理"跨独立 LLM 路由与级联"方法的综述，区别于 MoE 架构（模型内路由），聚焦于多个独立部署模型间的查询分配；提出三维度路由框架：**何时决策、基于何种信息、如何计算**。

🔧 **技术亮点**
- **七大路由范式**：查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联——全覆盖当前主流方法
- **三维框架（When × What × How）**：将实际系统建模为多范式的组合体，指导工程设计决策
- **开放挑战梳理**：跨架构、跨模态、跨应用的通用性仍是主要瓶颈，为未来研究指明方向

📊 **实验结果**
综述性工作，定性分析表明：设计良好的路由系统在效率与效果上可以超越单一最强模型，前提是充分利用专用模型的互补能力。

🎯 **与 Agent/Routing 的关联**
本文是 LLM Routing 领域的权威图谱，直接服务于"Agent 框架中如何选择最优子模型"这一核心工程问题。

## 🧠 今日洞察

**记忆成为 Agent 能力瓶颈的焦点**：从 AgeMem 的端到端记忆管理，到 LME-V2 的大规模评测，再到 SkillOS 的技能演化，三篇论文共同指向同一判断——当前 Agent 的核心局限不在于推理，而在于"记住什么、何时用"的记忆策略，RL 正在成为解决这一问题的主流路径。**Routing 从系统视角走向 Agent 内部**：LLM Routing 综述揭示了行业已从"选大模型还是小模型"进化到"动态组合专用能力"，这一范式正在向 Agent 内部工具选择和技能路由渗透（如 SkillOS）。**自演化与经验积累将是 2026 下半年的主旋律**：多篇工作均强调"从历史轨迹中学习"而非依赖静态提示或规则，Agent 正在从"单次执行者"向"持续成长的专业协作者"转型。
