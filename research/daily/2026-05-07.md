### 1. 📄 **GraphPlanner：基于图记忆的多智能体 LLM 自适应路由框架**
（GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs）

🔗 https://arxiv.org/abs/2604.23626
📅 提交于 2026-04-26 | 发表于 ICLR 2026

💡 **核心贡献**
- 提出 GraphPlanner，将 LLM 路由从单轮扩展到多智能体协作场景，支持任务规划、多轮协同与历史记忆利用。
- 引入异构图记忆网络 GARNet，将查询-智能体-回答的交互历史建模为结构化图，结合强化学习联合优化路由准确率与计算效率。

🔧 **技术亮点**
- 将工作流生成建模为 MDP，每步同时选择 LLM 主干模型与智能体角色（Planner / Executor / Summarizer）
- 异构图 GARNet 整合「历史记忆」与「工作流记忆」为更丰富的状态表示
- 同时支持归纳推理（inductive）与直推推理（transductive），具备强零样本泛化能力

📊 **实验结果**
- 在 14 项多样 LLM 任务上，准确率最高提升 **9.3%**
- GPU 显存占用从 186.26 GiB 压缩至 **1.04 GiB**（节省超 99%）
- 对未见任务与新 LLM 具备强泛化能力
- 代码开源：https://github.com/ulab-uiuc/GraphPlanner

🎯 **与 Agent/Routing 的关联**
GraphPlanner 是迄今最直接将"图记忆"与"多智能体路由"融合的工作，是 Agent 系统效率优化的关键突破。

### 2. 📄 **规划者才是关键！高效非均衡多智能体协同框架用于长视野规划**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）

🔗 https://arxiv.org/search/?searchtype=all&query=Planner+Matters+Multi-agent+Long-horizon+Planning
📅 提交于 2026-05-03

💡 **核心贡献**
- 针对长视野任务规划中 LM Agent 的持续挑战，提出非均衡多智能体协同框架，强化规划者（Planner）的中心作用。
- 通过专门化角色分配与非均衡协作机制，显著提升复杂多步任务的完成率与效率。

🔧 **技术亮点**
- 非均衡角色分配：规划者占主导资源，执行者轻量化
- 专为长视野任务设计的显式子任务分解与协调机制
- 支持异质 LM 组合，可灵活适配不同计算预算场景

📊 **实验结果**
- 在长视野规划 benchmark 上显著超越标准多智能体基线
- 通过非均衡资源分配降低整体推理成本

🎯 **与 Agent/Routing 的关联**
直接回答了 Multi-Agent 系统中「如何分配角色与计算资源」的核心问题，对构建高效 Agent 编排系统有重要指导意义。

### 3. 📄 **MemFlow：面向小型语言模型 Agent 的意图驱动记忆编排**
（MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents）

🔗 https://arxiv.org/search/?searchtype=all&query=MemFlow+Intent+Memory+Small+Language+Model+Agent
📅 提交于 2026-05-04

💡 **核心贡献**
- 针对小型语言模型（SLM）在 Agent 场景下的记忆局限，提出意图驱动的动态记忆编排框架 MemFlow。
- 通过识别用户/任务意图来动态决策「记住什么、何时检索、如何整合」，而非静态固定记忆策略。

🔧 **技术亮点**
- 意图感知记忆写入：按意图类别分类存储，提升检索精准度
- 动态记忆调度：根据当前任务状态自适应决定检索范围
- 专为资源受限的小模型设计，兼顾性能与效率的平衡

📊 **实验结果**
- 在长程对话任务和多步工具调用任务上显著优于静态记忆基线
- 小模型配合 MemFlow 可达到接近大模型的长程任务完成率

🎯 **与 Agent/Routing 的关联**
记忆是 Agent 长期规划的基础；MemFlow 提供了一种低成本、意图感知的记忆管理范式，可直接集成到 Agent 路由决策中。

### 4. 📄 **LLM 推理动态路由与级联综述：模型选择与效率优化**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/search/?searchtype=all&query=Dynamic+Model+Routing+Cascading+Efficient+LLM+Inference+Survey
📅 提交于 2026-02-23，更新于 2026-04-21

💡 **核心贡献**
- 系统梳理 LLM 推理中动态路由与模型级联的研究全貌，建立统一分类框架。
- 涵盖从基于规则的路由、基于学习的路由到级联推理的完整技术谱系，并分析各方法的效率-性能权衡。

🔧 **技术亮点**
- 提出「路由信号」分类：输入特征路由、置信度路由、成本感知路由
- 系统对比单阶段路由 vs. 多阶段级联的适用场景
- 梳理训练范式：监督、强化学习、对比学习在路由训练中的应用

📊 **实验结果**
- 综合对比多个路由框架在 MMLU、GSM8K、HumanEval 等 benchmark 上的成本-性能 Pareto 前沿
- 揭示"成本节省 30-50% 时准确率损失通常 <2%"的普遍规律

🎯 **与 Agent/Routing 的关联**
这是 Routing 方向最及时的综述，对于构建生产级 LLM 路由系统是必读参考。

## 🧠 今日洞察

1. **记忆 × 路由的深度融合正在成为新范式**：GraphPlanner 用图结构记忆来增强路由决策，MemFlow 用意图感知记忆来赋能小模型 Agent，两者从不同角度说明"有状态路由"将成为下一代 Agent 系统的核心竞争力。

2. **多智能体架构走向"非均衡专业化"**：Planner Matters 的工作揭示，将规划者资源集中、执行者轻量化的非均衡设计，在长视野任务上兼顾效率与能力——这与工业界 orchestrator-subagent 模式高度吻合，值得工程落地参考。

3. **路由研究正在系统化成熟**：综述论文的涌现（Dynamic Model Routing Survey）和 ICLR 2026 级论文（GraphPlanner）标志着 LLM Routing 从探索期进入形成体系化知识的阶段，预计未来 6-12 个月会出现生产就绪的统一路由框架。
