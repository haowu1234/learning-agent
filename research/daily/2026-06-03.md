### 1. AgeMem：统一长短期记忆管理的智能体框架

**原文标题**：Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem，将长期记忆（LTM）和短期记忆（STM）管理统一集成进 Agent 策略层，通过工具调用暴露记忆操作，让 LLM 自主决定何时存储、检索、更新、摘要或丢弃信息。采用三阶段渐进式强化学习（含 step-wise GRPO）训练统一记忆行为，解决记忆操作引发的稀疏/不连续奖励问题。

🔧 **技术亮点**
- 记忆操作作为 tool-based actions 暴露，Agent 端到端可优化，无需启发式辅助控制器
- 三阶段渐进 RL 策略：先建立基础记忆能力，再引入长期记忆，最后联合优化
- step-wise GRPO 专为记忆操作设计，缓解稀疏奖励下的训练不稳定性

📊 **实验结果**
在 5 个长时程基准测试上，AgeMem 持续优于强记忆增强 baseline，覆盖多个 LLM backbone，在任务完成率、长期记忆质量和上下文利用效率上均有提升。代码已开源：https://github.com/y1y5/AgeMem

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 长时程任务中上下文窗口受限的核心痛点，为长时程 Agent 的记忆管理提供端到端 RL 训练范式。

### 2. RL 训练长时程工具型 Agent 的完整配方

**原文标题**：Demystifying Reinforcement Learning for Long-Horizon Tool-Using Agents: A Comprehensive Recipe

🔗 https://arxiv.org/abs/2603.21972

💡 **核心贡献**
针对 RL 训练复杂多轮工具型 Agent 缺乏系统化设计指导的问题，以 TravelPlanner（需工具编排满足多约束）为测试床，从 5 个维度系统分解 Agentic RL 设计空间，提炼出 7 条关键结论，形成可复用的训练配方。

🔧 **技术亮点**
- 5 个设计维度：奖励塑形、模型规模、数据组成、算法选择、环境稳定性
- 关键发现：奖励与算法选择依赖模型规模——小模型受益于分阶段奖励+增强探索，大模型在简单稠密奖励下收敛更快
- ~1K 训练样本 + 难度均衡混合即为最优数据"甜点"，环境稳定性对防止策略退化至关重要

📊 **实验结果**
基于提炼配方训练的模型在 TravelPlanner 上取得 SOTA，显著超越 GPT-4o、Claude-3.5 等 leading LLMs，代码已开源：https://github.com/WxxShirley/Agent-STAR

🎯 **与 Agent/Routing 的关联**
为工具型 Agent 的 RL 训练提供了可操作的系统性方法论，对多工具、长时程 Agent 实际工程落地具有高度参考价值。

### 3. LLMRouterBench：大规模 LLM 路由基准与统一框架

**原文标题**：LLMRouterBench: A Massive Benchmark and Unified Framework for LLM Routing

🔗 https://arxiv.org/abs/2601.07206

💡 **核心贡献**
构建了迄今最大规模的 LLM 路由基准 LLMRouterBench，包含 400K+ 实例（21 个数据集 × 33 个模型），整合 10 种路由 baseline，提供性能导向路由和性能-成本权衡路由的完整评估体系，系统重新评估了整个路由领域。

🔧 **技术亮点**
- 统一评估框架揭示：许多路由方法在统一评测下性能相近，部分商业路由器无法稳定超越简单 baseline
- 关键发现：backbone 嵌入模型影响有限，更大的模型集合呈现收益递减；主要差距来自 model-recall failures
- 支持延迟感知分析（latency-aware analysis），更贴近生产场景

📊 **实验结果**
覆盖 33 个模型、21 个数据集，400K+ 实例，10 个路由方法对比；全部代码和数据已开源。

🎯 **与 Agent/Routing 的关联**
为 LLM Routing 研究提供了公正的统一评估平台，揭示了现有路由方法的系统性缺陷，对 Agent 推理成本优化有直接指导意义。

### 4. Domino：解耦因果建模与自回归起草的投机解码新框架

**原文标题**：Domino: Decoupling Causal Modeling from Autoregressive Drafting in Speculative Decoding

🔗 https://arxiv.org/abs/2605.29707

💡 **核心贡献**
提出 Domino，将因果依赖建模从高成本的自回归起草过程中解耦，先用并行起草骨干网络生成完整 block 的初步 draft 分布，再通过轻量 Domino Head 注入前缀相关因果信息，兼顾起草质量与起草效率。

🔧 **技术亮点**
- 并行 draft backbone + Domino Head 的分离式架构，突破自回归顺序开销瓶颈
- base-anchored training curriculum：先强化并行骨干，再逐步将优化目标转向因果修正分布
- 兼容 Transformers 和 SGLang 两种后端，适应不同生产部署场景

📊 **实验结果**
在 Qwen3 模型上，Transformers backend 实现最高 **5.49×** 端到端加速，SGLang serving 实现最高 **5.8×** 吞吐加速。

🎯 **与 Agent/Routing 的关联**
投机解码是降低 LLM 路由推理延迟的核心手段之一，Domino 的加速效果可直接提升 Agent 的响应速度与吞吐能力。

## 🧠 今日洞察

**趋势 1 — 记忆即策略（Memory-as-Policy）**：AgeMem 将记忆管理从启发式辅助控制器升级为端到端可训练的智能体策略，这一范式转变正在成为长时程 Agent 研究的主流方向。

**趋势 2 — RL 训练 Agent 进入工程化阶段**：Agent-STAR 的"配方式"研究（5 维度 × 7 结论）标志着 Agentic RL 已从探索期迈向方法论沉淀期，行业需要的不只是新方法，而是可复现的训练配方。

**趋势 3 — Routing 基础设施走向规范化**：LLMRouterBench 的出现揭示了路由领域缺乏统一评测标准的深层问题，400K+ 样本的大规模基准将推动路由研究回归可信的实证对比，而非"各自为战"的小规模验证。
