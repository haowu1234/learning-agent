## 📄 **AgeMem：统一长短期记忆管理框架**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
AgeMem 将长期记忆（LTM）与短期记忆（STM）统一为 Agent 策略的一部分，通过工具化动作让 LLM 自主决定何时存储、检索、更新、摘要或丢弃信息。提出三阶段渐进强化学习策略与步级 GRPO 来解决记忆操作引发的稀疏非连续奖励问题。

🔧 **技术亮点**
- 记忆操作以**工具调用**形式暴露，LLM 自主控制记忆生命周期
- **三阶段渐进 RL**：逐步增加任务复杂度，从单步到多步记忆链
- **步级 GRPO**：针对记忆操作稀疏奖励的专项优化算法

📊 **实验结果**
在五个长视野基准任务（Long-Horizon Benchmarks）上，AgeMem 持续优于强记忆增强基线，在多个 LLM 骨干上均实现更高任务完成率、更高质量长期记忆和更高效的上下文利用。代码已开源：https://github.com/y1y5/AgeMem

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 长链推理中的记忆瓶颈，为需要跨会话、跨任务持久化信息的 Agent 提供端到端可训练的记忆基础设施。

## 📄 **面向高效 Agent：记忆、工具学习与规划综述**
（Toward Efficient Agents: Memory, Tool Learning, and Planning）

🔗 https://arxiv.org/abs/2601.14192

💡 **核心贡献**
系统梳理 LLM Agent 三大核心组件（记忆、工具学习、规划）的效率问题，引入"效率 Pareto 前沿"框架，从延迟、Token 消耗、步数等维度对效率进行双向度量（固定成本下比较效果 vs 固定效果下比较成本）。涵盖 200 余篇参考文献，是 2026 年 Agent 效率方向的全景综述。

🔧 **技术亮点**
- **上下文压缩管理**：通过摘要/筛选限定上下文窗口膨胀
- **工具调用最小化**：设计 RL 奖励以减少冗余工具调用次数
- **可控搜索机制**：在规划过程中引入受控搜索以提升 step 效率

📊 **实验结果**
综述性论文，整合了各组件效率评估协议与常用效率指标，为后续研究提供了统一基准框架参考。

🎯 **与 Agent/Routing 的关联**
规划 + 工具效率的综述直接服务于 Agent Routing 的设计决策，Pareto 框架可直接用于评估 Routing 策略的成本-效果权衡。

## 📄 **多 LLM 动态路由与级联推理综述**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首次系统分析跨多个独立训练 LLM 的路由与级联方法（区别于 MoE 内部路由），提出三维概念框架：**何时决策、使用何种信息、如何计算**，覆盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联等七大路由范式。

🔧 **技术亮点**
- **三维框架**：决策时机 × 输入信息 × 计算方式，统一描述所有路由系统
- **级联路由**：先用小模型，不确定时再 escalate 到大模型，实现成本递进控制
- **多范式融合**：揭示实际系统往往是多路由范式的组合而非单一策略

📊 **实验结果**
综述性研究，指出设计良好的路由系统可以超越单一最强模型的性能，同时大幅提升效率；但跨架构、跨模态的泛化仍是开放挑战。

🎯 **与 Agent/Routing 的关联**
核心 Routing 研究，直接对应本日报主题，为 LLM Routing 系统的设计提供了最全面的分类学参考。

## 📄 **Route-To-Reason：LLM 与推理策略的自适应联合路由**
（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）

🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
RTR（Route-To-Reason）提出将"选哪个模型"与"用哪种推理策略"联合优化，通过学习专家模型与推理策略的压缩表示，在推理时同时完成两者的自适应选择，解决 Test-Time Scaling 中的"过度思考"与计算爆炸问题。

🔧 **技术亮点**
- **联合路由**：模型选择 + 推理策略选择同步进行，非独立两步
- **压缩表示学习**：模型与策略均编码为低维向量，推理时快速匹配
- **即插即用**：支持任意黑盒/白盒模型，无需重新训练即可扩展新模型

📊 **实验结果**
在 7 个开源模型 × 4 种推理策略的组合实验中，RTR 在所有基线中实现最优准确率-效率权衡：**准确率高于最强单模型，Token 使用量减少超 60%**。

🎯 **与 Agent/Routing 的关联**
RTR 是目前最贴近"智能 Routing"核心问题的工作，联合推理策略路由的思路可直接迁移到 Agent 任务分发与规划策略选择场景。
