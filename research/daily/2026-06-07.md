📄 **[MLEvolve：面向机器学习算法自动发现的自进化 Agent 框架]**（MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery）
🔗 https://arxiv.org/abs/2606.06473
💡 **核心贡献**
- 提出 MLEvolve，一个基于 LLM 的多 Agent 自进化框架，专为端到端机器学习算法发现设计，解决了长任务中跨分支信息孤立、无记忆搜索和缺乏层次控制的问题。
- 引入「回顾性记忆（Retrospective Memory）」机制，将冷启动领域知识库与动态全局记忆结合，支持任务特定的经验检索与复用，并将策略规划与代码生成解耦以稳定长任务迭代。

🔧 **技术亮点**
- **Progressive MCGS（渐进式蒙特卡洛图搜索）**：在传统树搜索基础上扩展为图结构，通过引用边实现跨分支信息流，并以熵驱动的渐进调度从广泛探索逐步过渡到聚焦利用。
- **Retrospective Memory（回顾性记忆）**：冷启动知识库 + 动态全局记忆，支持跨任务的经验积累与精准检索，让 Agent 随时间演进。
- **自适应编码模式**：将战略规划与代码生成分离，配合多种编码模式以适应不同任务阶段，提升长视野任务的稳定性。

📊 **实验结果**
- 在 MLE-Bench 上（12 小时预算）实现 SOTA 的平均奖牌率和有效提交率，性能优于所有基线。
- 在数学算法优化任务上超越 AlphaEvolve 等专用算法发现方法，展现跨域泛化能力。

🎯 **与 Agent/Routing 的关联**：直接体现长视野 Multi-Agent 规划与记忆机制的核心设计——Progressive MCGS + Retrospective Memory 是 Agent 如何在复杂任务流中动态路由与累积经验的范本。

📄 **[以想象力思考：结合世界模拟器的主动视觉空间推理 Agent]**（Thinking with Imagination: Agentic Visual Spatial Reasoning with World Simulators）
🔗 https://arxiv.org/abs/2606.06476
💡 **核心贡献**
- 提出 Astra，一个主动空间推理 Agent 框架，让 VLM 在推理过程中通过与世界模拟器交互获取「想象中的视觉证据」，突破当前 VLM 仅依赖已观测图像的空间推理局限。
- 通过 RL 训练策略（Astra-VL）和一致性增强世界模拟器（Astra-WM）的协同，实现「在哪里、何时、如何想象」的可学习 tool-use 策略。

🔧 **技术亮点**
- **Astra-WM（世界模拟器）**：基于 Bagel 的新视角生成模型，加入视角一致性调优，保证跨视角的位姿与内容一致性。
- **两阶段 RL 课程**（world-simulator-in-the-loop）：第一阶段稳定 tool-use 探索，第二阶段训练 Agent 只在想象可改善直接作答时才调用模拟器——本质是一个 adaptive tool routing 策略。
- **动态 tool-use 决策**：模型学习「何时不用工具」，避免无效调用，与 LLM routing 中的按需模型选择逻辑高度同构。

📊 **实验结果**
- Astra-WM 将 Gemini-3-Flash 在 MMSI-Bench 上从 45.1 提升至 49.5（+4.4）。
- Astra-VL 将 Qwen3-VL 在 MMSI-Bench 上从 29.8 提升至 38.8（+9.0），在 MindCube 上从 36.8 提升至 42.7（+5.9）。

🎯 **与 Agent/Routing 的关联**：以 tool-use 为核心的 agentic 推理框架，Agent 需决策「是否调用世界模拟器」，本质是一个细粒度 tool routing / adaptive inference 问题，对 LLM routing 系统设计极具参考价值。

📄 **[无循环预训练循环网络：监督式记忆训练（SMT）]**（Pretraining Recurrent Networks without Recurrence）
🔗 https://arxiv.org/abs/2606.06479
💡 **核心贡献**
- 提出 Supervised Memory Training（SMT），一种无需 BPTT 的 RNN 训练方法，将 RNN 训练转化为对单步记忆状态转移 $(m_t, x_{t+1}) \to m_{t+1}$ 的监督学习，彻底解耦「记什么」与「怎么更新记忆」。
- 通过 Transformer 编码器在预测性状态目标上提取记忆标签，使 RNN 能够时间并行训练，且任意两个 token 间的梯度路径为 $O(1)$。

🔧 **技术亮点**
- **记忆标签提取**：用 Transformer 编码器学习「只保留预测未来所需的过去信息」，生成高质量记忆状态监督标签。
- **时间并行训练**：完全去除 RNN 展开，任意时间步间梯度路径长度 $O(1)$，解决梯度消失/爆炸问题。
- **长程依赖捕获**：SMT 使非线性 RNN 在语言建模和序列建模中超越 BPTT，同时享有 Transformer 并行训练效率。

📊 **实验结果**
- 在语言建模（LM）和像素序列建模任务上，SMT 预训练多种 RNN 架构均优于 BPTT 基线（具体数值见论文 Figure 系列）。

🎯 **与 Agent/Routing 的关联**：为 Agent 长期记忆模块提供了新的训练范式——SMT 框架可直接赋能需要跨多轮、长序列状态积累的 Agent 记忆系统，有助于解决 Long-horizon Agent 的记忆遗忘问题。

📄 **[Goedel-Architect：通过蓝图生成与精炼简化形式定理证明]**（Goedel-Architect: Streamlining Formal Theorem Proving with Blueprint Generation and Refinement）
🔗 https://arxiv.org/abs/2606.06468
💡 **核心贡献**
- 提出 Goedel-Architect，一个以「蓝图（Blueprint）」为核心的 Agentic 框架，将定理证明分解为依赖图（定义和引理的依赖关系图），并行关闭各引理节点，失败引理驱动全局蓝图的迭代精炼。
- 与传统递归引理分解方法不同，该框架通过全局蓝图维护依赖关系，避免在死胡同策略上无效循环。

🔧 **技术亮点**
- **Blueprint 依赖图**：以依赖图形式对整个证明进行结构化规划，工具驱动的 Lean 证明组件在依赖图中并行运行。
- **反馈驱动的全局精炼**：失败的引理节点不仅触发局部修复，还反馈到全局蓝图进行结构性重规划，是一种真正的 long-horizon planning with reflection。
- **开源骨干 + 极低成本**：使用 DeepSeek-V4-Flash (284B-A13B) 作为骨干，计算成本比同类开源方案低达 500x。

📊 **实验结果**
- MiniF2F-test：99.2% pass@1（有自然语言证明辅助时达 100%）。
- PutnamBench：88.8%（597/672），IMO 2025：4/6，Putnam 2025：11/12，USAMO 2026：3/6。
- 在开源流水线中创 SOTA，成本极低。

🎯 **与 Agent/Routing 的关联**：Goedel-Architect 的蓝图精炼机制是 Agent 规划（Planning with Reflection）的典型实现，其「失败驱动全局重规划」模式与 LLM routing 中的 fallback 策略高度对应，对复杂 Agent 任务分发架构有直接参考价值。

## 🧠 今日洞察

1. **长视野 Agent 的「记忆-规划」协同成为核心主题**：MLEvolve 的 Retrospective Memory 与 SMT 的监督式记忆训练，从系统架构和训练机制两个维度同时推进 Agent 的跨轮次信息保持能力，预示着「有状态 Agent」将成为下一阶段研究热点。

2. **Tool-use Routing 的精细化决策正在崛起**：Astra 框架中 Agent 需学习「何时调用工具、何时直接作答」，本质是一个轻量级 routing 决策器；这与 LLM routing 领域「按需选择模型/工具」的目标完全对齐，表明 routing 不只是模型选择，更是 tool-use 的全面延伸。

3. **Agentic 规划的可靠性依赖「失败驱动的全局精炼」**：Goedel-Architect 的实践表明，局部失败信号若能反馈到全局规划层（而非仅局部修复），可大幅提升复杂任务完成率；这对构建鲁棒的多步 Agent pipeline 具有重要启示。
