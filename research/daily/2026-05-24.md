## 📄 Paper 1

**📄 AgeMem：统一长短期记忆管理的 LLM Agent 框架**（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem，将长期记忆（LTM）与短期记忆（STM）的管理统一为 Agent 策略的一部分，通过工具化的记忆操作（存储、检索、更新、摘要、遗忘）实现端到端优化。为解决记忆操作引发的稀疏与不连续奖励问题，设计了三阶段渐进式强化学习策略和 step-wise GRPO。

🔧 **技术亮点**
- 将记忆操作（store/retrieve/update/summarize/discard）暴露为 tool-based actions，Agent 自主决策记忆行为
- 三阶段渐进式 RL 训练：从基础记忆操作 → 综合任务 → 多跳推理逐步提升
- Step-wise GRPO 专门应对记忆操作带来的奖励稀疏与非连续性挑战

📊 **实验结果**
在 5 个长时域 benchmark 上一致超越强记忆增强基线；提升了任务完成率、长期记忆质量与上下文效率。代码开源：https://github.com/y1y5/AgeMem

🎯 **与 Agent/Routing 的关联**
直接针对 Long-horizon Agent 的记忆管理瓶颈，为需要持久状态的 Agent 设计提供了强化学习可训练的内存架构。

## 📄 Paper 2

**📄 DeepWeb-Bench：深度研究 Agent 的跨源证据与长时推导基准**（DeepWeb-Bench: A Deep Research Benchmark Demanding Massive Cross-Source Evidence and Long-Horizon Derivation）
🔗 https://arxiv.org/abs/2605.21482

💡 **核心贡献**
提出 DeepWeb-Bench，一个比现有 benchmark 更难的深度研究 Agent 评测集，要求 Agent 在开放 Web 上大规模收集证据、跨源融合并进行多步长时推导。从 Retrieval、Derivation、Reasoning、Calibration 四个能力维度独立评分，附带四级溯源信息。

🔧 **技术亮点**
- 三重难度来源：大规模证据收集、跨源对账（reconciliation）、长时多步推导
- 四能力维度独立评测，支持精细化 failure 分析
- 每条参考答案附带四级来源可信度标注和跨源交叉检验记录

📊 **实验结果**
评测 9 个前沿模型，发现：① 检索不是瓶颈（只占 12–14% 错误），推导+校准错误超 70%；② 强/弱模型失败模式质性不同（强模型=推导不完整，弱模型=幻觉精度）；③ 模型间专业化明显，跨模型一致性 ρ=0.61，单题分歧高达 18.8pp。

🎯 **与 Agent/Routing 的关联**
为评估 Agent 在现实深度研究场景中的长时规划与记忆能力提供了新的高难度标准，也为 routing 中的"模型专业化"提供了直接实证支撑。

## 📄 Paper 3

**📄 Insights Generator：LLM Agent 的语料级执行轨迹系统诊断**（Insights Generator: Systematic Corpus-Level Trace Diagnostics for LLM Agents）
🔗 https://arxiv.org/abs/2605.21347

💡 **核心贡献**
提出 Insights Generator（IG），一个多 Agent 系统，通过在执行轨迹语料库上提出并验证假设，自动生成带证据的自然语言诊断报告，将 Agent 调试从人工抽样检查升级为系统性、大规模的行为模式识别。

🔧 **技术亮点**
- Scout-Investigator 双层架构：Scout 宽泛扫描异常，Investigator 深入验证因果假设
- 在轨迹语料库级别（而非单条）进行模式检测，覆盖生产规模的数万 token 轨迹
- 支持将 IG 报告直接反馈为 scaffold 改进，实现闭环自我优化

📊 **实验结果**
人类专家使用 IG 报告后，scaffold 性能比未修改基线提升 **30.4pp**；coding agent 基于 IG insights 持续稳定增益；领域专家评分中 IG 报告在深度和证据质量上领先竞品。

🎯 **与 Agent/Routing 的关联**
为 Agent 系统的可观测性与自动化优化提供了关键基础设施，同样适用于 routing 系统的行为分析和策略迭代。

## 📄 Paper 4

**📄 多 LLM 动态路由与级联综述：高效推理的系统分析**（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）
🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首篇系统梳理跨独立 LLM 的路由与级联方法的综述，区别于模型内部的 MoE 机制，覆盖 6 大路由范式并引入三维度概念框架（决策时机 × 使用信息 × 计算方式）。

🔧 **技术亮点**
- 六大范式分类：难度感知路由、人类偏好对齐、聚类路由、RL 路由、不确定性路由、级联
- 三维概念框架揭示实际系统是多范式组合（compositional），而非单一策略
- 指出多模态路由（multimodal routing）为重要前沿方向，现有机制难以泛化

📊 **实验结果**
（综述性工作，无单一实验）分析表明：设计良好的路由系统可超越最强单一模型，通过跨模型专业化杠杆实现性能与效率双赢。

🎯 **与 Agent/Routing 的关联**
本文直接定义了 LLM Routing 研究领域的边界与分类体系，是 routing 方向的必读综述。

## 🧠 今日洞察

**1. 记忆管理正走向端到端可训练。** AgeMem 将记忆操作纳入 RL 优化循环，标志着 Agent 记忆从"附加组件"升级为"可学习策略"——未来 Agent 将能自主演化自己的遗忘与记忆策略。

**3. LLM Routing 进入系统化阶段。** 从点方法到综述框架，routing 领域正从"技巧"走向"学科"——三维设计空间的提出预示着未来将出现统一的 routing 设计理论，而非零散的经验方法。
