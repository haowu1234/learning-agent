### 1. HRBench：混合推理 LLM 中思维模式切换策略的基准测试与理解
**HRBench: Benchmarking and Understanding Thinking-Mode Switch Strategies in Hybrid-Reasoning LLMs**

🔗 https://arxiv.org/abs/2605.28398  
📅 提交日期：2026-05-27（最新）

💡 **核心贡献**
提出 HRBench，一个统一评估框架，系统研究混合推理 LLM（如 Qwen3、Kimi）中 Thinking 模式开关切换策略，覆盖 prompt-based、外部路由、投机执行三大策略族与四种训练机制共 12 个评估配置。
对 6 个模型（从 Qwen3.5-2B 到 Kimi-K2.5-1.1T）和 5 个推理基准进行实验，发现不同策略在效率-效果权衡空间中占据不同区域，为自适应推理路由提供了可控的研究基础。

🔧 **技术亮点**
- **三策略族对比**：Prompt-based（token-accuracy 优）、外部路由（成本稳定降低）、投机执行（高 token 代价换取高精度）
- **12+ 方法复现**：在同一 pipeline 中重新实现主流方法，消除评估环境差异，使横向比较真正公平
- **训练机制影响差异化**：发现 SFT、在线/离线 RL 对不同策略的提升效果差异显著，且最优策略随模型规模和任务域变化

📊 **实验结果**
- 在数学、科学、代码 5 个 benchmark 上，Prompt-based 方法通常提供最佳 token-accuracy 权衡
- 路由方法在控制推理成本方面更稳定，适合生产部署
- 模型规模越大，策略偏好发生系统性偏移（小模型偏 prompt-based，大模型偏路由）

🎯 **与 Agent/Routing 的关联**
直接研究 LLM 推理路由的核心问题——"何时开启深度思考"——是 Routing 领域的基准性工作，对 Agent 系统的计算资源调度具有直接指导意义。

### 2. GraphPlanner：多智能体 LLM 中图记忆增强的智能路由
**GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs**

🔗 https://arxiv.org/abs/2604.23626  
📅 提交日期：2026-04-26 | 发表于：ICLR 2026

💡 **核心贡献**
提出 GraphPlanner，将 LLM 路由扩展到 Agentic 场景，通过异构图记忆网络（GARNet）捕捉 query-agent-response 间的历史交互，同时为每个查询生成 LLM 骨干选择 + Agent 角色分配（Planner/Executor/Summarizer）的完整路由工作流。
将工作流生成形式化为 MDP，使用强化学习联合优化任务性能与计算效率，支持归纳推理（unseen tasks）和转导推理（历史 memory 复用）。

🔧 **技术亮点**
- **异构图记忆 GARNet**：同时建模历史查询记忆与工作流记忆，状态表示更丰富，避免重复推理
- **MDP 形式化路由**：每步决策 = (LLM 选择, 角色选择)，RL 优化使路由具备端到端学习能力
- **归纳 + 转导双模式**：零样本泛化到未见任务，同时利用历史 memory 加速已见任务

📊 **实验结果**
- 在 14 个多样化 LLM 任务上，较强单轮和多轮路由 baseline 准确率提升最高 **+9.3%**
- GPU 显存占用从 **186.26 GiB → 1.04 GiB**（下降 99.4%），极大降低部署成本
- 在 unseen tasks 和 unseen LLMs 上保持强零样本泛化能力

🎯 **与 Agent/Routing 的关联**
将路由（Routing）与 Agent 协作、记忆管理深度融合，是目前最接近真实 Multi-Agent 系统路由需求的工作，ICLR 2026 录用验证了其技术价值。

### 3. Planner Matters！长程规划中高效非对称多智能体协作框架
**Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning**

🔗 https://arxiv.org/abs/2605.02168  
📅 提交日期：2026-05-04

💡 **核心贡献**
通过系统性算力分配分析，揭示在多智能体框架（Planner + Actor + Memory Manager）中，Planner 是影响任务成功的主导因素，Actor 和 Memory Manager 用更小的模型即可达到竞争性表现。
基于此洞察提出以 Planner 为中心的强化学习方法，仅优化 Planner（冻结其他组件），使用 VLM-as-judge 的轨迹级奖励，在多个 long-horizon benchmark 上实现高效提升。

🔧 **技术亮点**
- **"不对称"资源分配**：用大模型做 Planner，用小模型做 Actor/Memory，打破"所有组件同等重要"的传统假设
- **VLM-as-judge 轨迹奖励**：利用视觉语言模型对整条执行轨迹打分，监督信号更完整、更语义化
- **模块化冻结训练**：仅训练 Planner，大幅降低训练成本，同时保持其他组件稳定

📊 **实验结果**
- 在 web navigation、OS control、tool use 三类基准上均取得 robust 提升
- 相比全模型同等优化方案，compute-efficient 且效果更优

🎯 **与 Agent/Routing 的关联**
直接指导 Multi-Agent 系统的模型选型与路由策略——规划阶段应路由至高能力模型，执行阶段可路由至轻量模型，是 cost-aware routing 的实证基础。

### 4. MemFlow：面向小语言模型智能体的意图驱动记忆编排
**MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents**

🔗 https://arxiv.org/search/?searchtype=all&query=MemFlow+intent+memory+orchestration+small+language+model+agents  
📅 提交日期：2026-05-04

💡 **核心贡献**
针对小语言模型（SLM）在 Agent 场景下记忆管理能力不足的问题，提出 MemFlow——一个以用户意图为驱动的记忆编排框架，通过动态感知任务意图来决定何时检索、写入和遗忘记忆，使 SLM 具备类似大模型的长期上下文理解能力。
该工作探索了在资源受限环境下为 Agent 赋予高效记忆能力的路径，对边缘部署和低成本 Agent 应用具有重要意义。

🔧 **技术亮点**
- **意图感知记忆门控**：根据当前任务意图动态决定记忆操作类型（检索/写入/遗忘），避免无关记忆干扰
- **面向 SLM 优化**：设计轻量级记忆编排机制，与小模型推理能力相匹配，无需依赖大模型作为记忆控制器
- **现代 Agent 记忆挑战的直接回应**：解决 SLM 在多轮复杂任务中的上下文漂移和记忆溢出问题

🎯 **与 Agent/Routing 的关联**
为 Agent 记忆管理提供轻量化方案，与路由系统结合后可实现"按意图动态路由至记忆子系统"的智能 Agent 架构。

## 🧠 今日洞察

1. **推理路由走向系统化**：HRBench 的出现标志着 LLM 推理模式切换已从"拍脑袋调参"演进为可量化、可复现的研究领域，Routing 不再是工程 trick，而成为独立研究方向。

2. **Multi-Agent 中的"不对称原则"正在确立**：GraphPlanner 和 Planner Matters 均指向同一结论——Multi-Agent 系统中不同角色的计算需求差异巨大，统一分配资源是次优选择，智能路由应根据角色重要性做出异构决策。

3. **SLM + 智能记忆 = 低成本 Agent 新路径**：MemFlow 等工作表明，通过精巧的记忆编排，小模型也能胜任复杂 Agent 任务，这将推动 Agent 部署从云端向边缘迁移，并对路由系统提出新的成本-能力 trade-off 需求。
