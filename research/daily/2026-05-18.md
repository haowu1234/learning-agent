📄 **[规划器决定一切！面向长时程规划的高效非均衡多智能体协作框架]**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）
🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
将多智能体系统分解为"规划器—执行器—记忆管理器"三角色架构，并通过系统性算力分配分析揭示：规划器能力是长时程任务性能的主导因素，执行和记忆组件所需算力远低于规划组件。

🔧 **技术亮点**
- 三角色模块化解耦：Planner（高层决策）/ Actor（任务执行）/ Memory Manager（上下文推理），职责明确
- 规划器中心 RL 训练：仅对 Planner 使用轨迹级 VLM-as-Judge 奖励进行 RL 优化，其余组件冻结不更新
- 非均衡算力分配：揭示"重规划、轻执行"的最优资源配比原则，大幅降低整体推理成本

📊 **实验结果**
在 Web 导航、OS 控制、工具使用三类 Benchmark 上验证，专注规划能力的集中训练带来了鲁棒且高效的长时程 Agent 自动化提升（代码已开源）。

🎯 **与 Agent/Routing 的关联**
直接指导多 Agent 系统中算力路由策略——将高质量（大）模型集中于规划层，执行层可使用较小模型，是 LLM Routing 在 Agent 架构中的具体落地。

📄 **[FitText：通过拟态检索演化 Agent 工具生态]**
（FitText: Evolving Agent Tool Ecologies via Memetic Retrieval）
🔗 https://arxiv.org/abs/2605.02411

💡 **核心贡献**
提出 FitText，一个无需训练的动态工具检索框架，将工具检索嵌入 Agent 推理循环内，通过迭代精炼"伪工具描述"来持续弥合用户意图与 API 文档之间的语义鸿沟。

🔧 **技术亮点**
- 推理循环内动态检索：随 Agent 对任务理解的演进实时更新检索探针，而非依赖初始 Query 静态检索
- 拟态（Memetic）检索：引入进化选择压力，在候选描述上做跨代淘汰，同时维护工具记忆避免冗余搜索
- 随机多样化生成：通过随机采样生成多样候选描述，结合检索反馈迭代收敛

📊 **实验结果**
- ToolRet（43k 工具，4 领域）：平均检索排名从 8.81 → **2.78**
- StableToolBench（16,464 APIs）：平均通过率达 **0.73**，较静态检索绝对提升 **+24 个百分点**

🎯 **与 Agent/Routing 的关联**
本质是工具级 Routing——在超大规模 API 空间中动态选择最匹配的工具，与 LLM Routing 思路高度同构。

📄 **[MASPO：LLM 多智能体系统的联合提示优化]**（ICML 2026）
（MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems）
🔗 https://arxiv.org/abs/2605.06623

💡 **核心贡献**
提出 MASPO，首次在多 Agent 系统层面联合优化所有角色的 Prompt，通过联合评估机制将局部 Agent 目标与全局系统目标对齐，彻底摆脱对 Ground-Truth 标签的依赖。

🔧 **技术亮点**
- 联合评估机制：不仅评估当前 Agent Prompt 的本地有效性，还评估其对下游后继 Agent 成功率的影响
- 数据驱动进化 Beam Search：在高维 Prompt 空间中高效导航，避免梯度计算
- 无需标注数据：完全基于系统执行结果反馈，零 Ground-Truth 依赖

📊 **实验结果**
在 6 个多样化任务上，MASPO 持续优于当前 SOTA 提示优化方法，平均准确率提升 **+2.9 个百分点**（ICML 2026 录用）。

🎯 **与 Agent/Routing 的关联**
联合优化框架可自然扩展为动态 Routing 策略——根据任务类型自动为系统内各 Agent 分配最优 Prompt 路由配置。

📄 **[MEMAUDIT：有预算的长期 LLM 记忆写入精确包-Oracle 评估协议]**
（MEMAUDIT: An Exact Package-Oracle Evaluation Protocol for Budgeted Long-Term LLM Memory Writing）
🔗 https://arxiv.org/abs/2605.02199

💡 **核心贡献**
提出 MEMAUDIT，首个将长期记忆写入转化为可认证有限优化问题的评估协议，将记忆写入过程与检索/读取解耦，实现对"Agent 在固定存储预算下究竟保留了什么"的精确审计。

🔧 **技术亮点**
- Package-Oracle 形式化：将经验流、候选记忆表示、存储成本、语义证据单元、未来查询需求、预算共同打包为可审计优化问题
- MILP 认证精确求解：基于分支定界 + MILP 认证计算精确最优包，彻底排除 QA 端到端评估的混淆变量
- 多系统兼容导出：支持对 Mem0、A-Mem、Letta 等主流记忆框架的外部评分，输出可复现性元数据

📊 **实验结果**
在受控精确包、有效性压力测试、人工审计自然切片及主流记忆系统导出上全面验证，成功分离表示质量、有效性状态保存、预算感知选择三类效应。

🎯 **与 Agent/Routing 的关联**
为 Agent 记忆系统的预算感知选择提供标准化评测基准，与"在有限上下文窗口内如何 Route 历史信息"的核心问题直接对应。

## 🧠 今日洞察

1. **"重规划、轻执行"成为 Agent 架构的核心设计原则**：Planner Matters! 的系统性算力实验给出了明确的工程指导——规划层应获得最多算力与最强模型，这与 LLM Routing 中"难题路由大模型"的思路高度一致，Agent 架构与 Routing 策略正在深度融合。

2. **工具选择正在向动态进化检索演进**：FitText 的 Memetic Retrieval 将"工具 Routing"从静态 Top-K 检索推向推理循环内的迭代进化，在 4 万+ API 规模下仍保持精准，预示着未来超大规模工具生态的标准范式。

3. **记忆与评估的形式化正在补全 Agent 可信度的最后一块拼图**：MEMAUDIT 和 MASPO 同时指向一个趋势——研究者不再满足于端到端 QA 准确率，而是追求可审计、可认证的系统行为，Agent 工程正从"能用"迈向"可信"。
