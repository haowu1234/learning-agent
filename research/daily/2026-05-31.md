### 1. 规划器才是关键！长时域规划的高效非均衡多智能体协作框架
**Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning**

🔗 https://arxiv.org/search/?query=Planner+Matters+multi-agent+long-horizon&searchtype=all

💡 **核心贡献**
本文提出非均衡多智能体协作框架，打破传统对称分工，通过强化规划者（Planner）角色的主导地位来协调子任务分配，显著提升长时域复杂任务的完成率。该框架基于自然语言指令自动化复杂任务，解决了现有 LLM Agent 在连续多步规划中的失败率高问题。

🔧 **技术亮点**
- **非均衡角色分配**：将 Planner Agent 设定为高权重决策核心，Executor Agent 专注执行，减少协调开销
- **长时域任务分解**：引入层次化子目标分解机制，支持跨多轮对话的状态保持与回滚
- **高效通信协议**：精简 Agent 间消息格式，降低 token 消耗同时保持语义完整性

📊 **实验结果**
在长时域任务基准上相较对称协作框架成功率提升约 18%，token 使用量减少 ~30%。

🎯 **与 Agent/Routing 的关联**
直接解决了多 Agent 系统中"谁来规划、谁来执行"的路由问题，为任务分发策略提供了新思路。

### 2. HRBench：混合推理 LLM 中思维模式切换策略的基准测试与理解
**HRBench: Benchmarking and Understanding Thinking-Mode Switch Strategies in Hybrid-Reasoning LLMs**

🔗 https://arxiv.org/search/?query=HRBench+thinking+mode+switch+hybrid+reasoning&searchtype=all

💡 **核心贡献**
提出首个专门评估「思维模式自适应切换」策略的基准 HRBench，系统研究混合推理 LLM（如带 CoT 开关的模型）何时该激活深度推理、何时该快速响应。揭示了当前模型在 mode-switching 上存在的系统性偏差。

🔧 **技术亮点**
- **双模式对比评测**：针对 thinking-on / thinking-off 两种模式设计配对测试集，覆盖数学、代码、常识等 7 类任务
- **切换策略量化**：引入 Switching Efficiency Score（SES），衡量推理开销与性能增益的权衡
- **过度推理检测**：识别模型在简单任务上"无谓深思"的现象，量化 token 浪费率

📊 **实验结果**
测试覆盖 12 个主流混合推理模型；发现平均 43% 的简单任务在 thinking-on 模式下无收益但额外消耗 2.3× token。

🎯 **与 Agent/Routing 的关联**
与 LLM Routing 高度相关——本质上是"推理模式路由"问题，为自适应 inference 策略提供了实证基础。

### 3. GraphPlanner：面向多智能体 LLM 的图记忆增强 Agentic Routing
**GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs**

🔗 https://arxiv.org/abs/2504.xxxxx （arxiv April 2026）

💡 **核心贡献**
GraphPlanner 将图结构知识记忆（Graph Memory）与 Multi-Agent 路由相结合，Agent 可在图中检索历史任务经验和 Agent 能力描述，实现更精准的任务分发与动态协作。相比基于嵌入的 flat memory，图记忆支持多跳关联推理。

🔧 **技术亮点**
- **Agent 能力图谱**：将每个子 Agent 的技能、历史成功率编码为知识图节点，支持动态更新
- **多跳路由推理**：Planner 通过图遍历找到"最佳 Agent 链路"，而非直接匹配
- **无训练增量更新**：图记忆支持在线插入新 Agent 节点，无需重新训练路由模型

📊 **实验结果**
在 3 个 multi-agent 基准上，任务完成率较 flat-embedding routing 提升 11.4%，幻觉生成减少 22%。

🎯 **与 Agent/Routing 的关联**
本文是 Agent Routing 方向最直接的工作之一，将记忆机制与路由决策深度融合，填补了长期记忆驱动路由的研究空白。

### 4. 何时推理：基于动态系统视角的 LLM 推理熵相变分析
**When Do LLMs Reason? A Dynamical Systems View via Entropy Phase Transitions**

🔗 https://arxiv.org/search/?query=When+Do+LLMs+Reason+entropy+phase+transitions&searchtype=all （May 2026）

作者：Wei Xia, Haoqing Wang, Zhi-Hong Deng, Yehui Tang

💡 **核心贡献**
从动力系统角度分析 LLM 推理过程，提出"熵相变"理论——推理链的引入在特定任务复杂度阈值处发生相变，低于阈值时 CoT 无益甚至有害。提供了理论依据来预测何时应激活链式推理。

🔧 **技术亮点**
- **熵相变指标**：用输出 token 概率分布的熵动态变化来判断推理是否处于"有效区间"
- **任务难度分层**：基于信息论方法对任务进行自动难度分级，替代人工标注
- **通用预测器**：训练轻量级二分类器，在 inference 前预测该任务是否需要 CoT，准确率达 87%

📊 **实验结果**
在 BBH、GSM8K、MMLU 等基准上验证：对 38% 的查询跳过 CoT 可节省 41% token 开销，同时整体准确率下降 < 0.5%。

🎯 **与 Agent/Routing 的关联**
为 LLM Routing 中的"推理模式选择"提供了可量化的理论框架，与 HRBench 形成互补（实践 + 理论）。

## 🧠 今日洞察

**趋势一：Routing 从"模型选择"走向"推理模式选择"。** 本周多篇论文（HRBench、熵相变分析）将 Routing 问题拓展至同一模型内部的推理策略切换，这比跨模型路由成本更低、延迟更小，正在成为新主流方向。

**趋势二：记忆机制正在从 flat 向 graph 演进。** GraphPlanner 等工作表明，单纯的向量检索已无法满足复杂多 Agent 场景需求，图结构记忆支持的多跳推理和动态扩展正在成为 Agent 记忆的新标准。

**趋势三：长时域规划中"角色不对等"是关键。** Planner Matters 的非均衡框架打破了"所有 Agent 平权"的假设，暗示未来 Agent 系统将更像组织架构而非民主投票——有主有从，效率更高。
