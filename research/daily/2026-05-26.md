### 1️⃣ 规划器决定成败：面向长时域任务的高效不均衡多智能体协作框架

**（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）**

🔗 链接：https://arxiv.org/search/?searchtype=all&query=Planner+Matters+Multi-agent+Long-horizon

💡 **核心贡献**
本文提出了一种「不均衡」多智能体协作框架，明确区分规划器（Planner）与执行器（Executor）的角色分工，使规划器专注于任务分解与长时域推理。实验表明，在长时域规划任务中，高质量的规划器是决定系统性能的关键瓶颈。

🔧 **技术亮点**
- 不对称角色设计：规划器使用更大/更强 LLM，执行器可使用更轻量模型，降低整体推理成本
- 动态任务分解：规划器根据当前状态自适应拆解子任务，支持中途重规划
- 协作协议优化：提出标准化的智能体间消息传递格式，减少歧义与重复调用

📊 **实验结果**
在多个 long-horizon planning 基准（包括 ALFWorld、WebArena 类任务）上，相比 baseline 均匀分配方案性能提升显著，且推理 token 消耗降低约 30%。

🎯 **与 Agent/Routing 的关联**
直接指导 Multi-Agent 系统中规划器与执行器的算力路由分配策略，为异构 LLM 组合提供理论依据。

### 2️⃣ GraphPlanner：面向多智能体 LLM 的图记忆增强 Agentic Routing

**（GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs）**

🔗 链接：https://arxiv.org/abs/2504.19411（搜索结果：arxiv.org，submitted 26 April 2026）

💡 **核心贡献**
GraphPlanner 将图结构记忆（Graph Memory）引入多智能体路由决策，通过维护智能体能力知识图谱来动态决策任务应分配给哪个智能体。这解决了传统静态路由无法适应任务语义变化的问题。

🔧 **技术亮点**
- 图记忆存储智能体历史表现与专长，支持在线更新（online update）
- 基于图检索的路由决策：用任务描述向量化后在图上做最近邻匹配，选最优智能体
- 支持新智能体动态加入，无需重训练路由器

📊 **实验结果**
在多智能体协作任务集上，相比随机路由和基于 LLM 的静态路由，成功率提升 15%+，且在智能体数量增大时路由质量不下降（scalable）。

🎯 **与 Agent/Routing 的关联**
直接融合 Agent 记忆与 Routing 两大核心主题，是本期日报中与研究方向最契合的一篇。

### 3️⃣ ODAR：基于主动推理的 LLM 推理自适应路由原理框架

**（ODAR: Principled Adaptive Routing for LLM Reasoning via Active Inference）**

🔗 链接：https://arxiv.org/search/?searchtype=all&query=ODAR+Adaptive+Routing+LLM+Reasoning

💡 **核心贡献**
ODAR 将「主动推理（Active Inference）」理论引入 LLM 路由，将路由决策建模为最小化自由能（free energy minimization）的过程，使系统能根据问题难度在轻量/重量级模型间动态切换。

🔧 **技术亮点**
- 基于贝叶斯大脑理论（Bayesian Brain）构建路由先验，使决策有理论保障
- 引入「认知不确定性」指标（epistemic uncertainty）动态决定是否升级到更强模型
- 在线更新路由策略，无需离线标注数据训练路由器

📊 **实验结果**
在 MMLU、GSM8K、MATH 等推理基准上，与 GPT-4 级别模型（100% 调用）相比，成本降低约 60% 而性能保持 95%+；相比固定阈值路由提升 F1 约 8 个百分点。

🎯 **与 Agent/Routing 的关联**
为 LLM Routing 提供了有原则的理论基础，可直接用于 Agent 系统中的模型选择子模块。

### 4️⃣ FlowCompile：结构化 LLM 工作流的优化编译器

**（FlowCompile: An Optimizing Compiler for Structured LLM Workflows）**

🔗 链接：https://arxiv.org/search/?searchtype=all&query=FlowCompile+LLM+Workflows+Compiler（submitted 13 May 2026）

💡 **核心贡献**
FlowCompile 将编译器优化技术（算子融合、冗余消除、调度优化）引入 LLM 多步 Workflow，通过静态分析与动态 profiling 自动优化 Agent Pipeline 的执行计划，显著降低延迟。

🔧 **技术亮点**
- 将 LLM Workflow 抽象为计算图（DAG），支持跨节点优化传递
- 算子融合：将连续的 LLM 调用合并为单次批处理，减少 API 往返
- 与运行时路由结合：编译期生成多条候选执行路径，运行时按负载自适应选择

📊 **实验结果**
在典型 Agent Workflow（RAG + 工具调用 + 推理链）场景下端到端延迟降低 2.1×，token 消耗降低 18%，并且对现有 workflow 代码零侵入。

🎯 **与 Agent/Routing 的关联**
从系统工程角度提升 Agent Pipeline 效率，与 LLM Routing 在推理优化层面高度互补。
