### 1️⃣

📄 **[AgeMem：统一长短期记忆管理的 LLM Agent 框架]**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem 统一框架，将长期记忆（LTM）与短期记忆（STM）管理直接内嵌到 Agent 策略中，以工具调用形式让 LLM 自主决策信息的存取与更新。采用三阶段渐进式强化学习训练，并引入逐步 GRPO 解决记忆操作引起的稀疏奖励问题。

🔧 **技术亮点**
- 将 store/retrieve/update/summarize/discard 全部暴露为工具动作，Agent 端到端自主管理记忆
- 三阶段渐进 RL + 步骤级 GRPO，解决记忆操作稀疏不连续奖励
- 统一 LTM/STM 架构，消除独立启发式控制器，支持完整端到端优化

📊 **实验结果**
在 5 个长时程 Benchmark 上，AgeMem 全面超越强记忆增强基线，在多个 LLM 骨干上均取得更高任务完成率、更优质的长期记忆和更高效的上下文利用。代码开源：https://github.com/y1y5/AgeMem

🎯 **与 Agent/Routing 的关联**
直接针对 Long-horizon Agent 的核心瓶颈——记忆管理，是构建能处理超长任务 Agent 的关键基础设施。

### 2️⃣

📄 **[LACUNA：以递归程序孔实现安全 Agent]**（LACUNA: Safe Agents as Recursive Program Holes）
🔗 https://arxiv.org/abs/2605.28617

💡 **核心贡献**
LACUNA 提出全新 Agent 编程模型：每个 Agent 动作是带类型的 `agent[T](task)` 调用，LLM 在执行时填充代码，并在运行前进行类型检查。被拒绝的动作对环境零影响，编译器诊断驱动自动重试，从而在让 Agent 代码可塑造运行时的同时保证安全边界。

🔧 **技术亮点**
- 类型系统约束工具与数据访问范围，防止提示注入与错误工具调用
- 整体接受/拒绝机制（all-or-nothing），失败不留不一致状态
- 统一原语表达 ReAct 循环、子 Agent、技能、并行分解及多模型规划

📊 **实验结果**
BrowseComp-Plus 上 8.6% 生成在执行前被拒绝（0.7 次重试/查询），达到 27.1% 精度；τ²-bench 上解决 392 任务中的 76.0%（跨 4 个领域），与基准 Agent 持平。

🎯 **与 Agent/Routing 的关联**
通过类型安全的代码生成解决多工具 Agent 中的安全与控制流问题，是 Multi-Agent 编排框架的重要安全机制探索。

### 3️⃣

📄 **[AgentHijack：计算机使用 Agent 鲁棒性基准测试]**（AgentHijack: Benchmarking Computer Use Agent Robustness to Common Environment Corruptions）
🔗 https://arxiv.org/abs/2605.25707

💡 **核心贡献**
引入 AgentHijack 基准，系统评估 MLLM 驱动的计算机使用 Agent 在真实环境扰动（弹窗、分辨率变化、竞争应用）下的鲁棒性；提出 AgentHijack-Agent 框架，集成增强感知的动作生成器与环境监控旁观者。（ICML 2026 录用）

🔧 **技术亮点**
- 9 类可配置常见扰动，复现真实执行环境的不完美场景
- AgentHijack-Agent：动作生成器（增强 grounding 能力）+ Onlooker（行为摘要+环境检查）双模块协同
- 发现即使轻微扰动也会导致 Agent 性能显著下降，量化了当前 Agent 的脆弱性

📊 **实验结果**
大量桌面任务实验验证：现有 MLLM Agent 对环境扰动高度敏感；AgentHijack-Agent 显著提升鲁棒性。代码开源：https://AgentHijack.github.io

🎯 **与 Agent/Routing 的关联**
直接评估真实世界 Computer-Use Agent 可靠性，为 Agent 系统的鲁棒路由与失败恢复策略提供基准参考。

### 4️⃣

📄 **[LLM 动态路由与级联推理综述]**（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）
🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
系统梳理多 LLM 动态路由与级联推理的最新方法，涵盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态路由等多种范式；提出三维概念框架（决策时机、所用信息、计算方式）统一理解路由系统。

🔧 **技术亮点**
- 区分 MoE 内部路由 vs. 多独立 LLM 跨模型路由，聚焦后者
- 三维分析框架：When（决策时机）/ What（信息来源）/ How（计算方式）
- 指出实际部署系统往往是多范式组合，在运营约束下集成多种策略

📊 **实验结果**
分析表明：设计良好的路由系统可通过策略性利用各模型专长超越单一最强模型，在性能和效率上取得双赢；但跨架构/跨模态的泛化路由机制仍是开放挑战。

🎯 **与 Agent/Routing 的关联**
是 LLM Routing 领域 2026 最全面的综述，直接涵盖 Routing 核心议题，为 Agent 系统中模型选择与推理优化提供全景视图。

## 🧠 今日洞察

1. **Agent 记忆管理正在从「附加组件」走向「策略核心」**：AgeMem 将 LTM/STM 管理内嵌入 Agent 策略本身，通过强化学习端到端优化，标志着记忆不再是外挂模块，而是 Agent 能力的内生组成部分。

2. **Agent 安全与可控性是 2026 年的焦点**：LACUNA 用类型系统约束 Agent 代码执行，AgentHijack 则量化了环境扰动对 Agent 的破坏——两项工作从不同角度（主动防护 vs. 基准评估）共同推动 Agent 可靠性研究走向系统化。

3. **LLM Routing 进入综合框架阶段**：路由研究已从单一策略走向多范式组合，三维分析框架的提出意味着该领域正在走向成熟，工程落地与理论泛化将成为下一阶段核心挑战。
