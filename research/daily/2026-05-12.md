### 1️⃣ **AgeMem：统一长短期记忆管理的智能体框架**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
将长期记忆（LTM）与短期记忆（STM）统一集成到 Agent 策略中，以工具调用形式暴露记忆操作，使 LLM Agent 能自主决定何时存储、检索、更新、汇总或丢弃信息；提出三阶段渐进式强化学习训练策略与步级 GRPO，解决记忆操作稀疏奖励问题。

🔧 **技术亮点**
- 记忆操作作为"工具动作"暴露给 Agent，实现端到端优化
- 三阶段渐进式 RL + step-wise GRPO，应对记忆操作引发的稀疏/不连续奖励
- 支持多 LLM backbone，框架具有良好的可迁移性

📊 **实验结果**
在五个长视野基准测试上，AgeMem 一致超越强记忆增强基线，实现更高任务性能、更优质的长期记忆内容与更高效的上下文利用。

🎯 **与 Agent/Routing 的关联**
直接解决 Long-horizon Agent 的记忆管理瓶颈，是构建持久化、自主规划 Agent 的核心基础组件。

### 2️⃣ **Planner Matters！高效非均衡多智能体长视野规划框架**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
提出以"规划者为中心"的多智能体框架，将任务分解为 Planner（高层决策）、Actor（执行）、Memory Manager（上下文推理）三个角色；通过系统性计算资源分析证明 Planning 是影响任务表现的主导因素，并仅对 Planner 进行 RL 优化。

🔧 **技术亮点**
- Planner-centric RL：仅优化规划者，Actor 和 Memory Manager 冻结，大幅降低训练成本
- 使用 VLM-as-judge 提供轨迹级奖励信号
- 实验覆盖 Web 导航、OS 控制、工具使用三大类长视野任务

📊 **实验结果**
在 Web 导航、OS Control、Tool Use 多个基准上，专注于规划器的算力分配策略带来鲁棒且计算高效的性能提升。

🎯 **与 Agent/Routing 的关联**
揭示了 Agent 资源分配的关键不对称性：将计算预算集中在规划阶段，为 Multi-Agent 系统中的模型路由策略提供了重要启示。

### 3️⃣ **ODAR：基于主动推断的原则性 LLM 推理自适应路由**
（ODAR: Principled Adaptive Routing for LLM Reasoning via Active Inference）

🔗 https://arxiv.org/abs/2602.23681

💡 **核心贡献**
提出 ODAR-Expert 自适应路由框架，通过摊销主动推断（amortized active inference）的难度估计器，动态将查询路由到启发式 Fast Agent 或深思熟虑的 Slow Agent；引入自由能原则的风险敏感融合机制，以变分自由能目标平衡对数似然与认知不确定性（varentropy）。

🔧 **技术亮点**
- 基于贝叶斯主动推断框架的查询难度估计，理论基础扎实
- Fast/Slow Agent 二元路由 + 自由能融合决策，避免暴力采样的过度思考问题
- 完全开源栈验证（Llama 4 + DeepSeek）

📊 **实验结果**
在 23 个基准测试中取得显著提升：MATH 准确率 98.2%，Humanity's Last Exam (HLE) 54.8%；计算匹配设置下改善 compute-accuracy frontier，与同质采样策略相比计算成本降低 **82%**。

🎯 **与 Agent/Routing 的关联**
直接针对 LLM Routing/Model Selection 问题，用原则性理论框架替代 ad hoc 投票策略，为 Routing 系统设计提供新范式。

### 4️⃣ **PrefixGuard：从 LLM-Agent 执行轨迹到在线故障预警监控**
（PrefixGuard: From LLM-Agent Traces to Online Failure-Warning Monitors）

🔗 https://arxiv.org/abs/2605.06455

💡 **核心贡献**
针对长任务 Agent 运行时"最终结果检查来得太晚"的问题，提出 PrefixGuard 框架：离线 StepView 归纳阶段将异构 trace 转换为确定性类型化步骤适配器，再训练轻量级前缀风险评分监控器，实现在线早期故障预警。

🔧 **技术亮点**
- StepView 离线阶段自动归纳 trace 的事件模式，无需手动定义 schema
- 前缀风险评分监控器：从终态结果学习事件抽象，轻量高效
- 后验 DFA（确定性有限自动机）提取支持有限状态审计（WebArena 仅 29 状态）

📊 **实验结果**
在 WebArena、τ²-Bench、SkillsBench、TerminalBench 上，最强 PrefixGuard 监控器 AUPRC 分别达 0.900 / 0.710 / 0.533 / 0.557，相比原始文本对照平均提升 **+0.137 AUPRC**；LLM-judge 在相同前缀预警协议下显著弱于 PrefixGuard。

🎯 **与 Agent/Routing 的关联**
为 Agent 系统提供运行时可观测性与早期干预能力，是 Agentic Pipeline 中 Routing/监控层不可或缺的安全防护组件。

## 🧠 今日洞察

1. **Memory × Planning 双轮驱动**：AgeMem 与 Planner Matters 从互补角度攻克 Long-horizon Agent 的两大核心瓶颈——记忆持久化与规划主导地位，共同指向"以规划为核心、记忆为基础"的 Agent 架构范式正在成型。

2. **Routing 进入原则性阶段**：ODAR 以贝叶斯主动推断为理论基底，将 LLM Routing 从启发式规则推向可解释、可优化的决策框架；82% 的计算节省证明自适应路由在实际部署中具备强大的经济价值。

3. **Agent 可靠性正在成为独立研究方向**：PrefixGuard 的出现标志着学界开始系统性解决 Agentic System 的可观测性与故障早期预警问题，这预示着"Agent 监控基础设施"将成为 2026 年下半年的重要研究热点。
