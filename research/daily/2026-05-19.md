### 1️⃣

📄 **[AgeMem：统一长短期记忆管理的自主 Agent 框架]**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem 框架，将长期记忆（LTM）和短期记忆（STM）的管理统一纳入 Agent 策略本身，让 LLM 自主决定何时存储、检索、更新、摘要或丢弃信息。通过三阶段渐进式强化学习（含 step-wise GRPO）解决记忆操作带来的稀疏奖励问题。

🔧 **技术亮点**
- 记忆操作作为"工具调用"暴露给 LLM，实现端到端可训练的记忆自主管理
- 三阶段渐进式 RL 训练策略，专门应对记忆操作奖励稀疏与不连续性
- Step-wise GRPO 优化算法，细粒度对齐记忆操作步骤与任务成果

📊 **实验结果**
在 5 个长时程基准任务上，AgeMem 持续优于多个强记忆增强基线，在多种 LLM 骨干上均表现稳定，同时提升任务成功率、长期记忆质量和上下文利用效率。

🎯 **与 Agent/Routing 的关联**
直接解决长时程 Agent 的核心瓶颈——上下文窗口有限下的记忆管理，是构建可持续运行 Agent 的基础能力。

### 2️⃣

📄 **[FitText：通过模因检索进化 Agent 工具生态]**
（FitText: Evolving Agent Tool Ecologies via Memetic Retrieval）

🔗 https://arxiv.org/abs/2605.02411

💡 **核心贡献**
提出 FitText 免训练框架，将工具检索嵌入 Agent 推理循环内部，让 Agent 在执行过程中动态生成和精化检索探针（伪工具描述），并通过模因算法对候选描述施加进化选择压力，避免冗余搜索。核心洞见：用户任务描述与 API 文档之间存在语义鸿沟，静态检索无法随执行过程演化。

🔧 **技术亮点**
- 推理循环内嵌入式动态工具检索，检索探针随执行状态实时更新
- Memetic Retrieval：用进化选择机制在候选描述上施压，工具记忆避免重复搜索
- 随机化多样探针生成 + 迭代检索反馈精化，兼顾精准与多样

📊 **实验结果**
在 ToolRet（43k 工具，4 领域）上平均检索排名从 8.81 → 2.78；在 StableToolBench（16,464 APIs）上平均通过率 0.73，比静态查询检索提升 **+24 个百分点**。

🎯 **与 Agent/Routing 的关联**
工具路由的动态化版本——不是选择哪个模型，而是选择哪个工具，且选择标准随 Agent 执行状态演化，与 LLM Routing 形成方法论呼应。

### 3️⃣

📄 **[MEMAUDIT：LLM 长期记忆写入的精确可审计评估协议]**
（MEMAUDIT: An Exact Package-Oracle Evaluation Protocol for Budgeted Long-Term LLM Memory Writing）

🔗 https://arxiv.org/abs/2605.02199

💡 **核心贡献**
设计 MEMAUDIT，首个将长期记忆写入问题形式化为可审计有限优化问题的评估协议。通过固定经验流、候选记忆表示、存储预算、语义证据单元和未来查询需求，将记忆选择与检索、提示、读取器推理完全解耦，实现精确可认证的记忆质量评估。

🔧 **技术亮点**
- Package-Oracle 范式：将记忆写入从端到端 QA 指标中分离，形成独立可验证的优化问题
- 采用分支定界 + MILP 认证计算精确最优解，评估结果可信
- 兼容 Mem0、A-Mem、Letta 等主流 Agent 记忆存储系统的外部评分接口

📊 **实验结果**
在受控精确包、有效性压力测试、人工审计自然支持切片以及主流记忆系统导出数据上均验证有效，清晰分离了表示质量、有效性保持和预算感知选择效应——这些在端到端 QA 中无法区分。

🎯 **与 Agent/Routing 的关联**
为 Agent 记忆系统提供标准化的质量基准，直接支撑记忆感知的 Agent 路由决策（选择记忆容量最优的方案）。

### 4️⃣

📄 **[MASPO：LLM 多智能体系统的联合提示优化框架]**
（MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems）

🔗 https://arxiv.org/abs/2605.06623

💡 **核心贡献**
提出 MASPO，针对多智能体系统（MAS）中各 Agent 角色提示的联合优化问题——核心难点在于局部 Agent 目标与整体系统目标不对齐。MASPO 的联合评估机制不仅评估局部提示有效性，还评估其对下游 Agent 成功的促进能力，无需依赖 ground-truth 标签。

🔧 **技术亮点**
- 联合评估机制：将 Agent 间协作效果纳入提示评分，打破局部最优陷阱
- 数据驱动进化 Beam Search，高效导航高维提示空间
- 完全自动化、迭代式精化，适配任意 LLM 多智能体架构

📊 **实验结果**
在 6 个多样化任务上持续优于 SOTA 提示优化方法，平均准确率提升 **+2.9 个百分点**。已被 **ICML 2026** 接收。

🎯 **与 Agent/Routing 的关联**
MASPO 的联合评估思路与 LLM Routing 高度互补——可将其扩展为：为不同复杂度子任务自动路由到最合适的 Agent 角色配置。

## 🧠 今日洞察

1. **记忆是 Agent 的第一性问题。** 本周多篇高质量论文聚焦记忆管理——从统一 LTM/STM 的端到端训练（AgeMem），到精确可审计的记忆写入评估（MEMAUDIT），研究共识正在形成：记忆质量直接决定长时程 Agent 的上限，不可再用 QA 准确率一刀切衡量。

2. **工具检索正在动态化。** FitText 的核心洞察代表一个趋势：Agent 执行过程中的工具需求是动态演化的，静态 RAG 式检索无法满足。将检索嵌入推理循环、用执行反馈驱动探针进化，是 Agent 工具能力扩展的关键方向。

3. **多 Agent 系统优化从单点走向联合。** MASPO 被 ICML 2026 接收，标志着 MAS 研究重心从"设计单个 Agent"转向"优化 Agent 间协调机制"——局部目标与全局目标的对齐问题，将成为多 Agent Routing 与编排的核心挑战。
