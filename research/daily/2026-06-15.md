### 1️⃣ **AgeMem：统一长短期记忆管理让 Agent 自主学习记忆策略**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
AgeMem 提出将长期记忆（LTM）与短期记忆（STM）统一为 Agent 策略的一部分，通过工具调用暴露记忆操作（存储/检索/更新/摘要/丢弃），让 LLM 自主决策何时、存什么。利用三阶段递进强化学习 + 逐步 GRPO 解决记忆操作引发的稀疏奖励问题。

🔧 **技术亮点**
- 把记忆操作设计为 tool action，实现端到端联合优化，不依赖辅助控制器或启发式规则
- 三阶段递进 RL 训练策略：先单一操作、再组合、最后全任务，逐步解锁复杂记忆行为
- Step-wise GRPO 专门应对记忆操作导致的奖励稀疏与不连续问题

📊 **实验结果**
在 5 个长视野基准（long-horizon benchmarks）上，AgeMem 持续超越强记忆增强基线，跨多个 LLM backbone 验证，同时提升任务成功率、记忆质量与上下文利用效率。

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 在长视野任务中的核心瓶颈——记忆管理，为 Memory 层提供可训练、可优化的统一框架。

### 2️⃣ **AgentSpawn：动态生成子 Agent 解决长视野代码生成的上下文失控问题**
（Adaptive Multi-Agent Collaboration Through Dynamic Spawning for Long-Horizon Code Generation）

🔗 https://arxiv.org/abs/2602.07072

💡 **核心贡献**
AgentSpawn 提出运行时动态生成 Agent 的协作架构，解决静态多 Agent 工作流在面对复杂度超预期任务时无法自适应的根本缺陷，核心机制包括自动记忆迁移、运行时复杂度触发的生成策略与并发一致性协议。

🔧 **技术亮点**
- **动态 Spawn 策略**：运行时复杂度指标触发新 Agent 生成，而非预设固定 Agent 数量
- **记忆自动传承**：父 Agent 向子 Agent 自动迁移上下文切片（Selective Memory Slicing），避免冗余传输
- **并发一致性协议**：多 Agent 同时修改代码时的冲突检测与合并机制

📊 **实验结果**
SWE-bench 等基准上，相比静态 baseline 完成率提升 **34%**，同时通过选择性切片将内存开销降低 **42%**。

🎯 **与 Agent/Routing 的关联**
动态 Spawn 策略本质是 Agent 粒度的路由决策——将任务路由到最合适的专家子 Agent，与 LLM Routing 理念高度互补。

### 3️⃣ **多轮评估揭示 Deep Research Agent 的"改写退化"困境**
（Multi-Turn Evaluation of Deep Research Agents Under Process-Level Feedback）

🔗 https://arxiv.org/abs/2606.09748

💡 **核心贡献**
首个针对 Deep Research Agent（DRA）多轮评估框架，区分"自我反思"与"过程级反馈"两种改进模式，并设计 RGI（Research Gap Inference）方法从 Rubric 满足模式中推断研究流程缺口，揭示当前 DRA 在多轮改写中的系统性退化问题。

🔧 **技术亮点**
- **RGI 方法**：分析已满足/未满足 Rubric 标准的模式，反向推断 Agent 研究策略的盲点
- **两种反馈模式对比**：自我反思 vs 过程级外部反馈，定量区分其改进效率差异
- **退化量化**：多轮改写后，Agent 在已满足标准上的退化率高达 **24%**，首次系统性测量

📊 **实验结果**
- 自我反思：满足/退化率几乎相等，净改进可忽略不计
- 单轮过程级反馈：归一化分数提升约 **8–15 分**，满足率约 **35–40%**
- 多轮叠加：收益不累积，退化率随轮次上升（ICML 2026 Workshop Oral）

🎯 **与 Agent/Routing 的关联**
直接指向 Multi-Agent 编排中的规划监控层——如何动态检测执行偏差并精准触发重规划，是 Agent Routing 在任务执行层面的核心挑战。

### 4️⃣ **ParetoBandit：非平稳环境下带预算约束的自适应 LLM 路由**
（Budget-Paced Adaptive Routing for Non-Stationary LLM Serving）

🔗 https://arxiv.org/abs/2604.00136

💡 **核心贡献**
ParetoBandit 针对真实生产环境的三大非平稳特征（模型定价变化、质量漂移、新模型上线），提出基于代价感知 Contextual Bandit 的自适应路由器，同时满足"实时预算约束"与"在线分布偏移适应"两个长期未被同时解决的核心需求。

🔧 **技术亮点**
- **在线 Primal-Dual 预算调速器**：在无需预知请求总量的情况下，实时执行每请求成本上限约束
- **几何遗忘机制（Geometric Forgetting）**：对充分统计量施加遗忘权重，使 Bandit 对质量/价格偏移具有有界记忆（Bounded Memory）
- **Hot-Swap 模型注册表**：支持运行时新增模型，通过预算受控探索冷启动集成

📊 **实验结果**
1,824 条 benchmark prompts，三模型组合下：预算合规误差 **<0.4%**；价格/质量偏移场景质量提升最高 **+0.071**；新模型约 **142 步**内完成冷启动集成。

🎯 **与 Agent/Routing 的关联**
直接解决 LLM Routing 在生产环境中最被忽视的难题——路由器本身的实时适应性，为 Agent 系统的模型选择层提供成本可控的动态路由基础设施。

## 🧠 今日洞察

**1. 记忆系统正在走向"主动推理层"：** AgeMem 的训练式统一记忆管理代表了一个趋势——记忆不再是被动的向量检索附件，而是 Agent 策略的核心组成，通过 RL 端到端优化，记忆操作与任务决策深度耦合。

**2. Multi-Agent 组织设计超越通信协议：** AgentSpawn 的动态 Spawn 与 DRA 多轮评估的退化研究共同指向同一核心：Multi-Agent 的瓶颈已从"如何传递消息"转向"如何设计执行-监控-重规划的闭环"，Agent 组织结构的自适应性成为新的核心竞争力。

**3. LLM Routing 进入"生产适应性"阶段：** ParetoBandit 标志着路由研究从学术 benchmark 竞赛转向真实部署挑战——非平稳环境、预算约束、在线适应三者并举，预示着 Routing 将成为 Agent 基础设施的标配能力层。
