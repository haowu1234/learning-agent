📄 **[AgeMem：统一长短期记忆管理的大语言模型 Agent 框架]**
（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
本文提出 AgeMem，将长期记忆（LTM）与短期记忆（STM）管理统一整合进 Agent 的策略网络，以工具调用形式暴露记忆操作（存储/检索/更新/摘要/遗忘），实现端到端的记忆管理优化。采用三阶段渐进式强化学习策略，并设计 step-wise GRPO 以应对记忆操作带来的稀疏与不连续奖励问题。

🔧 **技术亮点**
- 将记忆操作（store/retrieve/update/summarize/discard）建模为工具动作，Agent 自主决策何时、存什么
- 三阶段渐进式 RL 训练，逐步解锁复杂记忆行为，配合 step-wise GRPO 处理稀疏奖励
- 统一 LTM+STM 框架消除了依赖手工启发式或辅助控制器的传统做法，支持多 LLM backbone

📊 **实验结果**
在 5 个 long-horizon 基准测试上，AgeMem 持续超越强记忆增强基线，同时实现更高质量的长期记忆和更高效的上下文使用，代码开源于 GitHub。

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 长程任务中的记忆瓶颈，记忆操作作为工具动作的设计范式可迁移至 Tool-use Agent 系统。

📄 **[规划者才是关键！面向长程规划的高效非均衡多智能体协作框架]**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）
🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
提出三角色多 Agent 框架（规划者 / 执行者 / 记忆管理器），通过系统性计算分配分析揭示规划是影响任务性能的主导因素，执行和记忆管理只需较少算力即可达到竞争性效果，从而设计了以规划者为中心的强化学习方法。

🔧 **技术亮点**
- 系统化的计算分配消融分析，量化了规划、执行、记忆三个模块的相对重要性
- 采用 VLM-as-judge 提供轨迹级奖励，仅优化规划者，冻结其余组件，降低训练成本
- 在 Web 导航、OS 控制、Tool use 等多类 long-horizon 基准上进行全面评测

📊 **实验结果**
在 Web 导航、OS 控制、工具使用等多类 benchmark 上，集中算力于规划者后，相比均衡分配策略取得显著提升，且整体计算效率更优，代码开源。

🎯 **与 Agent/Routing 的关联**
揭示了多 Agent 系统中"非均衡算力分配"原则，直接指导 LLM Routing 中如何根据子任务类型动态分配模型能力。

📄 **[策略引导的逐步模型路由：高性价比推理方案]**
（Policy-Guided Stepwise Model Routing for Cost-Effective Reasoning）
🔗 https://arxiv.org/abs/2605.06116

💡 **核心贡献**
将逐步模型路由（在 CoT 推理链的每一步动态选择大/小模型）形式化为约束决策问题，通过 RL 训练一个轻量控制策略 + 阈值校准来调节性能-效率权衡，无需训练大型过程奖励模型。

🔧 **技术亮点**
- 在 CoT 推理链的每一步（step level）进行路由决策，粒度细于传统 query-level 路由
- 用强化学习训练小控制策略，配合置信度阈值校准，避免昂贵的 PRM 训练
- 在开源与闭源模型上均验证，覆盖 GSM8K、MATH500、OmniMath 三个数学基准

📊 **实验结果**
相比人工设计的路由策略，在 GSM8K/MATH500/OmniMath 上持续改善精度-成本权衡曲线；同时达到需要训练大型 PRM 的方案的可比效果，但训练成本大幅降低。

🎯 **与 Agent/Routing 的关联**
Step-level routing 是 LLM Routing 领域的前沿方向，将路由粒度从 query 下沉到推理步骤，显著提升了推理链的整体效率。

📄 **[LLMRouterBench：大规模 LLM 路由基准与统一评测框架]**
（LLMRouterBench: A Massive Benchmark and Unified Framework for LLM Routing）
🔗 https://arxiv.org/abs/2601.07206

💡 **核心贡献**
构建了迄今最大规模的 LLM 路由基准（400K+ 实例，21 数据集，33 个模型），整合 10 种代表性路由基线，提供面向性能导向和性能-成本权衡的双维度评估指标，系统性重新评估了当前路由领域的研究进展。

🔧 **技术亮点**
- 统一评测框架消除各研究自定义设置带来的可比性问题，揭示很多路由方法在公平对比下差异不显著
- 发现多种商业路由器无法可靠超越简单基线，而 Oracle 上界仍存在显著差距（主因是模型召回失败）
- 支持延迟感知分析（latency-aware），弥补现有评测忽视推理延迟的短板

📊 **实验结果**
证实了模型间互补性（LLM routing 的核心前提）；大规模 ensemble 相比精心策划的小型 ensemble 收益递减；backbone embedding 模型影响有限；整体数据集/代码全部开源。

🎯 **与 Agent/Routing 的关联**
为 LLM Routing 研究提供了权威评测平台，是任何路由方法验证的必测基准，直接服务于 Agent 推理成本优化场景。

## 🧠 今日洞察

1. **记忆管理正在走向端到端学习**：从 AgeMem 可以看出，LTM/STM 分离的传统架构正被统一政策网络取代，记忆操作作为工具动作的范式将成为主流；这一趋势也对 Agent 的 RL 训练提出了更高要求——需要专门设计奖励函数处理稀疏且非连续的记忆信号。

2. **算力非均衡分配是多 Agent 系统的关键设计原则**：Planner Matters 的研究量化地证明了规划子任务的算力价值远高于执行子任务，这与 LLM Routing 领域"按难度动态分配模型"的思路高度一致，预示着 Agent 系统内部的细粒度 Routing 将成为研究热点。

3. **Routing 从 query 粒度向 step 粒度演进**：Step-level routing（2605.06116）将决策点从整条查询细化到推理链的每一步，结合 LLMRouterBench 揭示的"简单基线仍有竞争力"现象，说明当前路由方法的突破口在于更细粒度的状态建模，而非更复杂的路由架构。
