### 1. 统一长短期记忆管理的智能体框架 AgeMem
**原文标题**: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents  
🔗 https://arxiv.org/abs/2601.01885  
💡 **核心贡献**  
AgeMem 将长期记忆（LTM）和短期记忆（STM）的管理统一为 Agent Policy 的一部分，通过工具调用方式暴露记忆操作（存储/检索/更新/摘要/丢弃），实现端到端可优化的记忆管理。为解决记忆操作带来的稀疏离散奖励问题，提出三阶段渐进强化学习策略配合逐步 GRPO 训练方法。

🔧 **技术亮点**  
- 将记忆操作（store/retrieve/update/summarize/discard）统一封装为 tool-based actions，Agent 自主决策何时执行  
- 三阶段渐进式 RL 训练：先监督热身 → 逐步放开记忆工具 → 全量 GRPO 优化  
- Step-wise GRPO：解决记忆操作在稀疏/不连续奖励场景下的信用分配难题  

📊 **实验结果**  
在 5 个长时序基准测试中，AgeMem 持续超越强记忆增强基线，任务完成率、记忆质量、上下文利用效率三指标均有显著提升；支持多种 LLM backbone 验证泛化性。

🎯 **与 Agent/Routing 的关联**  
直接解决 Agent 长时序推理的核心瓶颈——有限上下文窗口下的动态记忆管理，是构建可持续工作 Agent 的基础能力。

### 2. 规划才是关键！面向长时序任务的高效非均衡多智能体协作框架
**原文标题**: Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning  
🔗 https://arxiv.org/abs/2605.02168  
💡 **核心贡献**  
通过系统性计算资源分配分析，揭示了多智能体框架中规划模块是任务性能的主导因素，执行与记忆管理模块所需算力远低于规划模块。基于此洞察提出「以规划为中心」的 RL 优化策略，仅对规划 Agent 训练而冻结其他组件。

🔧 **技术亮点**  
- 三角色分工架构：Planner（高层决策）+ Actor（任务执行）+ Memory Manager（上下文推理），职责清晰解耦  
- 计算资源非均衡分配：实验证明 Planner 需要更大模型容量，Actor/Memory 可用轻量模型  
- VLM-as-Judge 轨迹级奖励：使用视觉语言模型对完整轨迹评分，作为 Planner RL 的稀疏奖励信号  

📊 **实验结果**  
在 Web 导航、OS 控制、Tool Use 三类长时序基准上，以规划为中心的 RL 优化带来显著的鲁棒性提升，且计算效率优于同等算力下的均衡分配策略。

🎯 **与 Agent/Routing 的关联**  
为多 Agent 系统中的"模型路由"提供了新视角：不同角色应分配不同规格模型，这是 Agent 内部的能力路由思想。

### 3. 基于主动推断的原则性自适应 LLM 路由框架 ODAR
**原文标题**: Principled Adaptive Routing for LLM Reasoning via Active Inference (ODAR-Expert)  
🔗 https://arxiv.org/abs/2602.23681  
💡 **核心贡献**  
ODAR 将 LLM 推理路由问题从启发式投票升级为基于自由能原则的原则性决策：用摊销主动推断（amortized active inference）估计查询难度，动态路由到 Fast Agent 或 Slow Agent，并以变分自由能目标融合答案。

🔧 **技术亮点**  
- 难度估计器：基于摊销主动推断，无需训练即可量化查询复杂度（epistemic uncertainty / varentropy）  
- Fast/Slow 双 Agent 架构：简单题走启发式快路径，复杂题走深度慢思考路径，与人类认知系统 1/系统 2 类比  
- 自由能融合：替代 majority voting，以最小化变分自由能为目标选择最优答案，理论基础更扎实  

📊 **实验结果**  
- 23 个基准测试持续取得收益；MATH 基准准确率 **98.2%**，HLE（人类最难考试）**54.8%**  
- 开源复现（Llama 4 + DeepSeek）：计算成本降低 **82%** 同时超越同算力均匀采样基线  
- 消融：去除难度估计器后宏平均准确率下降 8.3%，证明模块有效性  

🎯 **与 Agent/Routing 的关联**  
这是 2026 年 LLM Routing 领域最有代表性的理论驱动工作，将主动推断引入路由决策，为"什么时候用大模型"提供了信息论级别的量化依据。

### 4. 动态模型路由与级联推理综述
**原文标题**: Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey  
🔗 https://arxiv.org/abs/2603.04445  
💡 **核心贡献**  
系统梳理了多 LLM 动态路由与级联推理的研究全貌，提出三维度概念框架（决策时机 × 信息来源 × 计算方式），覆盖6大范式，是当前该领域最完整的综述之一。

🔧 **技术亮点**  
- 六大路由范式全覆盖：难度感知路由 / 人类偏好对齐 / 聚类路由 / RL 路由 / 不确定性路由 / 级联推理  
- 三维度框架：(1) 决策时机（生成前/生成后/多阶段）(2) 信息来源（查询/模型元数据/响应信号）(3) 计算方式（规则/分类器/自适应策略）  
- 明确区分 MoE 内部路由 vs 多独立 LLM 外部路由，厘清研究边界  

📊 **实验结果**  
综述性论文，系统对比各范式代表方法的 cost-performance trade-off，指出设计良好的路由系统可超越单一最强模型的性能。

🎯 **与 Agent/Routing 的关联**  
为 LLM Routing 领域提供了完整的知识图谱，是进入该领域的必读参考，对于构建 Agent 内部的动态模型调度具有直接指导价值。

## 🧠 今日洞察

**趋势一：记忆与规划走向「端到端可训练」。** AgeMem 和 Planner Matters 都在同一方向发力——将过去基于规则或启发式的 Agent 子系统（记忆管理、角色分工）转变为可通过 RL 端到端优化的可学习组件，「让 Agent 自己学会用工具」成为主流范式。

**趋势二：LLM Routing 从工程技巧升格为理论方向。** ODAR 将主动推断（Active Inference）引入路由决策，Survey 论文同步提供系统性综述，预示该领域正从"哪个模型更便宜"的工程权衡，演进为以信息论、强化学习为基础的原则性资源分配问题。

**趋势三：计算资源的「非均衡分配」成为共识。** Planner Matters 用实验证明了 Agent 各角色的算力需求存在本质差异；ODAR 的 Fast/Slow 双路设计则在推理端印证了同样逻辑——未来的高效 AI 系统，核心在于「把钱花在刀刃上」。
