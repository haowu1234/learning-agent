📄 **[统一长短期记忆管理的智能体记忆框架 AgeMem]**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem，首次将长期记忆（LTM）和短期记忆（STM）的管理统一为 Agent 策略的一部分，以工具化动作的方式暴露记忆操作（存储/检索/更新/摘要/丢弃）。通过三阶段渐进强化学习策略训练端到端记忆行为，并设计 step-wise GRPO 解决记忆操作引发的稀疏奖励问题。

🔧 **技术亮点**
- 记忆操作被封装为工具调用动作，Agent 自主决策 what/when to remember
- 三阶段渐进 RL + step-wise GRPO，解决记忆操作的稀疏奖励难题
- 不依赖辅助控制器，完全端到端可优化

📊 **实验结果**
在 5 个 long-horizon 基准测试上，AgeMem 持续优于强记忆增强 baseline，取得更高任务完成率、更高质量 LTM 及更高效的上下文使用率。

🎯 **与 Agent/Routing 的关联**
AgeMem 的工具化记忆操作范式对 Agent 规划框架中的动态上下文管理具有直接借鉴意义。

📄 **[AMA-Bench：评估智能体应用中长时序记忆的基准]**（AMA-Bench: Evaluating Long-Horizon Memory for Agentic Applications）
🔗 https://arxiv.org/abs/2602.22769

💡 **核心贡献**
现有 Agent 记忆基准以对话为中心，与真实 Agent 运行的机器生成交互序列差距显著。AMA-Bench 引入涵盖真实 agentic 轨迹与任意长度合成轨迹的评测体系，并配套提出 AMA-Agent（因果图 + 工具增强检索）。

🔧 **技术亮点**
- 两类评测轨迹：真实 agentic 应用（专家标注 QA）+ 任意长度合成轨迹（规则化 QA）
- 发现主流记忆系统缺失因果性与目标信息，且相似度检索本质有损
- AMA-Agent 引入因果图（causality graph）弥补语义检索盲区

📊 **实验结果**
AMA-Agent 在 AMA-Bench 达到 57.22% 平均准确率，超越最强记忆系统 baseline 11.16 个百分点。

🎯 **与 Agent/Routing 的关联**
提供了评估 Agent 长时序记忆的系统化方法论，可直接用于评估 Routing Agent 的跨轮上下文保持能力。

📄 **[RTR：自适应 LLM 与推理策略联合路由框架]**（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）
🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
提出 Route-To-Reason（RTR）框架，在推理预算约束下同时动态分配最合适的 LM 和推理策略，解决 test-time scaling 的过度计算（overthinking）与"思维陷阱"问题。

🔧 **技术亮点**
- 联合学习 expert model 和 reasoning strategy 的压缩表征，支持 inference time 联合自适应选择
- 低成本、高灵活性，可无缝扩展到任意黑盒/白盒模型与策略（plug-and-play）
- 统一路由框架，同时解决「选哪个模型」和「用哪种推理」两个维度

📊 **实验结果**
在 7 个开源模型 × 4 种推理策略的实验中，RTR 达到精度与计算效率的最优权衡：准确率高于最佳单一模型，同时 token 使用量减少超过 60%。

🎯 **与 Agent/Routing 的关联**
直接针对 LLM Routing 核心场景，将推理策略路由与模型路由统一，是 Routing 方向近期最具代表性的工作之一。

📄 **[UniRoute：面向高效 LLM 推理的通用模型路由]**（Universal Model Routing for Efficient LLM Inference）
🔗 https://openreview.net/forum?id=ka82fvJ5f1

💡 **核心贡献**
现有 LLM 路由工作仅针对固定模型池，而 UniRoute 针对动态路由（test time 有新未见过的 LLM 出现）进行设计——将每个 LLM 编码为基于代表性 prompt 预测的 feature vector，实现无需重训路由器即可接纳新模型。

🔧 **技术亮点**
- 将 LLM 能力刻画为 feature vector，支持跨模型泛化路由
- 两种实例化：基于聚类的路由 vs. 可学习聚类映射路由
- 理论上证明其为最优路由规则的近似，并给出 excess risk bound

📊 **实验结果**
在多个公开基准上验证 UniRoute 可有效路由 30+ 个未见过的 LLM，显著优于固定模型池路由基线。

🎯 **与 Agent/Routing 的关联**
解决了 Routing 领域的关键工程挑战：模型池动态变化时无需重训路由器，极大降低了 LLM Routing 的部署成本。

## 🧠 今日洞察

当前 Agent 研究呈现出**记忆与路由双轮驱动**的趋势：记忆方向正从启发式管理走向端到端可学习的统一框架（AgeMem/AMA-Agent），核心难点是因果关系保留和稀疏奖励；路由方向则从单维度（选模型）向多维度联合优化演进（RTR 同时路由模型+推理策略，UniRoute 处理动态模型池）。两条线索交汇点在于：**如何让 Agent 在长时序任务中既高效管理记忆上下文，又动态匹配最优计算资源**——这将是 2026 年 Agentic AI 落地的核心瓶颈之一。
