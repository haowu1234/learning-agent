📄 **TFlow：多智能体隐藏状态通过 LoRA 权重扰动传递，替代文本通信**
（Good Agentic Friends Do Not Just Give Verbal Advice: They Can Update Your Weights）
🔗 https://arxiv.org/abs/2605.13839

💡 **核心贡献**
提出 TFlow（Thought Flow），将发送方 Agent 的隐藏状态编译为接收方专属的瞬时低秩 LoRA 权重扰动，彻底替代传统的自然语言消息通信，在不永久修改模型权重、不扩展上下文的前提下实现实例级自适应。在 3 个 Qwen3-4B Agent 的实验中，相比文本通信三智能体基线减少 83.27% token，推理速度提升 4.6 倍。

🔧 **技术亮点**
- 隐藏状态→低秩 LoRA 扰动：无需将 Agent 间思维过程序列化为自然语言
- 实例级推理时适配：针对每次 inference 动态生成接收方 LoRA，不落盘不永久改权重
- 插件式兼容性：可无缝接入现有 LLM 架构，支持任意 Agent 数量组合

📊 **实验结果**
- 5 个基准测试中 4 个优于文本通信多 Agent 基线
- 比最强单接收器基线提升最高 8.5 个准确率点
- token 减少 83.27%，延迟降低 4.6×（vs 文本通信三 Agent 基线）

🎯 **与 Agent/Routing 的关联**
直接解决多 Agent 系统通信效率瓶颈，为 Multi-Agent Routing 层提供了比文本消息更高效的"思维传输"原语。

📄 **SkillOps：将 LLM Agent 技能库作为自维护软件生态管理**
（SkillOps: Managing LLM Agent Skill Libraries as Self-Maintaining Software Ecosystems）
🔗 https://arxiv.org/abs/2605.13716

💡 **核心贡献**
提出 SkillOps 框架，引入"技能技术债"概念——技能库因持续增删、复用、修补积累的潜在缺陷。SkillOps 用类型化 Skill Contract 表示技能，构建分层 Skill Ecosystem Graph，从效用/兼容性/风险/验证四维度诊断并维护技能库健康，作为与具体 Agent 方法无关的插件层。

🔧 **技术亮点**
- Skill Contract (P, O, A, V, F)：结构化表示技能的前置条件、输出、动作、验证和失败模式
- 分层 Skill Ecosystem Graph：支持跨技能依赖分析与兼容性检测
- 近零推理时 LLM 调用：维护逻辑基于规则，几乎不消耗额外 token

📊 **实验结果**
- ALFWorld 上作为独立 Agent 达 79.5% 任务成功率，超最强基线 8.8 个百分点
- 作为插件可为多种检索型基线带来 0.68–2.90 个百分点的稳定增益
- 提交 NeurIPS 2026，代码已开源：https://github.com/Hik289/SkillOps.git

🎯 **与 Agent/Routing 的关联**
直接关联 Agent Tool 管理与长期任务规划——健康的技能库是实现长 horizon 任务稳定执行的基础设施。

📄 **CANTANTE：基于对比信用归因优化多智能体系统**
（CANTANTE: Optimizing Agentic Systems via Contrastive Credit Attribution）
🔗 https://arxiv.org/abs/2605.13295

💡 **核心贡献**
CANTANTE 解决了多 Agent 系统中"只能观测系统级 reward、但可调参数分散在各 Agent"的信用分配难题。通过对同一 query 的多组联合 rollout 做对比，将系统级奖励分解为 Agent 级更新信号，用于各 Agent 的 Prompt 优化。

🔧 **技术亮点**
- 对比信用归因：比较多组联合 Agent 配置的 rollout，而非单次评估
- 系统级→Agent 级信号分解：自动将系统奖励拆分为各 Agent Prompt 的优化梯度方向
- 低推理成本：相比基线（GEPA、MIPROv2）在相同性能下推理成本更低

📊 **实验结果**
- 在 MBPP 上相对最强基线提升 18.9 个百分点
- 在 GSM8K 上提升 12.5 个百分点
- HotpotQA 三个测试集中取得最佳平均排名

🎯 **与 Agent/Routing 的关联**
为 Multi-Agent 系统中如何通过 Routing 决策（哪个 Agent 处理哪类子任务）的联合优化提供了信用归因的理论框架。

📄 **Route-To-Reason：自适应路由同时选择 LLM 和推理策略**
（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）
🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
提出 RTR（Route-To-Reason），一个统一路由框架，在预算约束下根据任务难度同时动态分配最优 LLM 和推理策略（如 CoT、ToT、直接回答等）。RTR 学习 Expert Model 和推理策略的压缩表示，支持联合自适应选择，实现真正的即插即用。

🔧 **技术亮点**
- 双维度路由：同时路由"选哪个模型"和"用哪种推理策略"，打破两者分离优化的局限
- 压缩表示学习：对 Expert 模型和策略学习低维嵌入，降低联合选择的搜索空间
- 黑白盒通用：可无缝适配任意闭源/开源模型，无需修改底层模型

📊 **实验结果**
- 跨 7 个开源模型、4 种推理策略的大规模实验
- 准确率超过最优单一模型，同时 token 使用量减少 60% 以上
- 在所有基线中实现最优精度-计算效率权衡

🎯 **与 Agent/Routing 的关联**
是 LLM Routing 领域的直接代表作，将 routing 从"选模型"扩展到"选模型+选策略"的二维空间，是 Adaptive Inference 的核心进展。

## 🧠 今日洞察

**1. Multi-Agent 通信正在突破文本范式**：TFlow 展示了以权重扰动替代语言作为 Agent 间通信媒介的可行性，意味着 Agent 协作不必再局限于"说话"这一方式，未来多 Agent 系统可能出现多种通信层并存的架构。

**2. Agent 技能工程化趋势明显**：SkillOps 和 CANTANTE 均在解决"Agent 系统规模化后的维护与优化"问题——前者面向技能库的健康管理，后者解决多 Agent 联合优化中的 credit assignment。这表明领域正从"让单个 Agent 更聪明"转向"让 Agent 系统更可维护、可优化"。

**3. Routing 从单维走向多维**：RTR 将 LLM Routing 扩展到"模型 × 策略"的二维联合选择空间，是近期 Routing 研究的重要范式升级，token 节省 60% 的同时保持精度领先，具备极强的工程落地价值。
