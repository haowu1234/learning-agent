### 📄 **统一长短期记忆管理的 Agent 框架 AgeMem**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem，将长期记忆（LTM）与短期记忆（STM）统一为 Agent 策略的一部分，通过工具调用形式让模型自主决定何时存储、检索、更新或丢弃信息；设计三阶段渐进式强化学习 + step-wise GRPO，解决记忆操作引发的稀疏/非连续奖励问题。

🔧 **技术亮点**
- 记忆操作以"工具动作"方式暴露给 Agent，实现端到端联合优化
- 三阶段 progressive RL 训练：基础能力 → 记忆操作 → 联合策略
- step-wise GRPO 解决记忆动作导致的奖励稀疏问题

📊 **实验结果**
在 5 个长时程 benchmark 上，AgeMem 持续超越强基线（多 LLM backbone 验证），在任务完成率、LTM 质量、上下文效率三方面均有提升；代码已开源（GitHub: y1y5/AgeMem）。

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 在长时程任务中的记忆瓶颈，是构建复杂工具调用 Agent 的基础组件。

### 📄 **多智能体系统的编排：架构、协议与企业落地**
（The Orchestration of Multi-Agent Systems: Architectures, Protocols, and Enterprise Adoption）

🔗 https://arxiv.org/abs/2601.13671

💡 **核心贡献**
提出统一编排架构框架，将规划、策略执行、状态管理和质量运营整合为一致的编排层；深入形式化分析 MCP（Model Context Protocol）和 Agent2Agent（A2A）协议，为企业级多智能体系统提供可互操作的通信基础。

🔧 **技术亮点**
- MCP 标准化 Agent 访问外部工具和上下文数据的方式
- A2A 协议管理 Agent 间对等协调、协商与委托
- 编排逻辑 + 治理框架 + 可观测机制三位一体，保障系统一致性与透明度

🎯 **与 Agent/Routing 的关联**
A2A 协议天然涉及任务路由与 Agent 选择，是多 Agent Routing 的工程实现范式。

### 📄 **基于蚁群优化的高效可解释多 Agent LLM 路由（AMRO-S）**
（Efficient and Interpretable Multi-Agent LLM Routing via Ant Colony Optimization）

🔗 https://arxiv.org/abs/2603.12933

💡 **核心贡献**
提出 AMRO-S，将多 Agent 系统路由建模为语义条件下的路径选择问题，用蚁群优化（ACO）替代昂贵的 LLM-based selector，实现低开销、可解释的动态路由；质量门控异步更新机制将推理与学习解耦。

🔧 **技术亮点**
- SFT 小语言模型做 intent inference，提供低开销语义接口
- 任务特化信息素（pheromone specialist）减少跨任务干扰
- 质量门控异步更新（quality-gated async update）保证低延迟同时持续优化路由

📊 **实验结果**
5 个公开 benchmark + 高并发压力测试下，AMRO-S 持续改善质量-成本权衡，并通过结构化信息素模式提供可追溯的路由证据；投稿 IEEE Transactions on Artificial Intelligence。

🎯 **与 Agent/Routing 的关联**
直接针对多 Agent 系统路由问题，兼顾效率与可解释性，是 LLM Routing 领域的重要进展。

### 📄 **LLM 动态路由与级联推理系统综述**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
系统梳理跨多个独立训练 LLM 的路由与级联方法，提出三维度概念框架（决策时机 × 使用信息 × 计算方式），覆盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态等多种路由范式。

🔧 **技术亮点**
- 区分 Mixture-of-Experts（单模型内路由）与跨模型路由，明确研究边界
- 三维概念框架：when / what / how，揭示实际系统的组合性本质
- 覆盖 RL-based routing、uncertainty-driven cascading 等前沿范式

📊 **实验结果**
综述性论文，结论：设计良好的路由系统可超越最强单模型，通过跨模型能力互补实现效率最大化；Trinity College Dublin + Huawei Ireland 联合研究。

🎯 **与 Agent/Routing 的关联**
是 LLM Routing 领域最系统的综述之一，为构建 Agent 路由策略提供完整知识地图。

## 🧠 今日洞察

2026 年 Agent 研究呈现出**三个收敛趋势**：①记忆不再是孤立模块，而是被纳入 Agent 策略的端到端可优化组件（AgeMem）；②多 Agent 协作正从学术概念走向工程化，MCP/A2A 协议标准化推动企业落地；③LLM Routing 从"选哪个模型"升级为"选模型 + 选策略"的联合优化问题（RTR/AMRO-S），效率与可解释性并重成为新评估维度。整体上，**Agent 研究的重心正从"能不能做"转向"如何高效、可控、可解释地做"**。
