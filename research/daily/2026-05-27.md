### 1. 规划者才是关键！面向长程任务的高效非均衡多智能体协作框架
**Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning**

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
本文通过系统性的算力分配分析，揭示了在多智能体框架中**规划器（Planner）是影响任务性能的主导因素**，执行器和记忆管理器所需算力显著更低。在此基础上提出以 Planner 为中心的强化学习方案，使用 VLM-as-judge 提供轨迹级奖励信号，仅优化规划器而冻结其他组件。

🔧 **技术亮点**
- 三角色分工：Planner（高层决策）+ Actor（任务执行）+ Memory Manager（上下文推理），职责清晰解耦
- 引入"非均衡算力分配"原则：将大模型容量集中在规划层，执行和记忆层使用轻量模型即可达到竞争性表现
- 规划器用 VLM-as-judge 评估完整轨迹后给出奖励，避免了稠密监督信号的需求

📊 **实验结果**
在网页导航、OS 控制、工具使用三类 benchmark 上验证，以更低总算力实现更优的长程自动化效果；代码已公开。

🎯 **与 Agent/Routing 的关联**
直接揭示了多智能体系统中"算力路由"的本质——应将重计算资源优先分配给规划层而非均匀分布，为 Agent 系统设计提供量化依据。

### 2. GraphPlanner：图记忆增强的多智能体 LLM 路由框架
**GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs**

🔗 https://arxiv.org/abs/2604.23626

💡 **核心贡献**
将 LLM Routing 从单轮查询扩展到真正的 Agentic 场景，提出 GraphPlanner，通过异构图（GARNet）捕获查询、智能体、响应之间的交互记忆，并将工作流生成建模为 MDP，用 RL 联合优化任务性能与计算效率。

🔧 **技术亮点**
- 每步同时选择 LLM 骨干模型 + Agent 角色（Planner / Executor / Summarizer），实现双维度路由
- 引入 GARNet 异构图，同时编码历史交互记忆和工作流记忆，支持 inductive/transductive 两种推理模式
- 整体 pipeline 用 RL 端到端优化，路由决策不依赖手工规则

📊 **实验结果**
在 14 个多样化 LLM 任务上评测：
- 准确率较强 baseline 提升最高 9.3%
- GPU 显存占用从 186.26 GiB 降至 **1.04 GiB**（降低约 180×）
- 对未见任务和 LLM 泛化能力强，支持零样本路由
发表于 **ICLR 2026**，代码已开源。

🎯 **与 Agent/Routing 的关联**
同时覆盖 Routing 与 Agent 两大主题：以图记忆驱动的 Agentic Routing 是迈向生产级多智能体系统的关键一步。

### 3. ODAR：基于主动推断的 LLM 推理自适应路由
**ODAR: Principled Adaptive Routing for LLM Reasoning via Active Inference**

🔗 https://arxiv.org/abs/2602.23681

💡 **核心贡献**
针对测试时计算扩展中"均匀暴力采样"的低效问题，提出 ODAR——用基于摊销主动推断（amortized active inference）的难度估计器，将查询动态路由至 Fast Agent 或 Slow Agent，并以自由能（Free Energy）最小化替代 ad hoc 投票实现答案融合。

🔧 **技术亮点**
- 难度感知路由器：用主动推断估计查询难度，自适应决定是否启用慢速推理路径，避免过度思考
- 自由能融合机制：在对数似然与认知不确定性（varentropy）之间取得有原则的权衡，优于多数投票
- 完全开源可复现：在 Llama 4 + DeepSeek 全开源栈上验证

📊 **实验结果**
- 23 个 benchmark 全面验证
- MATH 准确率达 **98.2%**，Humanity's Last Exam (HLE) 达 **54.8%**
- 与同算力均匀采样相比，计算成本降低 **82%**

🎯 **与 Agent/Routing 的关联**
为 LLM Routing 提供了坚实的信息论基础，以主动推断和自由能原理替代启发式路由规则，是 Routing 领域方法论升级的代表性工作。

### 4. MemFlow：面向小语言模型 Agent 的意图驱动记忆编排框架
**MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents**

🔗 https://arxiv.org/abs/2605.03312

💡 **核心贡献**
针对 SLM（小语言模型）在长程多轮 Agent 场景中的记忆失效问题，提出 MemFlow——将记忆规划从模型自身剥离出来，由独立的 Router Agent 按查询意图分类后，调度对应记忆层（Profile Lookup / Targeted Retrieval / Deep Reasoning）执行结构化证据准备。

🔧 **技术亮点**
- 三层记忆分级：Profile Lookup（浅）→ Targeted Retrieval（中）→ Deep Reasoning（深），按意图动态选层
- 无需训练（training-free）：冻结 1.7B 的 Qwen3-1.7B 骨干，纯通过结构化路由提升性能
- Validator Agent 自动重试机制：当答案证据不足时，升级到更重的记忆层重新检索

📊 **实验结果**
在 LongMemEval、LoCoMo、LongBench 三个长程记忆 benchmark 上：
- 相比全上下文 SLM baseline，准确率提升约 **2×**

🎯 **与 Agent/Routing 的关联**
将 Intent Routing 引入 Agent 的记忆编排层，揭示"记忆操作的匹配问题"是 SLM Agent 失败的核心原因，同时兼具 Routing（意图分类）和 Agent Memory 两个研究方向。

## 🧠 今日洞察

1. **Routing 正在从"模型选择"进化为"系统级资源调度"**：无论是 GraphPlanner 的双维度路由（模型 × 角色）、ODAR 的 Fast/Slow 分流，还是 MemFlow 的记忆层分级，都表明 Routing 研究的焦点已从"用哪个模型"扩展到"在系统的哪个层次分配多少计算资源"。

2. **图结构记忆 + RL 成为多智能体系统的新范式**：GraphPlanner 以 MDP + 异构图将路由决策与记忆状态统一建模，在 ICLR 2026 落地，预计该范式将向更多 Agentic 场景扩散。

3. **"非均衡"是效率突破口**：Planner Matters 和 ODAR 不约而同地指向同一结论——均匀分配计算资源是浪费，将计算集中在高价值决策节点（规划层、困难查询）可以以更低成本实现更高性能。
