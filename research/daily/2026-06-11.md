## 📄 Paper 1

📄 **[AgeMem：统一长短期记忆管理的自主 Agent 框架]**（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
LLM Agent 在长视野推理中受有限上下文窗口制约，现有方法将长期记忆（LTM）与短期记忆（STM）割裂处理。AgeMem 将 LTM/STM 管理统一为 Agent 策略的一部分，以工具调用形式暴露记忆操作（存储、检索、更新、摘要、丢弃），通过端到端强化学习实现自主记忆决策。

🔧 **技术亮点**
- 将记忆操作建模为 tool-based action，LLM Agent 自主决定"何时存什么"
- 三阶段渐进式强化学习策略，解决记忆操作引发的稀疏、不连续奖励问题
- 提出 step-wise GRPO 算法，专门应对记忆操作的奖励对齐挑战

📊 **实验结果**
在 5 个长视野基准上，AgeMem 在多个 LLM 基础模型上均优于强记忆增强 baseline，同时提升任务表现、长期记忆质量与上下文利用效率。代码开源：https://github.com/y1y5/AgeMem

🎯 **与 Agent/Routing 的关联**
直接解决 Agent 在长视野任务中的记忆管理核心瓶颈，是构建有状态 Agent 系统的基础性工作。

## 📄 Paper 2

📄 **[DeLM：基于共享上下文的去中心化多智能体系统]**（Decentralized Multi-Agent Systems with Shared Context）

🔗 https://arxiv.org/abs/2606.10662

💡 **核心贡献**
大多数 MAS（多智能体系统）依赖中心化 Orchestrator 调度，随子任务规模增长会产生通信与整合瓶颈。DeLM 提出去中心化框架，通过共享验证上下文（shared verified context）和异步任务队列替代中心控制器，Agent 异步认领任务、读取进度、写回验证更新。

🔧 **技术亮点**
- 共享验证上下文作为公共通信底层，Agent 可在彼此已验证进度之上继续推理
- 异步任务队列支持并行 Agent 自发协作，无需中心路由每条更新消息
- 层次化摘要机制（hierarchical summaries）保持上下文可扩展性

📊 **实验结果**
SWE-bench Verified 上 DeLM 在 Avg.@1、Pass@2、Pass@4 均达最优，最高超出最强 baseline **10.5 个百分点**，同时每任务成本降低约 **50%**；LongBench-v2 Multi-Doc QA 中，在四个前沿模型家族上均取得最高准确率，最高超出 baseline **5.7 个百分点**。

🎯 **与 Agent/Routing 的关联**
DeLM 的共享上下文机制本质上是一种隐式"路由"——Agent 根据任务队列状态自主决定接收哪个子任务，去除显式 Orchestrator 后路由逻辑内化到上下文协商中。

## 📄 Paper 3

📄 **[SkillAxe：通过评估引导自精炼提升 LLM 撰写的 Agent Skill 质量]**（SkillAxe: Sharpening LLM-Authored Agent Skills Through Evaluation-Guided Self-Refinement）

🔗 https://arxiv.org/abs/2606.10546

💡 **核心贡献**
Skill 文档（结构化自然语言指令）是现代 Agent 框架的关键组件，但 LLM 自动撰写的 Skill 效果远不如人工撰写。SkillAxe 是一个全无监督框架，让 LLM 迭代诊断并精炼自己的 Skill，无需 ground-truth 标签、测试套件或环境奖励。

🔧 **技术亮点**
- 将 Skill 质量分解为 4 个可解释维度：质量影响、触发精准度、指令遵从（含故障归因）、解决路径覆盖度
- 生成结构化改进简报（improvement briefs），引导 LLM 进行针对性自我精炼
- 支持持续改进（continuous improvement engine），从过往 Agent 轨迹中学习

📊 **实验结果**
SkillsBench 上，SkillAxe 相对未改进的 LLM Skill 提升 pass rate **28%（相对值）**，弥合了 LLM 与人工 Skill 差距的 **47–67%**；SpreadsheetBench 上，仅用 22 个 Skill，pass rate 从 16.0% 提升至 **52.0%**。

🎯 **与 Agent/Routing 的关联**
高质量 Skill 是 Agent 准确路由工具调用的前提，SkillAxe 直接提升 Skill 质量，降低 Agent 在工具选择阶段的误触发和指令误解概率。

## 📄 Paper 4

📄 **[RTR：面向 LLM 与推理策略联合选择的自适应路由框架]**（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）

🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
测试时扩展（test-time scaling）虽能提升推理能力，但计算成本高且易陷入"过度思考"。RTR 提出统一路由框架，在预算约束下根据任务难度**同时**动态选择最适合的语言模型（LM）和推理策略，实现精度与效率的最优权衡。

🔧 **技术亮点**
- 学习专家模型与推理策略的压缩表示，支持推理时联合自适应选择
- 低成本、高灵活性，可无缝扩展到任意黑盒/白盒模型与策略（即插即用）
- 双维度路由（模型 + 策略），相比单维路由显著减少冗余计算

📊 **实验结果**
跨 7 个开源模型 × 4 种推理策略的广泛实验中，RTR 在所有 baseline 中实现最优精度-效率权衡：准确率高于最佳单模型，同时 **token 用量减少超过 60%**。

🎯 **与 Agent/Routing 的关联**
RTR 是 LLM Routing 领域的标志性工作，将"选哪个模型"与"用什么推理策略"统一为一个路由决策，对构建成本感知的 Agent 推理系统具有直接指导价值。

## 🧠 今日洞察

1. **Memory 系统正在从"被动存储"走向"主动推理层"**：AgeMem 将记忆操作内化为 Agent 行为策略的一部分，标志着 LLM Agent 记忆架构从外挂 RAG 向内生自主记忆演进的关键转折。

2. **Multi-Agent 去中心化是扩展性突破口**：DeLM 用共享验证上下文替代中心 Orchestrator，在 SWE-bench 上同时实现更高性能与 50% 成本削减，证明去中心化协调架构在工程任务中已具备生产价值。

3. **Routing 从"选模型"扩展到"选推理策略"**：RTR 揭示了一个新范式——在预算约束下同时路由模型与推理路径，60%+ 的 token 节省提示 Routing 将成为降低 Agent 推理成本的核心基础设施。
