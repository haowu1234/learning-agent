### 1. 生产级 AI Agent 运行时治理的五平面参考架构

**原文标题**：A Five-Plane Reference Architecture for Runtime Governance of Production AI Agents

🔗 https://arxiv.org/abs/2606.12320

💡 **核心贡献**
企业安全体系传统上围绕"数据边界"构建，而生产 AI Agent 打破了这一假设——Agent 会在获得授权的单步操作中自主改变整个业务流程，现有策略引擎无法覆盖。论文提出由五个平面（推理平面 + 网络/身份/端点/数据 四个执行平面）构成的可组合运行时治理架构，支持复合主体（composite principals）的能力衰减和可审计的证据基底。

🔧 **技术亮点**
- **五平面分解**：推理平面负责意图裁决，四个执行平面实施决策，实现 stop-anywhere 中介（adjudication 单次运行时间达到个位数微秒）
- **六类中断原语**：对 allow/deny 进行泛化，定义了涵盖暂停、委托、降级等场景的六种中断类型，并给出四条正确性不变量
- **复合主体 + 能力衰减**：通过委托链对 Agent 权限进行有状态评估，防止"逐步授权"攻击；参考实现在全部测试中衰减正确性与证据可重建性均 100% 通过

📊 **实验结果**
- 预算合规偏差 < 0.4%；adjudication 延迟单位为微秒级；在五个具体企业工作流中成功封堵 7 类生产 Agent 威胁；审计基底篡改检测行为完全符合设计

🎯 **与 Agent/Routing 的关联**
直接解决 Multi-Agent 在企业部署中的委托链安全与可观测性问题，是 Production Agent Engineering 的基础设施论文。

### 2. 面向社交智能推理的多模态多 Agent 蒸馏框架（MODF-SIR）

**原文标题**：MODF-SIR: A Multi-agent Omni-modal Distilled Framework for Social Intelligence Reasoning

🔗 https://arxiv.org/abs/2606.12018

💡 **核心贡献**
提出基于轻量级 MLLM 的多 Agent 协作框架，专为社交智能推理设计，训练与推理阶段均通过知识蒸馏增强；核心创新在于将多模态社交长尾事件精准定位后转化为格式化文本，防止其在 tokenization 过程中被主流事件淹没。

🔧 **技术亮点**
- **全流程 TTA（Test-Time Adaptation）**：覆盖长尾事件提取与表示、CoT 提示、自反思三个推理阶段，通过 LoRA 对基础模型进行实例级微调
- **多 Agent 协作 + 知识蒸馏**：教师模型知识通过蒸馏压缩至轻量学生模型，训练仅使用 IntentTrain 约 30% 数据即达到 SOTA
- **Intent Router**：内置路由数据集 IntentRouterTrain，负责将不同子任务分发至对应 Agent 处理

📊 **实验结果**
- 仅使用 30% IntentTrain 训练数据，在多个开源与闭源模型对比基准中实现 SOTA；代码与 Demo 已开源（GitHub + HuggingFace Spaces）

🎯 **与 Agent/Routing 的关联**
该框架内置了基于任务意图的 Agent 路由机制（Intent Router），是 Multi-Agent + 任务路由协同设计的典型范例。

### 3. 动态模型路由与级联高效 LLM 推理综述

**原文标题**：Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
系统综述了多 LLM 路由与级联领域的最新进展，区别于 MoE（同一模型内路由），本文专注于跨多个独立训练 LLM 的路由问题；提出三维概念框架（何时决策 / 使用什么信息 / 如何计算），揭示实践中的路由系统往往是多范式组合体。

🔧 **技术亮点**
- **七大路由范式**：覆盖查询难度、人类偏好、聚类、不确定量化、强化学习、多模态、级联等，每类均分析代表性方法与关键权衡
- **三维分析框架**：when（决策时机）× what（信息来源）× how（计算方式），清晰揭示实践系统的组合本质
- **成本范围量化**：所调研模型池覆盖约 530× 的成本跨度，有效路由可超越单一最强模型的性能

📊 **实验结果**
综述性论文，未单独给出实验数据；但结论显示良好设计的路由系统可在保持精度的同时获得显著的效率收益，且目前跨架构、跨模态的泛化仍是开放挑战。

🎯 **与 Agent/Routing 的关联**
本文是 LLM Routing 领域 2026 年最全面的综述，为 Agent 系统的模型选择与推理优化提供了系统性参考框架。

### 4. RTR：面向 LLM 与推理策略联合自适应路由

**原文标题**：Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection

🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
提出 Route-To-Reason（RTR）统一路由框架，在预算约束下同时选择最优语言模型和推理策略，解决 test-time scaling 带来的"过度思考（overthinking）"与高计算成本问题；学习专家模型与推理策略的压缩表示，支持真正即插即用的黑盒/白盒扩展。

🔧 **技术亮点**
- **双维度联合路由**：同时路由 LM 选择 + 推理策略选择（如 CoT、PoT、直接回答等），超越仅选模型的传统路由
- **压缩表示学习**：对专家模型与策略的能力进行低维压缩编码，支持相似度感知的联合选择，低计算开销
- **即插即用设计**：可无缝接入任意黑盒/白盒模型，无需重新训练路由器

📊 **实验结果**
- 覆盖 7 个开源模型 × 4 种推理策略；在所有基线中实现精度-效率最优权衡；准确率高于最强单一模型，同时 token 用量减少 **60%+**

🎯 **与 Agent/Routing 的关联**
RTR 将 LLM 路由从"选哪个模型"升级为"选哪个模型 + 选哪种推理策略"的联合决策，对 Agent 推理系统的效率优化具有直接实践价值。
