### 1. MemoryArena：多会话 Agent 记忆基准评测

**（原文标题）** MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks

🔗 https://arxiv.org/abs/2602.16313

💡 **核心贡献**
现有 Agent 记忆评测要么只测"记忆召回"，要么只测"单会话行动"，割裂了两者的耦合关系；MemoryArena 首次提出跨会话 Memory-Agent-Environment 循环评测框架，要求 Agent 将早期交互经验蒸馏为记忆并用于后续任务决策。

🔧 **技术亮点**
- **4 类任务覆盖**：网页导航、偏好约束规划、渐进式信息检索、序贯形式推理
- **强依赖子任务设计**：任务间存在显式的信息依赖，Agent 必须正确携带跨会话上下文才能完成后续步骤
- **揭示评测盲区**：在 LoCoMo 等长上下文记忆基准接近饱和的模型，在 MemoryArena 的 Agentic 场景中仍大幅失败

📊 **实验结果**
顶级模型在 LoCoMo 上接近满分，但在 MemoryArena 多会话 Agentic 场景中出现明显性能下降，揭示了当前评测与真实记忆使用之间的系统性差距。

🎯 **与 Agent/Routing 的关联**
为 Agent 的长期记忆能力提供了更贴近实际部署场景的评测基准，是构建跨会话 Routing 和记忆管理系统的重要参考。

### 2. AgentFlow：流内智能体系统优化实现有效规划与工具调用

**（原文标题）** In-the-Flow Agentic System Optimization for Effective Planning and Tool Use

🔗 https://arxiv.org/abs/2510.05592

💡 **核心贡献**
提出 AgentFlow 框架，将 Agentic 系统分解为规划器/执行器/验证器/生成器四个专化模块，通过动态记忆协调，并在多轮交互循环内端到端训练规划器，解决了整体策略训练在长时序/多工具场景下扩展性差的问题。

🔧 **技术亮点**
- **Flow-GRPO 训练算法**：将多轮优化分解为一系列可处理的单轮策略更新，通过轨迹级奖励广播解决稀疏信用分配问题
- **组归一化优势**：稳定训练过程，防止梯度爆炸
- **7B 骨干超越 GPT-4o**：在 10 个基准上以小参数量实现更优性能

📊 **实验结果**
相比顶层基线，AgentFlow（7B）在搜索任务 +14.9%、Agentic 任务 +14.0%、数学 +14.5%、科学 +4.1%，整体超越 GPT-4o 等更大规模专有模型（ICLR 2026 Oral）。

🎯 **与 Agent/Routing 的关联**
Flow-GRPO 的模块化设计思路为多 Agent 系统中的子任务路由与分工提供了可训练的架构参考。

### 3. CAST：基于案例的 LLM 工具调用自适应推理校准

**（原文标题）** Case-Based Calibration of Adaptive Reasoning and Execution for LLM Tool Use

🔗 https://arxiv.org/abs/2605.15041

💡 **核心贡献**
提出 CAST 框架，将历史工具执行轨迹视为结构化案例库，从中提取复杂度画像（估算最优推理策略）与失败画像（预测结构性错误），通过细粒度奖励设计让模型在强化学习中自主内化案例知识。

🔧 **技术亮点**
- **双画像提取**：复杂度画像 + 失败画像共同驱动推理深度动态调节
- **自适应推理长度控制**：根据任务难度自动决定"深思熟虑"还是"快速响应"
- **BFCLv2 & ToolBench 双测验证**：在工具调用模式保真度和任务成功率上均提升

📊 **实验结果**
整体执行精度提升最高 5.85 个百分点，平均推理长度缩短 26%，显著降低高影响力结构性错误（2026-05-14 提交）。

🎯 **与 Agent/Routing 的关联**
CAST 的难度感知推理路由机制直接对应 LLM Routing 的核心问题：根据查询复杂度动态分配计算资源。

### 4. 动态模型路由与级联：高效 LLM 推理综述

**（原文标题）** Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首个系统梳理跨多个独立训练 LLM 的动态路由与级联方法的综述，提出三维度概念框架（决策时机 × 使用信息 × 计算方式），揭示实际系统往往是多路由范式的组合体。

🔧 **技术亮点**
- **7 大路由范式**：查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联
- **三维概念框架**：When（何时决策）× What（用什么信息）× How（如何计算），统一分析不同方法
- **实践指导**：指出最优路由策略高度依赖部署约束，设计良好的路由系统可超越最强单一模型

📊 **实验结果**
综述性论文，通过横向对比实验证明设计合理的路由系统在效率-性能帕累托前沿上优于静态模型选择（Trinity College Dublin & Huawei Ireland，2026-02-23 首发）。

🎯 **与 Agent/Routing 的关联**
直接对应 LLM Routing 主题，为构建 Agent 推理时的模型选择系统提供完整的方法论图谱。

## 🧠 今日洞察

**Agent 记忆正从"能记住"走向"善用记忆"**：MemoryArena 揭示了当前评测与真实场景的鸿沟——在长上下文召回上近乎满分的模型，在需要跨会话行动的任务中依然频繁失败，说明"记得住"与"用得好"是两个截然不同的能力维度。

**工具调用进入"自适应计算"阶段**：CAST 和 AgentFlow 都指向同一趋势——固定深度推理已不适合异构工具任务，系统需要根据任务复杂度动态调节推理资源，这与 LLM Routing 的核心目标高度同构。

**Routing 研究格局初步成型**：从2025年底到2026年5月，路由研究已从"能不能路由"演进到"如何设计鲁棒的多范式组合路由"，跨模型、跨模态、跨场景的通用路由框架有望成为下一个研究热点。
