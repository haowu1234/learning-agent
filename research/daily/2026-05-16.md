📄 **[规划器很重要！高效不均衡多智能体协同框架用于长程任务规划]**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
提出三角色多智能体框架（规划器、执行器、记忆管理器），通过系统性计算分配分析揭示规划器是决定任务性能的主导因素。引入以规划器为中心的强化学习方法，仅优化规划器（使用 VLM-as-Judge 的轨迹级奖励），冻结其他组件，实现高效的长程自动化改进。

🔧 **技术亮点**
- 三角色解耦设计：Planner（高层决策）+ Actor（任务执行）+ Memory Manager（上下文推理）
- 计算资源不均衡分配：规划器获得更多算力/模型容量，执行和记忆模块用更小模型即可竞争
- VLM-as-Judge 轨迹级奖励机制，通过强化学习专项优化规划能力

📊 **实验结果**
在覆盖 Web 导航、操作系统控制、工具使用的多个 benchmark 上验证，以更少的计算资源取得更优的长程 Agent 性能提升。

🎯 **与 Agent/Routing 的关联**
直接回答了多 Agent 系统中「哪个角色最值得投入计算」这一核心问题，对 Agent 资源路由和架构设计具有高指导价值。

📄 **[MEMAUDIT：有预算约束下长期 LLM 记忆写入的精确评估协议]**
（MEMAUDIT: An Exact Package-Oracle Evaluation Protocol for Budgeted Long-Term LLM Memory Writing）

🔗 https://arxiv.org/abs/2605.02199

💡 **核心贡献**
提出 MEMAUDIT 评估框架，将长期记忆写入问题形式化为有预算约束的有限可审计优化问题，使用 MILP 认证的分支定界法计算精确最优解，解耦了此前评估中记忆写入与检索、读取混在一起的问题。

🔧 **技术亮点**
- Package-Oracle 协议：固定经验流、候选记忆表示、存储开销、语义证据单元和未来查询需求，构建可认证分母
- 凹函数-模函数语义覆盖目标，在存储预算和每条经验最多一种表示的约束下优化
- 支持对 Mem0、A-Mem、Letta 等主流记忆系统进行横向评分

📊 **实验结果**
在受控精确包、有效性压力测试、人工审核自然切片等多类测试中，MEMAUDIT 能定位出端到端 QA 无法区分的表示质量、有效性保留和预算感知选择效应差异。

🎯 **与 Agent/Routing 的关联**
为 Agent 长期记忆的科学评估奠定基准，直接影响记忆增强型 Agent 系统的设计与优化方向。

📄 **[AgeMem：统一长短期记忆管理的 Agent 记忆框架]**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）

🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem 统一框架，将长期记忆（LTM）和短期记忆（STM）管理直接整合进 Agent 策略，通过工具调用形式暴露记忆操作（存储/检索/更新/摘要/丢弃），实现端到端优化。引入三阶段渐进式强化学习策略和逐步 GRPO 算法，解决记忆操作引起的稀疏且不连续奖励问题。

🔧 **技术亮点**
- 记忆操作工具化：LLM Agent 自主决定何时存储/检索/更新/摘要/丢弃信息
- 三阶段渐进式 RL 训练策略，逐步习得统一记忆管理行为
- 逐步 GRPO（Group Relative Policy Optimization）应对记忆操作的稀疏奖励挑战

📊 **实验结果**
在 5 个长程 benchmark 上，AgeMem 在多种 LLM 骨干上一致优于强记忆增强基线，取得更高任务性能、更优质的长期记忆和更高效的上下文使用率。

🎯 **与 Agent/Routing 的关联**
统一记忆管理与 Agent 策略的深度融合为长程 Agent 核心能力提供了关键支撑，与规划层的路由协作形成完整闭环。

📄 **[Route-To-Reason：LLM 与推理策略的自适应联合路由框架]**
（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）

🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
提出 RTR（Route-To-Reason）统一路由框架，在预算约束下同时动态选择适合的语言模型和推理策略，学习专家模型与推理策略的压缩表示，实现二者的联合自适应选择，支持即插即用扩展到任意黑/白盒模型。

🔧 **技术亮点**
- 双维度联合路由：同时路由「选哪个 LLM」和「用哪种推理策略」，而非分开优化
- 压缩表示学习：对模型能力和策略特征分别编码，支持低开销推理时决策
- 即插即用：可无缝扩展到新的黑盒或白盒模型，无需重新训练整个系统

📊 **实验结果**
在 7 个开源模型 × 4 种推理策略的组合实验中，RTR 在所有基线中达到精度与计算效率的最优权衡：**准确率高于最佳单模型，同时减少超过 60% 的 Token 用量**。

🎯 **与 Agent/Routing 的关联**
直接针对 LLM Routing 核心问题，将模型选择与推理策略联合优化，是本方向最具实验说服力的近期工作之一。

## 🧠 今日洞察

1. **记忆系统走向精细化工程**：从 AgeMem 的端到端统一框架到 MEMAUDIT 的精确评估协议，Agent 记忆领域正从"能不能用"转向"用得有多好、怎么衡量"，评估基础设施建设成为新焦点。

2. **计算资源的不均衡分配是关键杠杆**：Planner Matters! 的发现极具实践价值——在多 Agent 系统中，把算力集中在规划层而非均匀分配，能以更低成本获得更大收益，这对实际部署有直接指导意义。

3. **Routing 从单维扩展到多维联合优化**：RTR 将模型选择与推理策略解耦再联合优化的思路，预示着 LLM Routing 研究将从"选模型"演进为"选(模型, 策略, 资源)组合"的多目标优化问题。
