### 1. 规划器才是关键！面向长时程规划的高效非对称多智能体协作框架
**Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning**

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
提出三角色分工（Planner / Actor / Memory Manager）的多智能体框架，通过系统性计算分配分析，揭示"规划"是决定任务成败的主导因素。基于此提出以规划器为中心的 RL 方法，仅优化 Planner 而冻结其余组件，在保持高性能的同时大幅降低计算开销。

🔧 **技术亮点**
- 三模块解耦设计：Planner 负责高层决策、Actor 执行具体操作、Memory Manager 管理上下文
- 使用 VLM-as-Judge 产生轨迹级奖励，进行 Planner-centric 强化学习
- 计算分配实验证明：Planner 需要最大算力，Actor 和 Memory 以小模型即可媲美

📊 **实验结果**
在 Web 导航、OS 控制、Tool Use 三类 Benchmark 上均取得 SOTA 或持平结果，且总推理计算量显著低于全模型 RL 优化基线。

🎯 **与 Agent/Routing 的关联**
直接验证了 Agent 系统中"计算异构分配"策略的价值，为按能力动态路由子模块提供了实证基础。

### 2. RL 能让 LLM 学会长时程推理吗？表达能力是关键
**Can RL Teach Long-Horizon Reasoning to LLMs? Expressiveness Is Key**

🔗 https://arxiv.org/abs/2605.06638

💡 **核心贡献**
引入 ScaleLogic 合成逻辑推理框架，独立控制"推理深度（Horizon）"和"逻辑表达能力"两个维度，系统研究 RL 训练计算量如何随任务难度缩放。研究证明 LLM 长时程推理的短板并非架构性限制，可通过训练方法改进来克服。

🔧 **技术亮点**
- 双轴控制实验设计：推理深度（D）× 逻辑表达性（简单 if-then → 全一阶逻辑）
- 发现训练计算量 T 与推理深度 D 满足幂律：T ∝ D^γ，R² > 0.99
- 课程学习（Curriculum Training）显著提升 RL 缩放效率

📊 **实验结果**
更高表达性的训练设置在下游数学/推理 Benchmark 上带来最高 +10.66 点增益，且计算迁移效率更高；缩放指数 γ 从 1.04（低表达）升至 2.60（高表达），量化了任务复杂度对训练成本的影响。

🎯 **与 Agent/Routing 的关联**
为长时程 Agent 的训练课程设计和难度自适应调度（Routing by difficulty）提供了理论依据。

### 3. MASPO：面向 LLM 多智能体系统的联合 Prompt 优化
**MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems**

🔗 https://arxiv.org/abs/2605.06623

💡 **核心贡献**
提出 MASPO 框架，解决多智能体系统中各 Agent Prompt 局部优化与全局系统目标不一致的问题。通过联合评估机制和数据驱动的进化束搜索，自动迭代优化整个 MAS 中所有 Agent 的 Prompt，无需 ground-truth 标签。

🔧 **技术亮点**
- 联合评估机制：以 Prompt 对下游 Agent 成功率的贡献作为优化信号，而非单 Agent 局部指标
- 数据驱动进化束搜索（Evolutionary Beam Search）高效探索高维 Prompt 空间
- 框架无侵入：不改变 MAS 拓扑结构，适用于任意角色编排系统

📊 **实验结果**
在 6 个多样化任务上超越 SOTA Prompt 优化方法，平均准确率提升 2.9 个百分点；已被 ICML 2026 接收。

🎯 **与 Agent/Routing 的关联**
系统级 Prompt 优化本质上是一种"软路由"——通过优化每个 Agent 的指令使其更好地衔接任务流，与 LLM Routing 的目标高度一致。

### 4. 动态模型路由与级联：面向高效 LLM 推理的综述
**Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey**

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首篇系统梳理多 LLM 路由与级联方法的综述，涵盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态等多种路由范式，并提出三维分类框架（决策时机 × 信息来源 × 计算方式）。

🔧 **技术亮点**
- 区别于 MoE（单模型内路由），专注于跨独立训练 LLM 的外部路由
- 三维框架：When（决策时机）/ What（路由依据）/ How（计算方式），揭示实际系统的复合性
- 覆盖级联策略（Cascading）：从小模型到大模型渐进式调用，兼顾质量与成本

📊 **实验结果**
综述显示，设计良好的路由系统可超越单一最强模型的表现，同时大幅降低推理成本；但跨架构/模态的泛化能力仍是开放挑战。

🎯 **与 Agent/Routing 的关联**
本文是 LLM Routing 领域的权威综述，直接覆盖核心 Routing 技术全貌，是构建自适应推理系统的必读参考。

## 🧠 今日洞察

当前 Agent 研究呈现出**"异构化"与"自优化"**两大核心趋势：一方面，研究者开始打破"每个组件同等重要"的假设，转向计算资源的精准分配（Planner Matters 论文证明规划器主导性能），这与 LLM Routing 中"按难度分配模型"的逻辑高度同构；另一方面，Agent 系统的自我进化能力（SkillOS 的技能积累、MASPO 的 Prompt 联合优化）正在从"手工调优"走向"数据驱动的闭环迭代"。长时程推理的瓶颈被证明可通过训练方法突破（非架构限制），为更复杂 Agent 任务的落地提供了信心支撑。
