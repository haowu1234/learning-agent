📄 **【AgeMem】统一长短期记忆管理的 Agent 框架**（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885
💡 **核心贡献**
AgeMem 提出了将长期记忆（LTM）与短期记忆（STM）统一纳入 Agent 策略的端到端框架，彻底摒弃了传统的启发式辅助控制器方案。通过把记忆操作（存储/检索/更新/摘要/丢弃）暴露为工具级 Action，让 LLM 自主决策记忆的全生命周期管理。
🔧 **技术亮点**
- 记忆操作以 tool-based actions 形式集成进 Agent 策略，实现端到端可微优化
- 提出三阶段渐进强化学习策略，专门应对记忆操作导致的稀疏/非连续奖励
- 设计 step-wise GRPO（Group Relative Policy Optimization）解决奖励不连续问题
📊 **实验结果**
在 5 个长时程 Benchmark 上，AgeMem 持续优于强记忆增强 Baseline，在多个 LLM backbone 下均实现更高任务性能、更高质量长期记忆与更高效上下文利用率。
🎯 **与 Agent/Routing 的关联**
直接解决 Agent 长时程推理的核心瓶颈——有限上下文窗口下的记忆管理问题，为 Long-Horizon Agent 设计提供新范式。

📄 **【ODAR-Expert】基于主动推理的 LLM 自适应路由框架**（ODAR: Principled Adaptive Routing for LLM Reasoning via Active Inference）
🔗 https://arxiv.org/abs/2602.23681
💡 **核心贡献**
ODAR-Expert 采用摊销式主动推理（Amortized Active Inference）难度估计器，在"快速启发式 Agent"与"慢速深思 Agent"之间动态路由查询，并通过自由能原理融合异构模型输出。无需训练即可实现原则性自适应资源分配。
🔧 **技术亮点**
- 基于自由能（Free-Energy Principle）的答案融合策略，整合异构模型输出
- 训练无关（training-free）的难度估计器，在推理时零开销评估查询复杂度
- 双速 Agent 架构：Fast Heuristic + Slow Deliberative，实现计算预算自适应分配
📊 **实验结果**
在 MATH Benchmark 上达到 98.2% 精度，在 Humanity's Last Exam 上达到 54.8%；在 23 个 Benchmark 上将计算成本降低 82%，同时提升 compute-accuracy 前沿。
🎯 **与 Agent/Routing 的关联**
代表 LLM Routing 从"基于规则分流"升级为"基于主动推理动态分配"的范式转变，直接优化推理效率与精度的 Pareto 前沿。

📄 **【工具进化综述】LLM Agent 工具使用：从单工具调用到多工具编排**（The Evolution of Tool Use in LLM Agents: From Single-Tool Call to Multi-Tool Orchestration）
🔗 https://arxiv.org/abs/2603.22862
💡 **核心贡献**
系统综述 Multi-Tool LLM Agent 的最新进展，将问题框架从"孤立调用"重新定义为"长时程轨迹上的多工具编排"，涵盖推理时规划、训练策略、安全控制、资源效率等六大维度。
🔧 **技术亮点**
- 统一任务形式化定义，明确区分单次工具调用与长时程编排的本质差异
- 从六维度（推理规划、训练轨迹、安全控制、效率约束、能力评估、应用场景）组织文献
- 揭示工具编排三阶段演进路径：S1 单工具 → S2 串行多工具 → S3 动态 DAG 编排
🎯 **与 Agent/Routing 的关联**
为 Agent Tool-Use 领域提供全景地图，"工具编排"本质上是 Agent 决策层的 Routing 问题——在何时调用哪个工具、如何组合，与 LLM Routing 研究高度交叉。

📄 **【动态 LLM 路由综述】高效 LLM 推理的动态模型路由与级联方法**（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）
🔗 https://arxiv.org/abs/2603.04445
💡 **核心贡献**
系统梳理多 LLM 路由与级联方法，提出路由系统的三维分析框架（"何时决策 / 使用什么信息 / 如何计算"），覆盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联等七大路由范式。
🔧 **技术亮点**
- 提出三维路由框架（When / What / How），揭示实际系统是多范式的组合体
- 深入分析 MoE 内部路由 vs. 跨独立 LLM 路由的本质区别
- 总结路由系统需在性能、成本、延迟间进行多目标权衡的核心挑战
📊 **实验结果**
综述显示：设计良好的路由系统可通过战略性利用跨模型的专项能力，超越单一最强模型的性能表现。
🎯 **与 Agent/Routing 的关联**
直接定义并系统化 LLM Routing 研究领域，是 Multi-LLM 系统架构设计的权威参考，对构建高性价比 Agent 基础设施具有直接指导意义。

## 🧠 今日洞察

1. **记忆从"工具"升级为"策略"**：AgeMem 代表的统一记忆框架标志着 Agent Memory 研究进入新阶段——记忆不再是外挂模块，而是 Agent 决策策略的一部分，端到端强化学习使记忆管理本身成为可优化目标。

2. **Routing 从规则走向推理**：ODAR-Expert 用主动推理原理替代硬编码路由规则，而 Dynamic Routing Survey 则揭示实际部署中路由系统必须组合多种范式——这两篇合力表明 LLM Routing 正向"自适应、可解释、多目标"方向演进。

3. **工具编排是 Agent 研究的统一战场**：Multi-Tool Survey 的出现说明工具使用已从技术细节升华为 Agent 架构核心问题，Planning × Routing × Tool Orchestration 三者边界持续模糊，统一框架的需求愈发迫切。
