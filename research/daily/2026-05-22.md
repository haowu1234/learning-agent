📄 **MemGym：面向长时域任务的 LLM Agent 记忆评估环境**（MemGym: a Long-Horizon Memory Environment for LLM Agents）
🔗 https://arxiv.org/abs/2605.20833
💡 核心贡献
- 提出 MemGym 统一评测框架，将现有 Agent gym（tau2-bench、SWE-Gym、WebArena-Infinity 等）整合为单一记忆推理接口，覆盖工具对话、深度研究、代码、计算机操控四类 Agent 场景。
- 引入"记忆隔离得分"（memory-isolated score），将记忆能力从推理、检索、工具使用中解耦，使不同记忆策略可以公平比较。

🔧 技术亮点
- 五条评测赛道：tau2-bench（工具对话）/ MEMGYM-DR（多轮深度检索）/ SWE-Gym + MEMGYM-CODEQA（代码）/ WebArena-Infinity（计算机操控）
- 合成流水线长度可控，每阶段均有消融验证，确保评测紧贴下游真实场景
- 训练 MemRM（Qwen3-1.7B + QLoRA 微调）作为压缩质量奖励模型，替代完整 Docker rollout，大幅降低评测成本

📊 实验结果
- MemRM 作为轻量奖励代理，成功解决 coding 环境学术评测可行性问题（避免重量级 Docker 依赖）

🎯 与 Agent/Routing 的关联
该工作直接推动 Agent Memory 基础设施标准化，为不同记忆策略（向量 / 图 / 分层）的工程选型提供可信基准。

📄 **DeepWeb-Bench：要求大规模跨源证据与长链推导的深度研究基准**（DeepWeb-Bench: A Deep Research Benchmark Demanding Massive Cross-Source Evidence and Long-Horizon Derivation）
🔗 https://arxiv.org/abs/2605.21482
💡 核心贡献
- 针对前沿深度研究 Agent 在现有基准上趋于饱和的问题，构建了一个难度显著更高的评测集，每题须完成大规模证据收集、跨源信息调和与多步长链推导。
- 将难度分解为四类能力维度（Retrieval、Derivation、Reasoning、Calibration）并按维度报告结果，同时附带来源溯源记录，使得错误归因更为精确。

🔧 技术亮点
- 每道参考答案配备四级披露来源溯源记录（source-provenance record）与跨源核验
- 在 9 个前沿模型上全面评测（含 GPT-4o、Claude 3.7、Gemini 2.5 等级别）
- 公开数据集 + 评测代码 + Rubric，支持社区复现

📊 实验结果
- 检索失败仅占错误的 12-14%，而推导与校准失败占比超过 70%（颠覆"检索是瓶颈"的传统认知）
- 强弱模型失败模式质性不同：强模型主要因推导不完整失败，弱模型主要因幻觉精度失败
- 模型间跨任务一致性仅 ρ=0.61，单任务分歧高达 18.8 百分点，说明模型存在显著专业化差异

🎯 与 Agent/Routing 的关联
Routing 系统的选模策略可从本研究获益：不同模型在 Retrieval / Derivation / Calibration 维度的差异性，是构建能力感知路由器的重要依据。

📄 **Agentic Plan-Execute 流水线中的时序语义缓存与工作流优化**（Evaluating Temporal Semantic Caching and Workflow Optimization in Agentic Plan-Execute Pipelines）
🔗 https://arxiv.org/abs/2605.20630
💡 核心贡献
- 针对工业资产运维场景（AssetOpsBench），识别 Plan-Execute Agent 流水线中工具发现、LLM 规划、MCP 工具执行四大开销来源，提出时序语义缓存 + MCP 工作流优化两层互补方案。
- 揭示纯语义缓存在参数敏感工业查询场景下的关键失效模式，为 MCP 支撑的 Agent 基准评测提供重要方法论参考。

🔧 技术亮点
- 时序语义缓存（temporal semantic cache）：在嵌入相似度基础上叠加时间窗口与资产参数约束，避免过期缓存导致评测错误
- 磁盘级工具发现缓存 + 依赖感知并行步骤执行（dependency-aware parallel execution）组合
- 在 AssetOpsBench（AOB）工业 Agent 基准上完整评测，13 页论文 + 8 图 + 3 附录

📊 实验结果
- MCP 工作流优化：端到端延迟中位数降低 **40.0%**，整体 **1.67×** 加速
- 时序缓存命中时中位数加速达 **30.6×**

🎯 与 Agent/Routing 的关联
MCP 工具发现缓存 + 并行规划执行的思路，可直接移植至多 Agent 编排系统中的 Tool Routing 层，显著降低调度开销。

📄 **动态模型路由与级联：高效 LLM 推理综述**（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）
🔗 https://arxiv.org/abs/2603.04445
💡 核心贡献
- 系统梳理跨多个独立 LLM 的动态路由与级联方法（区别于 MoE 模型内部路由），覆盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联七大范式。
- 提出三维概念框架：**何时**做路由决策 × **使用何种信息** × **如何计算**，揭示实际系统通常是多范式组合的复合体。

🔧 技术亮点
- 七大路由范式全面覆盖，每类提供代表方法与关键 trade-off 分析
- 指出路由系统需在性能、成本、延迟之间平衡竞争目标，最优策略取决于部署约束
- 开放挑战：跨架构/跨模态通用路由机制仍是未解问题

📊 实验结果
- 综述结论：精心设计的路由系统可超过最强单一模型，通过跨模型专业化能力的战略性调用实现效率最大化

🎯 与 Agent/Routing 的关联
本综述是构建 LLM Routing 系统的必读参考，三维框架可直接用于指导工程架构设计。

## 🧠 今日洞察

1. **记忆成为 Agent 基础设施的核心度量维度**：MemGym 的出现标志着 Agent Memory 评测进入标准化阶段——不再满足于"有没有记忆"，而是要精确量化记忆能力对不同下游任务的贡献。

2. **"检索不是瓶颈"是今日最反直觉的发现**：DeepWeb-Bench 数据清晰表明，在复杂深度研究任务中，推导与校准失败占错误 70%+，而非检索本身——这对 RAG 系统的优化重心有重要指向意义。

3. **Routing 从"选模型"走向"选策略+选模型"**：今日路由相关工作（Survey + COAgents + 缓存优化）共同指向一个趋势：下一代路由系统不仅要按查询难度选择模型，还需感知工具、缓存状态、任务类型，走向全栈自适应推理编排。
