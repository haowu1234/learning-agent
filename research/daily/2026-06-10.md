📄 **[GraphPlanner：图记忆增强的多智能体路由框架]**（GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs）
🔗 https://arxiv.org/abs/2604.23626
💡 核心贡献：提出 GraphPlanner，一种异构图记忆增强的路由框架，将任务依赖和 Agent 能力建模为二部图，实现更智能的多 Agent 查询分发。通过图神经网络在任务-能力图上传播信息，动态生成每个查询的最优路由工作流。
🔧 技术亮点：
- 异构二部图建模：节点表示任务与能力，边编码前置依赖和适配度分数
- 图神经网络（GNN）作为路由决策主干，支持端到端强化学习训练
- 图记忆持久化历史路由经验，提升冷启动和复杂任务的规划质量
📊 实验结果：在多 Agent 基准上，路由准确率和任务完成率均显著优于基于 LLM prompt 的路由方案；初始版本于 2026.02 发布并开源（github.com/ulab-uiuc/GraphPlanner）
🎯 与 Agent/Routing 的关联：直接解决多 Agent 系统中的智能路由问题，是 Agent Routing 与图记忆融合的代表性工作。

📄 **[规划者至关重要！高效非对称多智能体长时域协作框架]**（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）
🔗 https://arxiv.org/abs/2605.02168
💡 核心贡献：提出"非对称"多 Agent 框架，将长时域任务分解为 Planner（高层决策）、Actor（任务执行）、Critic（反馈校验）三种角色，专用 Planner 负责全局规划，其他 Agent 专注执行，避免计算资源的均匀浪费。通过角色分工打破了传统对称多 Agent 框架在复杂任务中的瓶颈。
🔧 技术亮点：
- 非对称角色设计：Planner 使用大模型，Actor/Critic 可使用轻量模型，显著降低推理成本
- Planner 负责任务拆解与依赖图构建，Actor 并行执行子任务，Critic 动态校验执行结果
- 引入进度感知的重规划机制，遭遇执行失败时 Planner 自动修订计划
📊 实验结果：在长时域任务自动化基准上，任务完成率比对称多 Agent 基线提升约 18%，同等性能下计算成本降低约 30%
🎯 与 Agent/Routing 的关联：为多 Agent 系统提供了高效的角色路由与任务分发思路，Planner 本身即是轻量化路由决策的体现。

📄 **[MemFlow：面向小语言模型智能体的意图驱动记忆编排框架]**（MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents）
🔗 https://arxiv.org/abs/2605.03312
💡 核心贡献：提出 MemFlow，一种无需训练的记忆编排框架，将记忆规划从 SLM（小语言模型）中外化，以意图驱动的方式动态决定何时读写记忆、选择哪种记忆类型，大幅提升小模型 Agent 在复杂任务中的长期记忆利用效率。
🔧 技术亮点：
- 训练免费（Training-Free）设计：无需微调，可直接插件式接入任意 SLM Agent
- 意图感知记忆路由：根据当前任务意图分类选择情节记忆、语义记忆或程序记忆
- 记忆生命周期管理：自动压缩、归档和遗忘无关记忆，避免上下文窗口溢出
📊 实验结果：在多项长任务基准上，MemFlow 使 7B 级 SLM 的任务完成率接近 70B 模型水平，上下文利用效率提升显著
🎯 与 Agent/Routing 的关联：直接解决 Agent 记忆管理的核心痛点，意图驱动的记忆路由思路对大模型 Agent 同样有参考价值。

📄 **[OrcaRouter：混合离线-在线学习的生产级 LLM 路由器]**（OrcaRouter: A Production-Oriented LLM Router with Hybrid Offline-Online Learning）
🔗 https://arxiv.org/abs/2605.30736
💡 核心贡献：提出 OrcaRouter，一种面向生产环境的 LLM 路由系统，结合 LinUCB 上下文 Bandit 算法与词法+句子嵌入特征，通过混合离线预训练+在线强化学习实现动态最优模型选择。在保证质量的前提下，将昂贵大模型调用比例大幅压缩。
🔧 技术亮点：
- LinUCB 上下文 Bandit：利用查询特征进行探索-利用权衡，持续学习最优路由策略
- 混合学习架构：离线阶段用历史日志训练初始路由策略，在线阶段根据用户反馈实时更新
- 生产级设计：支持多模型池管理、低延迟决策（<5ms）、可配置成本-质量权衡
📊 实验结果：OrcaRouter-Adaptive 在多个生产评测集上，质量媲美全量使用 GPT-4 级模型，同时将高成本模型调用比例降低约 60%
🎯 与 Agent/Routing 的关联：为 LLM Routing 提供了工业级的完整解决方案，Bandit + 在线学习的组合是当前最具可行性的路由框架之一。

## 🧠 今日洞察

当前 Agent 与 Routing 研究呈现出两大融合趋势：**图结构记忆**正被引入路由决策（GraphPlanner），使 Agent 能够基于历史经验做出更优的任务分发，而非纯粹依赖即时提示；**非对称角色分工**（Planner Matters!）与**意图驱动的资源分配**（MemFlow、OrcaRouter）则共同指向同一核心洞见——并非所有 Token 都应等同对待，智能的差异化分配才是提升效率的关键。从 SLM 的记忆外化到生产级路由的 Bandit 学习，研究界正在快速收敛于一个共识：**下一代 Agent 系统的竞争力，将在很大程度上取决于其记忆与路由机制的精细程度**。
