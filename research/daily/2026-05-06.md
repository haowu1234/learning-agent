📄 **工具注意力机制：动态工具门控与惰性 Schema 加载，消除可扩展 Agentic 工作流中的 MCP/Tools Tax**
（Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP/Tools Tax in Scalable Agentic Workflows）

🔗 https://arxiv.org/abs/2604.21816

💡 **核心贡献**
- MCP 协议每次调用注入 10k–60k tokens 的 schema，形成严重"工具税"开销，本文提出 Tool Attention 中间件机制来动态过滤工具调用。
- 通过意图-模式重叠评分（ISO）+ 状态感知门控 + 两阶段惰性加载，将每轮工具 tokens 降低 95%，有效上下文利用率从 24% 提升至 91%。

🔧 **技术亮点**
- **Intent Schema Overlap (ISO) 评分**：基于句子嵌入计算请求意图与工具 schema 的语义重叠度，仅保留相关工具
- **状态感知门控函数**：在工具调用前检查前置条件和访问权限，避免无效调用
- **两阶段惰性 Schema 加载器**：上下文常驻摘要池，只对 top-k 工具加载完整 JSON Schema

📊 **实验结果**
- 在 120 工具、6 服务器的模拟基准上：工具 tokens 从 47.3k → 2.4k（减少 95%）
- 有效上下文利用率：24% → 91%
- 代码：https://github.com/asadani/tool-attention

🎯 **与 Agent/Routing 的关联**：直接解决了多工具 Agent 的上下文效率瓶颈，提出了"协议层效率而非原始上下文长度才是可扩展 Agentic 系统关键约束"这一核心命题。

📄 **DiffMAS：学会通信——多智能体语言系统的端到端优化**
（Learning to Communicate: Toward End-to-End Optimization of Multi-Agent Language Systems）

🔗 https://arxiv.org/abs/2604.21794

💡 **核心贡献**
- 现有多智能体系统将智能体间通信固定为文本接口，本文将通信机制本身改造为可学习组件。
- 提出 DiffMAS 框架，对多智能体潜在轨迹进行参数高效的监督训练，使智能体联合学习如何跨交互编码和解释信息。

🔧 **技术亮点**
- **潜在通信（Latent Communication）**：用内部 KV Cache 表示替代文本协议，降低通信成本同时提升信息密度
- **端到端联合优化**：通信机制与推理过程共同训练，而非分离优化
- **参数高效**：在不大幅增加参数的前提下实现跨智能体的表示共享

📊 **实验结果**
- AIME24：26.7%（超越基线多智能体方法）
- GPQA-Diamond：20.2%
- 在数学推理、科学QA、代码生成、常识推理四类基准上全面超越文本多智能体系统
- 投稿 COLM 2026，审稿中

🎯 **与 Agent/Routing 的关联**：DiffMAS 将多智能体协作通信抽象为可路由的潜在表示，为多 Agent 系统中的"信息路由"问题提供了新的优化范式。

📄 **HiAgent：层次化工作记忆管理，解决大语言模型的长程 Agent 任务**
（HiAgent: Hierarchical Working Memory Management for Solving Long-Horizon Agent Tasks with Large Language Model）

🔗 https://aclanthology.org/2025.acl-long.1575/

💡 **核心贡献**
- 现有 LLM Agent 将历史动作-观察对全量输入，导致长程任务中上下文冗余严重；HiAgent 引入子目标作为记忆块来分层管理工作记忆。
- 让 LLM 在生成动作前先制定子目标，并主动决策用摘要替换历史子目标，只保留当前子目标相关的动作-观察对。

🔧 **技术亮点**
- **子目标分块（Subgoal Chunking）**：将任务分解为子目标序列，作为工作记忆的最小管理单元
- **主动记忆压缩**：Agent 自主决定何时用摘要替换历史子目标信息，而非依靠截断
- **跨任务泛化**：在 5 个不同的长程任务上均显著改善，体现方法通用性

📊 **实验结果**
- 成功率提升 2 倍
- 平均完成步骤数减少 3.8 步
- 在 5 个长程任务上表现稳健，体现鲁棒性
- 代码：https://github.com/HiAgent2024/HiAgent（ACL 2025）

🎯 **与 Agent/Routing 的关联**：通过层次化记忆管理在长程任务中实现了隐式的"注意力路由"，决定哪些历史信息值得保留传递给下一步推理。

📄 **BEST-Route：基于测试期最优算力的自适应 LLM 路由**
（BEST-Route: Adaptive LLM Routing with Test-Time Optimal Compute）

🔗 https://openreview.net/forum?id=tFBIbCVXkG

💡 **核心贡献**
- 传统 LLM 路由仅从单一模型生成一个回复，廉价小模型单次输出质量不稳定；BEST-Route 引入"对小模型多次采样取最优"策略，在质量与成本间取得更优权衡。
- 根据查询难度和质量阈值动态选择模型及采样次数，实现测试期最优算力分配。

🔧 **技术亮点**
- **难度感知路由**：根据查询复杂度动态分配算力，简单查询转发廉价小模型，复杂查询路由至大模型
- **Best-of-N 采样策略**：对小模型生成 N 个回复后选择最优，通常优于大模型单次输出且成本更低
- **多头路由器（Multi-headed Router）**：同时预测最优模型选择和采样数量

📊 **实验结果**
- 成本降低最高 60%，性能下降不超过 1%
- 在真实数据集上验证（ICLR 2026 投稿）
- 代码：https://github.com/microsoft/best-route-llm

🎯 **与 Agent/Routing 的关联**：BEST-Route 是本期最直接的 LLM Routing 研究，通过测试期算力优化实现质量-成本的帕累托最优，对生产级多模型部署具有极高实用价值。

## 🧠 今日洞察

**趋势一：效率成为 Agentic 系统核心议题。** 从 Tool Attention 对 MCP Schema 开销的精确量化，到 HiAgent 对工作记忆的主动压缩，再到 BEST-Route 的测试期算力优化——研究者正在从"能做到"转向"低成本做到"，协议层和推理层的效率优化将成为 2026 年 Agent 落地的关键战场。

**趋势二：通信与路由的可学习化。** DiffMAS 将多智能体通信从固定文本协议升级为可端到端训练的潜在表示，BEST-Route 将路由决策本身变成预测性分类问题——两者共同指向同一方向：系统内部的"信息流动"正从规则驱动走向数据驱动。

**趋势三：Agent 记忆管理进入精细化阶段。** 不再满足于"存所有历史"或"截断历史"，HiAgent 展示了主动式、语义感知的分层记忆管理——这与人类解决问题时的认知策略高度吻合，预示着记忆压缩与检索的协同优化将成为长程 Agent 的标配能力。
