### 1. 规划器是关键！长视野规划的高效非对称多智能体协作框架
**原文标题**：Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
通过系统性计算分配分析，揭示"规划"是影响 Agent 任务性能的主导因素，执行与记忆管理需要的算力远低于规划；在此洞察基础上提出以规划器为中心的强化学习方法，仅优化 Planner 模块（VLM-as-judge 提供轨迹级奖励），冻结其余组件。

🔧 **技术亮点**
- 三角色分解：Planner（高层决策）+ Actor（任务执行）+ Memory Manager（上下文推理）
- 非对称资源分配：将大模型算力集中在 Planner，Actor/Memory 使用更小模型
- 规划器专用 RL：用 VLM-as-judge 生成轨迹奖励，只更新 Planner 参数

📊 **实验结果**
在 Web Navigation、OS Control、Tool Use 三类基准上均取得 compute-efficient 的显著提升；代码已开源（2026-05-04 提交，cs.AI/cs.MA）。

🎯 **与 Agent/Routing 的关联**
直接揭示 Agent 系统中模块计算分配的最优路由原则——"把算力路由给规划器"是提升长视野任务的最有效策略。

### 2. MINTEval：多目标干扰下的长视野 Agent 记忆评估基准
**原文标题**：MINTEval: Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems

🔗 https://arxiv.org/abs/2605.18565

💡 **核心贡献**
指出现有基准仅测试静态、独立记忆召回，无法反映真实场景中记忆被频繁更新和相互干扰的挑战；提出 MINTEval，包含 15.6k QA 对，上下文均长 138.8k tokens（最大 1.8M tokens），涵盖状态跟踪、多轮对话、Wikipedia 修订、GitHub 提交四类领域。

🔧 **技术亮点**
- 干扰感知评测：同一上下文中信息被多次更新，测试记忆对早期事实的保留与推理
- 双任务类型：单目标召回（精确检索）+ 多目标聚合（跨片段推理）
- 超长上下文覆盖：最大实例达 1.8M tokens，压力测试现有记忆系统

📊 **实验结果**
评测 7 个代表性系统（Vanilla LLM / RAG / Memory-augmented agent），平均准确率仅 27.9%，多目标聚合任务表现尤其差；干扰更新越多、精度下降越显著。

🎯 **与 Agent/Routing 的关联**
为长视野 Agent 记忆模块的路由与检索策略提供了严苛的评测标准，揭示现有系统的关键瓶颈。

### 3. MASPO：LLM 多智能体系统的联合 Prompt 优化
**原文标题**：MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems

🔗 https://arxiv.org/abs/2605.06623

💡 **核心贡献**
现有多智能体系统中各 Agent 的 Prompt 独立优化，导致局部目标与全局目标错位；MASPO 提出联合评估机制——评估 Prompt 不仅看本 Agent 局部表现，还看能否促进后继 Agent 的下游成功，从而对齐局部交互与全局结果。

🔧 **技术亮点**
- 联合评估机制（Joint Evaluation）：无需 Ground-Truth 标签即可评估 Prompt 对下游影响
- 数据驱动演化束搜索（Evolutionary Beam Search）：高效探索高维 Prompt 空间
- 迭代自动精炼：全系统 Prompt 闭环优化，不依赖人工标注

📊 **实验结果**
在 6 个多样化任务上持续优于 SOTA 的 Prompt 优化方法，平均准确率提升 +2.9%；代码开源，已接收 ICML 2026。

🎯 **与 Agent/Routing 的关联**
MASPO 的联合评估思路与 LLM Routing 中的级联模型选择同构——两者都在解决如何让上游决策对下游效果负责的问题。

### 4. ODAR：基于主动推断的 LLM 推理自适应路由
**原文标题**：ODAR: Principled Adaptive Routing for LLM Reasoning via Active Inference

🔗 https://arxiv.org/abs/2602.23681

💡 **核心贡献**
现有 Best-of-N 等方法在简单问题上浪费算力、在复杂问题上触发过度推理；ODAR 用摊销主动推断（Amortized Active Inference）估计查询难度，动态将查询路由至 Fast Agent（启发式）或 Slow Agent（深度推理），并用自由能原则融合两路答案。

🔧 **技术亮点**
- 难度估计器：基于摊销主动推断，无需训练即可量化查询的认知难度
- 双智能体路由：Fast Agent（低成本启发式）+ Slow Agent（高质量深度推理）的二元决策
- 自由能融合（Free-Energy Fusion）：用变分自由能平衡对数似然与认知不确定性（varentropy），取代简单投票

📊 **实验结果**
23 个基准全面提升：MATH 达 98.2%，Humanity's Last Exam 达 54.8%；在完全开源栈（Llama 4 + DeepSeek）上验证，推理计算成本降低 82%；消融实验显示随机路由会使宏平均准确率下降 8.3%。

🎯 **与 Agent/Routing 的关联**
ODAR 是当前 LLM Routing 领域最具理论基础的工作之一，其 Fast/Slow 双 Agent 架构与 System 1/2 认知理论深度结合，为 Routing 提供了可解释的决策框架。

## 🧠 今日洞察

**趋势一：计算路由（Compute Routing）成为核心范式。** 无论是多智能体框架（Planner Matters!）还是推理加速（ODAR），研究者都在回答同一个问题：把有限算力"路由"到哪里才最有价值？这标志着 AI 系统从"堆参数"走向"精算力"。

**趋势二：记忆干扰是长视野 Agent 的致命弱点。** MINTEval 揭示主流系统在干扰更新场景下准确率平均仅 27.9%，这意味着现有 RAG 和记忆框架根本无法应对真实世界的动态信息流，记忆系统的鲁棒性将成为 2026 年下半年的研究热点。

**趋势三：多智能体协同优化从结构设计转向学习。** MASPO 的 ICML 2026 录用说明学术界正在承认"静态 Prompt 编排"的天花板，未来多智能体系统将越来越依赖端到端的联合优化而非人工角色设计。
