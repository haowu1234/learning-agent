📄 **【统一长短期记忆管理的 Agent 框架 AgeMem】**
（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885

💡 **核心贡献**
提出 AgeMem，将长期记忆（LTM）和短期记忆（STM）统一为 Agent 策略的一部分，通过工具化的记忆操作（存储/检索/更新/摘要/丢弃）实现端到端优化。采用三阶段渐进式强化学习 + 步级 GRPO 训练，解决记忆操作引发的稀疏奖励问题。

🔧 **技术亮点**
- 记忆操作暴露为 **tool-based actions**，Agent 自主决策何时/何内容写入或清除记忆
- **三阶段渐进式 RL**：逐步从简单到复杂任务训练记忆行为
- **步级 GRPO**（Group Relative Policy Optimization）专门处理记忆操作的不连续稀疏奖励

📊 **实验结果**
在5个长视野 Benchmark 上持续超越强记忆增强基线，跨多个 LLM 骨干均取得更高任务表现、更高质量长期记忆、更低上下文 token 占用。

🎯 **与 Agent/Routing 的关联**
直接解决长视野 Agent 的记忆管理瓶颈，为需要跨多轮工具调用的复杂 Agent 系统提供核心记忆组件。

📄 **【PEEK：面向重复上下文 LLM Agent 的方向感知缓存】**
（PEEK: Context Map as an Orientation Cache for Long-Context LLM Agents）
🔗 https://arxiv.org/abs/2605.19932

💡 **核心贡献**
提出 PEEK 系统，通过构建一个可复用的"上下文地图"（Context Map）作为方向感知缓存，让 Agent 在重复访问同一文档库/代码仓库时无需每次重新探索，大幅降低迭代次数与调用成本。

🔧 **技术亮点**
- **Distiller 模块**：从推理时信号中提取可迁移的方向感知知识（实体、常量、schema）
- **Cartographer 模块**：将提取知识转化为结构化的上下文地图编辑操作
- **Evictor 模块**：基于优先级的驱逐机制，强制维持固定 token 预算

📊 **实验结果**
长上下文推理与信息聚合任务上比强基线提升 **6.3–34.0%**，同时减少 **93–145 次迭代**，成本比 SOTA 提示学习框架 ACE 低 **1.7–5.8x**；Context Learning 中准确率提升 6–14%，成本降低 1.4x。

🎯 **与 Agent/Routing 的关联**
为需要反复处理同一外部上下文（代码库、文档）的 coding Agent（如 OpenAI Codex）提供高效的记忆持久化机制，是长视野 Agent 效率提升的关键路径。

📄 **【Route-To-Reason：LLM 与推理策略的自适应联合路由框架】**
（Route to Reason: Adaptive Routing for LLM and Reasoning Strategy Selection）
🔗 https://arxiv.org/abs/2505.19435

💡 **核心贡献**
提出 RTR（Route-To-Reason），将"选哪个模型"和"用哪种推理策略"合并为一个统一路由决策，根据任务难度与预算约束动态分配，同时解决大模型"过度思考"（overthinking）陷阱问题。

🔧 **技术亮点**
- 联合学习 **模型 × 推理策略** 的压缩嵌入表示，实现二维联合选择
- **Plug-and-Play**：无缝扩展到任意黑盒/白盒模型与策略，无需重训骨干
- **预算感知路由**：在给定 token 预算下寻找精度-效率最优解

📊 **实验结果**
在7个开源模型 × 4种推理策略的组合实验中，RTR 比最强单一模型精度更高，同时将 **token 使用量降低超过 60%**。

🎯 **与 Agent/Routing 的关联**
直接针对 LLM Routing 核心场景，将模型路由从"选模型"升级为"选模型+选策略"的二维联合优化，是本方向最新代表工作。

📄 **【生产级 LLM Agent 的运行时架构模式方法论】**
（A Methodology for Selecting and Composing Runtime Architecture Patterns for Production LLM Agents）
🔗 https://arxiv.org/abs/2605.20173

💡 **核心贡献**
提出"随机-确定性边界"（Stochastic-Deterministic Boundary, SDB）作为生产 Agent 运行时的核心原语，并围绕此构建6种运行时模式（层级委托、Scatter-Gather+Saga、事件驱动序列等），给出5步模式选择方法论。

🔧 **技术亮点**
- 定义 **SDB 四元组**（proposer/verifier/commit/reject）规范 LLM 输出如何成为系统动作
- 引入 **"重放发散"故障模式**：同一确定性事件日志在模型版本更新后产生不同下游输出
- 提供5个典型工作负载的架构选型诊断 + 1个可运行的90天合同续约 Agent 参考实现

📊 **实验结果**
提供可量化的可靠性分解公式（per-call model variance vs. architectural momentum），说明随模型方差降低，SDB 强度与模式选择的重要性相对上升。

🎯 **与 Agent/Routing 的关联**
直接为多 Agent 编排与 routing 决策提供系统工程框架，SDB 原语可指导实际生产系统中 Agent routing 策略的设计与容错。

## 🧠 今日洞察

1. **记忆已成 Agent 架构的一等公民**：无论是端到端强化学习训练记忆策略（AgeMem），还是轻量级上下文缓存（PEEK），研究界正从"记忆是附属组件"向"记忆是核心策略"转变，并开始追求更强的 token 效率。

2. **Routing 进入"二维时代"**：路由研究已从单纯"选模型"演化为"模型 × 推理策略"的联合优化（RTR），甚至扩展为系统级架构模式的选型（Production Patterns），显示该方向正快速走向工程落地。

3. **Agent 可靠性与工程化提速**：随着 Agent 能力趋于成熟，关注点从"Agent 能做什么"转向"Agent 怎样在生产中稳定运行"，SDB 框架、重放发散等工程概念开始进入 arxiv，预示着 2026 下半年 Agent 工程学将成为热点。
