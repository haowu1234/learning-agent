📄 **【统一长短期记忆管理的 LLM Agent 框架】**（Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885
💡 核心贡献
- 提出 AgeMem，首个将长期记忆（LTM）与短期记忆（STM）统一建模为 Agent 策略内工具调用的框架，彻底替代依赖启发式规则或辅助控制器的独立组件模式。
- 设计三阶段渐进式强化学习策略 + 逐步 GRPO 算法，专门解决记忆操作导致的稀疏、离散奖励问题。

🔧 技术亮点
- 将 store/retrieve/update/summarize/discard 五类记忆操作统一暴露为工具动作，由 LLM 自主决策何时、对什么操作
- 三阶段渐进 RL 课程：基础记忆使用 → 记忆质量优化 → 长时程任务联合优化
- Step-wise GRPO 解决轨迹级别奖励稀疏问题，支持端到端优化整个记忆管理流程

📊 实验结果
在 5 个长时程基准测试上持续超越强 memory-augmented 基线；在多个 LLM backbone 上均有提升，同时表现为更高质量的长期记忆 + 更少的上下文消耗。

🎯 与 Agent/Routing 的关联
AgeMem 将记忆管理内化为 Agent 决策的一部分，为 Long-horizon Agent 提供了可训练、可端到端优化的统一记忆基础设施。

📄 **【面向稳定多轮 Agentic RL 的不确定性引导探索控制】**（T²PO: Uncertainty-Guided Exploration Control for Stable Multi-Turn Agentic Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.02178
💡 核心贡献
- 提出 T²PO，通过在 Token 级和 Turn 级双层显式控制探索强度，解决多轮 RL 训练中因低信息量动作积累导致的训练崩溃问题。
- 论文已被 **ICML 2026 Spotlight** 接收，代表该领域的前沿进展。

🔧 技术亮点
- **Token 级**：实时监控不确定性变化，当边际不确定性低于阈值时触发 "thinking intervention"，迫使模型深思
- **Turn 级**：识别探索进展可忽略的交互步骤，动态重采样该轮以避免无效 rollout 资源浪费
- 统一 uncertainty-aware 框架，兼容 WebShop、ALFWorld、Search QA 等多种交互环境

📊 实验结果
在 WebShop、ALFWorld、Search QA 三类环境中均取得训练稳定性的显著提升，探索效率改善，最终性能提高明显。

🎯 与 Agent/Routing 的关联
T²PO 从训练稳定性角度切入，为多轮 Agentic RL 提供探索控制机制，直接影响 Agent 在复杂长时程任务中的策略学习质量。

📄 **【通过模因检索演化 Agent 工具生态】**（FitText: Evolving Agent Tool Ecologies via Memetic Retrieval）
🔗 https://arxiv.org/abs/2605.02411
💡 核心贡献
- 提出 FitText，一个无需训练的动态工具检索框架，将工具检索嵌入 Agent 推理循环中，随执行过程迭代精化检索探针，突破"一次性静态查询"的瓶颈。
- 引入"模因检索（Memetic Retrieval）"机制，通过进化选择压力优化自然语言检索探针，并维护工具记忆避免重复搜索。

🔧 技术亮点
- 生成伪工具描述（pseudo-tool descriptions）作为检索探针，并利用检索反馈迭代精化
- 随机生成多样化候选描述 + 进化选择，避免局部最优的单一检索路径
- 工具记忆（tool memory）模块跟踪已探索工具，消除冗余检索开销

📊 实验结果
ToolRet（43k 工具，4 领域）：平均检索排名从 8.81 → **2.78**
StableToolBench（16,464 APIs）：平均通过率 **0.73**，比静态查询检索绝对提升 **+24 个百分点**

🎯 与 Agent/Routing 的关联
FitText 本质上是 Agent 内部的"工具路由"——在 4 万级别 API 生态中动态选择最合适工具，与 LLM Routing 的"选对模型"逻辑高度同构。

📄 **【LLM 动态路由与级联推理综述】**（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）
🔗 https://arxiv.org/abs/2603.04445
💡 核心贡献
- 首个系统分析跨多个独立训练 LLM 的路由与级联方法的综述，覆盖查询难度、人类偏好、聚类、不确定性量化、强化学习、多模态、级联等七大路由范式。
- 提出三维概念框架（何时决策 / 使用什么信息 / 如何计算），揭示实际系统通常是多范式组合的复合体。

🔧 技术亮点
- 明确区分 MoE（单模型内路由）与跨模型路由，聚焦真实部署场景
- 三维分析框架（when / what / how）为路由系统设计提供可操作的分类坐标
- 总结开放挑战：如何在不同架构、模态和应用间泛化路由机制

📊 实验结果
综述性论文，汇总业界最优方法的质量-成本权衡数据；指出精心设计的路由系统可超越单个最强模型的整体表现。

🎯 与 Agent/Routing 的关联
直接对标 Routing 主题，是当前 LLM 路由领域最全面的方法论参考，对构建生产级 Multi-LLM 推理系统具有高度指导价值。

## 🧠 今日洞察

**记忆与工具选择正在融合为 Agent 的"内生能力"。** AgeMem 将记忆操作内化为可训练的工具调用，FitText 将工具检索嵌入推理循环——两者共同指向同一趋势：Agent 不再依赖外部系统分派资源，而是自主、动态地调度记忆与工具。

**训练稳定性成为 Agentic RL 的关键瓶颈。** T²PO 被 ICML 2026 Spotlight 接收，说明社区已意识到"如何让多轮 Agent RL 稳定收敛"与"算法设计"同等重要；探索控制、奖励稀疏、轨迹信用分配将是近期核心战场。

**LLM Routing 从固定池走向开放池。** UniRoute（ICLR 2026）的核心命题是"路由器应能泛化到训练时未见过的新模型"，路由综述 (arXiv:2603.04445) 也将此列为开放挑战——随着模型迭代加速，动态路由能力将从"锦上添花"变为"基础设施"。
