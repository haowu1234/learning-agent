## 📄 Paper 1

**【MemFlow：面向小型语言模型 Agent 的意图驱动记忆编排框架】**
（MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents）

🔗 https://arxiv.org/abs/2605.03312

💡 **核心贡献**
提出 MemFlow——一个无需训练的记忆编排框架，通过将记忆规划从 SLM 外置，解决小模型在长对话 Agent 场景下的上下文溢出和检索噪声问题。框架引入「意图路由」机制，依据查询类型将请求分发到三级专属记忆通道，显著提升了资源受限场景下的精度。

🔧 **技术亮点**
- **三层记忆架构**：Profile Lookup（个人档案快查）/ Targeted Retrieval（精准检索）/ Deep Reasoning（深度推理），按意图动态分配
- **多 Agent 流水线**：Router Agent → Memory Agent → Answer Agent → Validator Agent，职责清晰、防止 tool-selection 幻觉
- **动态 tier-aware token budget**：不同记忆通道拥有独立 token 预算，避免上下文膨胀

📊 **实验结果**
在 LongMemEval、LoCoMo、LongBench 三个长对话 benchmark 上，以冻结参数的 Qwen3-1.7B 为骨干，MemFlow 准确率较全上下文 SLM baseline **提升约 2 倍**。

🎯 **与 Agent/Routing 的关联**
意图路由 + 分级记忆是 Agent 长程规划能力的关键基础设施，MemFlow 将 routing 思想延伸到了记忆管理层。

## 📄 Paper 2

**【规划者决定一切！面向长程任务规划的高效非对称多 Agent 协作框架】**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
提出 Planner-centric 多 Agent 框架，将自动化任务拆解为三角色：Planner（高层决策）、Actor（执行）、Memory Manager（上下文管理）。核心发现：规划是任务性能的主导因素，只需聚焦优化 Planner 即可获得高效收益。

🔧 **技术亮点**
- **算力分配分析**：系统量化证明规划 vs 执行 vs 记忆管理的算力贡献比差异
- **Planner-centric RL**：仅对 Planner 做 RL 优化（VLM-as-judge 提供轨迹级奖励），其余组件冻结
- **非对称 Agent 设计**：Planner 使用大模型，Actor 和 Memory Manager 使用轻量模型，兼顾性能与成本

📊 **实验结果**
跨越 Web 导航、OS 控制、工具调用三类 benchmark，Planner-centric RL 展现出鲁棒且计算高效的提升，代码已开源。

🎯 **与 Agent/Routing 的关联**
直接揭示了多 Agent 系统中"哪个角色值得路由更多算力"的核心问题，为 Agent 系统的算力路由策略提供了理论依据。

## 📄 Paper 3

**【GraphPlanner：面向多 Agent LLM 的图记忆增强 Agentic 路由器】**
（GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs）

🔗 https://arxiv.org/abs/2604.23626 ｜ ICLR 2026

💡 **核心贡献**
提出 GraphPlanner，将多 Agent LLM 路由问题建模为马尔可夫决策过程（MDP），在每步同时选择 LLM backbone 和 Agent 角色（Planner/Executor/Summarizer）。通过异质图记忆网络 GARNet 整合历史交互，同时支持归纳推理和直推推理。

🔧 **技术亮点**
- **异质图记忆（GARNet）**：捕获查询-Agent-响应的交互记忆，形成丰富状态表征
- **MDP 工作流生成**：将路由决策序列化为强化学习可训练的决策过程
- **双模推理**：归纳推理（新任务泛化）+ 直推推理（已见任务利用历史），灵活适配不同场景

📊 **实验结果**
在 14 个多样化 LLM 任务上：准确率最高提升 **9.3%**；GPU 显存需求从 186.26 GiB 压缩至 **1.04 GiB**（降低 99.4%）；对未见任务表现出强 zero-shot 泛化能力。

🎯 **与 Agent/Routing 的关联**
GraphPlanner 是当前将图记忆与 LLM 路由深度融合的最强工作之一，直接对标 Agent/Routing 双主题。

## 📄 Paper 4

**【动态模型路由与级联：高效 LLM 推理综述】**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首篇系统梳理跨模型路由与级联范式的综述论文，覆盖查询难度感知、人类偏好对齐、聚类、不确定性量化、强化学习、多模态路由等多个维度。引入"三维路由特征框架"：决策时机（when）、决策信息（what）、决策方式（how）。

🔧 **技术亮点**
- **跨模型路由 vs MoE 区分**：专注于多个独立训练 LLM 间的路由，而非单模型内部专家路由
- **三维特征框架**：when（推理前/中/后）× what（查询特征/模型信号）× how（规则/学习/RL）
- **级联机制分析**：从低成本模型逐步升级到高能力模型的动态决策链路

📊 **实验结果**
（综述性论文）分析表明：设计良好的路由系统可超越单一最强模型，在效率增益同时保留专业能力。

🎯 **与 Agent/Routing 的关联**
提供了 LLM Routing 领域完整的知识图谱，是理解当前路由研究格局的必读参考。

## 🧠 今日洞察

1. **记忆管理进入"路由化"时代**：MemFlow 和 GraphPlanner 不约而同地将 routing 思想注入记忆架构——不再是"检索所有 vs 检索部分"的二元选择，而是按意图/查询类型分派到专属记忆通道，这标志着 Agent 记忆研究正在走向精细化编排。

2. **"非对称计算分配"成为 Multi-agent 优化新共识**：Planner Matters 的实验结论为 Agent 系统设计提供了重要原则——不是所有角色都值得同等对待，把算力和学习信号集中在高层规划是效率最优解，这与 GraphPlanner 中按角色选 LLM backbone 的思路高度呼应。

3. **LLM Routing 走向 Agentic 场景**：从静态 query-to-model 映射，到动态工作流生成再到级联级联决策，LLM 路由正在从推理服务层向 Agent 编排层演进，GraphPlanner 入选 ICLR 2026 印证了这一趋势。
