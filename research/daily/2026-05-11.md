## 📄 论文一

**规划者才是关键！一种高效非对称多智能体协作框架**
（Planner Matters! An Efficient and Unbalanced Multi-agent Collaboration Framework for Long-horizon Planning）

🔗 https://arxiv.org/abs/2605.02168

💡 **核心贡献**
本文通过系统性的计算资源分配分析，发现在多智能体系统中"规划"是决定任务性能的主导因素，执行与记忆管理对模型容量需求相对较低。基于此提出以规划者为中心的强化学习方法，仅优化规划器组件同时冻结其他模块，实现高效且可扩展的长视野任务自动化。

🔧 **技术亮点**
- 将多智能体系统解耦为三类角色：Planner（高层决策）、Actor（任务执行）、Memory Manager（上下文管理）
- 提出"非对称计算分配"策略：规划器获得更大模型容量与更多训练资源，执行/记忆模块轻量化
- 使用 VLM-as-Judge 提供轨迹级奖励信号，驱动规划器的强化学习优化

📊 **实验结果**
在 Web 导航、OS 控制、工具使用三大 benchmark 上验证，聚焦规划器的策略在长视野任务自动化中产生显著且高效的性能提升，代码已开源。

🎯 **与 Agent/Routing 的关联**
直接为 Multi-Agent 规划架构提供设计原则：规划组件应优先获得算力与训练资源，类比于 LLM Routing 中"将复杂 query 路由至更强模型"的核心思想。

🔧 **技术亮点**

📊 **实验结果**
综述性论文，整理了当前 benchmark 设计与评估指标的最新状态，指出标准化评测仍是瓶颈。

🎯 **与 Agent/Routing 的关联**

## 📄 论文三

**多 LLM 动态路由与级联推理综述**
（Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey）

🔗 https://arxiv.org/abs/2603.04445

💡 **核心贡献**
首个系统性分析跨多个独立训练 LLM 之间的路由与级联方法的综述，明确区别于 MoE（模型内路由）。提出三维概念框架（决策时机 × 使用信息 × 计算方式），揭示实际系统往往是多范式的组合体。

🔧 **技术亮点**
- 覆盖六大路由范式：查询难度感知、人类偏好对齐、聚类路由、强化学习、不确定性量化、级联推理
- 引入三维设计空间框架：when（何时决策）、what（使用什么信息）、how（如何计算），为系统设计提供统一语言
- 分析了多模态路由的前沿探索以及跨架构泛化的开放挑战

📊 **实验结果**
综述结论：设计良好的路由系统可超越单一最强模型的性能，通过跨模型协作发挥各自专长，同时大幅降低推理成本。

🎯 **与 Agent/Routing 的关联**
Routing 领域的基础参考综述，直接对应 Routing 研究方向，6 大范式为路由系统设计提供了完整地图。

## 📄 论文四

**BEST-Route：基于测试时最优采样的自适应 LLM 路由**
（BEST-Route: Adaptive LLM Routing with Test-Time Optimal Sampling）

🔗 https://arxiv.org/abs/2506.22716

💡 **核心贡献**
BEST-Route 同时决定"路由到哪个模型"和"从该模型采样多少次"，将模型选择与推理时计算预算统一建模。在控制成本的前提下，通过最优采样数量调度实现精度-效率的 Pareto 最优。

🔧 **技术亮点**
- 联合优化（模型选择 × 采样次数）的双变量路由决策，突破以往仅做二元选择的局限
- 基于查询难度估计动态分配测试时计算预算（test-time compute allocation）
- Microsoft 开源实现（github.com/microsoft/best-route-llm），可削减高达 60% 的推理成本

📊 **实验结果**
在多个推理 benchmark 上实验验证：相比固定路由策略，成本降低 ~60%，同时维持或提升整体答题准确率。

🎯 **与 Agent/Routing 的关联**
将 LLM Routing 与 Test-Time Compute Scaling 深度结合，是当前 Routing 方向最前沿的实用框架之一，直接可迁移到 Agent 的工具/模型选择场景。

## 🧠 今日洞察

**1. 规划是多智能体系统的瓶颈，不对称资源分配是破局关键。** 2605.02168 的实验清晰表明：不是所有组件都需要"大模型"，把算力集中在规划上是最具性价比的设计选择。

**2. Routing 正从"选哪个模型"升级为"选模型 + 选计算量"。** BEST-Route 代表了一种新趋势：路由决策与 Test-Time Compute Scaling 融合，让系统能在延迟/成本/质量三角中动态权衡。

**3. 工具编排与模型路由正在走向统一范式。** 无论是多工具 Agent 选工具，还是 LLM Router 选模型，底层逻辑都是"基于 query 特征的动态资源分配"——未来这两个领域的方法很可能会相互借鉴融合。
