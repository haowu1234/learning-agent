## 📄 **MUSE-Autoskill：通过技能创建、记忆、管理与评估实现自进化 Agent**
（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）

🔗 https://arxiv.org/abs/2605.27366
🏛️ 机构：字节跳动 ByteDance | 提交：2026-05-26

💡 **核心贡献**
提出以技能为中心的 MUSE-Autoskill Agent 框架，构建统一的技能生命周期管理机制（创建→记忆→管理→评估→精炼），让 Agent 能够持续自我改进。额外引入技能级记忆（skill-level memory），跨任务积累每个技能的经验，实现长期有效的复用与适应性提升。

🔧 **技术亮点**
- 统一生命周期：技能按需生成、跨任务存储复用、通过单元测试与运行时反馈持续迭代
- 技能级记忆：为每个技能独立维护多任务经验记录，支持动态语义去重与合并
- 跨 Agent 迁移：生命周期管理的技能可在多个 Agent 间迁移复用，降低冷启动成本

📊 **实验结果**
在 SkillsBench 上验证，生命周期管理显著提升任务成功率、执行效率、技能复用率及跨 Agent 迁移能力。

🔄 **自进化类型**：数据飞轮 + 自我反思（技能生命周期闭环）

## 📄 **FluxMem：将记忆重构为持续演化的连接图**
（Rethinking Memory as Continuously Evolving Connectivity）

🔗 https://arxiv.org/abs/2605.28773
🏛️ 机构：浙江大学 + 阿里巴巴集团 + 同济大学 | 提交：2026-05-27

💡 **核心贡献**
提出 FluxMem，将 LLM Agent 记忆建模为异质图结构，通过三阶段（初始连接构建→反馈驱动精炼→长期巩固）动态演化记忆拓扑，取代静态存储库范式。框架自动修复缺失链接、剪枝噪声、对齐抽象粒度，将成功轨迹提炼为可复用的过程电路。

🔧 **技术亮点**
- 记忆即异质图：节点为知识单元，边为动态关系，随反馈信号实时重构连接
- 统一进化指标：以记忆泛化能力和进化成熟度作为统一优化信号，引导拓扑精炼
- 过程电路提炼：重复成功的轨迹被蒸馏为通用可复用策略电路，支撑未来决策

📊 **实验结果**
在 LoCoMo（长对话记忆）、Mind2Web（网页导航）、GAIA（通用 Agent 评测）三个基准上均达到 SOTA，展现跨域泛化能力。

🔄 **自进化类型**：持续学习 + 数据飞轮（反馈驱动记忆演化）

## 📄 **EvolveR：经验驱动生命周期的 LLM Agent 自进化框架**
（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）

🔗 https://arxiv.org/abs/2510.16079
🏛️ 机构：浙江大学 + 上海人工智能实验室 | **ICML 2026 录用**

💡 **核心贡献**
提出 EvolveR，通过"在线交互—离线自蒸馏—经验库维护—强化学习更新"的完整闭环，让 Agent 从自身历史轨迹（成功与失败）中提炼可复用的策略原则，实现超越 RAG 的经验级自我进化。关键创新：Agent 不仅能查外部知识，还能主动检索自身经验。

🔧 **技术亮点**
- 离线自蒸馏：从成功轨迹提炼指导原则，从失败轨迹提炼警示原则，自产训练信号无需外部教师
- 动态经验库：经语义去重、质量评分与低效原则剪枝，维持 5 万条原则时检索延迟仅 ~0.20s
- GRPO 强化学习：奖励信号同时关注答案正确性与推理过程（经验检索 + 工具调用质量）

📊 **实验结果**
Qwen2.5-3B 平均 EM 达 0.382（vs Search-R1-instruct 的 0.325）；Qwen2.5-7B 达 0.417（vs 0.385）。在 TriviaQA、HotpotQA、2WikiMultiHopQA 等多个 QA 基准上超越强化学习搜索 Agent 基线。

🔄 **自进化类型**：数据飞轮 + 奖励驱动（经验自蒸馏 + GRPO RL）

## 📄 **多 Agent 提示优化中时序与结构信用联合分配**
（Unifying Temporal and Structural Credit Assignment in LLM-Based Multi-Agent Prompt Optimization）

🔗 https://arxiv.org/abs/2605.30227
🏛️ 机构：同济大学 + 香港大学 | 提交：2026-05-28

💡 **核心贡献**
针对多 Agent 系统黑箱优化中信用分配困难问题，提出将目标分解为时序维度（识别关键轮次）和结构维度（隔离各 Agent 贡献）的双轴分解框架，并基于分解信号设计块坐标下降算法，用 LLM 生成的"代理梯度"精准定位薄弱环节迭代改进。

🔧 **技术亮点**
- 时序信用分配：用状态空间瓶颈识别交互轨迹中的关键决策轮次，聚焦高价值步骤优化
- 结构信用分配：平稳角色策略解耦各 Agent 贡献，避免优化冲突
- 可解释提示梯度：LLM 生成自然语言"梯度"替代不可微反向传播，支持离散空间优化

📊 **实验结果**
在多个推理基准上显著降低查询复杂度，同时提升多 Agent 系统整体性能；与盲目全局更新相比效率大幅提升。

🔄 **自进化类型**：自我反思 + 奖励驱动（多 Agent 协同自我改进）

## 📄 **受控 Agent 运行时演化：可执行操作认知框架**
（Governed Evolution of Agent Runtimes through Executable Operational Cognition）

🔗 https://arxiv.org/abs/2605.27328
🏛️ 机构：独立研究者 | 提交：2026-05-26

💡 **核心贡献**
提出通过可执行操作认知（Executable Operational Cognition）实现多 Agent 系统受控运行时演化的框架，将 Agent 生成的代码制品形式化为持久运行时能力，引入 HarnessMutation 机制在显式验证、可追溯性与回滚约束下实现生命周期感知的运行时自适应。

🔧 **技术亮点**
- HarnessMutation：将运行时适应建模为有界可观测过程，而非无约束自我修改
- 持久运行时能力：Agent 生成产物从临时输出升级为系统的持久操作基础
- 透明可审计演化：每步演化均附有验证记录与回滚点，保证安全性与可控性

🔄 **自进化类型**：持续学习 + 自我反思（受治理的运行时自进化）

## 🚀 今日洞察

**趋势一：从"静态知识"到"动态经验"的范式转变正在加速。** 本周最具代表性的工作（MUSE-Autoskill、EvolveR、FluxMem）不约而同地聚焦于如何让 Agent 将自身交互历史转化为可复用的结构化知识，技能生命周期管理与经验自蒸馏成为核心机制，体现出"经验即数据飞轮"的主流思路。

**趋势二：多 Agent 系统自优化进入精细化阶段。** 信用分配不再满足于粗粒度全局奖励，而是向时序维度与结构维度联合解耦演进，LLM 生成的"代理梯度"为离散空间中的迭代自改进提供了新路径。

**核心挑战：** 自进化的可控性与可审计性仍是瓶颈——如何在保持足够灵活性的同时，确保演化过程的边界清晰、行为可回溯，是 EvolveR、FluxMem 与 HarnessMutation 框架都在尝试回答却尚未完全解决的难题。
