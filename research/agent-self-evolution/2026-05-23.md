📄 **【MOSS】源码级自进化：在生产 Agent 系统中进行源码重写**（MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems）
🔗 https://arxiv.org/abs/2605.22807（papers.cool #1, cs.AI, 2026-05-21）
💡 核心贡献：
传统自进化 Agent 只能修改 Skill 文件、Prompt 配置等文本层面的制品，路由逻辑、状态不变量等存在于代码层的结构性缺陷无法触达。MOSS 提出了基于源码级重写的自进化范式，Agent 可以直接修改生产代码，突破文本层的进化上限，在 OpenClaw 平台四任务测试中，单轮无人工干预将平均评分从 0.25 提升至 0.61。

🔧 技术亮点：
- 源码级适应（Source-Level Adaptation）：图灵完备的进化介质，是所有文本可变 Scope 的严格超集
- 确定性多阶段流水线：失败证据自动整理 → 外部 Coding-Agent CLI 生成候选 → 临时 Worker 回放验证 → 用户同意门控的容器内原地替换
- 健康探针门控的回滚机制：确保进化的安全性，避免因代码变更导致系统崩溃

📊 实验结果：
在 OpenClaw 四任务 Benchmark 上，MOSS 将平均评分从 0.25 提升至 0.61（单轮进化，无人工干预），证明源码级进化显著优于纯文本层进化。

🔄 自进化类型：**源码重写 / 数据飞轮**

📄 **【OWPO】面向自进化 LLM 的单向策略优化**（One-Way Policy Optimization for Self-Evolving LLMs）
🔗 https://arxiv.org/abs/2605.22156（cs.LG + cs.AI, 2026-05-21）
💡 核心贡献：
RLVR（可验证奖励强化学习）中现有方法对参考策略的偏差进行无差别惩罚，当策略试图超越参考策略时会反向抑制收益。OWPO 提出解耦优化方向与更新幅度，由验证器决定方向、参考策略仅调整幅度，配合迭代参考更新产生"棘轮效应"，实现无需依赖固定外部参考的持续自进化。

🔧 技术亮点：
- 非对称重加权（Asymmetric Reweighting）：对"劣势偏差"（策略落后于参考）执行加速对齐，对"优势偏差"（策略超越参考）执行增益锁定
- 棘轮效应（Ratchet Effect）：迭代更新参考策略，持续巩固已获得的收益，避免退化
- 突破固定先验瓶颈：不依赖外部参考模型即可实现连续自进化，优于 DAPO、OPD、MOPD 等强基线

📊 实验结果：
在多个推理 Benchmark 上超越 DAPO、OPD、MOPD 等强基线，收益随训练步数持续递增，无停滞现象。

🔄 自进化类型：**奖励驱动 / 自我博弈**

📄 **【VPO】向量策略优化：训练多样性改善推理时搜索**（Vector Policy Optimization: Training for Diversity Improves Test-Time Search）
🔗 https://arxiv.org/abs/2605.22817（cs.LG + cs.AI + cs.CL, 2026-05-21）
💡 核心贡献：
标准 LLM 后训练优化单一标量奖励，导致模型输出分布熵低，难以支撑推理时搜索（如 AlphaEvolve）所需的多样性。VPO 将奖励建模为向量值，训练策略生成一组在向量奖励空间中各自专精不同权衡的多样化解，与推理时搜索形成协同，在进化搜索任务上解锁了 GRPO 完全无法解决的问题。

🔧 技术亮点：
- 向量值奖励建模：将多测试点正确性、多用户画像偏好等天然向量化奖励直接用于训练
- GRPO 兼容替换：VPO 可直接替代 GRPO 优势估计器，无需改动框架
- 训练多样性 → 测试搜索收益：随搜索预算增长，VPO 相对标量 RL 基线的优势持续扩大

📊 实验结果：
在代码生成、数学推理等四项任务上，pass@k 和 best@k 均匹配或超越最强标量 RL 基线；进化搜索任务上 VPO 解锁了 GRPO 模型完全无法解决的问题。

🔄 自进化类型：**奖励建模 / 自我博弈**

📄 **【SkillOS】学习技能策展以实现 Agent 自进化**（SkillOS: Learning Skill Curation for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2605.06614（Google Cloud AI Research + UIUC + MIT）
💡 核心贡献：
已有技能策展方法依赖手工规则或短期启发式策略，无法从间接、延迟的反馈中学习复杂的长期策略。SkillOS 提出基于 RL 的技能策展训练框架，将冻结的 Agent 执行器与可训练的技能策展器配对，通过任务流（Task Stream）的依赖关系构建奖励信号，让策展器学会何时新增/更新/删除技能，SkillRepo 随时间发展出更丰富的内部结构与元技能。

🔧 技术亮点：
- Frozen Executor + Trainable Curator 解耦：执行器不参与训练，策展器专注于长期技能管理策略学习
- 基于技能相关任务依赖的分组任务流：前序轨迹更新 SkillRepo，后续相关任务评估更新质量，提供清晰学习信号
- 复合奖励设计：将下游执行器反馈归因到具体策展决策，提升奖励信号的信噪比

📊 实验结果：
在多轮 Agentic 任务和单轮推理任务上一致超越无记忆基线和强记忆基线；策展器可跨执行器主干和任务域泛化；SkillRepo 发展出可观察的元技能层级结构。

🔄 自进化类型：**数据飞轮 / 持续学习**

📄 **【EvolveR】经验驱动的 LLM Agent 自进化生命周期**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079（ICML 2026 | 浙江大学 + 上海人工智能实验室）
💡 核心贡献：
传统 RAG 补充事实知识，但 Agent 的失败根因往往是策略错误。EvolveR 构建了"在线交互—离线经验自蒸馏—经验库动态维护—GRPO 强化学习更新"的闭环，让 Agent 从成功/失败轨迹中提炼可复用的策略原则，并在新任务中主动检索使用，超越了 Search-R1 等强化学习搜索 Agent 基线。

🔧 技术亮点：
- 自蒸馏 vs 教师蒸馏的规模依赖性：小模型（0.5B）依赖外部教师，大模型（3B+）自蒸馏更优，符合能力边界的自适应策略
- 动态经验库维护：语义去重 + 相似原则合并 + 使用成功率评分驱动的剪枝，5万条原则时 Top-3 检索延迟仅 0.20s
- 多目标 GRPO 奖励：不仅考察答案正确性，还追踪是否执行了合理思考、是否检索经验、是否调用外部知识

📊 实验结果：
Qwen2.5-3B 上平均 EM 达 0.382（vs Search-R1-instruct 的 0.325）；Qwen2.5-7B 上平均 EM 0.417（vs 0.385），在 TriviaQA、PopQA、Musique、Bamboogle 等多个 Benchmark 上全面超越。

🔄 自进化类型：**数据飞轮 / 持续学习 / 经验驱动**

## 🚀 今日洞察

1. **从文本层到代码层的进化跨越**：MOSS 的源码级自进化代表了一次范式突破——以往的自进化工作被局限在 Skill 文件和 Prompt 的文本层面，但真正的 Agent 结构性缺陷（路由逻辑、状态机、钩子顺序）隐藏在代码中，源码重写是通往完全自主 Agent 的必经之路。

2. **奖励建模正在成为自进化的核心引擎**：OWPO 通过棘轮效应解决 RLVR 的梯度压制问题，VPO 通过多样性训练赋能测试时搜索——两者共同揭示出一个趋势：下一代自进化 LLM 将不再依赖固定参考策略或标量奖励，而是走向动态、向量化的自我奖励机制。

3. **经验复用是持续进化的关键瓶颈**：EvolveR 和 SkillOS 分别从"策略经验提炼"和"技能策展学习"两个维度应对同一挑战——如何让 Agent 从海量历史轨迹中提炼真正有价值的可复用知识，而非简单堆积记忆。当前核心挑战在于经验的质量筛选与跨任务泛化，尤其是如何在开放域动态任务流中保持经验库的高信噪比。
