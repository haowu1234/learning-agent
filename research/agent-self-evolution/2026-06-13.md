📄 **[SkillCAT：面向 LLM Agent 的对比评估与拓扑感知技能自进化框架]**（SkillCAT: Contrastive Assessment and Topology-Aware Skill Self-Evolution for LLM Agents）
🔗 https://arxiv.org/abs/2606.13317
💡 核心贡献：提出 SkillCAT，一种无需模型训练的三阶段技能自进化框架，通过对比因果提取区分成功/失败轨迹，并以拓扑感知的方式组织可复用技能，实现推理时按需加载。该框架在多个 Agent 基准（SpreadsheetBench、WikiTableQuestions、DocVQA）上平均分提升最高达 40.40%。
🔧 技术亮点：
- **对比因果提取（CCE）**：对同一任务采样多条轨迹，通过对比成功/失败对识别决定性差异，提取因果证据而非表面模式
- **评估增强进化（AAE）**：在源任务克隆环境中回放候选 skill patch，仅保留能改善或维持任务成功率的补丁，再进行层次化合并，避免质量退化
- **拓扑感知执行（TTE）**：将进化后的技能编译成可路由的子技能拓扑图，推理时只加载与当前任务相关的能力节点，降低上下文消耗
📊 实验结果：跨 SpreadsheetBench / WikiTableQuestions / DocVQA 三个基准，超越基线最高 40.40%；支持跨模型和分布外泛化
🔄 自进化类型：**技能记忆进化 / 数据飞轮 / 持续学习**

📄 **[ProPlay：基于程序世界模型的 LLM Agent 自进化]**（ProPlay: Procedural World Models for Self-Evolving LLM Agents）
🔗 https://arxiv.org/abs/2606.12780
💡 核心贡献：提出 ProPlay，用程序级「预演（preplay）」替代孤立记忆规则，让 Agent 在执行前可通过已学世界知识模拟未来程序路径，实现环境动态的持续自我精炼。ProPlay 将成功轨迹抽象为「程序（procedure）」，并以有向图组织因果阶段转移，闭合了记忆与规划之间的反馈环。
🔧 技术亮点：
- **程序图（Procedure Graph）**：以程序而非原始动作为节点，记录任务阶段间的因果转移关系，内嵌可靠性向量估计各转移对过去结果的任务贡献
- **结构化软引导**：每轮执行前在已知图结构上模拟未来程序路径，作为结构化软指导约束行为；执行后用环境反馈更新图，实现闭环
- **无监督自进化**：整个过程不依赖外部监督信号，Agent 通过与环境交互自主积累世界模型
📊 实验结果：在公开基准上持续优于强基线，尤其在部分可观测环境下的环境理解和自进化能力两个维度均有显著提升
🔄 自进化类型：**自我博弈 / 持续学习 / 无监督世界模型**

📄 **[SkeMex：通过自进化技能记忆赋能医疗 Agent 可泛化推理]**（Experience Makes Skillful: Enabling Generalizable Medical Agent Reasoning via Self-Evolving Skill Memory）
🔗 https://arxiv.org/abs/2606.09365
💡 核心贡献：提出 SkeMex，一个部署后无需更新模型权重的自进化框架，将医疗交互轨迹蒸馏为结构化可复用技能，通过多分支记忆仓库（通用/任务专用/动作级）的闭环「读-写-评-治」生命周期，持续优化临床决策推理能力。
🔧 技术亮点：
- **值感知检索与仓库治理**：从环境反馈中估算上下文依赖的记忆效用，指导哪些技能应被复用、晋升或淘汰，避免记忆堆积与噪声污染
- **多分支技能分层**：技能按通用性分为三层（通用知识 / 任务专属 / 动作细节），层次化组织支持跨任务迁移
- **闭环自进化生命周期**：Read → Write → Assess → Govern 四步循环，新技能写入、效用更新、有益记忆晋升、有害记忆移除，实现稳健的持续学习
📊 实验结果：在离线和在线临床任务上均稳定超越同类记忆型 Agent；技能记忆可跨模型骨干迁移
🔄 自进化类型：**技能记忆自进化 / 奖励驱动 / 持续学习**

📄 **[PACE：面向自进化 Agent 的任意时刻有效接受测试]**（PACE: Anytime-Valid Acceptance Tests for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2606.08106
💡 核心贡献：发现当前自进化 Agent 的「接受器（acceptor）」是薄弱环节——贪心接受策略本质上是自适应多重检验中的 p-hacking，导致 Agent 持续积累伪改进并发生退化漂移。提出 PACE，将提交决策重新定性为序列假设检验，用 testing-by-betting 的 e-process 保证任意时刻有效性与每决策假提交率控制。
🔧 技术亮点：
- **Anytime-Valid e-process**：不依赖固定样本大小，在证据充分时提前停止，节省约 18% 评估开销，同时任意时刻保持假提交概率在用户设定阈值以下
- **配对对比设计**：将候选版本与当前版本在相同实例上进行配对比较，排除评估集噪声干扰，精准区分真实提升与随机波动
- **暴露 p-hacking 问题**：实验揭示贪心接受者在真实改进混于噪声候选时，提交了 30-42% 的假修改和 10-33% 的有害修改；无真实改进时，每轮累计 13-21 次伪自修改
📊 实验结果：Qwen2.5（0.5B-3B）在 GSM8K / SVAMP / ARC-Challenge 上，PACE 精确提交真实改进且几乎不提交其他内容，持有基准精度、方差显著降低、评估成本减少约 18%
🔄 自进化类型：**自我修正 / 自进化可靠性 / 统计验证**

📄 **[RA-RFT：通过类比推理检索增强强化微调]**（Learning to Reason by Analogy via Retrieval-Augmented Reinforcement Fine-Tuning）
🔗 https://arxiv.org/abs/2606.13680
💡 核心贡献：提出 RA-RFT，通过「黄金相关性蒸馏」训练一个以预期推理收益而非语义相似度排序的检索器，再用带可验证结果奖励的强化微调让策略模型学会利用类比推理路径；检索到的上下文提供互补的解题策略，从而为单个问题提供多元推理脚手架。
🔧 技术亮点：
- **推理感知检索**：与传统 RAG 不同，检索器按「推理收益」而非语义相似度排序，检索到的类比问题提供与目标问题不同但互补的推理策略
- **强化微调闭环**：结合 GRPO 等强化微调方法，在可验证奖励（如数学答案正确性）下端到端训练策略模型利用检索内容，形成「检索→推理→奖励→改进」的自提升循环
- **多样性分析**：发现推理感知检索能召回解题策略互补的上下文，而非语义近邻，为不同问题提供差异化推理脚手架
📊 实验结果：在数学推理基准上，Qwen3-1.7B 的 AIME 2025 average@32 比 GRPO 提升 7.1 分，Qwen3-4B 提升 2.8 分；超越 GPT-OSS 等强基线
🔄 自进化类型：**奖励驱动 / 自我改进 / 检索增强强化学习**

## 🚀 今日洞察

今日论文呈现出 Agent 自进化研究的三个核心趋势：**①技能记忆工程化**——SkillCAT 和 SkeMex 均将进化落脚于结构化可复用技能文档的生命周期管理，正从"如何生成技能"转向"如何治理技能质量"；**②自进化可靠性危机**——PACE 揭示了主流自进化流水线中被严重忽视的统计问题：接受器策略缺陷导致 Agent 在数百轮自修改后反而退化，这一发现对整个领域具有方法论层面的警示意义；**③世界模型 × 推理的融合加速**——ProPlay 和 RA-RFT 分别从「程序级预演」和「类比推理检索」角度，将外部结构化知识内化为 Agent 自我提升的驱动力，持续学习的核心挑战已从数据充足转向如何安全、稳健地积累与筛选有效经验。
