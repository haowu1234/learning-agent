📄 **Skill-R1：通过强化学习驱动的 Agent 技能进化**（Skill-R1: Agent Skill Evolution via Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.09359
💡 核心贡献：提出了一种基于可验证奖励的递归技能优化强化学习框架，训练轻量级技能生成器（而非修改任务 LLM 本身），实现对冻结黑盒模型（含闭源模型）的低成本技能自进化。区别于一次性自我精炼，Skill-R1 将技能优化建模为多代迭代过程，引入双层 GRPO 目标函数联合优化代内（intra-generation）和代际（inter-generation）优势。
🔧 技术亮点：
- 双层 Group Relative Policy Optimization（GRPO）：代内项对比共享技能条件下的多条 rollout；代际项奖励跨代次行为改进的技能修订
- 技能生成器与任务 LLM 解耦，兼容开源/闭源模型，大幅降低适配成本
- 将技能优化显式建模为定向进化（directional evolution），而非随机自我修正
📊 实验结果：在多个具有可验证奖励的 benchmark 上持续优于无技能基线和标准 GRPO，复杂多步任务上提升尤为显著
🔄 自进化类型：**奖励驱动 + 自我博弈（多代递归）**

📄 **自进化 Agent 会遗忘吗？终身自适应中的能力退化与保全**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）
🔗 https://arxiv.org/abs/2605.09315
💡 核心贡献：首次系统性揭示"自进化非单调性"现象——Agent 在适应新任务分布的过程中，往往以牺牲已有能力为代价，出现跨越工作流、技能、模型、记忆四大维度的能力侵蚀（Capability Erosion）。提出 Capability-Preserving Evolution（CPE）通用稳定化原则，在持续自适应过程中约束破坏性能力漂移。
🔧 技术亮点：
- 在工作流、技能、模型参数、持久记忆四条进化通道上均复现并量化了能力退化问题
- CPE 原则：约束进化过程中的能力漂移，保留先前获得的能力
- 在 GPT-5.1 优化下，workflow evolution 中简单任务保留率从 41.8% 提升至 52.8%，同时维持复杂任务适应性
📊 实验结果：CPE 在所有四条进化维度上均一致改善能力保留稳定性，且不损害新任务适配性能
🔄 自进化类型：**持续学习 + 灾难性遗忘防御**

📄 **GEAR：通过自蒸馏实现 LLM Agent 的细粒度自适应优势重加权**（GEAR: Granularity-Adaptive Advantage Reweighting for LLM Agents via Self-Distillation）
🔗 https://arxiv.org/abs/2605.11853
💡 核心贡献：针对 LLM Agent 强化学习训练中粗粒度 outcome-level 奖励导致的信用分配失效问题，提出 GEAR 框架——基于自蒸馏对轨迹进行自适应粒度信用分配，将 GRPO 的轨迹级优势通过 token/段级信号重塑，精准定位语义偏差起始点并动态调整局部权重。
🔧 技术亮点：
- 利用 ground-truth 条件 teacher 与 on-policy student 之间的散度，识别自适应段边界
- 散度尖峰（deviation onset）作为信用分配锚点，后续自回归 token 恢复低散度时保留 token 级精度
- 结合 Qwen3 4B/8B，在 8 个数学推理与 agentic 工具使用 benchmark 上验证
📊 实验结果：在较低 GRPO baseline 准确率的 benchmark 上提升最高达 ~20%，尤其适合复杂长程场景
🔄 自进化类型：**奖励驱动（细粒度信用分配）+ 模型蒸馏**

📄 **Swarm Skills：面向协调工程的可移植自进化多智能体系统规范**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.10052
💡 核心贡献：提出 Swarm Skills 规范，将多智能体协调协议从框架内部代码/静态配置中解耦，升级为可跨系统分发的一等资产（first-class distributable asset），并内置自进化语义结构，实现无人工监督的多智能体协调策略持续自优化。
🔧 技术亮点：
- 扩展 Anthropic Skills 标准，增加角色（roles）、工作流（workflows）、执行边界和自进化语义
- 自进化算法：自动从成功执行轨迹中蒸馏出新的 Swarm Skills，基于「有效性×利用率×新鲜度」多维评分持续 patch 现有技能
- 渐进式披露（Progressive Disclosure）实现零适配器跨框架可移植性，支持 JiuwenSwarm 参考实现
📊 实验结果：案例研究展示了跨框架零适配可移植性，支持 Agent 团队在无框架锁定下持续自进化协调策略
🔄 自进化类型：**数据飞轮 + 持续学习（多智能体）**

🔧 技术亮点：

## 🚀 今日洞察

当前 Agent 自进化研究正沿**三条主线**同步深化：① **奖励驱动的细粒度自进化**（GEAR、Skill-R1）将训练信号从结果级精化至 token/段级，解决长程任务中功劳分配失准的核心难题；② **持续学习与记忆稳定性**（Do Self-Evolving Agents Forget?）揭示了自进化的内生悖论——新能力获取往往以旧能力退化为代价，CPE 类防遗忘机制成为不可回避的工程刚需；③ **系统级协调规范化**（Swarm Skills）开始将自进化能力从单体 Agent 向多智能体协调层延伸。**核心挑战**仍在于：如何在开放、非静态任务分布下实现低代价、稳定、可解释的持续自进化，同时避免对齐漂移与能力侵蚀。
