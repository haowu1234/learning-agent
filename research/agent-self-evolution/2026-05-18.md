📄 **[FORGE：无权重更新的自进化 Agent 记忆——基于种群广播]**（FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast）
🔗 https://arxiv.org/abs/2605.16233
💡 核心贡献：
提出 FORGE 框架，让 LLM Agent 在完全不更新模型权重的前提下，通过"失败轨迹 → 可复用知识工件"的反思内循环 + 种群广播外循环实现自进化记忆；在随机网络防御环境（CybORG CAGE-2）中相比零样本基线提升 1.7–7.7×，相比 Reflexion 基线提升 29–72%。
🔧 技术亮点：
- 失败轨迹被专用反思 Agent（与策略共享同一 LLM，无蒸馏）转化为 Rules（启发式规则）、Examples（少样本示例）或 Mixed 三类知识工件
- **种群广播（Population Broadcast）**：每轮将表现最优实例的记忆广播给全体成员，消融实验证明此机制是性能增益的关键，"毕业冻结"主要节省算力
- 弱模型受益更显著，暗示 FORGE 可弥合模型能力差距而非放大强模型优势
📊 实验结果：在 CybORG CAGE-2 四种 LLM（Gemini-2.5-Flash-Lite、Grok-4-Fast、Llama-4-Maverick、Qwen3-235B）× 3 种表示共 12 条件下，重大失败率（奖励 < −100）降至 ~1%；Rules 方式 token 消耗减少 ~40%
🔄 自进化类型：**自我反思 + 数据飞轮（无权重更新）**

📄 **[FATE：基于失败轨迹的 On-Policy 自进化安全对齐]**（On-Policy Self-Evolution via Failure Trajectories for Agentic Safety Alignment）
🔗 https://arxiv.org/abs/2605.11882
💡 核心贡献：
揭示工具调用型 Agent 的安全失败发生在完整轨迹层面而非单步响应层面，提出 FATE 框架——让策略自身对失败轨迹提出修复方案、由验证器多目标评分后用于 on-policy 自进化，无需专家示范；同时引入 Pareto 前沿策略优化（PFPO）消除安全-效用权衡。
🔧 技术亮点：
- On-policy 修复：同一策略既生成失败、也提出修复候选，避免分布漂移
- PFPO 结合监督预热与 Pareto-aware 策略优化，同时守护安全性与任务有效性
- 稠密轨迹级监督信号取代稀疏的响应级奖励，解决工具链中间步骤对齐盲区
📊 实验结果（AgentDojo、AgentHarm、ATBench）：攻击成功率降低 33.5%，有害合规降低 82.6%，外部轨迹安全诊断提升 6.5%
🔄 自进化类型：**自我修正 + 奖励驱动（安全对齐）**

📄 **[自进化 Agent 会遗忘吗？持续 LLM Agent 适应中的能力退化与保全]**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）
🔗 https://arxiv.org/abs/2605.09315
💡 核心贡献：
首次系统性揭示 LLM Agent 自进化的"非单调性"——跨工作流、技能、模型、记忆四条演化通道，适应新任务分布会持续侵蚀已获能力（命名为 capability erosion）；提出 Capability-Preserving Evolution（CPE）通用稳定化原则加以缓解。
🔧 技术亮点：
- 跨四维演化通道（workflow/skill/model/memory）系统验证能力侵蚀现象的普遍性
- CPE 以约束形式阻止破坏性能力漂移，无需修改底层演化算法
- 以 GPT-5.1 优化为例：工作流演化下简单任务保留率从 41.8% 提升至 52.8%，同时增强复杂任务适应
📊 实验结果：CPE 在全部四个演化维度均稳定提升历史能力保留率，同时保持当前任务适应性能
🔄 自进化类型：**持续学习（能力防遗忘）**

📄 **[GEAR：基于自蒸馏的 LLM Agent 细粒度自适应优势重加权]**（GEAR: Granularity-Adaptive Advantage Reweighting for LLM Agents via Self-Distillation）
🔗 https://arxiv.org/abs/2605.11853
💡 核心贡献：
针对 LLM 强化学习中粗粒度结果奖励导致长轨迹信用分配不准的问题，提出 GEAR——通过自蒸馏对比 on-policy 学生与真值条件教师的 token/段级散度，自适应划定信用区域并重加权 GRPO 优势；在 8 个基准上相比标准 GRPO 最高提升 ~20%。
🔧 技术亮点：
- 散度峰值定位语义偏离起点，以此为锚划定自适应信用区段，而非固定 token/轮次粒度
- 自蒸馏完全来自模型自身（无外部教师），天然适配自进化流水线
- 在 Qwen3 4B/8B 上跨数学推理与 Agentic 工具调用任务均显著优于 token-level 及 turn-level 信用分配基线
📊 实验结果：8 个基准一致优于 GRPO；在 GRPO 基线准确率较低（更难）的设置下，提升幅度尤为显著（达 ~20%）
🔄 自进化类型：**奖励驱动（自蒸馏信用分配）**

📄 **[METIS：将课程判断内化为 LLM 强化微调的元认知能力]**（Internalizing Curriculum Judgment for LLM Reinforcement Fine-Tuning）
🔗 https://arxiv.org/abs/2605.11235
💡 核心贡献：
提出 METIS（METacognitive Internalized Self-judgment）框架，让模型以提示内奖励方差为信息量度量、通过 in-context learning 预测自身训练收益，从而内化课程判断（"知道接下来该学什么"），替代外部启发式或辅助模型；收敛速度加速最高 67%。
🔧 技术亮点：
- 提示内奖励方差作为课程有效性的轻量信号，无需额外标注或外部模型
- 策略同时优化 RFT 奖励与自我判断奖励，形成元认知闭环
- 适用范围广：数学推理、代码生成、Agentic 函数调用均有效
📊 实验结果：在离散和连续 RFT 多个基准上一致超越现有课程方法，收敛加速最高达 67%
🔄 自进化类型：**自我博弈（元认知课程自适应）**

## 🚀 今日洞察

**1. "失败即数据"成为 Agent 自进化的核心范式。** FORGE 和 FATE 均从失败轨迹出发重建知识或监督信号，与人类"从错误中学习"的认知路径高度契合，且无需额外专家标注——这正在成为低成本持续演化的主流技术方向。

**2. 能力侵蚀（Capability Erosion）是长周期自进化的关键挑战。** 自进化不是单调进步，而是一个适应与遗忘的动态平衡过程；如何在跨任务持续适应中保留历史能力，将是未来 Lifelong Agent 系统的核心设计约束，CPE 提供了首个系统性视角。

**3. 奖励信号的精细化是解锁长轨迹自我提升的技术瓶颈。** GEAR 的自适应信用分配和 METIS 的元认知课程内化，从"给什么奖励"和"学什么任务"两个维度同步推进 RL 微调的效率上限，指向无需人工设计奖励函数的全自动自进化训练流水线。
