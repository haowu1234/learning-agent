📄 **EvoArena：追踪记忆演化以构建动态环境中的鲁棒 LLM Agent**（EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments）
🔗 https://arxiv.org/abs/2606.13681
💡 **核心贡献**
提出 EvoArena —— 首个将环境变化建模为进化序列的 Agent 评测基准，覆盖终端、软件和社交三大动态域；同时提出 EvoMem，一种基于补丁的记忆范式，将记忆演化记录为结构化更新历史，让 Agent 能通过"记忆差异"感知环境变化并做出推理适应。
🔧 **技术亮点**
- 基准设计：将环境变化建模为渐进式更新序列（Progressive Update Chain），要求 Agent 完成连续依赖的进化子任务
- EvoMem：以"补丁"（patch）形式记录记忆更新历史，而非直接替换记忆状态，保留完整演化上下文
- 机制分析显示 EvoMem 显著提升记忆中的证据捕获能力，更好保留环境状态的完整演化轨迹
📊 **实验结果**
- 当前 SOTA Agent 在 EvoArena 上平均准确率仅 39.6%，证明动态评测的挑战性
- EvoMem 在 EvoArena 上平均提升 +1.5%，在 GAIA (+6.1%) 和 LoCoMo (+4.8%) 上均有提升
- Chain-level 任务（连续子任务）准确率提升 +3.7%
🔄 **自进化类型**：持续学习 / 记忆驱动适应

📄 **SkillCAT：用于 LLM Agent 的对比评估与拓扑感知技能自进化**（SkillCAT: Contrastive Assessment and Topology-Aware Skill Self-Evolution for LLM Agents）
🔗 https://arxiv.org/abs/2606.13317
💡 **核心贡献**
提出 SkillCAT，一个免训练的技能自进化框架，通过对比同任务成功/失败轨迹对来提取高质量技能文档，并引入评估驱动的验证机制和拓扑路由推理，解决了现有方法"单轨迹学习、无验证合并、全量加载"三大缺陷。
🔧 **技术亮点**
- CCE（对比因果提取）：多轨迹采样 + 成功/失败对比，精准定位导致结果差异的关键行为证据
- AAE（评估增强演化）：候选补丁在源任务克隆上回放验证，仅保留改善或保持任务结果的补丁后再进行层次化合并
- TTE（拓扑感知推理）：将演化后的技能编译为可路由的子技能拓扑图，推理时仅加载与当前任务相关的能力节点
📊 **实验结果**
在 SpreadsheetBench、WikiTableQuestions、DocVQA 等多个 Agent 基准上，SkillCAT 相比基线平均提升高达 +40.40%，且支持跨模型和分布外泛化
🔄 **自进化类型**：数据飞轮 / 技能进化 / 自我反思

📄 **EEVEE：面向真实世界自改进 Agent 的测试时提示学习**（EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents）
🔗 https://arxiv.org/abs/2606.11182
💡 **核心贡献**
提出首个多数据集测试时提示学习框架，让 LLM Agent 在面对真实世界异构任务流时能够在推理阶段自适应调整提示配置，无需重新训练模型权重。通过 Router-Prompt 协同进化策略解决异构数据流中的跨任务干扰问题。
🔧 **技术亮点**
- 任务路由器：将输入流划分为任务簇并匹配合适的提示配置，降低多数据集间干扰
- Router-Prompt 协同进化：交错路由训练与提示学习阶段，解决二者的相互依赖问题
- 支持在线实时适应，兼顾单基准学习能力与多基准跨域泛化效率
📊 **实验结果**
- 相比 Qwen3-4B-Instruct 基线，多基准平均分提升 +10.38 分
- 相比 DeepSeek-V3.2 基线，提升 +24.32 分
- 超越 SOTA 方法 GEPA 和 ACE 高达 37.2% 和 48.2%
🔄 **自进化类型**：测试时自适应 / 在线提示进化

📄 **INFUSER：影响力引导的自进化提升推理能力**（INFUSER: Influence-Guided Self-Evolution Improves Reasoning）
🔗 https://arxiv.org/abs/2606.09052
💡 **核心贡献**
提出 INFUSER，一个迭代协同训练框架，将生成器（Generator，从非结构化文档中草拟问题和答案）与求解器（Solver，从这些问题中学习）协同进化：生成器的奖励基于"所提问题对当前求解器在目标分布上是否真正有帮助"的优化器感知影响力分数，而非简单的难度启发式。
🔧 **技术亮点**
- 影响力分数（Optimizer-aware Influence Score）：度量候选问题对求解器在目标分布上的实际改进贡献，形成以solver状态为条件的自适应课程
- DuGRPO：为处理连续噪声影响力分数而提出的双归一化 GRPO 变体，用于生成器训练
- 完全无人工标注：从自动收集的非结构化文档池出发，构建自适应训练课程
📊 **实验结果**
- 在 Olympiad 和 SuperGPQA 基准上相比强基线提升超过 20% 相对提升
- 8B INFUSER 协同进化生成器在数学和编码任务上超越冻结的 32B thinking 生成器
🔄 **自进化类型**：数据飞轮 / 自我博弈 / 奖励驱动

📄 **Self-Harness：能自我改进的 Agent 运行框架**（Self-Harness: Harnesses That Improve Themselves）
🔗 https://arxiv.org/abs/2606.09498
💡 **核心贡献**
提出 Self-Harness 范式：LLM Agent 无需人工工程师或更强外部 Agent，通过挖掘自身执行轨迹中的失败模式来自动改进操控自身行为的「驱动框架（Harness）」，首次实现端到端的 Agent 自我架构进化。
🔧 **技术亮点**
- Weakness Mining（弱点挖掘）：从执行轨迹中识别模型特定的失败模式，而非通用错误
- Harness Proposal（框架提案）：生成与具体失败绑定的多样化最小修改方案（非泛化指令）
- Proposal Validation（提案验证）：通过回归测试只接受候选修改，防止退化
📊 **实验结果**
在 Terminal-Bench-2.0 上，三个不同模型家族（MiniMax M2.5 / Qwen3.5-35B-A3B / GLM-5）均持续提升：
- MiniMax M2.5：40.5% → 61.9%
- Qwen3.5-35B-A3B：23.8% → 38.1%
- GLM-5：42.9% → 57.1%
🔄 **自进化类型**：自我反思 / 架构自进化

## 🚀 今日洞察

当前 Agent 自进化研究呈现出**从参数进化向结构/记忆/框架进化**的明显转向：最新工作不仅关注模型权重的更新（INFUSER），更开始探索技能文档（SkillCAT）、运行框架（Self-Harness）、提示配置（EEVEE）和记忆结构（EvoMem）的自动演化，标志着自进化的粒度从"黑盒微调"走向"白盒架构改写"。核心挑战依然是**信号稀疏与验证成本**——如何在没有密集人工反馈的情况下判断一次自我改进是否真正有效（而非表面上的准确率提升），是 SkillCAT 的 AAE 验证和 INFUSER 的影响力分数都在攻坚的本质问题。此外，EvoArena 揭示了一个长期被忽视的盲点：大多数自进化评测假设静态环境，而真实部署中环境本身也在演化，「在演化中演化」将成为下一代 Agent 的核心能力。
