📄 **OpenSkill：开放世界 LLM Agent 的无监督自进化框架**（OpenSkill: Open-World Self-Evolution for LLM Agents）
🔗 https://arxiv.org/abs/2606.06741
💡 **核心贡献**
提出了 OpenSkill，一个无需目标任务标注的开放世界 Agent 自进化框架，能够从文档、代码仓库和互联网中自主引导技能学习与验证信号的构建；框架通过"自建虚拟任务"代替真实标注，实现技能的迁移性训练，最终在评测阶段才使用目标任务监督。
🔧 **技术亮点**
- 从文档/GitHub 仓库/Web 自主获取知识锚点（Grounded Anchors），无需人工标注的成功轨迹
- 构建自监督验证器（Self-Built Verifier），与真实答案对齐但从不访问真实答案，实现无监督闭环
- 生成的技能具有跨模型迁移能力，无需针对特定模型重新适配
📊 **实验结果**
在三个基准测试和两个目标 Agent 上取得最高自动通过率，同时满足"无目标任务监督"约束。
🔄 **自进化类型**：数据飞轮 + 无监督自我提升

📄 **ANCHOR：面向自进化系统的人机协作健康进化框架**（Towards Healthy Evolution: Exploring the Role and Mechanisms of Human-Agent Interaction in Self-Evolving Systems）
🔗 https://arxiv.org/abs/2606.06114
💡 **核心贡献**
揭示了自进化 Agent 在无人监督时产生能力退化与安全漂移的问题，提出 ANCHOR（Agent Norm Correction through Human-like Oversight and Review）——用 LLM 模拟人类监督，在自进化不同阶段注入反馈来纠正进化轨迹；在编程、数学推理和安全性上验证了有效性。
🔧 **技术亮点**
- 用 LLM 模拟人类监督员，成本远低于真实人工标注，同时有效遏制安全漂移
- 发现"输出验证阶段"是最关键的监督介入点，对进化质量提升效果最显著
- 揭示监督频率存在边际递减效应，过高频率不会带来对等收益
📊 **实验结果**
在两个开源自进化 Agent 系统上，即使极少量监督也能显著减轻安全退化，同时保持核心任务性能稳定。
🔄 **自进化类型**：自我博弈 + 人机协作对齐

📄 **RHO：基于自我偏好的回溯式 Agent Harness 自优化**（Retrospective Harness Optimization: Improving LLM Agents via Self-Preference over Trajectory Rollouts）
🔗 https://arxiv.org/abs/2606.05922
💡 **核心贡献**
提出 RHO（Retrospective Harness Optimization），一种无需外部标注的自监督 Agent 工具链（Harness）优化方法；利用历史轨迹多路并行 rollout，通过模型自验证和自一致性选择最优更新方案，实现持续自我改进。
🔧 **技术亮点**
- 从历史轨迹中选取多样困难任务构成核心集（Coreset），在无 Ground-Truth 情况下驱动优化
- 自验证（Self-Validation）+ 自一致性（Self-Consistency）双重过滤，生成最优 Harness 候选
- 通过模型自身的 Pairwise 自偏好打分选择更新，无需外部 Grader
📊 **实验结果**
单轮优化后，SWE-Bench Pro 通过率从 59% 提升至 78%，无需任何外部评分系统；跨软件工程、技术工作、知识工作三个领域均有显著提升。
🔄 **自进化类型**：自我反思 + 数据飞轮

📄 **Agentopia：多智能体社会长期生活仿真与 LLM 学习**（Agentopia: Long-Term Life Simulation and Learning in Agent Societies）
🔗 https://arxiv.org/abs/2606.07513
💡 **核心贡献**
构建了 Agentopia 框架，通过模拟 100 个 Agent 在 10 个仿真年中的长期社会生活，研究从社会经验中涌现的学习信号；定义"生活奖励"对标人类幸福感，用 Rejection Sampling 训练 LLM，使其从模拟社交经验中获得真实能力提升。
🔧 **技术亮点**
- 10 年跨度的多 Agent 长期仿真，远超以往仅数日规模的社会模拟
- 以"生活奖励"（Life Reward）为弱监督信号，通过 Rejection Sampling 实现自我训练
- 展示了 Agent 社会中涌现的复杂社交行为（关系建立、个人成长、目标追求）
📊 **实验结果**
生活奖励训练使底层 LLM 得到实质性增强：Agent 社会幸福感提升，并在下游角色扮演基准上泛化提升 **+15.6%**。
🔄 **自进化类型**：奖励驱动 + 自我博弈 + 模拟环境学习

📄 **SETA：面向任务无关持续学习的稀疏子空间专家共享**（Sparse Subspace-to-Expert Sharing for Task-Agnostic Continual Learning）
🔗 https://arxiv.org/abs/2606.07500
💡 **核心贡献**
提出 SETA（Sparse Experts for Task-Agnostic Continual Learning），通过自适应稀疏子空间分解将 LLM 参数动态划分为任务专用专家与共享专家，从机制层面解决持续学习中的塑性-稳定性两难困境，防止灾难性遗忘。
🔧 **技术亮点**
- 自适应弹性锚定（Adaptive Elastic Anchoring）保护共享专家权重，防止新任务覆写已有知识
- 路由感知正则化（Routing-Aware Regularization）在权重和路由双层面保护共享知识
- 统一的门控网络自动在推理时检索正确专家组合，无需任务标识符
📊 **实验结果**
在 LLaMA-2 7B 和 Qwen3-4B 上跨多个领域基准测试，达到或超越 SOTA 持续学习基线，早期任务知识保留尤其突出，反向迁移（Backward Transfer）表现优异。
🔄 **自进化类型**：持续学习 + 防遗忘

## 🚀 今日洞察

**趋势1 — 去标注化自进化成主流**：本日多篇论文（OpenSkill、RHO）都在核心聚焦一个共同问题：如何在无人工标注、无 Ground-Truth 验证器的情况下驱动 Agent 自进化。从"自建虚拟任务"到"历史轨迹 rollout + 自偏好"，无监督/自监督闭环已成为 2026 年最热的技术路线。

**趋势2 — 进化安全与对齐不容忽视**：ANCHOR 的研究提出了一个警示：纯粹的自我进化（无人类监督）会导致安全漂移与能力退化。如何在保持进化效率的同时引入轻量级人类监督，成为自进化研究的新核心挑战。

**趋势3 — 奖励信号多样化**：从 Agentopia 的"生活奖励"到 SETA 的持续学习，研究者正突破传统 task-specific reward 的局限，探索更广泛的弱监督信号（社会行为、幸福感代理、子空间稳定性），推动 LLM 在更稀疏信号下实现自我进化。
