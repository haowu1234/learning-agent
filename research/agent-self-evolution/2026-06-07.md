📄 **迈向健康进化：人机交互在自进化系统中的角色与机制**（Towards Healthy Evolution: Exploring the Role and Mechanisms of Human-Agent Interaction in Self-Evolving Systems）
🔗 https://arxiv.org/abs/2606.06114
💡 **核心贡献**：提出 ANCHOR 框架（Agent Norm Correction through Human-like Oversight and Review），通过 LLM 模拟人类监督，在自进化的不同阶段注入规范化反馈，解决自主进化导致能力退化与安全漂移的问题。该工作首次系统研究了人机交互在自进化系统中的功能机制与干预时机。
🔧 **技术亮点**：
- 设计了多阶段人类监督注入机制，可在自进化循环的训练前、训练中、部署后三个节点介入
- 用 LLM 模拟人类反馈，解耦真实标注成本与持续监督需求
- 在两个开源自进化 agent 系统上实验，验证不同干预时机对进化健康度的影响
📊 **实验结果**：ANCHOR 有效抑制自主进化中的能力退化和安全偏移，干预效果随介入阶段不同呈现显著差异
🔄 **自进化类型**：自我博弈 + 人机协作监督

📄 **MOSS：通过源码级重写实现自主 Agent 系统的自进化**（MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems）
🔗 https://arxiv.org/abs/2605.22794
💡 **核心贡献**：突破现有自进化框架只能修改 "文本可变构件"（提示词、技能文件、记忆模式）的局限，首次将自进化边界延伸至 Agent 源代码层，实现路由逻辑、钩子顺序、状态不变量等结构性缺陷的自动修复。这是 Agent 自进化从配置级向代码级的重要跃升。
🔧 **技术亮点**：
- 提出源码级重写（Source-Level Rewriting）机制，让 agent 能直接修改自身执行代码
- 区分"文本层失效"与"代码层结构性失效"两类问题，针对后者设计专用修复路径
- 部署后可持续从用户交互中学习，无需人工推送更新
📊 **实验结果**：在多个自主 Agent 基准上，MOSS 能修复纯文本进化方法无法触及的结构性故障，成功率显著提升
🔄 **自进化类型**：自我修复 / 持续学习（代码级）

📄 **团队协作进化：基于 LLM 的多智能体系统协作自进化**（Evolve as a Team: Collaborative Self-Evolution for LLM-based Multi-Agent Systems）
🔗 https://arxiv.org/abs/2605.29790
💡 **核心贡献**：针对多 Agent 系统（MAS）执行经验交织复杂、难以精确归因的痛点，提出协作自进化框架，让多 Agent 系统能从自身执行轨迹中识别协作瓶颈并联合进化。首次将自进化扩展至多 Agent 协作层面。
🔧 **技术亮点**：
- 建立跨多 Agent 执行链的经验提炼机制，解决归因难题（哪个 agent 的哪个步骤应该改进）
- 支持通信消息与执行记录的联合分析，精确定位协作失效点
- 进化不局限于单一 agent，而是在系统级别协同更新角色职责与交互协议
📊 **实验结果**：在复杂长时域任务上，协作自进化相比单 agent 独立进化显著提升整体任务完成率
🔄 **自进化类型**：多 Agent 协作进化 / 数据飞轮

📄 **EvoRepair：基于经验的自进化漏洞修复 Agent**（EvoRepair: Enhancing Vulnerability Repair Agents Through Experience-Based Self-Evolution）
🔗 https://arxiv.org/abs/2605.30105
💡 **核心贡献**：将自进化机制引入自动化漏洞修复（AVR）领域，解决 LLM 在修复过程中无法积累领域专用经验、跨漏洞知识无法复用的问题，构建了首个基于经验驱动的自进化 AVR Agent 框架。
🔧 **技术亮点**：
- 设计漏洞内经验积累机制（intra-vulnerability），在同一修复过程中不断迭代改进
- 建立跨漏洞经验复用库（cross-vulnerability），历史修复知识可迁移至新漏洞
- 经验以结构化知识图谱形式存储，支持高效检索与动态更新
📊 **实验结果**：在 CVE 漏洞修复基准上，EvoRepair 相比基线 LLM 修复成功率提升显著，尤其在复杂漏洞类别上优势明显
🔄 **自进化类型**：经验驱动自进化 / 数据飞轮 / 持续学习

📄 **RREDCoT：针对推理模型的分段奖励再分配**（RREDCoT: Segment-Level Reward Redistribution for Reasoning Models）
🔗 https://arxiv.org/abs/2606.06475
💡 **核心贡献**：针对 GRPO 等 RL 微调方法的延迟奖励问题（Chain-of-Thought 结束后才能赋予奖励），提出利用模型自身近似最优奖励再分配，在无额外生成开销的前提下实现链路中间步的信用分配。降低了 RL 训练的高方差问题。
🔧 **技术亮点**：
- 将 CoT 轨迹切分为语义片段，逐段估计中间状态价值
- 利用模型自身估算奖励分布，避免蒙特卡洛采样的计算开销
- 分析了 CoT 分段策略与状态价值估计对再分配效果的影响
📊 **实验结果**：相比标准 GRPO，RREDCoT 在多个推理基准上训练更稳定，最终推理准确率有所提升
🔄 **自进化类型**：奖励驱动 / 强化学习自改进

## 🚀 今日洞察

当前 Agent 自进化研究正沿三条主线快速推进：**①进化边界外扩**（MOSS 将自进化从提示词/技能扩展到源代码层，突破了此前"只能改配置"的天花板）、**②协作进化**（多 Agent 系统开始探索系统级联合进化而非单 Agent 独立优化）、**③安全对齐与人机协作**（ANCHOR 揭示了纯自主进化容易发生安全漂移，人类监督的介入时机与形式成为新的研究焦点）。核心挑战在于：如何在保持进化活力的同时防止能力退化与价值漂移，以及如何设计低成本、可扩展的经验积累与复用机制。
