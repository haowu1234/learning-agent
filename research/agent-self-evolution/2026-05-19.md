### 1. 自进化 Agent 会遗忘吗？终身 LLM Agent 适应中的能力退化与保留

**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）**

🔗 https://arxiv.org/abs/2605.09315
📅 提交：2026-05-10 | 作者：Ye Yu, Xiaopeng Yuan, Haibo Jin 等

💡 **核心贡献**
本文首次系统揭示了 LLM Agent 自进化过程中的"能力侵蚀"（Capability Erosion）现象：当 Agent 通过工作流、技能、模型参数或记忆四条进化路径适应新任务分布时，旧能力会发生非单调性退化。为此提出 **能力保留进化（CPE）** 通用稳定化原则，在持续自适应过程中约束破坏性能力漂移。

🔧 **技术亮点**
- 识别四条自进化通道（workflow / skill / model / memory）均存在能力侵蚀，首次给出统一分类框架
- CPE 通过在进化目标中引入能力锚定约束，防止已习得能力被新分布覆盖
- 在 GPT-5.1 优化下，workflow 进化中简单任务保留率从 41.8% → 52.8%，同时复杂任务适应性不降

📊 **实验结果**
- 覆盖全部四条进化维度，CPE 在所有维度均实现已有能力稳定性提升
- 工作流进化场景：简单任务 +11 个百分点（41.8% → 52.8%）

🔄 **自进化类型**：持续学习 / 能力保留 / 终身学习

### 2. Skill-R1：基于强化学习的 Agent 技能进化

**（Skill-R1: Agent Skill Evolution via Reinforcement Learning）**

🔗 https://arxiv.org/abs/2605.09359
📅 提交：2026-05-10 | 作者：Yash Vishe, Rohan Surana, Xunyi Jiang 等（UCSD / Adobe）

💡 **核心贡献**
提出 Skill-R1，一个**实例级循环技能优化**强化学习框架，训练轻量级技能生成器，通过可验证奖励反馈驱动技能跨代进化，无需修改任务 LLM，兼容闭源模型。该框架将技能优化建模为双层信用分配问题：单代内部质量提升 + 跨代方向性演进。

🔧 **技术亮点**
- 引入**双层 GRPO 目标**：代内优势（intra-generation）对比同技能 rollout，代际优势（inter-generation）奖励使后续代行为提升的版本修订
- 技能生成器条件化于任务上下文、历史 rollout 和验证结果，实现有记忆的方向性进化
- 保持任务 LLM 冻结（黑盒），适配 OpenAI/Anthropic 等闭源 API 场景

📊 **实验结果**
- 在含可验证奖励的多基准测试上持续超越无技能基线和标准 GRPO
- 多步复杂任务上提升尤为显著

🔄 **自进化类型**：奖励驱动 / 技能进化 / 自我博弈

### 3. Swarm Skills：用于多智能体协调工程的可移植自进化规范

**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）**

🔗 https://arxiv.org/abs/2605.10052
📅 提交：2026-05-11，更新：2026-05-15 | 作者：Xinyu Zhang, Zhicheng Dou 等

💡 **核心贡献**
提出 **Swarm Skills** 规范，将多智能体协调协议抽象为可跨框架移植的一等资产（包含角色、工作流、执行边界和自进化语义结构），打破框架锁定。配套自进化算法从成功执行轨迹蒸馏出新 Swarm Skills，并基于"效果-利用率-新鲜度"三维评分持续 patch 现有技能，无需人工干预。

🔧 **技术亮点**
- 扩展 Anthropic Skills 标准加入多智能体语义，实现**零适配跨 Agent 移植性**（progressive disclosure）
- 成功轨迹蒸馏 + 三维评分自动筛选机制，构成完整数据飞轮
- 以开源 JiuwenSwarm 为参考实现，可直接验证复现

📊 **实验结果**
论文以架构兼容性分析和综合案例研究为主，展示跨框架移植与自进化协调策略更新的可行性。

🔄 **自进化类型**：数据飞轮 / 多智能体自进化 / 模型蒸馏

### 4. Autogenesis：一种自进化 Agent 协议（AGP）

**（Autogenesis: A Self-Evolving Agent Protocol）**

🔗 https://arxiv.org/abs/2604.15034
📅 提交：2026-04-16，v3：2026-05-07 | 作者：Wentao Zhang, Zhe Zhao 等

💡 **核心贡献**
提出 **Autogenesis Protocol（AGP）**，通过双层协议架构（资源基底层 RSPL + 自进化层 SEPL）将"进化什么"与"如何进化"解耦：提示词、智能体、工具、环境、记忆均作为协议注册资源纳管，SEPL 提供可审计、可回滚的闭环改进接口。

🔧 **技术亮点**
- RSPL 为每类资源提供显式状态机、生命周期管理与版本化接口，避免单体式紧耦合
- SEPL 规范了"提议→评估→提交"闭环算子，演化链路完整可审计
- 代码已开源（github.com/DVampire/Autogenesis）

📊 **实验结果**
在多个需要长程规划和工具使用的基准上，AGS 持续超越强基线，验证资源管理与闭环自进化的有效性。

🔄 **自进化类型**：自我反思 / 持续学习 / 闭环自进化

### 5. 超越个体智能：LLM 多智能体系统中的协作、失败归因与自进化综述

**（Beyond Individual Intelligence: Surveying Collaboration, Failure Attribution, and Self-Evolution in LLM-based Multi-Agent Systems）**

🔗 https://arxiv.org/abs/2605.14892
📅 提交：2026-05-14/15 | 作者：Shihao Qi, Jie Ma 等（18 人）

💡 **核心贡献**
提出 **LIFE 进程**（Lay foundation → Integrate → Find faults → Evolve）作为统一框架，系统综述多智能体自进化的四个因果依赖阶段，首次厘清协作、失败归因与自进化三者之间的结构性依赖关系。揭示"失败归因"是从协作到自进化的关键缺失环节。

🔧 **技术亮点**
- LIFE 四阶段形式化定义每阶段间的双向约束关系，超越以往孤立综述
- 系统整理失败传播（error propagation）在多智能体中的独特放大效应
- 提出跨阶段研究议程：闭环系统 = 持续诊断 + 结构重组 + 行为精化

📊 **实验结果**
综述论文，无直接实验数据；提供系统分类法与未解挑战路线图。

🔄 **自进化类型**：多智能体自进化 / 自我反思 / 持续学习

## 🚀 今日洞察

当前 Agent 自进化研究正从单点能力突破走向**系统性闭环工程**：Skill-R1 用 RL 将技能优化从"提示工程"升级为"可学习过程"，Swarm Skills 和 AGP 则尝试在协议层解决可移植性与可演化性的基础设施问题。然而，"能力侵蚀"（Do Self-Evolving Agents Forget?）的发现揭示了自进化的核心悖论——**新能力习得与旧能力保留之间的张力**是终身学习 Agent 面临的最深层挑战，现有方法尚无优雅解。多智能体自进化综述（Beyond Individual Intelligence）进一步指出，失败归因（Fault Attribution）是当前从协作到自进化的最薄弱环节，构建真正能"从错误中学习"的多智能体闭环系统，仍是未来 2-3 年的核心开放问题。
