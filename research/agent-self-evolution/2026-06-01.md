📄 **[双向进化搜索驱动语言模型自我提升]**（Self-Improving Language Models with Bidirectional Evolutionary Search）
🔗 https://arxiv.org/abs/2605.28814
💡 **核心贡献**：提出 BES（双向进化搜索）框架，将正向候选进化与反向目标分解相耦合，突破传统自回归展开只能在高概率空间探索的局限；理论证明进化算子可"逃离"窄熵壳，后向搜索可指数级减少求解所需样本量。
🔧 **技术亮点**：
- 正向搜索：通过进化算子对部分轨迹进行重组（recombination），生成单模型 rollout 难以获得的多样候选
- 反向分解：将原始任务递归拆解为可检验子目标（checkable subgoals），提供密集中间反馈
- 双阶段联合：post-training 阶段与 inference 阶段均可应用，实验覆盖三个开放问题求解基准
📊 **实验结果**：在主流 post-training 算法失效的挑战性任务上实现持续增益；推理阶段在三个开放基准上优于现有开源框架的平均与最优表现。
🔄 **自进化类型**：自我博弈 + 数据飞轮

📄 **[团队协作自进化：多智能体系统的经验驱动演化]**（Evolve as a Team: Collaborative Self-Evolution for LLM-based Multi-Agent Systems）
🔗 https://arxiv.org/abs/2605.29790
💡 **核心贡献**：提出 Meta-Team 框架，针对多智能体系统（MAS）执行失败难以溯因的问题，通过保留每个智能体的执行上下文并协调跨任务后沟通，使各 Agent 协作交换分布式证据，实现经验驱动的多尺度自进化。
🔧 **技术亮点**：
- 执行上下文保留：记录各 Agent 完整的工具调用链与通信消息，而非仅保留最终输出
- 后任务协作通信（post-task communication）：允许 Agent 间交换失败归因的分布式证据
- 多尺度进化：同时优化 Agent 行为、跨 Agent 协调策略与团队级组织结构
📊 **实验结果**：在六个长视野 Agent 基准上持续超越单 Agent 系统、手工设计 MAS 及先前 MAS 进化方法；分析表明 Meta-Team 实现更可靠、可扩展的 MAS 自进化。
🔄 **自进化类型**：持续学习 + 自我反思（多 Agent 协作）

📄 **[SEAL：智能体与学习环境的协同共进化]**（SEAL: Synergistic Co-Evolution of Agents and Learning Environments）
🔗 https://arxiv.org/abs/2605.24426
💡 **核心贡献**：提出闭环协同进化框架 SEAL，识别并解决"Agent-环境错位"问题（Agent 能力边界在训练中动态变化，但提供监督信号的环境保持静态），通过诊断失败轨迹同时驱动环境侧和策略侧的双向更新。
🔧 **技术亮点**：
- On-policy 轨迹收集 + 可执行验证：实时诊断失败 rollout，生成 turn-level 失败标签
- 环境自适应：动态调整工具可用性提示、约束信息及面向恢复的反馈（recovery-oriented feedback）
- 诊断引导的优势重加权（diagnosis-guided advantage reweighting）：将诊断结果作为策略优化中的优势函数权重
📊 **实验结果**：仅用 400 个训练样本，在三个骨干模型上平均提升 +8.25 至 +26.25 分；同时展示正向的 OOD（out-of-distribution）迁移效果。
🔄 **自进化类型**：奖励驱动 + 持续学习（环境-Agent 联合进化）

📄 **[Search-E1：自蒸馏驱动搜索增强推理的自进化]**（Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning）
🔗 https://arxiv.org/abs/2605.22511
💡 **核心贡献**：去除外部监督、辅助模块（PRM/critic）、树搜索等复杂附加机制，仅用"GRPO + 在线策略自蒸馏（OPSD）"的极简组合实现搜索增强推理 Agent 的持续自进化，质疑并简化了该领域的方法论复杂度。
🔧 **技术亮点**：
- OPSD（On-Policy Self-Distillation）：每轮 GRPO 后，策略在训练问题上自我 rollout，再用 token 级前向 KL 目标对齐策略的推理时分布到更高效同胞轨迹（sibling trajectory）的分布
- 特权上下文（privileged context）：推理时暴露更优轨迹，提供天然密集的逐步监督信号，无需人工标注
- 极简 pipeline：无需 reward model、tree search 或外部蒸馏，完全自给自足
📊 **实验结果**：Qwen2.5-3B 在七个 QA 基准上平均 EM 达 0.440，超过同等规模全部开源基准方法。
🔄 **自进化类型**：模型蒸馏 + 数据飞轮（自蒸馏）

📄 **[FATE：基于失败轨迹的 Agent 安全自进化]**（On-Policy Self-Evolution via Failure Trajectories for Agentic Safety Alignment）
🔗 https://arxiv.org/abs/2605.11882
💡 **核心贡献**：提出 FATE 框架，将工具使用 Agent 的失败轨迹（包含不安全工具调用、注入指令跟随、有害请求服从等）转化为自我修复监督信号，无需专家演示即可实现安全对齐的自进化；引入 Pareto-Front Policy Optimization（PFPO）在安全性与功能性之间取得帕累托最优。
🔧 **技术亮点**：
- 失败挖掘与修复候选生成：由同一策略提出修复候选轨迹，再经多维度 verifier（安全性、功能性、过度拒绝控制、轨迹合法性）过滤
- PFPO：结合有监督预热（supervised warmup）与帕累托感知策略优化，避免"安全换性能"的零和取舍
- 完全 on-policy：不依赖离线数据或外部专家标注，纯 Agent 自我挖掘修复数据
📊 **实验结果**：在 AgentDojo、AgentHarm、ATBench 上，对比强基线：攻击成功率降低 33.5%，有害服从率降低 82.6%，轨迹安全诊断能力提升 6.5%。
🔄 **自进化类型**：自我反思 + 奖励驱动（安全对齐导向）

## 🚀 今日洞察

本周 Agent 自进化研究呈现三大趋势：**①"极简自进化"崛起**——Search-E1 和 BES 均证明去除外部 PRM、树搜索等重型组件后，通过搜索机制的根本性创新（双向进化 / 自蒸馏）同样可以突破性能瓶颈，预示着方法论从"堆砌组件"转向"结构化探索"的范式转移；**②"失败即资产"成共识**——FATE、SEAL 和 Meta-Team 均以失败轨迹/经验为核心原材料驱动策略更新，表明自进化的关键不在于收集更多成功示范，而在于充分利用失败的结构化信息；**③自进化安全研究正在从"事后约束"走向"过程对齐"**，FATE 的 PFPO 框架提示安全-功能权衡将是下一阶段自进化系统落地的核心工程挑战。
