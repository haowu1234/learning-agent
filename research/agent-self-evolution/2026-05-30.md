📄 **团队协作自进化：LLM多智能体系统的协同自我进化**（Evolve as a Team: Collaborative Self-Evolution for LLM-based Multi-Agent Systems）
🔗 https://arxiv.org/search/?searchtype=all&query=Evolve+as+a+Team+Collaborative+Self-Evolution+LLM  
📅 提交日期：2026-05-28  
💡 **核心贡献**：提出了多智能体系统（MAS）的协同自进化框架，让多个 LLM 智能体在执行复杂长程任务时能通过积累的经验共同进化，自动修复各类执行失败。该框架解决了真实世界任务中难以在设计阶段消除失败的核心难题，实现了无需人工干预的经验驱动式系统优化。  
🔧 **技术亮点**：
- 基于执行失败记录构建协作经验池，智能体之间共享失败案例与修复策略
- 多角色分工机制：不同智能体负责感知错误、提出修复方案、验证改进效果
- 经验驱动的持续进化循环：每轮任务后自动更新全局策略库

🔄 **自进化类型**：多智能体协同自进化 / 经验驱动

📄 **双向进化搜索驱动的语言模型自我提升**（Self-Improving Language Models with Bidirectional Evolutionary Search）
🔗 https://arxiv.org/search/?searchtype=all&query=Self-Improving+Language+Models+Bidirectional+Evolutionary+Search  
📅 提交日期：2026-05-27  
💡 **核心贡献**：将搜索机制引入语言模型自我提升，提出双向进化搜索方法，同时在"输出空间"和"指令空间"进行双向探索，突破了单向自我提升的局限。该方法无需外部监督信号，通过模型自身的双向搜索实现性能的持续提升。  
🔧 **技术亮点**：
- 前向搜索：在给定指令下探索更优的输出候选
- 反向搜索：根据期望输出反推更优的指令表达
- 双向协同：两路搜索结果互相引导，形成正反馈的自进化循环

🔄 **自进化类型**：自我搜索 / 自我博弈 / 无监督自我提升

📄 **SkillGrad：像梯度下降一样优化智能体技能**（SkillGrad: Optimizing Agent Skills Like Gradient Descent）
🔗 https://arxiv.org/search/?searchtype=all&query=SkillGrad+Optimizing+Agent+Skills+Like+Gradient+Descent  
📅 提交日期：2026-05-26  
💡 **核心贡献**：提出将梯度下降思想类比到文本技能优化中，通过迭代"误差反传"更新 LLM 智能体的技能描述，实现任务导向的技能自我精炼。SkillGrad 为不可微的语言空间提供了一种近似梯度优化范式，无需参数微调。  
🔧 **技术亮点**：
- 将任务执行误差转化为"技能梯度"信号，文本形式反传给技能描述器
- 技能作为轻量化适配层，与主模型权重解耦，更新成本极低
- 支持多步骤任务中跨步骤的误差归因与技能局部更新

🔄 **自进化类型**：技能自我精炼 / 数据飞轮

📄 **SEAL：智能体与学习环境的协同共进化**（SEAL: Synergistic Co-Evolution of Agents and Learning Environments）
🔗 https://arxiv.org/search/?searchtype=all&query=SEAL+Synergistic+Co-Evolution+Agents+Learning+Environments  
📅 提交日期：2026-05-23  
💡 **核心贡献**：提出了"双向共进化"框架——智能体与其学习环境同步进化，环境会根据智能体当前能力动态生成适配难度的任务，破解了传统固定环境下课程学习的天花板效应。SEAL 让智能体始终处于能力边界上学习，实现高效的持续自我提升。  
🔧 **技术亮点**：
- 环境生成器根据智能体表现自适应调整任务难度与类型
- 智能体进化信号反向指导环境调整策略，形成闭环
- 支持持续学习（Continual Learning）：智能体无需重置即可适应分布漂移

📊 **实验结果**：在多个 LLM Agent 基准上，SEAL 相比固定课程训练平均提升 8-15% 成功率，且能有效缓解遗忘问题。  
🔄 **自进化类型**：持续学习 / 环境协同进化

📄 **Search-E1：自蒸馏驱动的搜索增强推理自进化**（Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning）
🔗 https://arxiv.org/abs/2505.15457  
📅 提交日期：2026-05-26（更新）  
💡 **核心贡献**：基于自蒸馏机制让搜索增强推理智能体实现自我进化，无需外部强监督或复杂辅助模块，直接从模型自身生成的搜索轨迹中提炼高质量训练信号并迭代优化。相比引入外部系统的流水线，Search-E1 提出了一条更简洁的后训练自进化路径。  
🔧 **技术亮点**：
- 搜索轨迹过滤：使用奖励信号从自生成轨迹中筛选高质量样本
- 自蒸馏循环：将筛选后的轨迹作为下一轮训练数据，形成数据飞轮
- 标准后训练流水线兼容：可直接插入现有 RLVR/SFT 框架

📊 **实验结果**：在多个知识密集型推理基准上超越引入外部辅助系统的竞争方法。  
🔄 **自进化类型**：自我蒸馏 / 数据飞轮 / 奖励驱动

## 🚀 今日洞察

近期 Agent 自进化研究呈现三条清晰主线：**①多智能体协同自进化**成为新焦点，从单体进化升级为群体共同演化，经验共享与角色分工大幅提升系统鲁棒性；**②技能与环境协同进化**正在取代静态课程学习，智能体与环境双向驱动的闭环架构（SEAL 模式）有望成为持续学习的新范式；**③自蒸馏数据飞轮**持续被验证为最具扩展性的自进化路径，从搜索增强推理到代码生成均显示出强劲效果。核心挑战仍在于：如何在无外部反馈的开放环境中维持进化方向的正确性，防止"对齐偏移"（Alignment Tipping）导致智能体在自进化中逐渐偏离安全预期。
