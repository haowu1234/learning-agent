### 📄 **EvolveR：经验驱动闭环的LLM Agent自我进化框架**
（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）

🔗 https://arxiv.org/abs/2510.16079

💡 **核心贡献**
EvolveR 构建了一个完整的"离线自蒸馏 + 在线交互"闭环：Agent 在线执行任务积累轨迹，离线将成功/失败轨迹蒸馏为可复用策略原则并存入经验库，在线检索原则指导后续推理，形成持续强化的自我进化回路。相比仅依赖外部知识检索的 RAG，EvolveR 让模型从自身行为后果中总结"做题方法论"，在多跳问答上全面超越 Search-R1 等 RL Agent 基线。

🔧 **技术亮点**
- **经验库动态维护**：新原则入库前进行语义去重与相似合并，记录使用次数/成功率形成动态评分，持续剪枝低效原则，防止经验库退化为"流水账"
- **双阶段奖励设计**：GRPO 强化学习同时奖励最终答案正确率和推理过程完整性（是否调用经验检索、是否调用外部知识），学到"什么时候查经验、什么时候查知识"的元决策
- **离线蒸馏解耦**：成功轨迹→指导性原则，失败轨迹→警示性原则，区分极性保留更丰富的经验信号

📊 **实验结果**
- Qwen2.5-3B：平均 EM 0.382（vs. Search-R1-instruct 0.325，+17.5%）
- Qwen2.5-7B：平均 EM 0.417（vs. Search-R1-instruct 0.385，+8.3%）
- 测试集覆盖 TriviaQA、PopQA、2WikiMultiHopQA、Musique、Bamboogle

🔄 **自进化类型**：数据飞轮 + 经验蒸馏 + 奖励驱动
📌 已被 **ICML 2026** 接收；代码已开源

### 📄 **AgentEvolver：高效自进化Agent系统**
（AgentEvolver: Towards Efficient Self-Evolving Agent System）

🔗 https://arxiv.org/abs/2511.10395

💡 **核心贡献**
AgentEvolver 提出三位一体的自进化机制——自我提问（Self-Questioning）、自我导航（Self-Navigating）、自我归因（Self-Attributing）——让 LLM Agent 在无需人工构建数据集的情况下，通过好奇心驱动探索持续提升自身能力。核心创新是将 RL 的随机探索替换为语义理解指导的有目的探索，大幅降低样本复杂度和数据构建成本。

🔧 **技术亮点**
- **Self-Questioning**：Agent 在新环境中主动生成自问任务，以好奇心驱动替代外部数据集，消除对人工标注的依赖
- **Self-Navigating**：基于历史经验复用与混合策略引导，改善探索效率，避免 RL 中常见的漫无目的随机漫步
- **Self-Attributing**：按轨迹状态/动作对最终结果的贡献度分配差异化奖励，提升样本利用率，解决稀疏奖励中的信用归因难题

📊 **实验结果**
初步实验表明，AgentEvolver 在探索效率、样本利用率和任务适应速度上均优于传统 RL-based 基线。

🔄 **自进化类型**：自我博弈 + 奖励驱动 + 持续学习

### 📄 **SPARK：基于知识图谱非对称奖励的自我博弈**
（SPARK: Self-Play with Asymmetric Reward from Knowledge Graphs）

🔗 https://arxiv.org/abs/2605.05546

💡 **核心贡献**
SPARK 将自我博弈 RL 范式扩展到科学文献领域：自动从多文档科学文献构建统一知识图谱（KG），以 KG 路径作为关系推理问题的生成源，以 KG 结构化事实作为可验证奖励信号的锚点，让单个小型视觉-语言模型（sVLM）交替扮演 Proposer 和 Solver 角色完成信息不对称博弈，从而在无需人类标注的情况下提升多跳关系推理能力。

🔧 **技术亮点**
- **KG 结构化奖励**：以知识图谱代替人工标注的 ground truth，解决科学文献领域自我博弈中"奖励可验证性"难题
- **信息不对称设计**：Proposer 掌握完整 KG 路径，Solver 仅能观测问题，形成天然的博弈梯度，驱动 Solver 持续改进多跳推理链
- **可扩展在线适应**：框架设计原生支持在线适应扩展，博弈循环随 KG 更新而迭代

📊 **实验结果**
在公开基准及自建跨文档多跳 QA 数据集上持续优于无结构语料库自我博弈基线；跳数越多，性能优势越显著。

🔄 **自进化类型**：自我博弈 + 奖励驱动（结构化奖励）

### 📄 **Swarm Skills：可移植的自进化多Agent协作规范**
（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）

🔗 https://arxiv.org/abs/2605.10052

💡 **核心贡献**
Swarm Skills 将单 Agent 的"技能即资产"理念扩展到多 Agent 协作层面：提出一套可移植规范，把多 Agent 工作流（角色、协作流程、执行边界）打包为可跨系统分发的一等公民；配套自进化算法自动将成功执行轨迹蒸馏为新 Swarm Skill，并基于多维评分（有效性、利用率、新鲜度）持续修订现有技能，全程无需人工干预。

🔧 **技术亮点**
- **三维评分驱动修订**：Effectiveness（成功率）/ Utilization（使用频率）/ Freshness（时间衰减）构成多 Agent 技能的动态质量评估体系，过期/低效技能被自动淘汰
- **零适配器跨框架可移植性**：通过渐进披露（Progressive Disclosure）设计，Swarm Skills 可在不同 Agent 框架间无缝迁移，解决协调协议"锁死"在框架内部代码的痼疾
- **协调工程范式升级**：从单 Agent 的 Prompt/Context Engineering 迈向多 Agent Coordination Engineering，为协作协议的系统化迭代提供理论基础

📊 **实验结果**
通过 JiuwenSwarm 参考实现的架构兼容性分析和综合定性案例研究验证了跨 Agent 可移植性和自进化有效性。

🔄 **自进化类型**：数据飞轮 + 持续学习（多 Agent 协调层）

### 📄 **ProCrit：自激发多视角推理与Critic引导修订**
（ProCrit: Self-Elicited Multi-Perspective Reasoning with Critic-Guided Revision for Multimodal Sarcasm Detection）

🔗 https://arxiv.org/abs/2605.20867

💡 **核心贡献**
ProCrit 引入"提议-批评"双 Agent 框架，让模型对每条样本自主生成所需分析视角（而非依赖固定预设视角），并通过独立 Critic Agent 发现推理缺陷、给出自然语言反馈，驱动 Draft-Critique-Revise 循环；双阶段 RL 同步优化提议质量和反馈引导修订效果，同时根据反馈实际效果迭代优化 Critic Agent 本身，形成二阶自进化。

🔧 **技术亮点**
- **动态角色滚出（Dynamic-Role Agentic Rollout）**：强 VLM 在共享上下文中顺序生成多角色轨迹，保留跨视角依赖关系，解决过程级监督数据稀缺问题
- **Critic 自我优化**：Critic Agent 的反馈质量根据其建议被采纳后的实际性能增益迭代更新，形成 Critic-of-Critic 二阶进化闭环
- **双阶段强化学习**：Stage 1 优化提议生成；Stage 2 基于 Critic 反馈优化修订过程，解耦两个子目标防止相互干扰

📊 **实验结果**
在三个广泛使用的多模态讽刺检测基准上验证了 ProCrit 的有效性（具体数值待论文发布后补充）。

🔄 **自进化类型**：自我反思 + 自我修正（Critic-of-Critic 二阶进化）

## 🚀 今日洞察

**趋势一：经验蒸馏成为自进化核心范式。** EvolveR、AgentEvolver、Swarm Skills 三篇工作不约而同地将"从执行轨迹中蒸馏可复用知识"作为自进化的核心机制——区别于传统 RL 的梯度更新，这种非梯度、基于符号原则的蒸馏路径成本更低、可解释性更强，正在形成"数据飞轮 + 符号知识库"的新范式。

**趋势二：奖励信号的可验证性是瓶颈，结构化知识是突破口。** SPARK 用知识图谱构建可验证奖励，Swarm Skills 用多维评分取代单一准确率，ProCrit 用 Critic 反馈效果反哺奖励——三条路径共同指向同一核心挑战：如何在开放域中设计稠密且可信的奖励信号，这是阻碍 Agent 无监督自进化规模化的最大技术壁垒。

**趋势三：自进化正在从单 Agent 向协作协议层延伸。** Swarm Skills 的出现标志着自进化研究正式突破单模型边界，开始关注多 Agent 协调策略本身的自适应进化——这意味着未来的自进化系统不仅要让单个模型变强，还要让整个 Agent 生态中的协作模式随任务演化而自动优化。
