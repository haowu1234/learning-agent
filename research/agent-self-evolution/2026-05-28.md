📄 **[PACE：小型语言模型 Agent 的双时间尺度自进化框架]**（PACE: Two-Timescale Self-Evolution for Small Language Model Agents）
🔗 https://arxiv.org/abs/2605.23019
💡 核心贡献（2句）：提出 PACE 框架，让冻结的小语言模型（4B-14B）无需更新权重、无需 frontier 模型指导，即可通过双时间尺度协调实现 Agent 自进化。低风险的 Prompt 精化与高风险的控制逻辑更新分层进行，通过保留集验证保障更新质量。
🔧 技术亮点：
- 双时间尺度解耦：快速 Prompt 优化 + 慢速控制逻辑演化，优先消耗低成本搜索空间
- 约束式控制逻辑更新：仅当 prompt 级增益饱和后才触发，并通过 held-out 验证集把关
- 无权重更新：完全在推理层进化，对闭源/小模型友好，规避灾难性遗忘风险
📊 实验结果：在 3 个冻结 SLM 骨干 × 4 个基准（共 12 组合）中全面最优；相比 vanilla SLM agent 最高提升 +9.2%，相比单模式进化基线最高提升 +5.4%；tau-bench 多轮工具使用成功率显著提升。
🔄 自进化类型：**自我修正 / 持续学习（推理层）**

📄 **[自进化 Agent 会遗忘吗？终身适应中的能力退化与保留]**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）
🔗 https://arxiv.org/abs/2605.09315
💡 核心贡献（2句）：首次系统性揭示 LLM Agent 自进化的"非单调性"问题——在 workflow、skill、model、memory 四个进化维度上，适应新任务分布均会引发已有能力的渐进退化。提出通用的能力保留进化（CPE）原则，在持续适应中显式约束破坏性能力漂移。
🔧 技术亮点：
- 跨维度能力侵蚀分析：覆盖工作流进化、技能积累、模型自训练、记忆持久化四条进化路径
- CPE（Capability-Preserving Evolution）：在每条进化路径上引入保留约束，防止灾难性遗忘
- 在 GPT-5.1 优化下，工作流进化中简单任务保留率从 41.8% 提升至 52.8%，同时不损失复杂任务适应能力
📊 实验结果：CPE 在所有四个进化维度上同时改善了保留稳定性与适应表现，是迄今覆盖进化维度最全的遗忘研究。
🔄 自进化类型：**持续学习 / 灾难性遗忘防控**

📄 **[Skill-R1：基于强化学习的 Agent 技能进化]**（Skill-R1: Agent Skill Evolution via Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.09359
💡 核心贡献（2句）：将技能优化建模为实例级递归 RL 问题，使用可验证奖励驱动技能文本的持续改写，而非更新任务 LLM 本身。通过双层信用分配（技能对 rollout 的贡献 + 修订对下一轮技能的改进）实现闭环技能进化。
🔧 技术亮点：
- 实例级递归优化：每个 episode 后用 RL 修订技能描述，形成技能→轨迹→奖励→技能的飞轮
- 模型无关：只修改技能文本，不触碰任务 LLM 权重，对闭源模型完全兼容
- 双层信用分配：同时解决"好技能让当前 rollout 更好"与"好修订让下一轮技能更好"两个耦合问题
📊 实验结果：在 Web 导航、代码生成等多个 agent 基准上超越 prompt engineering 和直接对齐基线（具体数值待 PDF 核验）。
🔄 自进化类型：**奖励驱动 / 数据飞轮 / 自我修正**

📄 **[GEAR：通过自蒸馏实现 LLM Agent 的粒度自适应优势重加权]**（GEAR: Granularity-Adaptive Advantage Reweighting for LLM Agents via Self-Distillation）
🔗 https://arxiv.org/abs/2605.11853
💡 核心贡献（2句）：针对长时序 Agent RL 训练中粗粒度结果奖励信号不足的问题，提出 GEAR 框架，利用自蒸馏从 token 级和片段级动态重塑 GRPO 优势函数。通过比较在线策略学生与真值条件化教师，自动定位语义偏离锚点并进行自适应信用分配。
🔧 技术亮点：
- 自蒸馏对比信号：ground-truth 条件化 teacher vs. 在线 student，提取参考引导的散度信号
- 自适应粒度：语义对齐处保持 token 级精度，偏离处聚合为自适应片段并加权调制
- 语义偏离锚点检测：散度突增点作为信用区域边界，解决长序列中的信用稀释问题
📊 实验结果：在 8 个数学推理和 agent 工具调用基准（Qwen3 4B/8B）上全面超越 GRPO、纯自蒸馏和 token/轮次级信用分配基线；低基线准确率基准上最高提升约 **+20%**。
🔄 自进化类型：**奖励驱动 / 模型蒸馏**

📄 **[METIS：LLM 强化微调的元认知内化课程学习]**（Internalizing Curriculum Judgment for LLM Reinforcement Fine-Tuning）
🔗 https://arxiv.org/abs/2605.11235
💡 核心贡献（2句）：提出 METIS 框架，让 LLM 将课程判断（"下一步该学什么"）内化为自身能力，而非依赖外部启发式规则或辅助模型。基于"prompt 内奖励方差有效衡量 prompt 信息量"这一关键观察，让模型学会自主分配训练资源。
🔧 技术亮点：
- 奖励方差作为信息量代理：prompt 内 reward 分散度越高，说明该 prompt 对当前策略越有训练价值
- 轻量级上下文学习预测：以近期训练结果为 in-context 示例，预测 prompt 信息量，无需额外模型
- 闭环元认知：同时优化标准 RFT 奖励和自判断奖励，让策略学会"知道自己不知道什么"
📊 实验结果：在数学推理、代码生成、Agent 函数调用等 RFT 基准上全面优于基线；训练收敛速度加快最高 **67%**。
🔄 自进化类型：**持续学习 / 奖励驱动 / 元认知**

## 🚀 今日洞察

当前 Agent 自进化研究呈现出三条清晰的汇聚趋势：**资源约束下的轻量化进化**（PACE 证明无需 frontier 模型即可进化小模型 Agent）、**精细化信用分配**（GEAR、METIS 共同指向从粗粒度结果奖励到细粒度过程奖励的范式转移），以及**遗忘防控的系统化**（Do Self-Evolving Agents Forget? 将灾难性遗忘问题扩展到 workflow/skill/model/memory 四个维度，推动社区正视进化的副作用）。核心挑战在于：如何在持续进化中同时满足"新能力获取"与"旧能力保留"的双重目标，现有方法大多只解决其中一侧，端到端闭环的自进化框架仍是未竟之题。
