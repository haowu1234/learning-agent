## 📄 1. **双向进化搜索驱动语言模型自我提升**
（Self-Improving Language Models with Bidirectional Evolutionary Search）

🔗 https://arxiv.org/abs/2605.28814

💡 **核心贡献**
提出 BES（Bidirectional Evolutionary Search）框架，通过前向进化重组与后向目标分解的双向搜索机制克服现有自我提升方法中"高概率区域困陷"问题。BES 在主流 post-training 算法失败的高难度任务上实现持续增益，并在推理阶段超越现有开源框架。

🔧 **技术亮点**
- **前向进化搜索**：引入进化算子对部分轨迹进行重组（crossover/mutation），生成单次模型 rollout 难以直接到达的候选解，打破自回归概率质量限制
- **后向目标分解**：递归将原始任务分解为可验证子目标（checkable subgoals），提供稠密中间反馈信号，指导前向搜索方向
- **理论证明**：候选扩展搜索被限制在窄熵壳（entropy shell）内，进化算子可逃逸此限制；后向分解可指数级降低找到正确答案所需的采样数

📊 **实验结果**
在三个开放问题求解基准（open problem solving benchmarks）上推理时 BES 超越所有对比开源框架（平均性能与最优性能均更优）；在多个 post-training 困难任务上取得主流算法无法实现的持续增益。

🔄 **自进化类型**：自我博弈 / 数据飞轮（搜索+自我提升闭环）

## 📄 2. **Search-E1：自蒸馏驱动搜索增强推理的自进化**
（Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning）

🔗 https://arxiv.org/abs/2605.22511

💡 **核心贡献**
提出极简自进化流水线 Search-E1：仅用 vanilla GRPO 与在线策略自蒸馏（On-Policy Self-Distillation, OPSD）交替训练，无需外部教师模型、辅助奖励模块或树搜索，即可让搜索增强推理 Agent 持续自我进化，证明复杂外部机器都是可选的。

🔧 **技术亮点**
- **在线策略自蒸馏（OPSD）**：每轮 GRPO 后，策略在自身训练问题上 rollout；通过 token 级前向 KL 目标将当前策略的推理时分布对齐到「暴露了更高效兄弟轨迹的特权上下文」，提供稠密 per-step 监督信号
- **极简架构**：无需 process reward model、retrospective critic、树搜索或多阶段课程，整个流水线紧凑可复现
- **自我蒸馏闭环**：模型用自己的更优轨迹教自己，形成无标注数据自我提升飞轮

📊 **实验结果**
Qwen2.5-3B 在 7 个 QA 基准测试上平均 EM 达 0.440，超越所有同等规模开源 baseline。

🔄 **自进化类型**：数据飞轮 / 模型蒸馏（自蒸馏）

## 📄 3. **Meta-Team：LLM 多智能体系统协作自进化**
（Evolve as a Team: Collaborative Self-Evolution for LLM-based Multi-Agent Systems）

🔗 https://arxiv.org/abs/2605.29790

💡 **核心贡献**
提出 Meta-Team 框架，通过「协作自进化」让 MAS（多智能体系统）在执行真实任务中持续从经验驱动地改进自身，解决了 MAS 运行时各类故障难以事先消除的核心痛点。

🔧 **技术亮点**
- **执行上下文保留**：Meta-Team 在每个 Agent 维护完整执行上下文，并协调任务后通信（post-task communication），使各 Agent 能交换分布式证据
- **多尺度自进化**：将执行经验转化为三层可复用改进——单 Agent 行为优化、Agent 间协调优化、团队组织结构优化
- **经验驱动演化**：通过协作反思机制识别"哪个 Agent 哪步出了问题"，实现精准归因与有针对性的进化

📊 **实验结果**
在 6 个长程 Agent 基准测试上，Meta-Team 持续超越单智能体系统、手工设计 MAS 和之前的 MAS 进化方法；分析表明 Meta-Team 实现了更可靠和可扩展的 MAS 自进化。

🔄 **自进化类型**：协作自进化 / 自我反思（多 Agent 协同归因）

## 📄 4. **MUSE-Autoskill：技能生命周期驱动的 Agent 自进化**
（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）

🔗 https://arxiv.org/abs/2605.27366

💡 **核心贡献**
提出 MUSE-Autoskill（Memory-Utilizing Skill Evolution）框架，通过统一的技能生命周期管理（创建→记忆→管理→评估→精炼）让 Agent 持续提升任务求解能力，将技能作为具备长期经验感知能力的可复用资产而非孤立静态工件。

🔧 **技术亮点**
- **技能生命周期闭环**：Agent 按需创建技能、跨任务存储与复用、高效组织与检索，并通过单元测试与运行时反馈持续精炼
- **技能级记忆（Skill-level Memory）**：为每个技能跨任务累积经验，使技能随使用量增加而自我优化，实现更高效的复用与适应
- **跨 Agent 迁移**：实验验证生命周期管理的技能支持跨 Agent 迁移，提升团队级知识共享效率

📊 **实验结果**
在 SkillsBench 上，生命周期管理的技能在任务成功率、执行效率、技能复用率及跨 Agent 迁移四个维度均优于对比方法。

🔄 **自进化类型**：技能自进化 / 持续学习（经验累积+技能精炼）

## 📄 5. **On-Policy 失败轨迹驱动的 Agent 安全对齐自进化**
（On-Policy Self-Evolution via Failure Trajectories for Agentic Safety Alignment）

🔗 https://arxiv.org/abs/2605.07474

💡 **核心贡献**
提出首个专注于工具使用型 LLM Agent 安全对齐的「在线策略自进化」方法，通过挖掘自身失败轨迹（而非仅最终响应）中的安全信号，解决现有对齐方案对 trajectory-level 安全威胁覆盖不足的问题。

🔧 **技术亮点**
- **轨迹级安全自进化**：将 Agent 的失败轨迹（执行不安全工具调用、遵循注入指令、过度拒绝等）作为在线策略监督信号，而非仅依赖 response-level 或 off-policy 安全信号
- **Safety-Utility 权衡优化**：在降低安全风险的同时避免能力退化（safety-utility tradeoff），证明在线策略方法优于离线对齐
- **自进化闭环**：Agent 在与环境交互中持续暴露安全盲区，再通过自进化修补，无需人工重新标注

📊 **实验结果**
在工具使用型 Agent 安全基准上，相比 off-policy 基线在安全性与有用性双指标均取得改善，且不显著牺牲通用任务性能。

🔄 **自进化类型**：奖励驱动 / 自我反思（失败轨迹反思 + 在线策略对齐）

## 🚀 今日洞察

**趋势一：搜索即自进化——以搜索替代外部监督成为新范式。** BES 和 Search-E1 均证明，通过设计更优越的搜索结构（双向进化搜索、自蒸馏 GRPO）可以替代大量外部监督组件（process reward model、更强教师模型），让模型从自身轨迹中持续自我提升，"极简主义"自进化路线正在实证验证阶段。

**趋势二：技能作为自进化的中间表示成为主流。** MUSE-Autoskill 延续了近期技能驱动自进化的热潮，强调技能不应是静态产物而应具有生命周期，这与 SkillGrad、Skill-R1 等同期工作共同表明：技能库的动态更新与精炼正在成为 Agent 持续学习的核心基础设施。

**核心挑战：多尺度归因与安全-能力双收敛仍是难题。** Meta-Team 揭示 MAS 中跨 Agent 的失败归因是经验驱动进化的最大瓶颈；而 On-Policy 安全自进化工作则警示：Agent 在自我进化过程中可能累积安全盲区——如何在自进化速度与安全对齐之间保持动态平衡，是下一阶段最需攻克的核心问题。
