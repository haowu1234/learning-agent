📄 **【Autogenesis：自进化 Agent 协议】**（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.15034
💡 **核心贡献**：提出 Autogenesis Protocol（AGP），将 Agent 的资源（提示词、工具、记忆等）纳入统一的协议注册层（RSPL），并配套闭环自进化操作接口（SEPL），实现可审计、可回滚的版本化演化。构建于 AGP 之上的多 Agent 系统 AGS 在长程规划与工具使用基准上超越了强基线。
🔧 **技术亮点**：
- Resource Substrate Protocol Layer（RSPL）：将所有 Agent 资源（prompt/tool/memory/env）统一为带有显式生命周期与版本接口的协议对象
- Self Evolution Protocol Layer（SEPL）：定义 "提案 → 评估 → 提交" 的标准闭环算子，内置谱系追踪与回滚机制
- 解耦 "演化什么（what evolves）" 与 "如何演化（how it evolves）"，彻底克服单体组合 + 脆性胶水代码问题
📊 **实验结果**：在多个长程规划 + 工具使用基准上一致优于强基线（v3 于 2026-05-07 更新，性能进一步提升）
🔄 **自进化类型**：**资源注册 + 闭环自进化协议**

📄 **【STALE：LLM Agent 能知道哪些记忆已经过时吗？】**（STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?）
🔗 https://arxiv.org/abs/2605.06527
💡 **核心贡献**：识别出 Agent 记忆管理中一个被严重忽视的失效模式——"隐式冲突（Implicit Conflict）"（新观测隐式废除旧记忆而非显式否定），并构建了 400 个专家验证场景的 STALE 基准（1,200 条评测 query，150K token 上下文）。同时提出 CUPMem 原型，在写入时进行结构化状态巩固与感知传播搜索。
🔧 **技术亮点**：
- 三维探针框架：状态解析（State Resolution）/ 前提抵抗（Premise Resistance）/ 隐式策略自适应（Implicit Policy Adaptation）
- 覆盖 100+ 日常主题，上下文长度达 150K token，全面压测记忆修订能力
- CUPMem：写入时显式状态裁决，通过传播感知搜索在检索阶段消解过时信念
📊 **实验结果**：最优前沿模型整体准确率仅 55.2%，揭示"检索到更新证据 ≠ 行动更新"的根本差距
🔄 **自进化类型**：**记忆自修正 / 自适应记忆管理**

📄 **【CRAFT：遗忘感知干预的 LLM 持续学习框架】**（CRAFT: Forgetting-Aware Intervention-Based Adaptation for Continual Learning）
🔗 https://arxiv.org/abs/2605.05732
💡 **核心贡献**：提出 CRAFT，通过在**隐空间**上学习低秩干预（而非更新权重本身）实现持续学习，以输出分布 KL 散度同时驱动任务路由、正则化与干预合并三阶段，用单一目标统一全流程。
🔧 **技术亮点**：
- 无需修改模型权重：在隐层表示上学习低秩干预矩阵，天然减少灾难遗忘
- KL 散度多用途：既用于相似任务分组路由，也作为防遗忘正则化信号，还驱动干预合并
- 对任务顺序鲁棒，跨多个 benchmark 和模型规模优于强 LoRA-based 基线
📊 **实验结果**：在多个持续学习基准上整体性能提升、遗忘率显著降低，优于 LoRA-based 竞对（2026-05-08 v2 更新）
🔄 **自进化类型**：**持续学习 / 灾难遗忘抑制**

📄 **【归因引导的 LLM 持续微调】**（Attribution-Guided Continual Learning for Large Language Models）
🔗 https://arxiv.org/abs/2605.05285
💡 **核心贡献**：利用改进版 LRP（层级相关性传播）算法，在每个 Transformer 层逐元素估算参数对历史任务的重要性，并用这些重要性分数调制梯度更新，令旧知识相关参数"冻而不死"、新任务相关参数仍具塑性。
🔧 **技术亮点**：
- 元素级参数重要性估计：精细到 Transformer 每一层的每个参数，而非粗粒度 layer/module 级冻结
- 梯度调制而非参数冻结：避免完全冻结带来的塑性损失，实现保护与学习的精细平衡
- 无需数据回放，语义感知地区分"该保留"和"该更新"的参数空间
📊 **实验结果**：在持续学习基准上一致优于基线，旧任务保留率高，新任务竞争力不损失
🔄 **自进化类型**：**持续学习 / 参数重要性感知自适应**

📄 **【cotomi Act：通过观察用户行为学习自动化工作】**（cotomi Act: Learning to Automate Work by Watching You）
🔗 https://arxiv.org/abs/2605.03231
💡 **核心贡献**：构建浏览器 Agent，将**被动观察用户操作**转化为可持续增长的组织知识库（task boards + wiki），并与执行 Agent 共享工作空间，实现"经验积累 → 能力提升"的数据飞轮；同时在 WebArena 达到 80.4% 的成功率，超越人类基线（78.2%）。
🔧 **技术亮点**：
- behavior-to-knowledge 管道：被动观察用户浏览行为 → 渐进式抽象为可复用知识制品（任务板/Wiki）
- 自适应懒惰观察 + verbal-diff 历史压缩 + 粗粒度动作选择 + best-of-N 测试时扩展
- 用户与 Agent 共享可编辑工作空间，知识随交互持续更新
📊 **实验结果**：WebArena 179-task 人工评估子集得分 80.4%，超越 78.2% 人类基线；控制实验确认行为衍生知识积累可提升任务成功率（ACM CAIS 2026 系统演示论文）
🔄 **自进化类型**：**数据飞轮 / 行为驱动持续学习**

## 🚀 今日洞察

1. **记忆自修正成为新焦点**：Agent 不仅需要"记住"，更需要知道"何时忘记/修正"——STALE 揭示当前最优模型在隐式冲突场景下仅 55.2% 准确率，记忆版本管理与状态裁决将是下一个核心战场。

2. **持续学习从"参数保护"走向"精细调制"**：CRAFT 和 Attribution-Guided CL 分别从表示空间干预和元素级归因两个维度超越了粗粒度冻结/回放范式，标志着 LLM 持续学习正进入精细化、原则性阶段。

3. **从被动执行到主动进化**：Autogenesis Protocol 和 cotomi Act 从协议层和行为观察层双管齐下，指向同一个趋势——Agent 不再是静态工具，而是在运行时持续积累、修订、演化自身能力的动态系统；如何在闭环自进化中保证安全性（可回滚、可审计）将是工程落地的关键挑战。
