📄 **[SkillCAT：面向 LLM Agent 的对比评估与拓扑感知技能自进化框架]**（SkillCAT: Contrastive Assessment and Topology-Aware Skill Self-Evolution for LLM Agents）
🔗 https://arxiv.org/abs/2606.13317
💡 核心贡献
- 提出 SkillCAT，一个**无需模型训练**的三阶段技能自进化框架，通过对比因果提取（CCE）从同一任务的成败轨迹对中识别关键差异，大幅提升技能演化质量。
- 引入拓扑感知执行（TTE）将演化后的技能编译为可路由的子技能拓扑，推理时只加载与任务相关的能力节点，显著降低 token 消耗。
🔧 技术亮点
- **对比因果提取（CCE）**：对同一任务采样多条轨迹，成功/失败对比找根因，而非单轨迹学习
- **评估增强演化（AAE）**：对候选技能补丁在源任务克隆上 replay 验证，合并前先过质量关，层次化合并减少噪声
- **拓扑感知执行（TTE）**：技能组织为有向子技能图，推理时按任务动态路由，避免全量加载
📊 实验结果：在 SpreadsheetBench、WikiTableQuestions、DocVQA 上平均提升基线最高 **40.40%**，且跨模型泛化与分布外泛化均有效
🔄 自进化类型：**技能库演化 / 数据飞轮**（无训练，执行反馈驱动）

📄 **[ProPlay：面向自进化 LLM Agent 的过程化世界模型]**（ProPlay: Procedural World Models for Self-Evolving LLM Agents）
🔗 https://arxiv.org/abs/2606.12780
💡 核心贡献
- 提出 ProPlay，将成功轨迹抽象为「过程（Procedure）」并组织成因果过程图，实现 Agent 对环境动力学的持续自我认知建模，无需外部监督信号。
- 引入「过程级预演（Procedure-Level Preplay）」机制，在每轮交互前利用学到的世界知识预演未来过程路径，作为软引导，执行后用环境反馈精炼图结构。
🔧 技术亮点
- **过程图（Procedure Graph）**：节点为任务阶段，边为因果转移，每条边附带可靠度嵌入估算历史贡献
- **预演（Preplay）**：执行前在过程图上模拟未来轨迹，提供结构化软引导，而非硬约束
- **反馈驱动精炼**：执行后用环境反馈更新图，形成「规划→执行→精炼」闭环，不更新模型权重
📊 实验结果：在多个公共 benchmark 上持续优于强基线，代码已开源（github.com/antman9914/proplay）
🔄 自进化类型：**持续学习 / 世界模型自构建**

📄 **[Socratic-SWE：基于轨迹衍生技能的自进化代码 Agent]**（Socratic-SWE: Self-Evolving Coding Agents via Trace-Derived Agent Skills）
🔗 https://arxiv.org/abs/2606.07412
💡 核心贡献
- 提出 Socratic-SWE，一个闭环自进化框架：将 Agent 的历史求解轨迹蒸馏为结构化「Agent 技能」，再以此技能在真实代码仓库中生成有针对性的修复任务，形成课程自演化。
- 设计「求解器梯度对齐奖励（solver-gradient alignment reward）」对候选任务评分，使保留的任务既可通过执行验证，又对求解器改进最有效，解决了训练数据飞轮质量问题。
🔧 技术亮点
- **轨迹→技能蒸馏**：从历史轨迹中归纳反复出现的失败模式与有效修复模式，形成可复用技能文档
- **技能→任务生成**：技能驱动在真实 repo 中生成针对性 repair task，分布紧贴 Agent 当前弱点
- **执行验证 + 奖励过滤**：执行校验 + 梯度对齐奖励双重过滤，确保训练信号有效，三轮迭代后持续提升
📊 实验结果：SWE-bench Verified 三轮迭代后达到 **50.40%**，在 SWE-bench Lite/Pro、Terminal-Bench 2.0 均超过同计算预算的自进化基线
🔄 自进化类型：**数据飞轮 / 自我反思（失败分析）**

📄 **[SkeMex：基于自进化技能记忆的可泛化医疗 Agent 推理]**（Experience Makes Skillful: Enabling Generalizable Medical Agent Reasoning via Self-Evolving Skill Memory）
🔗 https://arxiv.org/abs/2606.09365
💡 核心贡献
- 提出 SkeMex，一个**部署后无需更新模型权重**的医疗 Agent 自进化框架，将交互轨迹蒸馏为结构化技能，按通用/任务特定/动作级三分支组织技能库，解决了传统记忆机制冗余噪声问题。
- 设计「读-写-评估-治理（Read–Write–Assess–Govern）」闭环生命周期，基于环境反馈估算上下文相关效用，驱动价值感知检索与技能库自动治理。
🔧 技术亮点
- **三分支技能库**：通用经验 / 任务特定技能 / 动作级技能分层管理，检索精准度高
- **效用感知治理**：从环境反馈中估算记忆的情境效用，自动晋级有用技能、剔除有害条目
- **离线 + 在线均有效**：在多样化临床任务上，离线批评估和在线交互均显著优于基于记忆的 SOTA Agent
📊 实验结果：跨多个临床任务持续优于代表性记忆 Agent；跨模型泛化与技能迁移均得到验证
🔄 自进化类型：**技能库演化 / 持续学习 / 奖励驱动**

📄 **[SIGA：面向科学模拟的自进化编码 Agent 适配器]**（SIGA: Self-Evolving Coding-Agent Adapters for Scientific Simulation）
🔗 https://arxiv.org/abs/2606.09774
💡 核心贡献
- 提出 SIGA（Simulator-Interface Grounding Adapter），通过检索、过程记忆、轨迹内验证与验证强制终止，为通用编码 Agent 提供特定模拟器的「可执行契约」（词汇、结构约束、验证规则），消除领域专业门槛。
- 自进化机制从历史轨迹中重写适配器内容，使 Agent 在无人工干预下持续改进对模拟器接口的掌握，实现人类专家 3 小时工作约 36 倍的墙钟加速。
🔧 技术亮点
- **接口基底化（Interface Grounding）**：最小化模拟器专用适配，而非重训 Agent，做轻量级桥接层
- **自进化适配器**：从先前轨迹自动重写适配器内容，历史经验持续内化为结构知识
- **验证强制终止**：在轨迹执行中实时验证输出，防止错误滚雪球；跨 OpenFOAM/LAMMPS 迁移证实机制泛化性
📊 实验结果：GEOS benchmark 上 TreeSim > 0.90，自进化后达到最高均值；跨 seed 标准差降低最高 **16 倍**
🔄 自进化类型：**过程记忆自进化 / 工具接口自适应**

## 🚀 今日洞察

1. **技能库自进化正成为主流范式**：本日 5 篇论文中有 4 篇（SkillCAT、Socratic-SWE、SkeMex、SIGA）都以「技能文档/适配器」为核心记忆单元，从执行轨迹中提炼可复用知识，绕过模型权重更新，印证了「轻量级符号记忆 + 闭环反馈」是当前最具工程可行性的自进化路径。

2. **从「记录轨迹」到「提炼知识」的质变**：早期工作直接检索原始轨迹；而本日论文普遍引入**对比提取**（SkillCAT）、**失败模式归纳**（Socratic-SWE）、**效用感知治理**（SkeMex）等机制，标志着自进化从被动记忆转向主动知识精炼，核心挑战从「怎么存」转为「存什么、何时忘」。

3. **自进化的核心开放挑战**：如何在无 ground truth 的情况下**可靠评估技能质量**（避免自我加强偏见）、如何**防止技能库腐化**（有害记忆污染），以及如何将自进化收益**从专项任务泛化至跨域场景**，仍是该领域最需攻克的三大核心难题。
