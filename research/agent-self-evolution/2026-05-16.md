📄 **G-Zero：无需验证器的开放式生成自博弈框架**（G-Zero: Self-Play for Open-Ended Generation from Zero Data）
🔗 https://arxiv.org/abs/2605.09959
💡 核心贡献：针对开放式任务中外部 LLM 评审带来的能力上限与奖励黑客问题，提出 G-Zero——一种无外部验证器的协同进化框架，完全依赖模型内部分布动态生成监督信号，实现持续自我进化。
🔧 技术亮点：
- 引入 **Hint-δ 内在奖励**：量化 Generator 在无辅助回答与自生成 Hint 条件回答之间的预测偏移，作为内在奖励信号
- **Proposer-Generator 双角色共演**：Proposer 通过 GRPO 持续合成针对 Generator 盲区的挑战性查询；Generator 通过 DPO 内化 hint 引导的改进
- 提供最优迭代次优性的理论保证（best-iterate suboptimality guarantee），要求 Proposer 保证足够探索覆盖度
📊 实验结果：在多个开放式生成基准上超越依赖外部 judge 的基线方法，且显示出更强的扩展性
🔄 自进化类型：**自我博弈 / 内在奖励驱动**

📄 **SLIM：面向 Agentic RL 的动态技能生命周期管理**（Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.10923
💡 核心贡献：提出 SLIM 框架，将 agent 的外部技能集视为与策略学习联合优化的动态变量，突破"技能只增不减"的假设，实现技能的自适应保留、退役与扩展。
🔧 技术亮点：
- **Leave-One-Skill-Out 边际贡献估计**：通过逐一留出验证来量化每个技能的边际外部价值
- **三类生命周期操作**：保留高价值技能、淘汰贡献趋零的技能、在能力缺口暴露时自动扩展技能库
- 策略内化与外部保留**并行不悖**：部分技能被内化为参数，部分继续提供外部价值
📊 实验结果：ALFWorld 和 SearchQA 上平均超越最佳基线 **7.1 个百分点**
🔄 自进化类型：**持续学习 / 技能动态管理**

📄 **Swarm Skills：面向协调工程的可移植自进化多智能体规范**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.10052
💡 核心贡献：提出 Swarm Skills 规范，将多智能体协作协议从框架内部代码中解耦，封装为可跨系统分发的资产，并内置自进化机制——从成功执行轨迹中自动蒸馏新技能。
🔧 技术亮点：
- 扩展 Anthropic Skills 标准，加入角色（Role）、工作流（Workflow）、执行边界（Execution Bounds）和自进化语义结构
- 自进化算法基于 **多维评分（有效性 × 利用率 × 新鲜度）** 对现有技能持续打补丁，无需人工在环
- **零适配跨 Agent 可移植性**（zero-adapter portability）通过渐进式公开（progressive disclosure）实现框架无关
📊 实验结果：通过开源 JiuwenSwarm 参考实现进行定性案例分析验证，展示零迁移成本
🔄 自进化类型：**数据飞轮 / 轨迹蒸馏 / 多智能体自进化**

📄 **SOL：自优化语言模型的动态计算分配**（Compute Where it Counts: Self Optimizing Language Models）
🔗 https://arxiv.org/abs/2605.10875
💡 核心贡献：提出 SOL，通过轻量策略网络学习对每个 token 动态分配计算预算（注意力稀疏 + MLP 剪枝 + 量化比特宽），用 GRPO 训练策略使模型在不修改基座权重的前提下自我优化推理效率。
🔧 技术亮点：
- **冻结基座 + 轻量策略网络**：策略网络读取隐藏状态并为每步选择离散效率动作，保持基座权重不变
- 训练采用 **teacher-forced GRPO**：固定 token 序列，对同一 token 路径采样多个算力调度方案并比较似然
- 同时控制三个正交维度：token 级注意力稀疏度 / MLP 结构化激活剪枝 / 激活量化 bit-width
📊 实验结果：相同预算下优于静态分配和随机搜索；MMLU 准确率比均匀预算策略最高提升 **7.3%**；已被 **ICML 2026** 接收
🔄 自进化类型：**奖励驱动 / 推理自优化**

📄 **Self-Evolving Recommendation System：端到端自主模型优化**（Self-Evolving Recommendation System: End-To-End Autonomous Model Optimization With LLM Agents）
🔗 https://arxiv.org/abs/2602.10226
💡 核心贡献：YouTube 团队提出基于 Gemini 家族 LLM 的自进化推荐系统，通过内外双循环 Agent 实现超参数搜索、架构设计和奖励函数优化的端到端自主化，已在生产环境落地。
🔧 技术亮点：
- **双循环架构**：内循环 Offline Agent 高吞吐假设生成（代理指标验证）+ 外循环 Online Agent 北极星业务指标验证（线上实验）
- Agent 充当专业 MLE 角色：自主发现优化算法改进、架构创新，以及面向长期用户参与的奖励函数设计
- 整个进化流程完全自动化，包括模型训练与部署，工程迭代速度显著超越传统人工流程
📊 实验结果：多个改进已成功在 YouTube 生产环境上线，验证 LLM 驱动进化可在开发速度和模型性能两方面超越传统工作流
🔄 自进化类型：**数据飞轮 / 自主 ML 工程 / 奖励建模**

## 🚀 今日洞察

1. **自博弈与内在奖励正在取代外部评审**：G-Zero 用 Hint-δ 内在奖励绕过外部 judge 的能力上限，而 Swarm Skills 则通过轨迹蒸馏构建自演化闭环——这一趋势预示"无外部监督的持续自进化"将成为 2026 年核心范式。

2. **技能即资产、动态管理成共识**：SLIM 将技能生命周期纳入强化学习优化框架，Swarm Skills 让协作协议变为可分发资产，两者都指向同一方向：Agent 的能力单元不应静态堆叠，而应像软件依赖一样被动态评估与淘汰。

3. **自优化正从"能力"延伸至"效率"**：SOL 展示了 Agent 不仅可以自我改进任务能力，还能自主学习如何分配推理算力——这为算力受限的部署环境提供了一条无需重新训练基座模型的自适应优化路径，工程价值极高。
