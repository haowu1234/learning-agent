📄 **INFUSER：基于影响力引导的自进化提升推理能力**（INFUSER: Influence-Guided Self-Evolution Improves Reasoning）
🔗 https://arxiv.org/abs/2606.09052
💡 **核心贡献**
- 提出 INFUSER，一个「生成器-求解器」双角色协同训练框架，生成器从无结构文档池中自动合成问题，求解器基于正确性奖励持续自我提升。
- 创新引入「优化器感知影响力分数」作为生成器奖励，确保生成的问题对当前求解器真正有用，而非仅仅"难"，从而形成自适应课程。
🔧 **技术亮点**
- 提出 DuGRPO（双规范化 GRPO 变体）解决影响力分数连续、噪声大的训练问题
- Generator 由影响力奖励驱动，自动从无监督文档池中挖掘对 Solver 最有价值的问题
- 迭代协同进化：Solver 的能力提升反过来更新 Generator 的优化目标，形成数据飞轮
📊 **实验结果**
- Qwen3-8B-Base 上，INFUSER 在 Olympiad 和 SuperGPQA 基准上超越强自进化基线 20%+
- 8B INFUSER 协同进化 Generator 在数学与代码任务上超越固定 32B thinking Generator
🔄 **自进化类型**：数据飞轮 / 奖励驱动 / 自适应课程

📄 **EEVEE：面向真实世界的测试时提示学习自我改进 Agent**（EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents）
🔗 https://arxiv.org/abs/2606.11182
💡 **核心贡献**
- 提出首个多数据集测试时提示学习框架，解决现有方法仅适配单数据集、无法应对真实异构任务流的局限。
- 引入路由器-提示协同进化策略（router-prompt co-evolution），在不同任务分布间动态匹配最优提示配置。
🔧 **技术亮点**
- 任务路由器：将输入流划分为任务簇，按簇分配对应提示配置，避免跨数据集干扰
- 交错训练：路由器学习与提示学习交替进行，缓解二者相互依赖带来的训练不稳定
- 测试时在线适应，无需重新训练基础模型参数
📊 **实验结果**
- 在多个基准上，平均多任务得分相比 Qwen3-4B-Instruct +10.38 分、相比 DeepSeek-V3.2 +24.32 分
- 超越 SOTA 方法 GEPA 和 ACE 最多 37.2% 和 48.2%
🔄 **自进化类型**：测试时自适应 / 数据飞轮

📄 **Self-Harness：自我改进的 Agent 运行框架**（Self-Harness: Harnesses That Improve Themselves）
🔗 https://arxiv.org/abs/2606.09498
💡 **核心贡献**
- 提出 Self-Harness 范式：LLM Agent 能够在无人类工程师或更强外部 Agent 协助下，通过执行轨迹自主优化自身运行 Harness（提示、工具、记忆等运行框架）。
- 将 Harness 的自进化形式化为三阶段迭代循环，专注识别模型特有弱点并有针对性地修复。
🔧 **技术亮点**
- Weakness Mining：从执行轨迹中识别模型特有失败模式（非通用问题）
- Harness Proposal：基于失败模式生成多样但最小化的 Harness 修改方案
- Proposal Validation：通过回归测试过滤退化修改，保证每次迭代只接受有效改进
📊 **实验结果**
- Terminal-Bench-2.0 上，MiniMax M2.5 通过率 40.5%→61.9%，Qwen3.5-35B-A3B 23.8%→38.1%，GLM-5 42.9%→57.1%
- 定性分析表明修改具体针对模型特有弱点，而非添加通用指令
🔄 **自进化类型**：自我反思 / Harness 自进化

📄 **ANCHOR：人机交互引导下的健康自进化**（Towards Healthy Evolution: Exploring the Role and Mechanisms of Human-Agent Interaction in Self-Evolving Systems）
🔗 https://arxiv.org/abs/2606.06114
💡 **核心贡献**
- 揭示自进化 Agent 在无监督自主演化中面临的能力退化与安全漂移问题，提出 ANCHOR 框架以 LLM 模拟人类监督，在自进化不同阶段注入校正反馈。
- 实证证明「适量监督」就能显著抑制安全退化，且监督位置比监督频率更关键。
🔧 **技术亮点**
- LLM-based 人类监督模拟器：无需真实人工介入，低成本复现监督效果
- 多阶段干预对比分析：揭示输出验证阶段（而非数据生成/训练阶段）是最有效的监督介入点
- 覆盖代码生成、数学推理、安全三大领域的系统性评估
📊 **实验结果**
- 仅限制频率的监督在安全指标上显著优于无监督基线，且保持核心进化目标性能
- 监督频率提升出现明显边际递减，轻量监督即可达到最大收益
🔄 **自进化类型**：自我博弈 / 人机协同进化 / 安全对齐

📄 **OpenSkill：开放世界中 LLM Agent 的自进化**（OpenSkill: Open-World Self-Evolution for LLM Agents）
🔗 https://arxiv.org/abs/2606.06741
💡 **核心贡献**
- 提出 OpenSkill，首个面向「无任何监督信号」约束的开放世界自进化框架：Agent 仅凭任务提示，从文档/代码库/网页中自举构建技能库和验证信号。
- 实现验证信号的自我构建（self-built verifier），无需目标任务答案即可对齐 Ground Truth。
🔧 **技术亮点**
- 从文档与仓库中提取锚点（verification anchors），作为监督无关的验证依据
- 基于自建虚拟任务（grounded virtual tasks）进行技能精化，完全独立于目标任务标注
- 技能跨模型迁移：同一技能库无需适配即可在不同 Base Model 上复用
📊 **实验结果**
- 三个基准、两个目标 Agent 上均取得最优自动化通过率，满足零监督约束
- 自建验证器与 Ground Truth 对齐度高，验证了无监督验证可行性
🔄 **自进化类型**：开放世界自进化 / 数据飞轮 / 无监督自我提升

## 🚀 今日洞察

当前 Agent 自进化研究呈现三大趋势：
1. **从"有监督辅助"走向"完全自举"**：OpenSkill、Self-Harness、INFUSER 均探索在极少或零外部监督下构建自进化闭环，验证信号的自我生成成为核心技术挑战。
2. **Harness 自进化成为新方向**：不仅是模型权重或提示的优化，Agent 运行框架（工具调用逻辑、记忆结构、提示工程）本身的自动演化（EEVEE、Self-Harness、Adaptive Auto-Harness）正在成为独立研究方向。
3. **安全与对齐是自进化的隐性瓶颈**：ANCHOR 的结果表明无监督自进化存在显著安全漂移风险，"健康自进化"需要在性能提升和安全稳定之间设计轻量级对齐机制，这是领域走向实用化必须解决的核心挑战。
