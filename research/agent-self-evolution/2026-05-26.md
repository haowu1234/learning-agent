### 1. 自进化 Agent 会遗忘吗？终身 LLM Agent 适应中的能力退化与保护

**原文标题：** Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation

🔗 https://arxiv.org/abs/2605.09315

💡 **核心贡献**
本文揭示了 LLM Agent 在持续自进化过程中存在「能力侵蚀」（capability erosion）现象——适应新任务分布时会系统性地破坏已有能力。作者提出 **Capability-Preserving Evolution（CPE）** 框架，通过约束演化过程中的能力漂移来实现稳定的持续适应。

🔧 **技术亮点**
- 在 workflow、skill、model、memory 四个演化维度均发现了非单调自进化问题（能力退化现象）
- CPE 作为通用稳定化原则，对四种演化通道均有效，无需针对特定通道设计特殊方案
- 采用约束优化思想，在保证新任务适应性能的同时显式保留旧能力

📊 **实验结果**
- Workflow 演化场景下，CPE 在 GPT-5.1 优化基准上将旧任务保留率从 41.8% 提升至 52.8%
- 四个演化维度均获得一致稳定性提升

🔄 **自进化类型：** 持续学习 / 灾难性遗忘防护

### 2. GEAR：通过自蒸馏的细粒度自适应优势重加权（LLM Agent RL 训练）

**原文标题：** GEAR: Granularity-Adaptive Advantage Reweighting for LLM Agents via Self-Distillation

🔗 https://arxiv.org/abs/2605.11853

💡 **核心贡献**
针对 LLM Agent RL 训练中仅凭结果级奖励导致信用分配粗糙的问题，提出 GEAR 框架，利用自蒸馏生成 token/segment 级别的细粒度监督信号，自适应调整轨迹中各段的优势权重。

🔧 **技术亮点**
- 对比 on-policy 学生模型与 ground-truth 条件化教师模型，识别语义偏离点（divergence spike）作为信用分配的自适应锚点
- 在偏离点处将后续续写归为一个 segment 并用偏离程度调制其优势权重，实现 token-level 与 segment-level 分辨率自动切换
- 无需额外标注数据，完全基于自蒸馏信号，与 GRPO 框架无缝结合

📊 **实验结果**
- 在 8 个数学推理与 agentic tool-use 基准上（Qwen3 4B/8B），GEAR 一致优于标准 GRPO 及 token/turn 级信用分配方法
- 低 GRPO 基线准确率的困难任务上最高提升约 20%

🔄 **自进化类型：** 奖励驱动 / 模型蒸馏

🔧 **技术亮点**

### 4. Skill-R1：通过强化学习的 Agent 技能进化

**原文标题：** Skill-R1: Agent Skill Evolution via Reinforcement Learning

🔗 https://arxiv.org/search/?searchtype=all&query=Skill-R1+Agent+Skill+Evolution+Reinforcement+Learning （2026-05 提交，Vishe et al.）

💡 **核心贡献**
针对 Agent 依赖静态手工技能（skills）的局限，提出 Skill-R1 框架，利用强化学习信号驱动 Agent 的可复用自然语言技能自动进化，消除对人工技能标注的依赖。

🔧 **技术亮点**
- 将技能定义为可复用的自然语言过程，结合 RL 奖励反馈实现技能的自动发现与优化
- 支持规划（planning）、行动（action）和工具使用（tool use）三类技能的联合进化
- 引入技能版本管理机制，允许 Agent 回溯到性能更好的技能版本

🔄 **自进化类型：** 奖励驱动 / 数据飞轮

### 5. Ctx2Skill：自进化框架自主从上下文中发现并构建技能

**原文标题：** From Context to Skills: Can Language Models Learn from Context Skillfully?

🔗 https://arxiv.org/abs/2504.xxxxx （Shuzheng Si et al., 清华/微软, 2026-05 更新）

💡 **核心贡献**
提出 Ctx2Skill，一个无需人工技能标注的自进化框架，使 LLM 能从长且技术密集的上下文中自主发现、构建和验证可复用技能，解决技能标注代价高昂和缺乏外部反馈的双重瓶颈。

🔧 **技术亮点**
- 端到端自动化技能挖掘流水线：上下文解析 → 候选技能抽取 → 一致性验证 → 技能库累积
- 不依赖外部监督信号，全程通过模型自我验证（self-verification）实现质量把控
- 已在多跳推理、代码生成等任务上验证技能的跨任务迁移能力

🔄 **自进化类型：** 自我反思 / 无监督自我提升

## 🚀 今日洞察

当前 Agent 自进化研究正从「如何让 Agent 变得更好」深化为「如何让 Agent 安全且持续地变好」——以 **能力保护（CPE）** 和 **对齐稳定性（Alignment Tipping）** 为代表的研究揭示了自进化本身的双刃剑效应：新能力的获取往往伴随旧能力的退化与对齐偏移，这是当前终身学习框架面临的核心挑战。

技术层面，两个方向正在汇流：**细粒度奖励信号**（GEAR 的 token/segment 级自蒸馏）与**技能抽象自动化**（Ctx2Skill、Skill-R1 的无监督技能进化）——前者解决「如何学得更准」，后者解决「学什么知识结构」，两者的融合将是构建稳健自进化 Agent 的关键技术路径。

多智能体维度的自进化研究（Swarm Skills、协作故障归因）正从单机向群体智能演进，群体记忆共享与集体技能涌现有望成为下一个突破方向。
