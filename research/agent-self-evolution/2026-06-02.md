📄 **[EvolveR：经验驱动闭环生命周期的 LLM Agent 自进化框架]**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079
💡 核心贡献：
提出 EvolveR，通过"离线自蒸馏 + 在线交互"闭环，让 Agent 从自身历史轨迹中提炼可复用的策略原则，而非仅依赖外部知识检索。结合 GRPO 强化学习更新策略，在复杂多跳问答任务上超越 Search-R1-instruct 等强 RL 基线（已被 ICML 2026 接收）。
🔧 技术亮点：
- 离线自蒸馏：从成功/失败轨迹中提炼正向指导原则与负向警示原则，形成结构化经验库
- 动态经验维护：通过语义去重、相似原则合并、成功率评分实现经验库的剪枝与优化
- GRPO 奖励设计：同时关注最终答案正确性与推理过程完整性（是否调用经验/知识检索）
📊 实验结果：
- Qwen2.5-3B：平均 EM 0.382 vs Search-R1 的 0.325（+17.5%）
- Qwen2.5-7B：平均 EM 0.417 vs Search-R1 的 0.385（+8.3%）
- 测试集覆盖 TriviaQA、PopQA、2WikiMultiHopQA、Musique、Bamboogle
🔄 自进化类型：**数据飞轮 + 自我反思 + 奖励驱动**

📄 **[MUSE-Autoskill：通过技能创建、记忆、管理与评估实现 Agent 自进化]**（Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）
🔗 https://arxiv.org/abs/2605.27366
💡 核心贡献：
提出 MUSE-Autoskill Agent（记忆驱动技能进化），建立统一的技能生命周期管理框架（创建→记忆→管理→评估→精炼），让 Agent 能持续改善任务解决能力，技能跨任务复用与跨 Agent 迁移。论文提交于 2026-05-26。
🔧 技术亮点：
- 技能级记忆：为每个技能积累跨任务经验，支持更有效的复用和自适应改进
- 单元测试 + 运行时反馈：通过可执行测试实现技能的持续精炼与可靠性验证
- 技能生命周期一体化：将技能视为"长寿命、经验感知、可测试资产"而非一次性产物
📊 实验结果：
在 SkillsBench 上验证技能生命周期管理可提升任务成功率、效率、复用率及跨 Agent 迁移能力
🔄 自进化类型：**持续学习 + 数据飞轮（技能层）**

📄 **[SkillOS：面向自进化 Agent 的技能精选学习]**（SkillOS: Learning Skill Curation for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2605.06614
💡 核心贡献：
提出 SkillOS，用强化学习训练一个专用"技能策展者（Skill Curator）"，从累积经验中学习复杂的长期技能管理策略，解决现有方法依赖人工启发式规则的瓶颈。发布于 2026-05-08。
🔧 技术亮点：
- Executor + Curator 双角色分离：冻结执行器负责技能检索应用，可训练策展者负责 SkillRepo 更新
- 组合奖励 + 任务流训练：前期轨迹更新技能库，后续相关任务评估更新效果，提供间接延迟反馈学习信号
- 跨 Executor 泛化：学到的策展者可迁移至不同骨干模型和任务域，无需重新训练
📊 实验结果：
在多轮 Agentic 任务和单轮推理任务上均优于无记忆和强记忆基线，有效性和效率双提升
🔄 自进化类型：**持续学习 + 奖励驱动（技能策展）**

📄 **[Autogenesis：自进化 Agent 协议]**（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.15034
💡 核心贡献：
提出 Autogenesis Protocol（AGP），通过将 Prompt、Agent、工具、环境和记忆统一为"协议注册资源"，并提供标准化的闭环进化接口（提案→评估→提交+回滚），解决现有 A2A/MCP 协议在跨实体生命周期管理和安全进化方面的缺失。发布于 2026-04-16，最新版本 2026-05-19。
🔧 技术亮点：
- RSPL（资源基底协议层）：将 Prompt/Agent/工具/记忆建模为带版本接口的可注册协议资源
- SEPL（自进化协议层）：规范闭环进化算子接口，支持可审计溯源与回滚操作
- AGS（Autogenesis System）：在运行时动态实例化、检索、精炼协议注册资源的多 Agent 系统
📊 实验结果：
在需要长程规划与跨异构资源工具使用的多个 Benchmark 上持续超越强基线
🔄 自进化类型：**自我进化协议 + 持续学习（架构层）**

📄 **[SePT：无外部奖励的 LLM 推理自进化后训练]**（A Model Can Help Itself: Reward-Free Self-Training for LLM Reasoning）
🔗 https://arxiv.org/abs/2510.18814
💡 核心贡献：
提出 SePT（Self-evolving Post-Training），证明语言模型仅用自身采样的响应即可提升推理能力，无需任何外部奖励信号。通过"自生成→在线训练"交替循环和在线数据刷新机制实现持续自我迭代（最新版本 2026-05-15）。
🔧 技术亮点：
- 极简设计：仅需采样-训练循环 + 温度扫描，无需奖励模型、验证器或教师模型
- 在线数据刷新：每批数据由最新版本模型生成，避免分布偏移，确保持续改进
- 温度动态调节：温度曲线对自我训练效果有显著影响（关键消融发现）
📊 实验结果：
在6个数学推理 Benchmark 上，SePT 超越强无训练基线（最优解码温度评估），验证了纯自生成监督的可行性
🔄 自进化类型：**无监督自我提升 + 数据飞轮**

## 🚀 今日洞察

当前 Agent 自进化研究正从"单次任务优化"转向**技能层与协议层的系统性自进化**——无论是 EvolveR 的经验蒸馏闭环、SkillOS/MUSE-Autoskill 的技能生命周期管理，还是 Autogenesis 的协议级进化架构，都体现出"让 Agent 把自己的行为经验结构化为可复用、可精炼的资产"这一核心趋势。核心挑战在于：如何在没有精确奖励信号的情况下评估"进化质量"（SePT 的无奖励路径提供了一个极简但有效的切入点），以及如何防止技能库膨胀与经验腐化——这将成为 2026 年下半年 Agent 持续学习研究的关键战场。
