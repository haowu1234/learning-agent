📄 **SkillOS：面向自进化 Agent 的技能策展强化学习框架**（Learning Skill Curation for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2605.06614
💡 核心贡献：提出 SkillOS，将技能策展（skill curation）建模为长时序 RL 问题，通过训练一个可学习的 SkillCurator 模块管理外部 SkillRepo，使 Agent 在流式任务流中能从过往经验中持续自我进化。现有方法要么依赖人工策展、要么只有短视启发式操作，SkillOS 首次从间接延迟奖励中学习复杂的长期策展策略。
🔧 技术亮点：
- 冻结 Agent 执行器（Executor）+ 可训练技能策展器（Skill Curator）的解耦架构
- 以累积经验驱动的 RL 训练菜谱，处理间接和延迟反馈
- 外部 SkillRepo 作为可版本化的外部记忆，实现跨任务知识复用与更新
📊 实验结果：在流式任务上持续优于强基线，验证了闭环技能进化的有效性
🔄 自进化类型：**数据飞轮 + 持续学习**（经验驱动的技能库自动更新）

📄 **SPEAR：联邦 LLM 在线微调中的自博弈优势加权精炼**（Self-Play Enhancement via Advantage-Weighted Refinement in Online Federated LLM Fine-Tuning with Real-Time Feedback）
🔗 https://arxiv.org/abs/2605.07977
💡 核心贡献：提出 SPEAR，一种在联邦学习场景下、仅需部分非答案反馈（无需 ground-truth）的在线 LLM 微调算法，通过反馈引导的自博弈循环构造对比样本对，同时支持在线和资源受限边缘设备上的高效训练。填补了现有方法必须离线或需要特权 ground-truth 的双重缺陷。
🔧 技术亮点：
- 反馈引导自博弈循环：自动生成正确/错误对比样本，无需人工标注
- 双目标训练：最大似然（正确完成）+ 置信度加权负样本惩罚（错误 tail token）
- 兼容联邦学习架构，适配边缘设备资源约束
📊 实验结果：在多个基准数据集上超越当前 SOTA 基线，代码已开源
🔄 自进化类型：**自我博弈 + 奖励驱动**（在线反馈闭环 + 联邦自提升）

📄 **Autogenesis：自进化 Agent 协议**（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.15034
💡 核心贡献：提出 Autogenesis Protocol（AGP），将 Agent 系统中"进化什么"与"如何进化"解耦，通过资源底层协议层（RSPL）统一管理 prompt/工具/记忆/环境作为带版本的协议资源，通过自进化协议层（SEPL）实现可审计、可回滚的闭环改进。AGS 系统在此协议上实现了动态实例化和多 Agent 自我精炼。
🔧 技术亮点：
- RSPL：将 prompt、Agent、工具、环境、记忆抽象为带显式状态/生命周期/版本的注册资源
- SEPL：指定提案→评估→提交的闭环算子接口，支持血统追溯和版本回滚
- AGS：基于 AGP 的多 Agent 系统，运行时动态检索和精炼协议注册资源
📊 实验结果：在长时序规划与工具使用基准上持续优于强基线（v3 更新版本）
🔄 自进化类型：**自我反思 + 持续学习**（带版本管理的闭环系统级自进化）

📄 **SAGE：多 Agent 协同自进化推理框架**（SAGE: Multi-Agent Self-Evolution for LLM Reasoning）
🔗 https://arxiv.org/abs/2603.15255
💡 核心贡献：提出 SAGE（Self-evolving Agents for Generalized reasoning Evolution），一个四智能体（Challenger/Planner/Solver/Critic）从共享 LLM 主干出发、仅用小量种子集进行闭环协同自进化的框架，在减少人工标注依赖的同时避免了自博弈常见的课程漂移问题。
🔧 技术亮点：
- Challenger 持续生成难度递增任务，形成自驱动课程
- Planner 将任务转化为结构化多步计划，Solver 按计划求解
- Critic 评分过滤生成的问题和计划，防止课程漂移并保持训练信号质量
📊 实验结果：Qwen-2.5-7B 在 LiveCodeBench 提升 +8.9%，OlympiadBench 提升 +10.7%
🔄 自进化类型：**自我博弈 + 多 Agent 协同自进化**

📄 **UniSD：LLM 自蒸馏统一框架**（UniSD: Towards a Unified Self-Distillation Framework for Large Language Models）
🔗 https://arxiv.org/abs/2605.06597
💡 核心贡献：提出 UniSD，首个系统性研究 LLM 自蒸馏（无需更强外部教师）的统一框架，整合多教师一致性、EMA 教师稳定化、token 级对比学习、特征匹配和散度截断等互补机制，深入揭示各组件的交互作用与边界条件。
🔧 技术亮点：
- 多教师投票一致性提升监督可靠性，EMA 教师防止训练振荡
- Token 级对比学习解决自生成轨迹的正确性依赖问题
- 散度截断（Divergence Clipping）增强训练稳定性
📊 实验结果：六个基准、六个模型、三个模型家族评估；整合版 UniSDfull 较基础模型 +5.4 分，较最强基线 +2.8 分
🔄 自进化类型：**模型蒸馏**（自生成数据驱动的无教师自适应）

## 🚀 今日洞察

当前 Agent 自进化研究呈现三条汇聚主线：**闭环系统化**（AGP/SAGE 将进化过程协议化、可审计化）、**轻量在线化**（SPEAR 等将自博弈推向联邦/边缘在线场景，摆脱 ground-truth 依赖）、**技能/经验外化**（SkillOS/UniSD 均将"如何复用过往经验"视为核心瓶颈，显示记忆与技能库将成为自进化的基础设施）。核心挑战仍然集中在两点：如何在无监督或弱监督条件下维持训练信号质量（防止课程漂移 / 幻觉自强化），以及如何在系统层面保证进化的安全可回滚性。
