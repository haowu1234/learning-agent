📄 **[G-Zero：无需外部验证器的开放式生成自进化框架]**（G-Zero: Self-Play for Open-Ended Generation from Zero Data）
🔗 https://arxiv.org/abs/2605.09959
💡 **核心贡献：**
提出 G-Zero，一个无需外部 verifier 的协同自进化框架，核心创新在于 Hint-δ 内在奖励——量化 Generator 有无自生成 Hint 时的预测分布偏移，以此驱动 Proposer 持续挖掘模型盲点并生成挑战性样本，实现开放式任务的鲁棒自进化。同时对理想化 DPO 版本给出了最优次迭代下界的理论保证。
🔧 **技术亮点：**
- Hint-δ 内在奖励：无需 LLM-Judge，用内部分布动态作为自监督信号，避免奖励 hacking
- Proposer（GRPO）+ Generator（DPO）双模型协同进化，分别负责难题合成与内化提升
- 理论证明：在 Proposer 充分覆盖且伪标签噪声受控条件下，存在最优次迭代收敛保证
📊 **实验结果：** 在多个开放式生成基准上超越依赖外部 Judge 的自进化方法，特别是在 verifiable domain 迁移到 open-ended domain 上表现显著。
🔄 **自进化类型：** 自我博弈 / 无监督内在奖励驱动

📄 **[SLIM：Agent 强化学习中的动态技能生命周期管理]**（Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.10923
💡 **核心贡献：**
提出 SLIM 框架，打破"外部技能只增不减"或"最终全部内化"的两种极端假设，将活跃外部技能集视为与策略学习联合优化的动态变量，通过边际贡献估计动态执行技能的保留、退役与扩展操作。
🔧 **技术亮点：**
- Leave-one-skill-out 验证：在线估计每项技能的边际外部贡献，识别高价值与冗余技能
- 三类生命周期操作：保留（retain）、退役（retire）、扩展（expand），适应任务阶段与能力缺口
- 技能与策略非互斥：部分技能被策略内化，其余继续提供外部价值，支持混合范式
📊 **实验结果：** 在 ALFWorld 和 SearchQA 上平均优于最强基线 7.1 个百分点，开源实现于 https://github.com/ejhshen/SLIM
🔄 **自进化类型：** 持续学习 / 技能库动态演化 / 奖励驱动

📄 **[Swarm Skills：可移植的自演化多智能体系统规范]**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.10052
💡 **核心贡献：**
提出 Swarm Skills，将多智能体协作协议从框架内部代码中解耦，标准化为可分发、可自演化的技能资产，并配套自演化算法——从成功执行轨迹中蒸馏新技能、依多维评分持续修补旧技能，实现无需人工介入的持续优化。
🔧 **技术亮点：**
- 扩展 Anthropic Skills 标准，加入角色、工作流、执行边界、自演化结构等多智能体语义
- 自演化算法：轨迹蒸馏（Distill）+ 多维评分修补（Effectiveness / Utilization / Freshness）
- 渐进式披露机制（Progressive Disclosure）实现跨 Agent 零适配可移植性，无框架锁定
📊 **实验结果：** 通过开源 JiuwenSwarm 参考实现的架构兼容性分析与案例研究验证了跨 Agent 可移植性与持续自演化能力。
🔄 **自进化类型：** 数据飞轮 / 轨迹蒸馏 / 多智能体协调自演化

📄 **[SOL：自优化语言模型的按 Token 动态算力分配]**（Compute Where it Counts: Self Optimizing Language Models）
🔗 https://arxiv.org/abs/2605.10875
💡 **核心贡献：**
提出 SOL（Self-Optimizing Language Models），用轻量策略网络从 LLM 隐藏状态实时感知 token 难度，并通过 GRPO 学习每步最优算力分配策略（注意力稀疏 + MLP 剪枝 + 量化位宽联合控制），无需修改基座模型权重，在相同预算下提升生成质量。论文已被 ICML'26 接收。
🔧 **技术亮点：**
- 三维算力动作空间：attention 稀疏度 × MLP 结构化剪枝 × 激活量化 bit-width 联合优化
- Teacher-forced GRPO：在固定 token 路径上采样多套"反事实"算力调度方案并比较 likelihood
- 策略网络仅读隐藏状态、输出离散动作，不改动基座模型权重，部署侵入性极低
📊 **实验结果：** 在多种模型规格和算力区间上均优于静态分配与随机调度搜索；MMLU 准确率相对均匀预算策略提升最高 7.3%。（ICML'26 accepted）
🔄 **自进化类型：** 奖励驱动 / 推理时自优化 / 元学习策略

📄 **[RSPO：扩散语言模型的相对分数策略优化]**（Relative Score Policy Optimization for Diffusion Language Models）
🔗 https://arxiv.org/abs/2605.10218
💡 **核心贡献：**
针对扩散大语言模型（dLLM）后训练中 RLVR 因难以精确计算序列级 log-ratio 而引入高方差的问题，提出 RSPO——用可验证奖励的 advantage 同时作为更新方向与相对 log-ratio 目标值，稳定训练过程。
🔧 **技术亮点：**
- 双重利用 reward advantage：既作梯度更新方向，又作相对似然估计目标值的校准锚点
- 避免 ELBO 近似：规避现有方法因 Evidence Lower Bound 近似导致的高方差与不稳定问题
- 适用于并行生成的扩散 LLM，开辟非自回归模型后训练优化新路径
📊 **实验结果：** 规划任务提升尤为显著，数学推理具备竞争力，相对 ELBO 基线训练稳定性大幅改善。
🔄 **自进化类型：** 奖励驱动 / 后训练自优化 / 扩散模型 RLVR

## 🚀 今日洞察

1. **技能库动态化成新热点**：SLIM 与 Swarm Skills 均指向同一趋势——静态技能积累已不够用，下一代 Agent 需要对技能进行动态生命周期管理（边际贡献评估、退役、轨迹蒸馏再生），技能集本身成为可学习的优化变量。

2. **无监督内在奖励突破开放域瓶颈**：G-Zero 的 Hint-δ 信号代表一类新范式：无需外部 Judge，完全依靠模型内部分布动态自我驱动，这对扩展到无法定义 verifiable reward 的开放式任务至关重要，也是克服当前 self-play 能力天花板的关键方向。

3. **"推理时自进化"与"训练时自进化"走向融合**：SOL 将 GRPO 带入推理阶段算力调度，RSPO 将 RL 后训练延伸至扩散 LLM，表明自进化不再局限于权重更新，而是从模型结构（技能库）、推理策略（动态计算）到生成机制（扩散 RLVR）全链路展开，核心挑战是如何在高维动作空间中稳定地学习自我优化信号。
