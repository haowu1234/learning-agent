📄 **[无需外部奖励的自发演化：通过世界知识探索训练 LLM Agent]**（Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration）
🔗 https://arxiv.org/abs/2604.18131
💡 **核心贡献**：提出让 Agent 在无需外部奖励或人类指导的情况下，在推理阶段自发进行世界知识探索与自我进化的新范式。训练阶段使用基于结果的奖励机制（衡量自生成知识对下游任务成功率的提升），推理时 Agent 无需任何外部信号，凭内部参数完成原生自进化适应。
🔧 **技术亮点**：
- 设计 outcome-based reward：以"自生成知识使下游任务成功率提升多少"作为训练信号，训练结束后奖励退出
- 推理阶段完全 reward-free：Agent 自发探索未知环境、总结知识，不依赖任何人类反馈
- 轻量化代价大收益：仅 14B Qwen3 模型在获得自生成知识加持后超越未辅助的 Gemini-2.5-Flash
📊 **实验结果**：在 WebVoyager 和 WebWalker 上，Qwen3-30B 和 Seed-OSS-36B 相比基线提升 **+20%**；14B Qwen3 超越未辅助 Gemini-2.5-Flash
🔄 **自进化类型**：奖励驱动（训练期）+ 无监督自探索（推理期）

📄 **[Ctx2Skill：语言模型能否从上下文中灵活学习技能？]**（From Context to Skills: Can Language Models Learn from Context Skillfully?）
🔗 https://arxiv.org/abs/2604.27660
💡 **核心贡献**：提出 Ctx2Skill，一个无需人工标注、无需外部反馈的自进化框架，能够从复杂上下文中自主发现、精化与筛选任务相关技能。通过多智能体自博弈循环，持续构建可插拔的技能库，赋能任意骨干语言模型。
🔧 **技术亮点**：
- **多智能体自博弈**：Challenger（出题）、Reasoner（答题）、Judge（裁判）三者共进化，Proposer/Generator 分析失败案例合成技能更新
- **Cross-time Replay 机制**：防止因对抗博弈崩溃（过度极端出题/过度特化技能），通过历史最优技能集回放保证泛化性
- **完全无监督**：从上下文中自动抽取规则和程序性知识，无需人类标注，生成技能可即插即用到任意 LM
📊 **实验结果**：在 CL-bench 四项上下文学习任务上，跨骨干模型一致性提升任务求解率
🔄 **自进化类型**：自我博弈 + 数据飞轮（技能库自动构建）

📄 **[TT-SI：测试时自我提升 —— LLM Agent 的在线自进化新范式]**（Self-Improving LLM Agents at Test-Time）
🔗 https://arxiv.org/abs/2510.07841
💡 **核心贡献**：提出测试时自我提升（TT-SI）算法，通过三步循环（自我觉察不确定样本 → 自我数据增广 → 测试时微调）实现推理阶段无监督自进化，以极少样本获得显著性能提升。
🔧 **技术亮点**：
- **Self-awareness（自我觉察）**：识别当前模型在哪些样本上不确定/表现弱，精准定位改进方向
- **Self-data augmentation（自我数据增广）**：从检测到的不确定样本出发，自动生成相似的扩充样本
- **TT-SI vs TT-D**：对比"同模型自我提升"与"强模型蒸馏辅助"两种变体，TT-SI 无需外部模型即可实现提升
📊 **实验结果**：跨 Agent 基准平均绝对精度提升 **+5.48%**，训练样本量仅需标准方法的 **1/68**
🔄 **自进化类型**：自我反思 + 持续学习（测试时在线微调）

📄 **[AgentEvolver：面向高效自进化 Agent 系统]**（AgentEvolver: Towards Efficient Self-Evolving Agent System）
🔗 https://arxiv.org/abs/2511.10395
💡 **核心贡献**：提出 AgentEvolver，一套将自提问（探索）、自导航（经验复用）、自归因（差异化奖励）三者统一的自进化 Agent 训练框架，大幅降低数据构建成本并提升样本效率。
🔧 **技术亮点**：
- **Self-questioning**：好奇心驱动的任务自生成，减少对手工数据集的依赖
- **Self-navigating**：基于经验复用和混合策略引导，提升探索效率（解决盲目随机探索问题）
- **Self-attributing**：对轨迹中不同状态/动作按贡献分配差异化奖励，提高样本利用率
📊 **实验结果**：相比传统 RL 基线，探索效率更高、样本利用更优、适应更快（阿里 ModelScope 团队出品）
🔄 **自进化类型**：奖励驱动 + 数据飞轮 + 自我博弈

📄 **[DocSync：通过 Critic 引导的 Reflexion 实现智能文档维护]**（DocSync: Agentic Documentation Maintenance via Critic-Guided Reflexion）
🔗 https://arxiv.org/abs/2605.02163
💡 **核心贡献**：提出 DocSync，通过融合 AST 结构感知 + RAG + Critic-guided Reflexion 反射循环，使 Agent 能对代码-文档不一致问题进行自动检测和自我纠正，无需增加参数规模。
🔧 **技术亮点**：
- **AST + RAG 融合**：将抽象语法树结构信息注入生成上下文，提供依赖感知的代码理解
- **Critic-guided Reflexion 循环**：以 Reflexion 范式为基础，批判者评估生成的文档更新并驱动模型自我修正
- **小模型高效实现**：基于 LoRA 适配的小语言模型即可实现，迭代 Critic 循环在不增加参数的前提下显著提升语义准确性
📊 **实验结果**：自动评分达 3.44/5.0，显著优于 CodeT5-base 的 1.91；在语义对齐、摘要忠实度、自动裁判偏好上全面胜出
🔄 **自进化类型**：自我反思（Reflexion）+ 自我修正

## 🚀 今日洞察

当前 Agent 自进化研究正呈现三条清晰主线：**①摆脱外部监督**——从依赖人工标注和奖励信号，走向推理时完全自发的内驱探索（如 arXiv:2604.18131 的 reward-free 范式）；**②自博弈闭环构建知识**——多智能体对抗博弈成为无监督技能发现的核心机制（如 Ctx2Skill），解决了"无外部反馈如何验证质量"的核心挑战；**③测试时在线适应**——以极少样本在推理阶段完成轻量微调（TT-SI），标志着自进化开始从训练范式向推理范式迁移。核心瓶颈仍在于：如何防止自进化中的对抗崩溃与灾难性遗忘，以及如何建立可信的自我评估信号。
