📄 **【SkillOS】技能策划的强化学习：自进化 Agent 的经验驱动训练**（SkillOS: Learning Skill Curation for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2605.06614
💡 核心贡献：提出 SkillOS，一种面向流式任务场景、基于 RL 训练的技能策划方案，使 LLM Agent 能够从历史交互经验中持续提炼并更新可复用技能库（SkillRepo），实现真正的经验驱动自进化。技能策划器与冻结执行器解耦，通过分组任务流上的复合奖励信号学习长期策略。
🔧 技术亮点：
- 冻结 Agent 执行器 + 可训练技能策划器的双角色架构，解耦检索与更新
- 复合奖励设计：基于早期轨迹更新 SkillRepo，后期关联任务评估更新效果，提供延迟学习信号
- 技能库随时间演化为结构化 Markdown 文件，编码高阶元技能（meta-skills）
📊 实验结果：在多轮 Agentic 任务和单轮推理任务上均超越无记忆基线及强记忆基线，技能策划器可跨不同执行器骨干和任务域泛化
🔄 自进化类型：**数据飞轮 / 持续学习**

📄 **【EvolveR】经验驱动生命周期的自进化 LLM Agent**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079
💡 核心贡献：提出 EvolveR 框架，构建完整闭环的 Agent 经验生命周期——离线自蒸馏阶段将历史交互轨迹提炼为抽象可复用策略原则库，在线交互阶段主动检索原则指导决策，并通过策略强化机制迭代更新 Agent。ICML 2026 录用。
🔧 技术亮点：
- 两阶段闭环：(1) 离线自蒸馏，将轨迹抽象为结构化策略原则；(2) 在线交互，检索原则 + 积累新行为轨迹
- 策略强化机制（Policy Reinforcement Mechanism）：基于任务表现迭代更新 Agent，无需外部标注
- 不依赖外部数据扩增，完全从自身行为后果中学习
📊 实验结果：在复杂多跳问答基准上超越强 Agentic 基线，代码已开源（github.com/Edaizi/EvolveR）
🔄 自进化类型：**自我反思 / 持续学习**

📄 **【Swarm Skills】可移植的自进化多智能体协调规范**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.10052
💡 核心贡献：将 Agent 协调协议从框架内部代码中解放出来，提出 Swarm Skills ——一套扩展 Anthropic Skills 标准、面向多智能体语义的可移植规范，并配套自进化算法，自动从成功执行轨迹中蒸馏新 Swarm Skills 并持续修补已有技能，无需人工干预。
🔧 技术亮点：
- 将多智能体工作流封装为一等可分发资产（角色 + 流程 + 执行边界 + 语义自进化结构）
- 自进化算法基于多维评分（有效性、利用率、新鲜度）自动蒸馏和修补技能
- Progressive Disclosure 架构实现零适配器跨 Agent 框架可移植性
📊 实验结果：通过 JiuwenSwarm 开源参考实现的兼容性分析和案例研究验证，支持跨框架零适配器移植
🔄 自进化类型：**数据飞轮 / 自我博弈**

📄 **【POW3R】策略感知的 Rubric 奖励框架**（POW3R: Not Every Rubric Teaches Equally — Policy-Aware Rubric Rewards for RLVR）
🔗 https://arxiv.org/abs/2605.20164
💡 核心贡献：揭示 Rubric RL 中静态奖励聚合的本质缺陷——已饱和或当前不可达的准则无法提供有效优化信号；提出 POW3R，在训练过程中动态适应准则级奖励权重，利用轮次对比强调当前能区分策略输出的准则，显著提升 RLVR 训练效率。
🔧 技术亮点：
- 保持人类分配的权重和类别平衡作为最终目标，仅在训练中自适应调整准则级奖励权重
- 基于 rollout 级对比（Rollout-Level Contrast）识别当前有效的学习信号
- 与 GRPO 无缝结合，不改变底层评估目标
📊 实验结果：在 3 个基础策略 × 2 个数据集（多模态 + 纯文本）的 30 个比较组中赢得 24 个，训练步骤减少 2.5–4×
🔄 自进化类型：**奖励驱动**

📄 **【AIRA】Agent 递归自改进：LLM 自主设计神经架构**（Agentic Discovery of Neural Architectures: AIRA-Compose and AIRA-Design）
🔗 https://arxiv.org/abs/2605.15871
💡 核心贡献：迈向递归自我改进的重要一步——让 LLM Agent 自主设计超越标准 Transformer 的基础模型架构；双框架 AIRA-Compose（高层架构搜索）和 AIRA-Design（底层机制实现）协同，在 24 小时预算内发现 14 种新架构。
🔧 技术亮点：
- AIRA-Compose：11 个 Agent 协同探索计算原语空间，评估百万参数候选并外推至 350M-3B 规模
- AIRA-Design：20 个 Agent 协同编写新颖注意力机制和训练脚本，针对长程依赖优化
- 发现的 AIRAformer-C 比 Llama 3.2 扩展速度快 54%，AIRAhybrid-C 比 Nemotron-2 快 23%
📊 实验结果：AIRAformer-D 和 AIRAhybrid-D 在下游任务上分别提升 2.4% 和 3.8%（vs Llama 3.2）；Long Range Arena 上接近人类 SOTA（差距 <2.6%）
🔄 自进化类型：**递归自改进 / 自我博弈**

## 🚀 今日洞察

当前 Agent 自进化研究正沿三条主线同步推进：**经验驱动的技能/知识积累**（SkillOS、EvolveR）聚焦从历史交互中提炼可复用结构，形成持续进化的知识飞轮；**奖励信号的精细化设计**（POW3R）转向动态、策略感知的奖励调度，解决传统静态权重下的训练失效问题；**递归自改进**（AIRA）则将 Agent 能力的边界推向自主架构发现，初步验证了"AI 设计 AI"的可行性。核心挑战依然是：如何在无外部监督的条件下保证自进化方向的对齐与可控，以及如何突破单一任务域、实现跨领域泛化的持续学习。
