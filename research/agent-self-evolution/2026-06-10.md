📄 **[EEVEE：面向真实世界自进化 Agent 的测试时 Prompt 学习框架]**（EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents）
🔗 https://arxiv.org/abs/2606.11182
💡 核心贡献
- 提出首个**多数据集**测试时 Prompt 学习框架，使 LLM Agent 在真实异构任务流中实现自进化，突破现有方法局限于单数据集的瓶颈。
- 设计 Router-Prompt 协同进化策略（交替训练路由器与 Prompt），解决二者之间的互依赖问题，显著提升跨分布任务的鲁棒性。
🔧 技术亮点
- **动态路由器**：将输入按任务分布划分为 cluster，分配到最适合的 Prompt 配置，降低跨数据集干扰
- **Router-Prompt 协同进化**：交替迭代路由器训练阶段与 Prompt 学习阶段，自动解耦互依赖关系
- **测试时在线更新**：无需访问训练集，直接在推理流上持续自我优化
📊 实验结果
- 相比 Qwen3-4B-Instruct 基线提升 **+10.38** 分、相比 DeepSeek-V3.2 提升 **+24.32** 分（多 benchmark 均值）
- 超越 SOTA 方法 GEPA 和 ACE 分别达 **37.2%** 和 **48.2%**
🔄 自进化类型：**测试时自我进化 / 持续自适应学习**

📄 **[反馈对齐在自蒸馏中的作用]**（The Role of Feedback Alignment in Self-Distillation）
🔗 https://arxiv.org/abs/2606.11173
💡 核心贡献
- 系统研究自蒸馏中"上下文设计"（context design）对学习效果的关键影响，揭示**步骤对齐的批评反馈**是最优的自我提升信号。
- 提出逐步对齐（Step-aligned critique）策略：仅针对推理轨迹中"出错的 token"施加修正，保留正确行为，避免全量覆盖。
🔧 技术亮点
- **三类反馈信号对比实验**：二元奖励（GRPO）vs 参考答案 vs 步骤对齐批评，系统定量揭示差距来源
- **Per-token Advantage 分析**：精细到 token 级别分析不同反馈策略如何塑造模型更新方向
- **自蒸馏 + 冻结批评者（frozen critic）**：模型自我评价轨迹，蒸馏"带反馈版本"到"无反馈版本"
📊 实验结果
- Step-aligned critique 相比 GRPO 提升 **+16.11** 分（Avg@12），相比参考答案蒸馏提升 **+5.27** 分
- 本文被接收于 ICML 2026 Workshop on RL from World Feedback（RLxF）
🔄 自进化类型：**自我反思 / 模型蒸馏 / 奖励驱动**

📄 **[通过目标分布设计统一监督微调视角]**（A Unifying Lens on Supervised Fine-Tuning Through Target Distribution Design）
🔗 https://arxiv.org/abs/2606.11189
💡 核心贡献
- 将 SFT 重新定义为"目标分布设计"问题，提出 **Q-target 框架**，系统统一了现有 SFT 变体（DPO、KL-regularized SFT 等）为不同目标分布的特例。
- 基于此框架提出 **Target-SFT**，直接从期望目标分布构建训练目标，解决传统 SFT 在噪声/冗余 token 上过拟合的问题。
🔧 技术亮点
- **Q-target 分解**：明确分离"对观测 token 的依赖强度"与"剩余概率质量的分配策略"两个自由度
- **统一视角**：将 label smoothing、confidence penalty、DPO 等均解释为 Q-target 的不同实例
- **自动平衡预训练先验与微调目标**：让模型在知识先验与监督信号间自适应权衡
📊 实验结果
- 在 **10 个** 推理数据集-模型组合上持续优于标准 SFT 基线
🔄 自进化类型：**数据飞轮 / 弱监督自我提升 / 持续学习**

📄 **[预测未来行为使推理模型引导更有效]**（Predicting Future Behaviors in Reasoning Models Enables Better Steering）
🔗 https://arxiv.org/abs/2606.11172
💡 核心贡献
- 发现现有推理模型引导（steering）方法依赖"检测特征"（detection features）而非"预测特征"（prediction features），导致干预质量差，并提出基于预测特征的引导新范式。
- 提出 **FPCG（Future Probe Controlled Generation）**：通过多候选采样 + 预测探针打分，实现几乎无质量损失的行为引导，并在激活引导失败的场景下仍有效。
🔧 技术亮点
- **激活探针训练**：在中间推理步骤上训练探针，预测未来行为发生概率（准确率 64%–91%）
- **文本级引导（Text-level steering）**：采样多候选句子后用预测探针选择最优，避免对隐表示的直接干预
- **预测 vs 检测特征解耦**：首次系统区分"已发生行为检测"和"未来行为预测"两类内部特征
📊 实验结果
- 行为预测准确率 **64%–91%**（多种行为类型）
- FPCG 在激活引导完全失败的评估任务上仍能有效引导，且输出质量几乎无损
🔄 自进化类型：**自我反思 / 行为引导 / 推理过程优化**
