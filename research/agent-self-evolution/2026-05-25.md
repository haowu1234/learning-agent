### 1. 📄 **MOSS：通过源码级重写实现 Agent 自进化**
（Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems）

🔗 https://arxiv.org/abs/2605.22794

💡 **核心贡献**
当前自进化 Agent 方案仅修改文本可变的制品（技能文件、Prompt、工作流图），无法触及路由逻辑、钩子顺序等存于代码层的结构性问题。MOSS 通过 **源码级自重写**（source-level self-rewriting）对生产级 Agent 基座进行自适应，实现了真正图灵完备的自进化闭环。

🔧 **技术亮点**
- 基于生产失败证据自动构建批次，经过多阶段确定性流水线生成代码修改（委托外部 coding-agent CLI 执行，MOSS 保留阶段控制权）
- 通过在临时 trial worker 中回放失败批次验证候选版本，以 **健康探针门控的容器热替换** 与人工同意机制完成上线
- 在 OpenClaw 四任务评估集上，单轮自进化周期内 grader 均分从 **0.25 提升至 0.61**，无需人工干预

📊 **实验结果**
单次自进化周期，mean grader score: 0.25 → 0.61（+144%）

🔄 **自进化类型**：代码层自我修正 / 数据驱动持续更新

### 2. 📄 **Swarm Skills：可携带、自进化的多 Agent 协调规范**
（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）

🔗 https://arxiv.org/abs/2605.10052

💡 **核心贡献**
单 Agent 技能已可作为可移植资产分发，但多 Agent 协调协议仍被锁在框架内部代码中，无法跨系统共享或自主优化。Swarm Skills 将多 Agent 工作流升级为一等可分发制品，并内置语义化自进化结构。

🔧 **技术亮点**
- 扩展 Anthropic Skills 标准，引入角色（roles）、工作流（workflow）、执行边界（execution bounds）和内建自进化语义层
- 配套自进化算法：自动将成功执行轨迹蒸馏为新 Swarm Skill，并基于多维评分（有效性 Effectiveness、利用率 Utilization、新鲜度 Freshness）持续打补丁
- 通过渐进式披露（progressive disclosure）实现**零适配器跨框架可移植**，无需人工参与精化循环

🔄 **自进化类型**：轨迹蒸馏 / 数据飞轮 / 多智能体协调自优化

### 3. 📄 **SLIM：面向 Agentic RL 的动态技能生命周期管理**
（Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning）

🔗 https://arxiv.org/abs/2605.10923

💡 **核心贡献**
现有 Agent RL 方案假设外部技能单调积累或最终被策略完全内化，忽视了技能边际贡献的动态变化。SLIM 将活跃外部技能集作为与策略学习**联合优化的动态变量**，实现细粒度技能生命周期管理。

🔧 **技术亮点**
- 通过 **leave-one-skill-out（LOO）验证**估计每项技能的边际外部贡献，精确评估哪些技能真正必要
- 三类生命周期操作：保留高价值技能 / 淘汰贡献趋零技能 / 在持续失败暴露能力缺口时主动扩展技能库
- 实验证明策略学习与技能保留并不互斥：部分技能被吸收进策略参数，另一些持续提供外部价值

📊 **实验结果**
在 ALFWorld 和 SearchQA 上平均优于最佳基线 **7.1 个百分点**

🔄 **自进化类型**：奖励驱动 / 技能动态管理 / 持续学习

### 4. 📄 **SOL：自优化语言模型——动态计算自适应**
（Compute Where it Counts: Self Optimizing Language Models）

🔗 https://arxiv.org/abs/2605.10875（ICML 2026 录用）

💡 **核心贡献**
现有 LLM 推理压缩方案对每个 token 使用统一计算预算，忽视 token 难度差异。SOL 让模型通过轻量策略网络**动态学习每步应分配多少算力**，实现计算资源的自主优化。

🔧 **技术亮点**
- 在冻结 LLM 外挂轻量策略网络，读取隐藏状态后联合控制三类效率动作：token 级注意力稀疏度、MLP 结构化激活剪枝、激活量化 bit-width
- 使用 **GRPO（Group-Relative Policy Optimization）** 在 teacher-forced 轨迹上训练策略：相同 token 路径，采样多种计算调度，比较其似然值
- 奖励函数平衡语言模型质量与 episode 平均预算软约束，形成完整的自优化 RL 闭环

📊 **实验结果**
相同预算下 MMLU 准确率最高提升 **7.3%**，优于均匀预算分配策略；在所有实验中均发现更优质量-效率帕累托前沿

🔄 **自进化类型**：奖励驱动 / 自适应计算 / 在线 RL 自优化

### 5. 📄 **从自我奖励中强化学习（无需参考答案的 LLM 自我提升）**
（Reinforcement Learning from Self Reward）

🔗 https://arxiv.org/abs/2505.08827

💡 **核心贡献**
LLM 通过 RL 训练通常依赖人工设计的可验证奖励，成本高且覆盖领域有限。本文证明 LLM 可以**通过自我判断（self-judging）有效自我提升**，无需参考答案，利用"生成"与"验证"之间天然的不对称性实现闭环。

🔧 **技术亮点**
- 模型同时扮演生成者和评判者，利用生成难度 > 验证难度的内在不对称性提供可靠奖励信号
- 与合成题目生成结合，构建完整自我提升闭环：模型自己生成练习题、求解、再自我评分，全程无需外部验证
- 在 Countdown 谜题和积分问题上实现与形式化验证相当的性能；Qwen 2.5 7B DeepSeek Distilled 用自我奖励训练后达到 MIT Integration Bee 竞赛门槛

📊 **实验结果**
Qwen 2.5 7B 自我奖励训练后可入选 MIT Integration Bee；无需 ground truth 在多领域实现与外部验证相当的效果

🔄 **自进化类型**：自我奖励 / 自我反思 / 无监督自我提升 / 数据飞轮

## 🚀 今日洞察

1. **"自进化"正从文本层深入到代码层与算力层**：MOSS 突破了文本可变制品的边界，首次在生产级 Agent 上实现代码自重写进化；SOL 则将自优化从任务行为延伸至推理计算资源的动态分配——两者共同指向一个趋势：Agent 自进化的粒度和深度在快速下沉。

2. **技能管理成为 Agent 持续学习的新核心挑战**：SLIM 和 Swarm Skills 从不同角度指出，外部技能的动态管理（何时保留/淘汰/扩展）是 Agent RL 中被低估的关键变量。随着技能库规模增长，如何量化技能价值并实现自主更新，将成为 2026 年下半年的研究热点。

3. **奖励瓶颈正被"自判断"机制突破**：从 Self Reward 论文到 SLIM、Swarm Skills 的多维评分，研究界在一致探索如何让 Agent 自主产生训练信号——这既是对人工标注成本的规避，也是迈向真正自主自进化 Agent 的必要条件，但如何防止奖励偏移和自我欺骗仍是核心待解难题。
