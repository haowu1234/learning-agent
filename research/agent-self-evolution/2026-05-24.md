📄 **【经验图驱动的自进化 Agent 框架】**（EXG: Self-Evolving Agents with Experience Graphs）
🔗 https://arxiv.org/abs/2605.17721
💡 **核心贡献**
当前自进化 Agent 大多依赖临时性反思或非结构化记忆，EXG 首次将 Agent 在线执行中积累的成功与失败轨迹显式组织为**结构化经验图**（Experience Graph），支持跨任务经验复用。该框架既可在线实时扩展经验图，也可将其作为离线外部记忆模块，作为即插即用组件接入已有自进化系统。
🔧 **技术亮点**
- 将经验以图结构表示，节点为关键策略，边为因果与相似关系，支持高效结构化检索
- 在线模式：执行时实时更新图，立即复用跨任务经验；离线模式：将固化后的图用作外部记忆
- 作为 plug-and-play 组件，可将已有反思/记忆型 Agent 的历史经验统一整合进图
📊 **实验结果**
在代码生成和推理 benchmark 上，EXG 在在线与离线评估中均优于基于反思和基于记忆的基线，性能-效率权衡更优
🔄 **自进化类型**：数据飞轮 / 经验结构化记忆

📄 **【经验驱动闭环自进化 LLM Agent】**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079
💡 **核心贡献**
浙大联合上海 AI Lab 等提出 EvolveR，通过"在线交互→离线自蒸馏→经验库维护→强化学习更新"的闭环，让 Agent 能从自身历史轨迹中提炼可复用**策略原则**（而非事实知识）。该论文已被 **ICML 2026** 接收。
🔧 **技术亮点**
- 离线自蒸馏：从成功轨迹提炼正向原则，从失败轨迹提炼避坑原则，经验由 Agent 自己生成而非外部教师注入
- 动态经验库：语义去重 + 使用频次动态打分 + 低效原则剪枝，5 万条原则 Top-3 检索延迟仅 0.20s
- GRPO 强化学习更新，奖励不仅考察最终答案，也奖励"合理调用经验检索"行为
📊 **实验结果**
Qwen2.5-3B 上 EvolveR 平均 EM 0.382 vs Search-R1-instruct 0.325；Qwen2.5-7B 上 0.417 vs 0.385。在 TriviaQA、HotpotQA、2WikiMultiHopQA 等多数据集均领先
🔄 **自进化类型**：数据飞轮 / 奖励驱动 / 自我反思

📄 **【Agent 记忆系统的元进化框架】**（MemEvolve: Meta-Evolution of Agent Memory Systems）
🔗 https://arxiv.org/abs/2512.18746
💡 **核心贡献**
现有自进化记忆系统在**固定的记忆架构**上积累经验，但记忆架构本身无法根据任务上下文动态调整。MemEvolve 提出元进化框架，**同时进化 Agent 的经验知识和记忆架构本身**，实现"学习如何学习"。该论文已被 **ICML 2026** 接收。
🔧 **技术亮点**
- 双循环元进化：内循环在给定记忆架构下积累经验，外循环跨架构搜索并进化记忆系统本身
- 引入 EvolveLab——将 12 种代表性记忆系统蒸馏为模块化设计空间（encode/store/retrieve/manage），提供标准实现基座
- 记忆架构设计可跨任务、跨 LLM backbone 迁移
📊 **实验结果**
在 4 个 agentic benchmark 上，MemEvolve 使 SmolAgent 和 Flash-Searcher 等框架性能提升最高 **17.06%**，跨任务跨模型迁移效果显著
🔄 **自进化类型**：持续学习 / 模型蒸馏 / 元学习

📄 **【可移植自进化多智能体协调规范】**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.10052
💡 **核心贡献**
当前多 Agent 协调协议被锁定在框架内部，无法跨系统共享或自主进化。Swarm Skills 将 Anthropic Skills 标准扩展至多 Agent 语义，将协调工作流变为**可分发的一等公民资产**，内置语义结构支持自进化。
🔧 **技术亮点**
- 引入可移植的多 Agent 协作规范（角色、工作流、执行边界、语义结构），支持零适配器跨框架移植
- 配套自进化算法：自动将成功执行轨迹蒸馏为新 Swarm Skill，基于"有效性+利用率+新鲜度"多维评分持续打补丁
- 无需人类介入的协调策略自我精炼循环
🔄 **自进化类型**：自我博弈 / 数据飞轮 / 多智能体协调进化

📄 **【联邦 LLM 在线微调的自博弈增强算法】**（SPEAR: Self-Play Enhancement via Advantage-Weighted Refinement in Online Federated LLM Fine-Tuning with Real-Time Feedback）
🔗 https://arxiv.org/abs/2605.07977
💡 **核心贡献**
现有基于反馈的 LLM 自改进方法局限于离线设置且需要特权的 ground-truth 上下文。SPEAR 提出在**联邦学习**中实现真正在线的自博弈自进化，仅依赖非答案的部分反馈，无需昂贵的批量采样或标准答案。
🔧 **技术亮点**
- 反馈引导的自博弈循环：为每个 prompt 自动构建对比正负样本对
- 双目标训练：正确完成的 MLE 训练 + 对错误完成尾部 token 的置信度加权 unlikelihood 训练
- 在资源受限边缘设备上高效运行，兼容联邦学习通信约束
📊 **实验结果**
在多个标准 benchmark 上超越 SOTA 基线，代码已开源（github.com/lee3296/SPEAR）
🔄 **自进化类型**：自我博弈 / 在线学习 / 奖励驱动

## 🚀 今日洞察

当前 Agent 自进化研究呈现两条清晰路线：**经验结构化**（EXG、EvolveR）和**架构自进化**（MemEvolve）——前者在固定架构上让 Agent 学会"用好经验"，后者走向更深一层的元学习，让记忆系统本身随任务进化。核心挑战在于如何在经验积累的规模扩大（5 万条原则、在线持续更新）时保持经验库的质量与检索效率，防止知识退化和灾难性遗忘。联邦场景下的在线自进化（SPEAR）正在打通"用户侧实时反馈→模型边缘自更新"的新范式，预示着未来 LLM 自进化将从集中式实验室走向分布式持续部署。
