📄 **[自进化语言模型：协同进化判别式评分规则驱动的无监督自我提升]**（EvolLM: Self-Evolving Language Models through Co-Evolved Discriminative Rubrics）
🔗 https://arxiv.org/abs/2605.03871
💡 核心贡献：提出 EVOLM，一种无需外部监督的后训练方法，通过让模型自身的评估能力生成判别式评分规则，同时训练规则生成器与策略模型，以历史检查点的时序对比作为偏好信号实现自我提升。该方法彻底打破了对人工标注、专有 API 或标量奖励模型的依赖，使奖励能力随模型本身规模同步增长。
🔧 技术亮点：
- 单模型内交替训练两种能力：实例特定评分规则生成器 + 基于规则条件奖励的策略优化
- 规则生成优化目标为最大化小型冻结判别模型对优/劣响应的区分能力（判别效用）
- 所有偏好信号均来自策略自身输出的时序对比（temporal contrast），零标注成本
📊 实验结果：Qwen3-8B 在 RewardBench-2 上生成的规则比 GPT-4.1 高出 **25.7%**；策略在 OLMo3-Adapt suite 上达到 **69.3%** 平均分，超越基于 GPT-4.1 规则训练的策略 3.9%，超越 SOTA 8B 奖励模型 SkyWork-RM **16%**
🔄 自进化类型：**自我奖励 / 奖励驱动 / 数据飞轮**

📄 **[Evolving-RL：经验驱动自进化能力的端到端优化框架]**（Evolving-RL: End-to-End Optimization of Experience-Driven Self-Evolving Capability within Agents）
🔗 https://arxiv.org/abs/2605.10663
💡 核心贡献：提出 Evolving-RL 框架，将经验提取与经验利用作为统一过程进行端到端联合优化，解决了现有工作只关注系统设计而忽视底层模型自进化能力内化的问题。通过协同进化经验提取器与求解器，实现将可复用经验模式直接内化到模型参数中。
🔧 技术亮点：
- 以经验提取与评估为学习中心，用评估衍生的双重监督信号分别优化提取器和求解器
- 经验提取与利用的协同进化（co-evolution）是性能增益完全释放的必要条件
- Evolving-RL 同时充当经验增强 RL 算法，在无测试时经验积累的情况下依然大幅超越标准基线
📊 实验结果：ALFWorld 未见任务上相对 GRPO 基线提升 **98.7%**，Mind2Web 上提升 **35.8%**
🔄 自进化类型：**数据飞轮 / 持续学习 / 奖励驱动**

📄 **[自进化 Agent 会遗忘吗？终身 LLM Agent 适应中的能力退化与保持]**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）
🔗 https://arxiv.org/abs/2605.09315
💡 核心贡献：首次系统揭示并量化 LLM Agent 自进化过程中的「能力侵蚀」现象——适应新任务分布时已习得的旧能力会非单调地退化，跨工作流、技能库、模型权重和记忆四个进化维度均普遍存在。同时提出 Capability-Preserving Evolution（CPE）通用稳定化原则作为缓解方案。
🔧 技术亮点：
- 在工作流、技能、模型、记忆四个维度上全面检验自进化的「灾难性遗忘」问题
- CPE 原理通过约束自进化过程中的破坏性能力漂移实现稳定化
- 在 GPT-5.1 优化下，工作流进化中 CPE 将简单任务保留率从 41.8% 提升至 52.8%，同时不损复杂任务适应性
📊 实验结果：跨四个进化维度验证，CPE 在保留能力稳定性的同时维持适应性能
🔄 自进化类型：**持续学习 / 自我反思 / 模型蒸馏**

📄 **[Continual Harness：面向自进化具身 Agent 的在线适应框架]**（Continual Harness: Online Adaptation for Self-Improving Foundation Agents）
🔗 https://arxiv.org/abs/2605.09998
💡 核心贡献：提出 Continual Harness，一种无需重置环境的自进化具身 Agent 框架，将之前在 Gemini Plays Pokémon（GPP）实验中发现的人机协作自进化信号形式化和自动化。Agent 在单次运行中交替执行动作和优化自身 prompt、子 Agent、技能库和记忆，无需预置知识或手工工具。
🔧 技术亮点：
- Reset-free 在线适应：在单次运行内通过任意历史轨迹数据持续自我修正，无需跨 episode 重置
- 闭环奖励共学习：使用前沿教师模型对开源 Agent 的轨迹进行过程奖励重标注，并用于更新模型权重
- 验证于 Pokémon Red/Emerald 等复杂具身任务，起点仅为最小环境接口，无领域先验
📊 实验结果：相较极简基线显著降低按键成本，弥合与手工专家 harness 的大部分差距（GPP 实验首次完成 Pokémon Blue/Yellow Hard Mode/Crystal 全通关）
🔄 自进化类型：**自我反思 / 持续学习 / 奖励驱动**

📄 **[SPEAR：联邦 LLM 微调中基于优势加权修正的自博弈增强]**（Self-Play Enhancement via Advantage-Weighted Refinement in Online Federated LLM Fine-Tuning with Real-Time Feedback）
🔗 https://arxiv.org/abs/2605.07977
💡 核心贡献：提出 SPEAR 算法，在联邦学习场景下实现基于实时用户反馈的在线 LLM 自进化微调，无需离线设置、无需完整标准答案。利用反馈引导的自博弈循环构建对比训练对，同时优化最大似然（正确完成）与置信度加权反似然（错误尾部 token）。
🔧 技术亮点：
- 自博弈构建自然对比对，仅需部分非答案反馈（non-answer feedback），无需特权上下文
- 优势加权修正机制降低边缘设备训练成本，资源高效适配联邦场景
- 在线学习与联邦隐私保护并行，无需集中式离线数据
📊 实验结果：在多个基准测试上超越 SOTA 基线（代码开源：github.com/lee3296/SPEAR）
🔄 自进化类型：**自我博弈 / 奖励驱动 / 持续学习**

## 🚀 今日洞察

本周 Agent 自进化研究呈现三条清晰主线：**①「无外部监督」的奖励内化**（EVOLM 等通过让模型自身生成评估规则并以时序对比为偏好信号，将奖励扩展能力从外部依赖彻底转移至模型自身）；**②「经验-遗忘」的双重张力**（Evolving-RL 与 CPE 研究共同揭示：高效经验提取与反灾难性遗忘缺一不可，端到端联合优化是突破孤立系统设计的关键）；**③「具身在线进化」的工程化跨越**（Continual Harness 和 SPEAR 将自进化落地于 reset-free 游戏环境与边缘联邦场景，标志着自进化从理论范式向实际部署迈出重要一步）。核心挑战正在从「能否自我提升」转向「如何在长时程适应中同时保持旧能力、拓展新能力、并在资源受限条件下维持稳定」。
