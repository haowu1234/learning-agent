📄 **【无监督原生自进化】通过世界知识探索训练无奖励自发自进化 LLM 智能体**
（Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration）
🔗 https://arxiv.org/abs/2604.18131

💡 **核心贡献**
提出一种「内禀元进化」范式：在任务执行前，Agent 自主探索陌生环境并生成 World Knowledge，通过结果驱动的奖励信号仅在训练阶段教会模型如何有效探索与总结，推理阶段无需任何外部奖励或人类指引即可原生自进化。

🔧 **技术亮点**
- **结果驱动奖励**：以「自生成世界知识能将下游任务成功率提升多少」作为训练时奖励信号，不依赖 GT 标注
- **推理时零外部依赖**：推理阶段模型利用内部参数自发执行 Native Self-Evolution，适应未见环境
- **跨模型迁移**：世界知识甚至使 14B Qwen3 模型在无辅助条件下超越 Gemini-2.5-Flash

📊 **实验结果**
应用于 Qwen3-30B 和 Seed-OSS-36B，在 WebVoyager 和 WebWalker 基准上性能提升 **+20%**；14B 小模型超越 Gemini-2.5-Flash

🔄 **自进化类型**：无监督内禀自进化 / 数据飞轮（世界知识蒸馏）

📄 **【技能全生命周期管理】MUSE-Autoskill：通过技能创建、记忆、管理与评估实现自进化智能体**
（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）
🔗 https://arxiv.org/abs/2605.27366

💡 **核心贡献**
提出以「技能」为中心的 Agent 框架 MUSE-Autoskill（Memory-Utilizing Skill Evolution），通过统一的技能全生命周期管理（创建→记忆→管理→评估→精炼），让 Agent 在跨任务执行中持续提升技能复用率和可靠性，并引入 **技能级记忆**（Skill-Level Memory）积累每个技能的跨任务经验。

🔧 **技术亮点**
- **技能全生命周期**：Creation → Memory → Management → Evaluation → Refinement 五阶段闭环
- **单元测试 + 运行时反馈**：双重评估机制保障技能质量，驱动持续精炼
- **跨 Agent 技能迁移**：Skill-Level Memory 使技能经验可在不同 Agent 实例间共享复用

📊 **实验结果**
在 SkillsBench 基准上验证，生命周期管理技能在任务成功率、效率、复用率和跨 Agent 迁移四个维度均有改善（30 页报告，含 8 图 13 表）

🔄 **自进化类型**：持续学习 / 技能蒸馏 / 数据飞轮

📄 **【自我博弈 + 联邦在线学习】SPEAR：在线联邦 LLM 微调中基于优势加权精炼的自我博弈增强**
（Self-Play Enhancement via Advantage-Weighted Refinement in Online Federated LLM Fine-Tuning with Real-Time Feedback）
🔗 https://arxiv.org/abs/2605.07977

💡 **核心贡献**
提出 SPEAR，一种在线联邦 LLM 微调算法，通过反馈引导的自我博弈循环构建对比样本对，在无需 Ground-Truth 上下文的条件下实现实时自我提升，适配边缘设备资源约束。

🔧 **技术亮点**
- **反馈引导自我博弈**：基于用户实时反馈（仅部分、非答案级）自动构建正负样本对
- **优势加权精炼**：对正确补全进行 MLE，对错误补全的尾 token 进行置信度加权负样本学习
- **在线 + 资源高效**：无需离线群体生成，可在资源受限的边缘设备上运行联邦 RL 训练

📊 **实验结果**
在多个基准数据集上优于当前 SOTA，具体数值见原文（27 页）

🔄 **自进化类型**：自我博弈 / 奖励驱动 / 联邦在线学习

📄 **【闭环协议级自进化】Autogenesis：一种自进化 Agent 协议**
（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.15034

💡 **核心贡献**
提出 Autogenesis Protocol（AGP），一种将「进化什么」与「如何进化」解耦的自进化协议；通过 Resource Substrate Protocol Layer（RSPL）将 prompt、agent、工具、环境和记忆建模为协议注册资源，并通过 Self-Evolution Protocol Layer（SEPL）规范闭环算子接口（提议→评估→提交），支持可审计溯源与回滚。

🔧 **技术亮点**
- **资源生命周期协议（RSPL）**：统一建模所有 Agent 资源，含显式状态、生命周期和版本化接口
- **闭环进化算子（SEPL）**：Propose → Assess → Commit 三步闭环，带 Lineage 审计与 Rollback 保障
- **AGS 多智能体系统**：基于 AGP 构建的 Autogenesis System，动态实例化和精炼协议注册资源

📊 **实验结果**
在多个需要长视野规划和异构资源工具使用的基准上一致优于强基线（v4 最新版本，代码开源）

🔄 **自进化类型**：持续学习 / 自我反思 / 协议驱动闭环

## 🚀 今日洞察

1. **从「依赖外部监督」到「内禀原生进化」是当前最热前沿**：传统自我改进依赖人类标注或奖励信号，而 2026-04/05 最新工作（如 Reward-Free Self-Evolution、SPEAR）正在挑战这一前提，追求推理时零外部依赖的内驱进化能力，但如何在无 GT 场景中防止进化方向漂移仍是核心挑战。

2. **技能/经验的结构化管理成为持续学习新范式**：MUSE-Autoskill、ReasoningBank 等工作均表明，单纯「对话即记忆」已不够，需要技能级生命周期管理（创建、复用、评估、精炼）和推理策略的显式蒸馏，Agent 自进化正从参数层面向知识/工具层面延伸。

3. **协议层与系统层创新加速**：Autogenesis Protocol 将自进化从模型能力拔高到系统协议层，解决多智能体组合中的脆性「胶水代码」问题，暗示 Agent 自进化正走向基础设施化，未来的进化单元将是「资源 + 协议」而非单一模型。
