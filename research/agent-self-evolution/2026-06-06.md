📄 **MLEvolve：用于自动化机器学习算法发现的自进化框架**（MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery）
🔗 https://arxiv.org/abs/2606.06473
💡 核心贡献：提出 MLEvolve，一个让 LLM Agent 在机器学习工程（MLE）长时序任务中实现持续自进化的框架，解决了跨分支信息孤岛、无记忆搜索和缺乏层级控制三大瓶颈。该框架通过跨分支知识共享、持久化记忆搜索和层级优化控制，使 Agent 在长期科学发现任务中具备真正的自进化能力。
🔧 技术亮点：
- 跨分支信息共享机制（cross-branch knowledge sharing），打破独立探索分支之间的信息壁垒
- 持久化记忆模块（persistent memory search），让 Agent 能记住并复用历史探索经验
- 层级控制架构，使高层规划与低层执行有机协调，支持长时序任务的持续优化
📊 实验结果：在自动化 ML 算法发现任务上显著超越现有 MLE Agent 基线，具备更强的长期优化能力
🔄 自进化类型：**数据飞轮 + 持续学习**

📄 **RREDCoT：推理模型的分段级奖励再分配**（RREDCoT: Segment-Level Reward Redistribution for Reasoning Models）
🔗 https://arxiv.org/abs/2606.06475
💡 核心贡献：针对 GRPO 等 RL 微调方法中"稀疏奖励"问题，提出在 Chain-of-Thought 推理链的分段级别重新分配奖励信号，解决只有最终答案才能获得反馈的延迟奖励困境。通过更细粒度的奖励归因，显著提升推理模型在 RL 训练阶段的学习效率。
🔧 技术亮点：
- 分段级奖励再分配（segment-level reward redistribution），将最终奖励分解至 CoT 各子段
- 与 GRPO/REINFORCE 等主流 RL 算法兼容，作为即插即用的奖励模塑（reward shaping）模块
- 缓解长链 CoT 中的奖励稀疏性与信用分配（credit assignment）问题
📊 实验结果：在多个推理基准上对比 vanilla GRPO 有稳定提升，尤其在长链推理任务中效果显著
🔄 自进化类型：**奖励驱动 + 自我反思**

📄 **TailLoR：参数高效持续学习中主成分保护**（TailLoR: Protecting Principal Components in Parameter-Efficient Continual Learning）
🔗 https://arxiv.org/abs/2606.06494
💡 核心贡献：提出 TailLoR，在基于谱分解的参数高效微调（PEFT）框架下，通过将预训练权重的奇异基向量固定为参考系、只对奇异值矩阵施加低秩更新，有效防止持续学习过程中的灾难性遗忘（catastrophic forgetting）。软谱惩罚项约束更新远离主奇异方向，从而保护已学知识。
🔧 技术亮点：
- 以预训练权重奇异基（U, V）为固定参考系，低秩更新仅作用于奇异值矩阵
- 软谱惩罚（soft spectral penalty），在不硬冻结参数的前提下保护主成分方向
- 比 LoRA/IA³ 等标准 PEFT 方法在持续学习场景下显著降低遗忘率
📊 实验结果：在多个持续学习 benchmark（如 Split-CIFAR、CORe50）上超越现有参数高效持续学习方法
🔄 自进化类型：**持续学习**

📄 **面向扩散语言模型的自增强检索**（Self-Augmenting Retrieval for Diffusion Language Models）
🔗 https://arxiv.org/abs/2606.06474
💡 核心贡献：发现离散扩散语言模型在去噪过程中丢弃的低置信度 token 本质上是一种"前瞻"信号，可以作为检索增强生成（RAG）的查询源，从而实现模型利用自身中间生成状态进行自我检索增强。这种无需外部标注的自增强机制让扩散 LM 无需额外训练即可获得 RAG 能力。
🔧 技术亮点：
- 将推理过程中被丢弃的低置信 token 复用为 RAG 检索查询，零成本获取检索线索
- 无需任何有监督微调，纯推理阶段即插即用
- 自增强检索信号优于随机 token 采样，证明低置信 token 具有语义信息价值
📊 实验结果：在知识密集型问答任务上，自增强 RAG 显著提升扩散 LM 的生成质量，接近或超过有监督 RAG 基线
🔄 自进化类型：**自我反思 + 数据飞轮**

📄 **Goedel-Architect：基于蓝图生成与精化的形式化定理证明**（Goedel-Architect: Streamlining Formal Theorem Proving with Blueprint Generation and Refinement）
🔗 https://arxiv.org/abs/2606.06468
💡 核心贡献：提出 Goedel-Architect，一个以"蓝图（Blueprint）生成—精化"为核心的 Lean 4 形式化定理证明 Agentic 框架，通过将大定理分解为依赖关系图并迭代精化子目标，实现了自主定理证明的结构化自进化。核心贡献是将自我修正机制融入证明搜索过程，大幅减少人工干预。
🔧 技术亮点：
- 蓝图生成：将主定理分解为带依赖关系的定义/引理有向图，提供证明路线图
- 迭代精化（iterative refinement）：根据 Lean 4 验证器反馈自动修正蓝图中的错误子目标
- 可选地融合自然语言草稿作为蓝图引导，增强人机协作灵活性
📊 实验结果：在 miniF2F 等形式化数学 benchmark 上取得 SOTA 或竞争性结果，证明蓝图导向的自我修正有效提升证明成功率
🔄 自进化类型：**自我反思 + 自我修正**
