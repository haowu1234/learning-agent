### 1

📄 **通过参数化记忆扩展自进化 Agent**（Scaling Self-Evolving Agents via Parametric Memory）
🔗 https://arxiv.org/abs/2606.04536
💡 **核心贡献**
提出 TMEM 框架，突破现有记忆增强 Agent 仅将经验存在 Prompt 空间的局限——Agent 在单次 Episode 内通过轻量级在线 LoRA 更新，将提取到的监督信号真正写入模型参数，让策略随经验实时改变。通过强化学习端到端优化"提取动作"质量，使在线 LoRA 适应所用的数据本身也被纳入优化目标。

🔧 **技术亮点**
- 将 Agent 决策建模为带快权重（fast-weight）滚动动态的 Agentic Decision Process：动作从 π_{θ₀+Δt} 采样，提取动作产生监督并更新 Δt
- 引入基于 SVD 的 LoRA 子空间初始化，加速在线收敛，降低遗忘风险
- RL 训练 θ₀ 同时优化任务动作质量与在线适应数据质量，形成双向提升飞轮

📊 **实验结果**
在 LoCoMo、LongMemEval-S、多目标搜索、CL-Bench 四个基准上，TMEM 跨模型尺度一致超越基于摘要和基于检索的基线方法。

🔄 **自进化类型**：数据飞轮 × 持续学习 × 奖励驱动

### 2

📄 **面向开放性任务的协同进化策略自我博弈（SCOPE）**（Self-Play via Co-Evolving Policies for Open-Ended Tasks）
🔗 https://arxiv.org/abs/2605.31433
💡 **核心贡献**
提出 SCOPE——一种无需外部数据的开放任务自我博弈框架，通过协同进化 Challenger（负责生成文档驱动任务）和 Solver（多轮检索作答）两个策略，摆脱了传统 self-play 依赖可规则检验答案的限制。使用冻结的初始模型作为"自裁判"，基于源文档生成任务专属评分标准，解决开放任务中无法获得客观奖励信号的核心难题。

🔧 **技术亮点**
- Challenger 与 Solver 双策略协同进化，Challenger 持续将任务难度对齐 Solver 能力前沿，防止训练坍塌
- 使用冻结初始模型作为 self-judge，无需前沿模型外部标注，实现真正的数据无监督 self-play
- 收益同时来源于检索能力和知识合成能力的提升，二者相对贡献因任务而异

📊 **实验结果**
在三个 7-8B 指令微调模型（Qwen2.5/Qwen3/OLMo-3）上，SCOPE 在 8 个开放任务基准提升最高 +10.4 点，在 7 个短答案 QA 保留集上提升最高 +13.8 点，在全部三个模型上超越使用 ~9K 精心整理提示的 GRPO_data 基线。

🔄 **自进化类型**：自我博弈 × 无监督自我提升

### 3

📄 **基于世界知识探索的自发性、无奖励 LLM Agent 自进化训练**（Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration）
🔗 https://arxiv.org/abs/2604.18131
💡 **核心贡献**
提出一种让 Agent 在推理阶段无需任何外部奖励或人工指令即可自主探索、自我进化的训练范式。设计基于结果的奖励机制（仅在训练阶段使用），衡量 Agent 自生成的世界知识对下游任务成功率的提升幅度，将"如何探索和总结"的元能力内化为模型参数。

🔧 **技术亮点**
- 奖励信号仅用于训练期教学，推理时 Agent 完全依赖内部参数进行原生自进化（Native Self-Evolution）
- 通过结果奖励驱动的世界知识生成，将外部监督从推理链路中彻底解耦
- 14B 小模型在获得自生成世界知识加持后可超越未辅助的 Gemini-2.5-Flash，验证了知识内化的强大潜力

📊 **实验结果**
应用于 Qwen3-30B 和 Seed-OSS-36B 后，在 WebVoyager 和 WebWalker 基准上性能提升 20%；14B Qwen3 超越未辅助的 Gemini-2.5-Flash。

🔄 **自进化类型**：奖励驱动 × 无监督自我提升 × 数据飞轮

### 4

📄 **EvolveR：通过经验驱动生命周期的自进化 LLM Agent**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079
💡 **核心贡献**（ICML 2026 录用）
提出 EvolveR，通过完整的闭环经验生命周期使 LLM Agent 系统性地从自身行动后果中学习——区别于现有框架仅聚焦于弥补外部知识差距的范式，EvolveR 直接解决了无法迭代优化问题求解策略这一根本瓶颈。

🔧 **技术亮点**
- **离线自蒸馏**：将交互轨迹合成为结构化抽象原则库（reusable strategic principles）
- **在线交互**：推理时主动检索蒸馏原则指导决策，积累多样化行为轨迹
- 策略强化机制基于性能反馈迭代更新模型，形成"蒸馏-检索-强化"三位一体闭环

📊 **实验结果**
在复杂多跳问答基准上超越强 Agentic 基线方法；已被 ICML 2026 接收。

🔄 **自进化类型**：自我反思 × 模型蒸馏 × 持续学习

### 5

📄 **AgentCL：面向语言 Agent 持续学习的严格评估框架**（AgentCL: Toward Rigorous Evaluation of Continual Learning in Language Agents）
🔗 https://arxiv.org/abs/2606.02461
💡 **核心贡献**
针对现有持续学习基准无法严格评估语言 Agent 跨任务积累与复用能力的痛点，提出 AgentCL 评估框架：构建可控组合任务流（其中早期子解、证据或工作流在后续任务中有意可复用），与无法保证复用性的朴素任务流形成对照，为非参数记忆设计提供诊断工具 MemProbe。

🔧 **技术亮点**
- 可控组合任务流 vs. 朴素任务流的对照设计，使记忆方案的可塑性差异得以清晰呈现
- MemProbe 存储交互、洞见和技能，在整合阶段过滤不可靠经验，精准诊断记忆设计对持续学习的影响
- 揭示"朴素流"和保留集常导致有限收益甚至记忆引发的性能退化，倒逼更强记忆设计

📊 **实验结果**
在编码、深度研究、语言理解/推理三类任务上的实证分析：可控流显著优于朴素流区分不同记忆设计的能力；朴素流在区分不同方案时效果有限。

🔄 **自进化类型**：持续学习 × 记忆机制

## 🚀 今日洞察

1. **参数化记忆成为新主战场**：从 TMEM（参数化记忆+在线 LoRA）到 EvolveR（轨迹蒸馏原则库），研究社区正从"记忆存在 Prompt 里"向"记忆写进模型权重"的范式迁移——这意味着 Agent 的进化不再受限于上下文窗口，可在单次 Episode 内实现真正的行为改变。

2. **去监督化（Supervision-Free）自进化**：SCOPE 的 self-judge + co-evolving 机制和 2604.18131 的 reward-free 推理时自进化，都在攻克同一难题——如何让 Agent 在没有人类标注或外部奖励的情况下自主提升。这是迈向真正自主 Agent 的核心挑战，当前突破路径集中在"用冻结初始模型做裁判"和"训练期内化奖励以解耦推理期"两条技术路线。

3. **评估体系建设滞后于方法创新**：AgentCL 的出现表明社区已意识到评估基准的不严谨性——现有朴素任务流无法有效区分不同记忆/持续学习方案的优劣，亟需更严格的组合任务流与跨任务迁移增益度量，这将成为 2026 年下半年研究的重要方向。
