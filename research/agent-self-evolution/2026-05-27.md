### 📄 **【MUSE-Autoskill】通过技能创建、记忆、管理与评估实现自进化 Agent**
（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）

🔗 https://arxiv.org/abs/2605.27366  
📅 提交日期：2026-05-26（今日最新）  
🏛 机构：未注明（cs.AI / cs.CL / cs.LG / cs.MA）

💡 **核心贡献**  
提出 MUSE-Autoskill 框架，将 LLM Agent 的技能管理提升为一个完整生命周期（创建→记忆→管理→评估→精炼），使技能不再是孤立静态的工件，而成为有记忆、可进化的长期资产。引入技能级记忆（skill-level memory），跨任务积累每个技能的使用经验，从而实现更有效的复用和适应。

🔧 **技术亮点**
- **统一技能生命周期**：创建→存储→组织选择→单元测试+运行时反馈评估→精炼，形成完整闭环
- **技能级记忆**：每个技能独立维护跨任务的经验记忆，支持更有针对性的复用决策
- **跨 Agent 迁移**：优化后的技能可在不同 Agent 间共享迁移，降低技能获取成本

📊 **实验结果**  
在 SkillsBench 上，生命周期管理技能相比静态技能显著提升了任务成功率、效率和跨 Agent 迁移能力。

🔄 **自进化类型**：数据飞轮 + 持续学习

### 📄 **【SkillOpt】自进化 Agent 技能的文本空间优化执行策略**
（SkillOpt: Executive Strategy for Self-Evolving Agent Skills）

🔗 https://arxiv.org/abs/2605.23904  
📅 提交日期：2026-05-22  
🏛 机构：Microsoft Research, 上海交通大学, 同济大学, 复旦大学

💡 **核心贡献**  
首次将深度学习优化器的设计哲学（epoch、批量大小、学习率、验证门控）引入到 Agent 技能的文本空间优化中，在不修改模型权重的前提下系统地进化自然语言技能文档，实现稳定且可复现的技能提升。独立的 Optimizer 模型将带评分的 rollout 转换为有界的增/删/替换编辑操作，编辑仅在通过验证集得分提升时才被接受。

🔧 **技术亮点**
- **文本学习率预算（Textual LR budget）**：限制每轮技能编辑幅度，防止灾难性偏移，类比神经网络优化中的步长控制
- **拒绝编辑缓冲区（Rejected-edit buffer）**：保存被拒绝的修改，支持回溯和元更新（epoch-wise slow/meta update）
- **零推理开销部署**：优化过程的所有额外计算仅发生在训练阶段，部署时无额外模型调用

📊 **实验结果**  
跨 6 个基准、7 个目标模型、3 种执行框架（直接对话、Codex、Claude Code）共 52 个评测单元全部达到最优或并列最优。在 GPT-5.5 上平均提升：直接对话 +23.5 分、Codex Agent 环境 +24.8 分、Claude Code 环境 +19.1 分；跨模型规模和执行环境的迁移实验也验证了技能工件的可移植性。

🔄 **自进化类型**：自我改进（文本空间梯度优化）

### 📄 **【Swarm Skills】面向协作工程的可移植自进化多智能体系统规范**
（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）

🔗 https://arxiv.org/abs/2605.10052  
📅 提交日期：2026-05-14  
🏛 机构：多机构合作（Xinyu Zhang et al., cs.CL / cs.MA）

💡 **核心贡献**  
提出 Swarm Skills 规范，将多智能体协作协议从框架内部代码/静态配置解放出来，打包为跨系统可分发的一等资产（包含角色、工作流、执行约束和内置语义自进化结构）。附带的自进化算法从成功执行轨迹中蒸馏新的 Swarm Skills，并基于多维度评分（有效性、利用率、新鲜度）持续修补现有技能，无需人工介入。

🔧 **技术亮点**
- **渐进式披露（Progressive Disclosure）**：技能规范分层暴露接口，实现零适配器跨 Agent 移植性
- **多维度自动评分**：Effectiveness（任务成功率）、Utilization（复用频率）、Freshness（信息时效性）三维度驱动持续进化
- **轨迹蒸馏自动化**：成功执行轨迹直接转化为新的 Swarm Skills，形成数据飞轮闭环

📊 **实验结果**  
通过 JiuwenSwarm 开源参考实现的案例研究，验证了跨 Agent 零适配器移植和自进化能力。

🔄 **自进化类型**：数据飞轮 + 模型蒸馏（轨迹蒸馏）

### 📄 **【MemSkill】面向自进化 Agent 的可学习演化记忆技能**
（MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents）

🔗 https://arxiv.org/abs/2602.02474  
📅 提交日期：2026-02-03（v2 近期更新）  
🏛 机构：cs.CL / cs.AI / cs.LG

💡 **核心贡献**  
将 Agent 记忆管理中的"提取、整合、剪枝"操作从固定手工规则重构为可学习、可进化的记忆技能（MemSkill）。采用 Controller 学习技能选择策略 + LLM Executor 生成技能引导记忆的架构，并引入 Designer 组件周期性审查失败案例、提议技能集演化，形成技能选择策略与技能集协同进化的闭环。

🔧 **技术亮点**
- **双轮进化闭环**：Controller（选择策略）和技能集（Designer 提议修改/新增）同时迭代优化
- **跨度级记忆（Span-level memory）**：从传统轮次级、手工设计操作转向更精细的跨度级、技能条件化生成
- **硬案例驱动演化**：Designer 专注于选错技能或技能产出错误/不完整记忆的失败案例，精准定位演化方向

📊 **实验结果**  
在 LoCoMo、LongMemEval、HotpotQA、ALFWorld 四个数据集上均优于强基线，展现良好的跨场景泛化能力。

🔄 **自进化类型**：持续学习 + 自我反思（失败驱动的技能演化）

### 📄 **【SAGE】基于强化学习与技能库的自改进 Agent**
（Reinforcement Learning for Self-Improving Agent with Skill Library）

🔗 https://arxiv.org/abs/2512.17102  
📅 提交日期：2025-12-18  
🏛 机构：cs.AI / cs.LG

💡 **核心贡献**  
提出 SAGE（Skill Augmented GRPO for self-Evolution）框架，将技能库与 RL（GRPO）训练深度整合：通过 Sequential Rollout 跨任务链式部署 Agent，使技能在任务链中逐步积累可用；引入技能集成奖励（Skill-integrated Reward），将技能生成与利用质量纳入奖励信号，驱动模型主动产生和使用有效技能。

🔧 **技术亮点**
- **Sequential Rollout**：Agent 在相似任务链上迭代部署，每轮任务生成的技能可供后续任务使用，形成持续累积的技能库
- **技能集成奖励**：在原始结果奖励之外补充技能质量奖励，引导 Agent 学会"何时创建/何时调用"技能
- **GRPO 基础**：在相对策略优化框架下训练，天然适配无标注、自生成的数据分布

📊 **实验结果**  
在多个复杂推理和多轮交互任务上，SAGE 相比纯 RL 基线和单纯提示方法均有显著提升。

🔄 **自进化类型**：奖励驱动 + 持续学习（技能库增强 RL）

## 🚀 今日洞察

**Agent 自进化已从单一"自我反思"走向系统化"技能工程"。** 本周多篇顶级论文（SkillOpt、MUSE-Autoskill、Swarm Skills、MemSkill）不约而同地聚焦于将技能（Skill）作为自进化的核心载体——技能不再是一次性生成物，而是具备生命周期管理、经验记忆和持续精炼能力的"可训练资产"，折射出领域共识：**技能库质量是 Agent 自进化能力的关键瓶颈**。

**文本空间优化（Text-Space Optimization）正成为权重冻结时代的新范式。** SkillOpt 证明将深度学习优化器的训练纪律（学习率、验证门控、批量更新）移植到自然语言技能进化是可行且高效的，这为在不重新训练基础模型的前提下持续改进 Agent 行为开辟了低成本通道。

**核心挑战仍在于评估与泛化。** 多篇论文均在特定基准（SkillsBench、ALFWorld等）上验证，但真实开放环境下技能的有效性评估、跨 Agent 迁移稳定性以及对抗性/分布外任务的泛化，仍是未被充分解决的问题，也是下一阶段自进化研究的主战场。
