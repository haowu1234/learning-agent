📄 **[技能金字塔：一种面向自进化 Agent 的层次化技能整合框架]**（SkillPyramid: A Hierarchical Skill Consolidation Framework for Self-Evolving Agents）
🔗 https://arxiv.org/abs/2606.03692
💡 **核心贡献：**
提出 SkillPyramid，一个基于层次技能拓扑的自进化框架，通过系统性的技能积累与迁移机制，解决了现有 Agent 技能库碎片化、无法跨任务泛化的根本缺陷。框架内置自进化机制，使 Agent 在任务执行中自主组合、验证并吸纳新技能，将静态技能资源池转化为动态演化系统。
🔧 **技术亮点：**
- 层次化技能拓扑（Hierarchical Skill Topology）：按抽象层次组织技能，高层技能通过组合低层技能泛化到新场景
- 执行时自进化（Runtime Self-Evolution）：Agent 在解任务过程中实时 compose → validate → incorporate，无需离线重训
- 经验复用机制：避免跨任务重复构建相似能力，将技能积累转化为可迁移的资产
📊 **实验结果：**
在 ALFWorld、WebShop、ScienceWorld 三大 benchmark、四种骨干模型上，平均奖励提升 **38.0%**，执行步数减少 **27.7%**。
🔄 **自进化类型：** 数据飞轮 / 持续学习（技能库动态演化）

📄 **[FederatedSkill：面向 Agent 技能演化的联邦学习框架]**（FederatedSkill: Federated Learning for Agentic Skill Evolution）
🔗 https://arxiv.org/abs/2606.03143
💡 **核心贡献：**
首次将联邦学习引入 Agent 技能进化场景，解决了多用户协作自进化中的数据隐私与个性化矛盾。用"语义技能 diff"代替原始轨迹共享，在保护用户隐私的同时实现跨用户技能协同进化。
🔧 **技术亮点：**
- 语义技能 Diff（Semantic Skill Diffs）：以结构化补丁（patch）而非原始轨迹作为通信单元，彻底消除隐私风险
- 服务端进化 Agent：聚合各客户端 patch，动态建模每个客户端的能力边界，实现严格个性化技能进化
- 超越全局均值：避免单一全局库对异构客户端能力的损害
📊 **实验结果：**
在 20 个不同 Agent 任务族上，相比 self-evolving baseline 成功率提升最高 **44.4%**，计算开销降低 **37.5%**。
🔄 **自进化类型：** 数据飞轮 / 持续学习（联邦协同进化）

📄 **[SAGE：Agent 生态系统中社会化进化的量化评估]**（SAGE: A Quantitative Evaluation of Socialized Evolution in Agent Ecosystems）
🔗 https://arxiv.org/abs/2606.03544
💡 **核心贡献：**
首次系统量化"社会化进化"（SocialEvo，多 Agent 共享历史）相比"孤立自进化"（SelfEvo）的边界条件，发现同伴历史并非万能放大器——最强 Agent 无法超越自进化上界，但陷入平台期的 Agent 可借助同伴经验实现突破。
🔧 **技术亮点：**
- 计算量匹配对照实验：SocialEvo vs SelfEvo 设计严格控制计算量，排除信息量差异干扰
- 三类进化场景：开放式 ML 研究、长视角经济规划、策略多人博弈，覆盖不同任务特性
- 抽象胜过曝光量：过滤后的 peer trace 和反思摘要优于原始日志，说明社会增益依赖知识抽象而非原始信息量
📊 **实验结果：**
13 页论文（5 图），跨 5 个不同模型家族多轮进化对照，在竞争场景中发现 Agent 呈现通用能力提升而非对手专项策略。
🔄 **自进化类型：** 自我博弈 / 多智能体协同进化

📄 **[双向进化搜索：支持自我提升语言模型的搜索框架]**（Self-Improving Language Models with Bidirectional Evolutionary Search）
🔗 https://arxiv.org/abs/2605.28814
💡 **核心贡献：**
提出 BES（Bidirectional Evolutionary Search），以前向候选进化 + 后向目标分解的双向搜索克服 best-of-N / tree search 的稀疏奖励和探索局限，在主流 post-training 算法失效的高难任务上实现稳定提升。
🔧 **技术亮点：**
- 前向进化算子（Forward Evolution Operators）：重组部分轨迹以生成单次 rollout 难以到达的候选，逃出模型概率质量的"窄熵壳"
- 后向目标分解（Backward Goal Decomposition）：递归将原始任务分解为可检验子目标，产生密集中间反馈指导前向搜索
- 理论保证：证明前向扩展候选被限制在窄熵壳中，而进化算子可突破；后向搜索可指数级减少所需样本数
📊 **实验结果：**
在三个开放问题求解 benchmark 上，推理时优于现有开源框架（均值和最优性能），代码与模型已开源：github.com/Embodied-Minds-Lab/BES
🔄 **自进化类型：** 自我博弈 / 奖励驱动（密集反馈 + 进化搜索）

📄 **[MUSE-Autoskill：通过技能创建、记忆与全生命周期管理实现 Agent 自进化]**（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）
🔗 https://arxiv.org/abs/2605.27366
💡 **核心贡献：**
将 Agent 技能的完整生命周期（创建→记忆→管理→评估→精炼）纳入统一框架 MUSE-Autoskill，引入技能级记忆（Skill-Level Memory）跨任务积累每项技能的使用经验，使技能成为有记忆、可测试的长寿命资产。
🔧 **技术亮点：**
- 统一技能生命周期：覆盖 creation / memory / management / evaluation / refinement 五阶段
- 技能级记忆（Skill-Level Memory）：独立于任务层面的记忆，记录每个技能在不同任务中的表现，支持更精准的复用与自适应
- 单元测试 + 运行时反馈双重评估：借鉴软件工程方法验证技能质量，闭环持续精炼
📊 **实验结果：**
在 SkillsBench 上验证，生命周期管理技能改善了任务成功率、效率、复用率与跨 Agent 迁移效果。
🔄 **自进化类型：** 数据飞轮（技能生命周期管理 + 记忆驱动复用）

## 🚀 今日洞察

2026 年 6 月初，Agent 自进化研究呈现出**技能系统化**与**协同进化**两大核心叙事：SkillPyramid、MUSE-Autoskill、FederatedSkill 三篇同日涌现，均聚焦技能库从静态池到动态演化系统的范式升级，标志着"技能即资产"正成为自进化的基础设施共识。与此同时，SAGE 实证了社会化进化的边界条件——同伴历史只在特定 Agent 状态（陷入平台期）下解锁额外提升，抽象能力是关键，这为多 Agent 协同设计提供了重要约束。核心挑战仍在于如何在无 ground truth 信号的长尾任务中维持稳定进化信号，BES 的双向分解提供了一条通过密集子目标反馈破解稀疏奖励的路径，但泛化到开放域 Agent 任务的可靠性尚待检验。
