📄 **【自认知探索的自我进化 Web Agent】**（Learning to Adapt: Self-Improving Web Agent via Cognitive-Aware Exploration — SCALE）
🔗 https://arxiv.org/abs/2605.31365
💡 **核心贡献**：提出 SCALE 框架，通过三角色对抗机制（Selector/Predictor/Judger）让 Web Agent 自主发现自身认知局限并扩展能力边界，无需昂贵的人工专家轨迹。构建 SCALE-20k 大规模探索数据集（源自 19 个真实网站）支持持续自我进化训练。
🔧 **技术亮点**：
- 三角色对抗架构：Selector 选择候选行动、Predictor 预测执行结果、Judger 评估实际差距，形成认知边界的闭环自发现
- SCALE-Hop 图探索策略：将任务状态建模为图，实现全局规划并规避局部探索陷阱
- 全流程无监督：Agent 从环境交互轨迹中自动生成带结构化标注的训练样本，摆脱对标注数据的依赖
📊 **实验结果**：在多个真实 Web 环境评测上显著提升多款 MLLM 性能，泛化能力明显优于依赖专家演示的基线
🔄 **自进化类型**：自主探索 / 数据飞轮 / 自我博弈

📄 **【MUSE-Autoskill：技能生命周期管理驱动的自进化 Agent】**（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）
🔗 https://arxiv.org/abs/2605.27366
💡 **核心贡献**：提出以技能为核心的 Agent 自进化框架 MUSE-Autoskill，通过"创建→记忆→管理→评估→精炼"完整生命周期，让 Agent 在跨任务复用中持续提升技能质量。引入技能级经验记忆，每个技能随使用积累专属经验，跨 Agent 迁移成为可能。
🔧 **技术亮点**：
- 统一技能生命周期：技能不再是孤立静态工件，而是拥有版本、测试覆盖和运行反馈的"长期资产"
- 技能级经验记忆：为每个技能独立维护跨任务的历史使用经验，指导后续自适应改进
- 单元测试 + 运行时反馈双轨评估：技能质量通过代码级测试和实际任务执行结果共同验证
📊 **实验结果**：SkillsBench 上，生命周期管理的技能在任务成功率、执行效率、复用率和跨 Agent 迁移上均优于静态技能基线
🔄 **自进化类型**：数据飞轮 / 技能进化 / 持续学习

📄 **【EvolveR：经验驱动闭环的 LLM Agent 自进化框架（ICML 2026）】**（EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle）
🔗 https://arxiv.org/abs/2510.16079
💡 **核心贡献**：提出 EvolveR 框架，通过"在线交互→离线自蒸馏→经验库维护→GRPO 强化学习"闭环，让 Agent 从成功/失败轨迹中提炼可复用策略原则而非仅记忆事实，在复杂多跳问答上超越 Search-R1 等 RL 搜索 Agent 基线（已被 ICML 2026 接收）。
🔧 **技术亮点**：
- 经验自蒸馏（Offline Experience Distillation）：Agent 从历史轨迹中自主提炼"做题方法论"式的指导原则，小模型依赖教师蒸馏、大模型（3B+）自蒸馏效果更优
- 动态经验库维护：语义去重 + 成功率动态评分 + 低效原则剪枝，避免经验库劣化退化
- GRPO 奖励信号多维度设计：奖励覆盖最终答案正确性、推理完整性、经验检索调用质量
📊 **实验结果**：Qwen2.5-3B 平均 EM 0.382（vs Search-R1-instruct 0.325），Qwen2.5-7B 达 0.417（vs 0.385），经验检索消融后平均分下降 0.042
🔄 **自进化类型**：奖励驱动 / 自我反思 / 持续学习

📄 **【ASI-Evolve：AI 加速 AI 研究的进化框架】**（ASI-Evolve: AI Accelerates AI）
🔗 https://arxiv.org/abs/2603.29640
💡 **核心贡献**：提出 ASI-Evolve，一个让 AI Agent 自主完成"学习-设计-实验-分析"研究闭环的框架，首次在数据策划、网络架构搜索、强化学习算法三个 AI 核心组件上同时实现 AI 驱动发现，向"AI 加速 AI"范式迈出实质性一步。
🔧 **技术亮点**：
- 认知库（Cognition Base）：将人类研究先验知识注入进化迭代，避免 Agent 盲目搜索
- 专用分析器（Analyzer）：将复杂实验结果蒸馏为可复用洞察，为下一轮进化提供结构化信号
- 跨领域迁移验证：框架在数学和生物医学领域均展示了初步迁移能力
📊 **实验结果**：发现 105 个 SOTA 线性注意力架构（最优超 DeltaNet +0.97 分）；预训练数据策划平均提升 +3.96 分（MMLU 提升 >18 分）；RL 算法发现超 GRPO：AMC32 +12.5 分，AIME24 +11.67 分，OlympiadBench +5.04 分
🔄 **自进化类型**：自主探索 / 元学习 / 数据飞轮

📄 **【RLVR 训练的时序调度：何时学习与在哪里学习同等重要】**（Not only where, But when: Temporal Scheduling for RLVR）
🔗 https://arxiv.org/abs/2605.25381
💡 **核心贡献**：在可验证奖励强化学习（RLVR）中引入"时序调度"维度——训练初期聚焦特定策略行为的目标 token，逐步过渡至通用优化，从而缓解策略熵坍塌、提升学习稳定性，提供一种无需改变奖励函数即可改善 LLM 自我进化训练的正交优化手段。
🔧 **技术亮点**：
- 时序调度信用分配：credit allocation 标准在训练过程中动态变化，而非静态广播全局标量奖励
- 轨迹百分位区分策略行为：用简洁的百分位统计区分轨迹多样行为类型，无需复杂标注
- 策略熵健康分析：揭示标准 RLVR 同时优化异构行为时的熵坍塌机制，时序调度保持更健康的熵演化曲线
📊 **实验结果**：数学推理与通用推理 benchmark 上一致性提升，训练动态更稳定（详细数据见原文）
🔄 **自进化类型**：奖励驱动 / 强化学习训练优化

## 🚀 今日洞察

当前 Agent 自进化研究正在从**单次任务优化**转向**持续闭环进化**——EvolveR、SCALE、MUSE-Autoskill 均构建了完整的"交互→反思→更新→再部署"生命周期，而非孤立的单次微调。**经验库与技能库正成为 Agent 长期记忆的核心载体**，如何在动态维护中避免遗忘与噪声积累，是当前最核心的工程挑战。此外，RLVR 时序调度和 ASI-Evolve 都指向同一前沿问题：**奖励信号的质量与调度策略比奖励数量更决定自进化的上限**，未来的突破口可能在于更精细的过程级奖励建模与异构行为的解耦训练。
