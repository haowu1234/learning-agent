### 1️⃣

📄 **[TheraAgent：用于精准综合治疗规划的自我进化治疗 Agent]**（TheraAgent: Self-Improving Therapeutic Agent for Precise and Comprehensive Treatment Planning）

🔗 https://arxiv.org/abs/2605.05963

💡 **核心贡献**
本文提出 TheraAgent，一个将一次性生成替换为迭代"生成-评判-精炼"（generate-judge-refine）管道的 Agentic 框架，使治疗方案从粗糙草稿逐步演化为精准、完整、更安全的临床规范。为支撑关键的"评判"环节，研究团队设计了专用模块 TheraJudge，将其嵌入推理循环以强制执行临床标准。

🔧 **技术亮点**
- 迭代 generate-judge-refine 三阶段闭环：每轮精炼均由 TheraJudge 进行临床合规评估，驱动模型自我修正
- TheraJudge 作为轻量领域评判器集成于推理时推断（inference-loop）而非训练时，实现零额外训练成本的自进化
- 自进化机制与人类专家的迭代修订过程对齐，通过多轮反思将"粗稿"转化为"精稿"

📊 **实验结果**
- 在 HealthBench 上达到 SOTA，Accuracy 与 Completeness 指标领先
- 专家评估中 86% 的胜率（vs. 医生），在 Targeting 和 Harm Control 方面显著优于对比基线
- ACL 2026 录用

🔄 **自进化类型**：自我反思 / 生成-评判-精炼闭环

### 2️⃣

📄 **[SPARK：基于知识图谱非对称奖励的自我博弈]**（SPARK: Self-Play with Asymmetric Reward from Knowledge Graphs）

🔗 https://arxiv.org/abs/2605.05546

💡 **核心贡献**
SPARK 将知识图谱（KG）引入自我博弈强化学习范式，自动从多文档科学文献中构建统一知识图谱，以 KG 路径作为可验证问题的结构来源，解决了科学文献领域难以获取显式关系和可靠奖励信号的核心痛点。同一个小型视觉语言模型交替担任 Proposer（出题者）和 Solver（解题者），通过信息不对称博弈实现自我提升。

🔧 **技术亮点**
- 从多模态多文档中自动构建统一 KG，KG 路径成为结构化"课程生成器"
- Proposer/Solver 双角色信息不对称设计，KG 的结构事实为奖励计算提供可验证基础
- 单一 sVLM 在 Proposer/Solver 角色间交替，可自然扩展至在线持续适应

📊 **实验结果**
- 在公开 benchmark 和自建跨文档多跳 QA 数据集上，SPARK 持续优于基于平坦语料库的自我博弈基线
- 随 hop 数增加性能差距扩大，证明 KG 结构对多跳关系推理的贡献

🔄 **自进化类型**：自我博弈 / 结构化课程生成 / 奖励驱动

### 3️⃣

📄 **[Escher-Loop：基于闭环自指优化的相互进化框架]**（Escher-Loop: Mutual Evolution by Closed-Loop Self-Referential Optimization）

🔗 https://arxiv.org/abs/2604.23472

💡 **核心贡献**
Escher-Loop 提出完全闭环的相互进化框架，核心在于两类 Agent 群体的协同进化：Task Agent（解决具体问题）与 Optimizer Agent（递归精炼 Task Agent 及其自身）。通过动态基准机制将新生成的 Task Agent 实验分数直接用作 Optimizer Agent 的相对胜负信号，实现无额外开销的自指导进化。

🔧 **技术亮点**
- Task Agent 群体和 Optimizer Agent 群体双向协同进化，Optimizer 通过分析历史成败不断提升自身优化策略
- 动态基准机制：将 Task Agent 的涌现分数作为评估 Optimizer 的内生信号，闭环无外部监督
- 相互进化机制突破了静态基线的性能天花板，在后期阶段持续提升

📊 **实验结果**
- 在数学优化问题上，Escher-Loop 在所有评测任务中达到最高绝对峰值性能（相同计算量下）
- 实验观察到 Optimizer Agent 动态调整策略以匹配高性能 Task Agent 的需求，解释了系统持续改进的机制

🔄 **自进化类型**：自我博弈 / 元学习 / 持续进化 / 自指优化

### 4️⃣

📄 **[ANCORA：通过流形锚定自我博弈学习提问，用于可验证推理]**（ANCORA: Learning to Question via Manifold-Anchored Self-Play for Verifiable Reasoning）

🔗 https://arxiv.org/abs/2604.27644

💡 **核心贡献**
ANCORA 提出开放式课程自我博弈新范式：统一策略同时学习"提问"（生成可验证问题）和"解答"，并将验证器反馈转化为自我改进信号，完全无需人工标注解答。通过流形锚定迭代自蒸馏（iterative self-distilled SFT）与 UCB 引导的课程 DAG，有效防止 Proposer 崩溃。

🔧 **技术亮点**
- 双层 group-relative 更新将 Proposer 优势（跨规格）与 Solver 优势（跨解答尝试）耦合于同一 MLRL 目标
- 迭代自蒸馏 SFT：每轮 RL 前先将基础模型投影到有效输出流形，解决稀疏验证器反馈导致的崩溃问题
- UCB 引导课程 DAG：在自组合下可证明扩展问题集，实现开放式难度增长

📊 **实验结果**
- Lean4 形式化定理证明：从 26.6%（SFT 基线）提升至 81.5%（TTT 零样本），超过 PSV 自我博弈 15.8 个百分点
- 迁移实验：训练集种子迁移至 MBPP 36.2% / HumanEval 17.2% pass@1

🔄 **自进化类型**：自我博弈 / 开放式课程学习 / 自我蒸馏

### 5️⃣

📄 **[StraTA：通过战略轨迹抽象激励 Agentic 强化学习]**（StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction）

🔗 https://arxiv.org/abs/2605.06642

💡 **核心贡献**
StraTA 在 Agentic RL 中引入显式轨迹级策略（trajectory-level strategy），使模型先从初始任务状态采样紧凑策略，再基于策略执行后续动作，并通过分层 GRPO 联合训练策略生成与动作执行，辅以多样策略展开和关键自判断机制，克服了现有 Agentic RL 纯反应式、长时信度分配困难的缺陷。

🔧 **技术亮点**
- 显式策略采样层：在行动之前生成紧凑策略，赋予 Agent 前瞻性自我规划能力
- 分层 GRPO 式展开设计：将策略生成和动作执行的优化统一于同一框架，互相监督
- 多样策略展开（diverse strategy rollout）+ 关键自判断（critical self-judgment）防止策略同质化与过早收敛

📊 **实验结果**
- ALFWorld：93.1% 成功率；WebShop：84.2% 成功率
- SciWorld：63.5% 总分，超越主流闭源前沿模型
- 样本效率与最终性能双优于强基线

🔄 **自进化类型**：奖励驱动 / 自我规划 / Agentic 持续学习

## 🚀 今日洞察

当前 Agent 自进化研究呈现三条清晰主线：**验证器增强的自我博弈**（VHG、ANCORA、SPARK）正成为主流——通过引入独立验证器或结构化知识图谱解决奖励 hacking 和问题有效性问题；**闭环相互进化**（Escher-Loop、TPGO）探索 Task Agent 与 Optimizer Agent 协同进化的元学习路径，从"自己优化自己"升级到"系统优化系统"；**战略层次化 Agentic RL**（StraTA）则试图弥合反应式 RL 与长时规划之间的鸿沟。核心挑战集中在两点：如何在开放式任务中防止 Proposer 崩溃（稀疏奖励下），以及如何将自进化机制从封闭可验证域（数学/代码/定理）扩展至现实世界非结构化任务。
