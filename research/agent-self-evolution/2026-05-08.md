📄 **无需验证器的 Agent 逐轮信用分配：自诱导结果势函数**（Self-Induced Outcome Potential: Turn-Level Credit Assignment for Agents without Verifiers）
🔗 https://arxiv.org/abs/2605.04984
💡 核心贡献：提出 SIOP 框架，通过将最终答案语义聚类为潜在"结果状态"，无需人工标注或任务特定验证器，即可为长链 Agent 的中间行动步骤提供稠密的过程奖励信号；突破了传统 GRPO 只在轨迹末端分配优势的局限。
🔧 技术亮点：
  - 对多轮 rollout 的最终答案做语义聚类，构建可靠性感知的结果分布作为潜在奖励锚点
  - 对每个中间 turn 计算其推进"可靠结果状态"后验概率的增量，形成基于势函数的奖励整形
  - 完全标签无关（label-free），兼容无监督搜索增强 Agent，在 7 个推理基准上优于 GRPO
📊 实验结果：在 7 个搜索增强 Agent 推理 benchmark 上超越无验证器 outcome-level 基线，且接近有 gold 答案监督的 Oracle 上界
🔄 自进化类型：**奖励驱动 / 过程奖励自生成**

📄 **基于偏好的自蒸馏：奖励正则化超越 KL 匹配**（Preference-Based Self-Distillation: Beyond KL Matching via Reward Regularization）
🔗 https://arxiv.org/abs/2605.05040
💡 核心贡献：提出 PBSD 框架，将 on-policy 自蒸馏从简单的 KL 散度匹配重构为奖励正则化优化问题，理论证明最优目标策略优于原始教师策略，解决了同模型自蒸馏探索多样性不足与训练不稳定的问题。
🔧 技术亮点：
  - 推导奖励正则化目标的解析最优解，得到奖励重加权的教师分布（provably superior to teacher）
  - 通过优化教师-学生样本间的偏好差距（preference gap）替代硬性 KL 匹配，保持 on-policy 采样
  - 给出自蒸馏何时优于外部教师的统计理论条件（formal bounds）
📊 实验结果：在数学推理（MATH）和工具使用多个模型规模上，PBSD 在所有对比基线中平均性能最强，训练稳定性显著优于先前自蒸馏方法
🔄 自进化类型：**自我蒸馏 / 无监督自我提升**

📄 **多轮 Agentic RL 的自适应熵调制**（AEM: Adaptive Entropy Modulation for Multi-Turn Agentic Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.00425
💡 核心贡献：提出 AEM，一种无需额外监督的信用分配方法，通过自适应调制 RL 训练过程中的熵动态，改善 Agent 在长链多轮交互中探索与利用的平衡，实现对稀疏奖励环境的更高效自进化。
🔧 技术亮点：
  - 将熵分析从 token 级提升至 response 级，与 Agent 的有效行动粒度对齐，减少 token 采样噪声干扰
  - 揭示自然梯度更新下熵漂移由「采样优势 × 相对惊讶度」共同控制的数学规律
  - 基于正负样本动态平衡推导出响应级不确定性代理，驱动从探索到利用的自然过渡
📊 实验结果：在 ALFWorld、WebShop、SWE-bench-Verified 上（1.5B~32B 模型），AEM 持续提升强 RL 基线，在 SWE-bench SOTA 训练框架上额外增益 +1.4%
🔄 自进化类型：**奖励驱动 / 持续学习**

📄 **滚动通过率控制：让二元奖励 RL 驶向最信息丰富区间**（Rollout Pass-Rate Control: Steering Binary-Reward RL Toward Its Most Informative Regime）
🔗 https://arxiv.org/abs/2605.05112
💡 核心贡献：系统证明 50% rollout 通过率是二元奖励 RL 的最优信息工作点，并提出 Prefix Sampling（PS）策略，通过重放轨迹前缀主动将偏斜 rollout 群体向该最优点靠拢，大幅提升 Agentic RL 训练效率。
🔧 技术亮点：
  - 从奖励熵、GRPO 优势能量、成功/失败对比结构四个维度理论证明 50% 通过率是信息最大化点
  - Prefix Sampling：成功前缀作为"起跑优势"用于失败率高的群体；失败前缀作为"负重"用于成功率高的群体
  - 在有状态 Agent 环境中通过轨迹重放重建前缀状态，仅优化当前策略生成的续写片段
📊 实验结果：在 SWE-bench Agentic RL 上 Qwen3-14B 端到端加速 2.01×，32B 加速 1.55×；14B 峰值 SWE-bench Verified 从 0.273 升至 0.295
🔄 自进化类型：**奖励驱动 / 数据飞轮**

📄 **认知启发的记忆自进化：学会如何记忆与记什么**（Learning How and What to Memorize: Cognition-Inspired Two-Stage Optimization for Evolving Memory）
🔗 https://arxiv.org/abs/2605.00702
💡 核心贡献：提出 MemCoE 框架，借鉴前额叶-海马体功能分工，将长期记忆进化分解为「如何组织记忆（全局 Guideline 归纳）」和「更新什么信息（策略优化）」两阶段，解决 LLM Agent 个性化记忆在长交互中持续退化的问题。
🔧 技术亮点：
  - Stage 1：Memory Guideline Induction —— 将对比反馈解释为文本梯度，优化全局记忆组织准则
  - Stage 2：Guideline-Aligned Memory Policy Optimization —— 以归纳准则定义结构化过程奖励，执行多轮 RL 学习记忆演化策略
  - 支持从稀疏结果奖励到密集过程奖励的自动转化，提升长时程优化稳定性
📊 实验结果：在 3 个个性化记忆 benchmark（显式/隐式偏好，不同规模与噪声）上一致优于强基线，展示出良好的鲁棒性与迁移性
🔄 自进化类型：**持续学习 / 记忆自进化**

## 🚀 今日洞察

当前 Agent 自进化研究正在从粗粒度的终态奖励转向**过程级别的自主信号生成**：无论是 SIOP 利用结果语义聚类免标注地生成中间奖励、AEM 用熵动态替代外部过程监督，还是 MemCoE 从文本对比反馈中蒸馏结构化过程奖励，核心趋势都是**让模型自己告诉自己"哪一步是关键"**。与此同时，训练效率成为新前沿：Prefix Sampling（PS）和 PBSD 都在解决同一个问题——如何让每一次采样都落在信息密度最高的区间，避免奖励信号的稀疏浪费。核心挑战在于：当 Agent 既是评估者又是被评估对象时，如何防止自奖励的系统性偏差与演化方向的"误漂移"（misevolution），这一问题在更长时间尺度的持续学习场景中将愈发紧迫。
