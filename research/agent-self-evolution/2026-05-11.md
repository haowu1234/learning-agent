📄 **【Mem²Evolve】走向自进化 Agent：协同进化的能力扩展与经验蒸馏**（Mem²Evolve: Towards Self-Evolving Agents via Co-Evolutionary Capability Expansion and Experience Distillation）
🔗 https://arxiv.org/abs/2604.10923
💡 **核心贡献**：提出"经验-资产协同进化"新范式，将过去割裂的"积累经验"与"动态创建工具/专家子代理"统一为互馈闭环。通过 Experience Memory 指导资产创建、Asset Memory 沉淀新经验，实现能力空间持续扩张与稳定进化。
🔧 **技术亮点**：
- 双记忆机制：Experience Memory（失败模式/成功策略）× Asset Memory（动态生成的工具/专家代理）形成协同飞轮
- 以经验指导资产生成，避免"无监督从头生成"导致的不稳定性
- 以新资产带来的新任务经验反哺记忆，打破静态工具集上限
📊 **实验结果**：跨 6 类任务、8 个基准测试，相比标准 LLM 提升 18.53%、相比纯经验进化提升 11.80%、相比纯资产创建提升 6.46%；ACL 2026 Main 录用
🔄 **自进化类型**：数据飞轮 + 持续学习

📄 **【AEL】Agent 进化学习：应对开放式环境的双时间尺度框架**（AEL: Agent Evolving Learning for Open-Ended Environments）
🔗 https://arxiv.org/abs/2604.21725
💡 **核心贡献**：揭示 Agent 自我提升的核心瓶颈不在于"记什么"，而在于"如何用所记之物"，并通过双时间尺度（快/慢）框架分别处理检索策略选择与失败模式反思。
🔧 **技术亮点**：
- 快时间尺度：Thompson Sampling Bandit 在线学习最优记忆检索策略
- 慢时间尺度：LLM 驱动的反思诊断失败模式并注入因果洞察到决策提示
- "越少越好"消融实验揭示：内存+反思本身带来58%累积提升，叠加更多机制反而退化
📊 **实验结果**：顺序投资组合基准（10只股票，208 episodes），Sharpe 比率 2.13±0.47，超越5种已发表自我改进方法及全部非LLM基准
🔄 **自进化类型**：自我反思 + 持续学习

📄 **【Autogenesis/AGP】自进化 Agent 协议：资源基底 + 闭环进化双层架构**（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.15034
💡 **核心贡献**：针对现有 Agent 协议（A2A/MCP）在生命周期管理、版本追踪和进化安全更新方面的不足，提出 Autogenesis Protocol（AGP）——将"进化什么"与"如何进化"解耦的自进化协议标准。
🔧 **技术亮点**：
- 资源基底协议层（RSPL）：将 Prompt、Agent、工具、环境、记忆统一建模为带状态和版本接口的协议注册资源
- 自进化协议层（SEPL）：规范"提议-评估-提交"的闭环算子接口，支持可审计谱系与回滚
- 基于 AGP 构建的 AGS 系统可在执行中动态实例化、检索并精炼协议注册资源
📊 **实验结果**：在多个需要长期规划与工具使用的 Benchmark 上持续优于强基线；代码开源
🔄 **自进化类型**：持续学习 + 自我反思（协议级闭环优化）

📄 **【Ctx2Skill】从上下文到技能：语言模型能否在上下文中技巧性地学习？**（From Context to Skills: Can Language Models Learn from Context Skillfully?）
🔗 https://arxiv.org/abs/2604.27660
💡 **核心贡献**：提出 Ctx2Skill，一个无需人工标注和外部反馈、可自主发现-精炼-筛选上下文专用技能的自进化框架，解决超出参数知识范围的复杂上下文理解问题。
🔧 **技术亮点**：
- 多 Agent 自博弈循环：Challenger（生成探测任务+评分标准）× Reasoner（在进化技能库引导下求解）× Judge（二元反馈）
- Proposer/Generator 代理分析失败案例，自动为双方合成定向技能更新
- 跨时回放（Cross-time Replay）机制防止对抗性崩塌（极端任务生成 + 过度特化）
📊 **实验结果**：在 CL-bench 四类上下文学习任务上，对各骨干模型均持续提升求解率
🔄 **自进化类型**：自我博弈 + 自我反思

📄 **【RetroAgent】从求解到进化：回顾性双内在反馈框架**（RetroAgent: From Solving to Evolving via Retrospective Dual Intrinsic Feedback）
🔗 https://arxiv.org/abs/2503.17219 *(arXiv March 2026)*
💡 **核心贡献**：突破标准 RL 只优化外在奖励、经验隐式困于参数中的局限，引入双内在奖励（任务好奇心 + 自我反思一致性）驱动 Agent 在持续探索中显式积累可复用知识。
🔧 **技术亮点**：
- 外在奖励 × 双内在奖励（探索好奇心 + 回顾一致性）三路联合优化
- 显式记忆库将经验从参数"解放"出来，供后续任务检索与复用
- 在线 RL 框架，无需离线数据集，适应动态交互环境
🔄 **自进化类型**：奖励驱动 + 自我反思

## 🚀 今日洞察

**趋势一：记忆驱动的协同进化成为主流范式。** 今日多篇高质量论文（Mem²Evolve、AEL、Autogenesis）殊途同归，均指向"经验记忆 × 行为资产的协同飞轮"架构——单独积累经验或单独创建工具已被证明存在能力天花板，联合进化才是破局关键。

**趋势二：自博弈与内在奖励弥补外部反馈稀缺。** Ctx2Skill 的多 Agent 自博弈循环和 RetroAgent 的双内在奖励，都在回答同一问题：当真实反馈昂贵甚至不可得时，如何构造自驱动的学习信号？这是无监督/弱监督自进化的核心挑战。

**核心挑战：进化稳定性 vs. 探索多样性。** AEL 消融实验中"越多机制越差"的反直觉结论，以及 Ctx2Skill 专门引入防崩塌机制，共同揭示自进化研究的深层矛盾：过强的进化压力极易导致收敛到局部最优甚至分布崩塌，如何在稳定性与持续探索之间寻得均衡，仍是当前最亟待解决的开放问题。
