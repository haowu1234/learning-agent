📄 **自进化 Agent 会遗忘吗？终身 LLM Agent 适应中的能力退化与保持**（Do Self-Evolving Agents Forget? Capability Degradation and Preservation in Lifelong LLM Agent Adaptation）
🔗 https://arxiv.org/abs/2605.09315
💡 核心贡献：
本文揭示了 LLM Agent 自进化过程中一个被忽视的关键问题——"能力侵蚀"：当 Agent 持续适应新任务分布时，其已有能力会系统性退化，且这一现象跨越工作流进化、技能积累、模型微调、记忆管理四个维度普遍存在。提出了 Capability-Preserving Evolution（CPE）原则，在持续适应中通过显式约束来防止破坏性能力漂移。
🔧 技术亮点：
- 首次系统识别并命名"能力侵蚀（capability erosion under self-evolution）"现象，涵盖 workflow / skill / model / memory 四个进化通道
- 提出 CPE 通用稳定化原则，约束进化过程中的破坏性漂移，兼顾新任务适应与旧能力保持
- 在 workflow 进化维度，CPE 将 GPT-5.1 优化下简单任务保留率从 41.8% 提升至 52.8%，同时复杂任务适应性同步提升
📊 实验结果：跨四个进化维度验证 CPE 一致改善能力稳定性；简单任务保留率 +11% (41.8%→52.8%)，复杂任务适应性同步提升
🔄 自进化类型：**持续学习 / 灾难性遗忘防护**

📄 **Skill-R1：通过强化学习实现 Agent 技能进化**（Skill-R1: Agent Skill Evolution via Reinforcement Learning）
🔗 https://arxiv.org/abs/2605.09359
💡 核心贡献：
提出 Skill-R1 框架，用强化学习训练轻量级技能生成器，代替直接微调任务 LLM，通过可验证奖励实现实例级递归技能优化。核心创新在于双层群体相对策略优化（bi-level GRPO），同时捕捉单代内部与跨代际的改进信号，使技能持续向更优版本演化。
🔧 技术亮点：
- 训练轻量 skill generator（而非任务 LLM），保持对黑盒模型（含闭源）的兼容性，大幅降低适配成本
- 双层 GRPO：intra-generation 对比同代 rollout、inter-generation 奖励跨代行为改进，确保技能定向进化而非一次性自我修正
- 多轮生成循环：当前技能生成 rollout → 验证结果回馈 → 生成下一版技能，形成闭环数据飞轮
📊 实验结果：在含可验证奖励的多个基准上持续超越无技能基线和标准 GRPO，多步骤复杂任务提升尤为显著
🔄 自进化类型：**奖励驱动 / 数据飞轮 / 技能进化**

📄 **SIPDO：通过合成数据反馈实现闭环提示词优化**（SIPDO: Closed-Loop Prompt Optimization via Synthetic Data Feedback）
🔗 https://arxiv.org/abs/2505.19514
💡 核心贡献：
提出 SIPDO（Self-Improving Prompts through Data-Augmented Optimization）闭环框架，将合成数据生成融入提示词优化过程。合成数据生成器持续暴露当前提示词的弱点，驱动优化器增量式修正，形成无需外部监督的自我改进闭环。
🔧 技术亮点：
- 将合成数据生成器与提示词优化器深度耦合，生成器专门构造揭示当前提示薄弱点的样本，驱动精准修正
- 纯自驱动：不依赖外部标注或新任务，仅靠合成反馈信号即可持续提升提示词性能
- 适用于静态数据集之外的动态迭代改进场景，突破现有方法对固定分布的依赖
📊 实验结果：在问答与推理基准上优于标准提示词调优方法，验证合成数据反馈循环的有效性
🔄 自进化类型：**自我修正 / 数据飞轮 / 弱监督自我提升**

📄 **Swarm Skills：可移植自进化多智能体系统规范**（Swarm Skills: A Portable, Self-Evolving Multi-Agent System Specification for Coordination Engineering）
🔗 https://arxiv.org/abs/2605.11039（May 15, 2026）
💡 核心贡献：
面向多智能体协调工程，提出 Swarm Skills 规范，将技能抽象为可移植的结构化单元，支持跨 Agent 迁移与自进化。将 AI 工程范式从单智能体的提示工程推进至多智能体协调工程，技能可在多 Agent 系统内自动积累、共享与演化。
🔧 技术亮点：
- 技能可移植性设计：技能以标准化格式编写，支持跨模型、跨 Agent 无缝迁移，打破技能孤岛
- 自进化协调机制：技能库随任务执行自动更新，形成集体智能数据飞轮
- 协调工程范式：引入"Coordination Engineering"新视角，将多 Agent 协作本身作为可优化目标
📊 实验结果：展示在云技术支持等企业场景中，相比固定工作流的 Agent 显著提升任务完成率
🔄 自进化类型：**数据飞轮 / 多 Agent 自进化 / 技能积累**

📄 **Autogenesis：一种自进化 Agent 协议**（Autogenesis: A Self-Evolving Agent Protocol）
🔗 https://arxiv.org/abs/2604.12xxx（May 19, 2026 v2 更新）
💡 核心贡献：
提出 Autogenesis 协议，使 LLM Agent 系统能够自主演化自身的工具调用接口、子 Agent 配置和任务规划策略，以应对复杂长视野任务。系统在执行过程中持续生成新的子 Agent 并复用已验证的执行单元，实现增量式自生长。
🔧 技术亮点：
- 自主生成并管理子 Agent：运行时动态创建专用子 Agent，完成后沉淀为可复用模块
- 可执行子 Agent 积累机制：历史成功的子 Agent 进入复用库，形成滚雪球式能力扩增
- 协议层自进化：不仅优化单次任务，还能修改自身调度协议以适应新挑战
🔄 自进化类型：**自我博弈 / 持续学习 / Agent 自生成**

## 🚀 今日洞察

当前 Agent 自进化研究正沿两条主线并行推进：**能力稳健性**与**技能驱动进化**。一方面，"Do Self-Evolving Agents Forget?" 首次系统量化了持续自进化中的灾难性遗忘，将其提升为与效果提升同等重要的核心挑战；另一方面，Skill-R1 和 Swarm Skills 展示了将技能抽象为可独立优化、可移植、可复用单元的技术路线，以更低成本实现定向进化。核心挑战正在从"如何让 Agent 自我改进"转向"如何让 Agent 在改进的同时不丢失已有能力"——即自进化的稳定性与可控性，这将是未来 6-12 个月的关键战场。
