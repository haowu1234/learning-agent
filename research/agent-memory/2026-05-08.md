📄 **[自主LLM智能体的记忆体系：机制、评估与前沿]**（Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers）
🔗 https://arxiv.org/abs/2603.07670
💡 核心贡献：
本综述系统梳理了 2022-2026 年间 LLM Agent 记忆设计的全貌，将记忆形式化为 write-manage-read 闭环，并提出跨越时间范围、表征底层和控制策略三个维度的分类体系。覆盖了情境压缩、RAG 存储、反思式自改进、分层虚拟上下文、策略学习管理五大机制族群。

🔧 技术亮点：
- 三维分类体系：时间范围（短期/长期）× 表征底层（向量/图/结构化数据）× 控制策略（显式/隐式）
- 评估范式从静态召回基准转向多会话 Agentic 测试，揭示现有系统在持续整合与因果检索上的系统性缺口
- 覆盖个人助手、编程 Agent、开放世界游戏、科学推理、多 Agent 协作等 5 类应用场景，讨论写路径过滤、矛盾处理与隐私治理

📊 实验结果：分析了 4 个最新基准（multi-session agentic tests），揭示现有记忆系统在持续整合和因果定向检索方面存在顽固短板

🧩 技术分类：
- Memory维度：情景记忆 / 语义记忆 / 工作记忆 / 外部存储 / 记忆检索（综合）
- Context维度：上下文压缩 / 上下文管理

🔗 Memory ↔ Context 关联：将上下文窗口内的压缩（context-resident compression）作为记忆的最短时间域，揭示了上下文与长期记忆在连续统上的统一设计视角。

📄 **[A-MEM：面向LLM Agent的主动式记忆系统]**（A-MEM: Agentic Memory for LLM Agents）
🔗 https://arxiv.org/abs/2502.12110
💡 核心贡献：
提出一种受 Zettelkasten 方法启发的动态自组织记忆系统，新记忆写入时自动生成多属性注释（上下文描述、关键词、标签），并通过语义链接与历史记忆构建互联知识网络。记忆会随新输入持续演化——新记忆触发旧记忆的上下文属性更新，实现"记忆网络的自我精炼"。

🔧 技术亮点：
- Agent 驱动的动态索引与链接：类比人类笔记卡片系统，记忆间通过有意义的相似度建立双向链接
- 记忆演化机制：新记忆不仅被添加，还触发对已有历史记忆上下文表示的更新，避免记忆静态化
- 在 6 个基础模型上评估，相比现有 SOTA 基线取得显著提升（NeurIPS 2025 录用）

📊 实验结果：在 6 个基础模型上优于已有 SOTA 基线，代码开源于 GitHub (WujiangXu/A-mem)

🧩 技术分类：
- Memory维度：情景记忆 / 语义记忆 / 外部存储 / 记忆检索

🔗 Memory ↔ Context 关联：动态知识网络将上下文窗口内的即时历史转化为跨会话可检索的长期记忆，实现 in-context 与 external memory 的无缝接力。

📄 **[Focus：主动上下文压缩——LLM Agent的自主记忆管理]**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 核心贡献：
提出 Focus Agent，受生物黏菌（Physarum polycephalum）探索策略启发的 Agent 中心化架构，使 LLM Agent 能够自主决策"何时将关键学习固化到持久知识块，何时主动剪枝原始交互历史"，彻底告别依赖外部被动摘要的方式。

🔧 技术亮点：
- Agent 自主压缩决策：模型本身决定何时触发压缩，而非外部启发式规则
- 持久"知识块"（Knowledge Block）设计：提炼关键学习点并保存，丢弃冗余历史
- 平均每任务执行 6.0 次自主压缩，最高单任务 token 节省 57%

📊 实验结果：在 SWE-bench Lite 5 个上下文密集实例上，实现 22.7% 整体 token 压缩（14.9M→11.5M），准确率与基线持平（60% vs 60%），使用 Claude Haiku 4.5

🧩 技术分类：
- Memory维度：工作记忆 / 外部存储
- Context维度：上下文压缩 / 上下文管理

🔗 Memory ↔ Context 关联：将上下文压缩决策从外部系统移至 Agent 内部，让记忆管理成为 Agent 核心能力，实现上下文大小与记忆价值密度的自适应平衡。

📄 **[ACON：面向长时域LLM Agent的上下文压缩优化]**（ACON: Agent Context Optimization — Optimizing Context Compression for Long-horizon LLM Agents）
🔗 https://arxiv.org/abs/2510.00615
💡 核心贡献：
提出 ACON 统一框架，在自然语言空间中优化压缩指引（compression guideline），通过分析"完整上下文成功、压缩上下文失败"的对比轨迹来自动迭代改进压缩策略，并支持将大型 LLM 压缩器蒸馏到小模型以降低额外开销。

🔧 技术亮点：
- 压缩指引优化（CGO）：在自然语言空间中学习"怎样压缩才不损失任务关键信息"
- 对比轨迹驱动：用成功/失败对比分析自动识别压缩失败的根因并更新策略
- 压缩器蒸馏：将大型 LLM 压缩器蒸馏到小模型，保留 95% 以上准确率同时降低推理开销（ICML 2026 录用）

📊 实验结果：AppWorld/OfficeBench/Multi-objective QA 上减少 26-54% 峰值 token；蒸馏后小型压缩器保留 >95% 精度；小模型作为长时域 Agent 性能提升最高 46%

🧩 技术分类：
- Context维度：上下文压缩 / 上下文管理

🔗 Memory ↔ Context 关联：将上下文压缩从启发式摘要升级为策略优化问题，使长时域记忆在有限 token 预算下保持任务相关性最大化。

📄 **[推理技能记忆：更少Token，更高准确率]**（Thinking with Reasoning Skills: Fewer Tokens, More Accuracy）
🔗 https://arxiv.org/abs/2604.21764
💡 核心贡献：
将可复用的"推理技能"（reasoning skills）从大量试错探索中提炼、摘要并存储为外部记忆，在推理时通过检索相关技能引导模型规避冗余推理路径，突破"每次从零推理"的范式，显著降低 per-request token 成本。

🔧 技术亮点：
- 推理技能提炼：从 CoT 探索轨迹中抽象出可迁移技能单元并结构化存储
- 推理时技能检索：依据查询语义检索最相关技能，提供高质量推理路板
- 在编程和数学推理任务上同时降低推理 token 用量并提升整体性能（ACL 2026 Industry Track）

📊 实验结果：编程与数学推理任务上，token 消耗显著下降，性能指标同步提升（具体数值见论文）

🧩 技术分类：
- Memory维度：情景记忆 / 语义记忆 / 记忆检索
- Context维度：上下文管理 / In-Context学习

🔗 Memory ↔ Context 关联：将蒸馏出的推理经验以"外部技能库"形式存储，在 in-context 中动态注入最相关技能摘要，将外部记忆与上下文学习紧密结合。

📄 **[Tool Attention：消除MCP工具税的动态门控上下文管理]**（Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP/Tools Tax in Scalable Agentic Workflows）
🔗 https://arxiv.org/abs/2604.21816
💡 核心贡献：
针对 MCP 协议中"静态/急切 schema 注入"导致每轮 10k-60k token 工具税问题，提出 Tool Attention 中间件，将"Attention Is All You Need"从 token 自注意力泛化到工具门控注意力，按需动态加载工具 schema，大幅降低无关工具对上下文的占用。

🔧 技术亮点：
- 意图-模式重叠（ISO）评分：基于句子嵌入计算用户意图与工具 schema 的语义重叠，动态筛选工具
- 两阶段延迟 schema 加载：上下文中仅保留简洁工具摘要池，仅对 Top-K 门控工具展开完整 JSON schema
- 状态感知门控函数：结合前置条件与访问范围过滤工具候选

📊 实验结果：120 工具、6 服务器仿真基准上，每轮工具 token 减少 95%（47.3k→2.4k），有效上下文利用率从 24% 提升至 91%

🧩 技术分类：
- Context维度：上下文压缩 / 上下文管理

🔗 Memory ↔ Context 关联：通过动态过滤工具 schema，将"工具知识"由全量 eager 加载变为按需检索注入，实质上将工具描述纳入一种"外部工具记忆+按需上下文注入"的框架。

## 🧠 今日洞察

1. **记忆自治化是核心趋势**：从 A-MEM 的自组织知识网络到 Focus Agent 的自主压缩决策，研究重心正从"被动存储+检索"向"主动整合+演化"转移——Agent 不仅拥有记忆，更能管理和优化自身的记忆系统。

2. **上下文压缩进入策略优化阶段**：ACON 用对比轨迹学习压缩策略、Tool Attention 用动态门控管理工具上下文，标志着上下文管理从启发式规则走向数据驱动的策略学习，且均面向生产部署的 token 经济性。

3. **Memory 与 Context 协同设计加速成熟**：推理技能记忆（2604.21764）将长期外部技能存储与 in-context 注入深度耦合，而综述论文（2603.07670）将上下文内压缩定义为记忆时间谱系的最短端——两者共同指向一个统一结论：高效的 Agent 架构必须将记忆层与上下文层作为协同优化的整体来设计，而非独立模块。
