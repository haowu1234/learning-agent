### 论文 1

📄 **VikingMem：面向有状态 LLM 应用的记忆库管理系统**（VikingMem: A Memory Base Management System for Stateful LLM-based Applications）
🔗 https://arxiv.org/abs/2605.29640
💡 核心贡献：提出「记忆库（Memory Base）」数据管理范式，通过事件-实体二层抽象实现跨应用可泛化的长期记忆；构建 VikingMem 端到端系统，在向量引擎 VikingDB 上落地，兼顾检索效果与低延迟的互动体验。
🔧 技术亮点：
- **事件驱动提取 + 实体动态更新**：将交互流切分为事件（局部发生）并关联到实体，实体由事件增量修正，实现状态演化式记忆。
- **主题级时间轴压缩（Topic-wise Timeline）**：对同主题事件做层级摘要，时间加权召回优先返回近期记忆，自动淡化（fade）过期信息。
- **三原则设计**：选择性提取高价值记忆 / 内生 statefulness + 演化 / 跨任务泛化抽象（教育、推荐、Agent 均适用）。
📊 实验结果：在长期记忆基准上检索效果比基线最高提升 30%，同时维持交互应用所需的低延迟；已被 VLDB 2026 接收。
🧩 技术分类：**Memory 维度**：外部存储 / 记忆检索；**Context 维度**：上下文管理
🔗 Memory ↔ Context 关联：VikingMem 将长期外部存储与即时上下文检索打通，通过时间加权召回动态决定哪些记忆应填入 Agent 的当前上下文窗口。

### 论文 2

📄 **超越 RAG 的 Agent 记忆：解耦与聚合检索**（Beyond RAG for Agent Memory: Retrieval by Decoupling and Aggregation）
🔗 https://arxiv.org/abs/2602.02007
💡 核心贡献：指出标准 RAG 与 Agent 记忆的结构性失配——平铺 top-k 检索在高相关性、近似重复的交互流中会返回大量冗余上下文；提出 xMemory，以"解耦在前、聚合在后"原则构建可修订的层级记忆结构。
🔧 技术亮点：
- **四级层级记忆**：原始消息 → Segment（局部事件）→ Memory Component（解耦后的可复用事实/更新/区别特征）→ Group（稀疏-语义忠实目标下聚合的高层组）。
- **自顶向下检索**：先选互补 Group+Component 骨架，仅在读者不确定性未降低时才展开到原始 Segment/消息，节省推理 token。
- **增量维护**：随新交互到来持续更新层级结构，无需全量重建。
📊 实验结果：在 LoCoMo 和 PerLTQA 基准、多个开源/闭源 LLM 上，答案质量和推理 token 效率均有一致提升。（v4 于 2026-05-12 更新）
🧩 技术分类：**Memory 维度**：情景记忆 / 记忆检索；**Context 维度**：上下文管理
🔗 Memory ↔ Context 关联：xMemory 的自顶向下检索机制直接控制注入上下文的证据密度，将"记忆组织"与"上下文填充效率"协同优化。

### 论文 3

📄 **Focus：LLM Agent 的主动上下文压缩与自主记忆管理**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 核心贡献：提出 Focus Agent，受黏菌（Physarum polycephalum）生物探索策略启发，让 Agent 自主决策何时将关键学习内容固化为持久"Knowledge"块并主动裁剪原始交互历史，解决"上下文膨胀（Context Bloat）"问题。
🔧 技术亮点：
- **Agent 内生压缩**：压缩时机由 Agent 自行触发（平均每任务 6.0 次），而非依赖外部被动汇总。
- **Knowledge 块持久化**：关键学习内容被提炼至专用持久存储块，工作记忆（原始交互历史）被截断而知识不丢失。
- **无需微调**：通过提示工程在 Claude Haiku 4.5 上实现，证明有能力的模型可以用适当工具实现自主上下文自律。
📊 实验结果：SWE-bench Lite 上（N=5 上下文密集实例）实现 22.7% token 减少（14.9M→11.5M），准确率不变（3/5=60%），单任务最高节省 57% token。
🧩 技术分类：**Memory 维度**：工作记忆 / 外部存储；**Context 维度**：上下文压缩
🔗 Memory ↔ Context 关联：Focus 将"记忆巩固"（工作记忆→长期知识块）直接映射到"上下文压缩"操作，是记忆与上下文协同设计的典型范本。

### 论文 4

📄 **ACON：长视野 LLM Agent 的上下文压缩优化框架**（ACON: Optimizing Context Compression for Long-horizon LLM Agents）
🔗 https://icml.cc/virtual/2026/poster/66270（ICML 2026 接收）
💡 核心贡献：提出统一框架 ACON（Agent Context Optimization），在自然语言空间对观测和历史做联合压缩优化，通过迭代失败分析精炼压缩指南，无需模型微调；并将优化后的压缩器蒸馏到小模型以降低计算开销。
🔧 技术亮点：
- **自然语言空间优化**：基于 Agent 失败案例迭代精炼压缩准则，避免脆弱启发式或参数更新。
- **观测 + 历史联合压缩**：同时处理环境观测和交互历史两路信息，而非只压缩其中一路。
- **压缩器蒸馏**：将优化后的大模型压缩策略蒸馏进小型语言模型，使小 LM 也能胜任长视野 Agent 任务。
📊 实验结果：AppWorld、OfficeBench、Multi-objective QA 上 peak token 用量降低 26–54%，任务性能不变；小模型通过缓解上下文干扰，性能最高提升 46%。
🧩 技术分类：**Memory 维度**：工作记忆；**Context 维度**：上下文压缩 / 上下文管理
🔗 Memory ↔ Context 关联：ACON 通过自然语言优化将"记忆内容的价值评估"转化为"上下文分配决策"，实现记忆选择性与上下文效率的一体化设计。

### 论文 5

📄 **Meta-Soft：基于可组合元 Token 的上下文保留 KV Cache 压缩**（Meta-Soft: Leveraging Composable Meta-Tokens for Context-Preserving KV Cache Compression）
🔗 https://arxiv.org/abs/2605.22337
💡 核心贡献：提出 Meta-Soft 动态 KV Cache 压缩框架，用可学习正交基矩阵 + Gumbel-Softmax 选择器动态合成输入自适应的 Soft Tokens；引入注意力流集成机制，将被驱逐 token 的语义重新分配到保留 token，避免不可逆信息丢失。
🔧 技术亮点：
- **动态 Soft Token 合成**：从元库（meta-library）的正交基动态合成任务自适应查询，克服静态 Soft Token 无法随输入变化的缺陷。
- **注意力流语义迁移**：被删除 token 的信息不直接丢弃，而是通过注意力流重新分配给保留 token，保持上下文连贯性。
- **无上下文断裂**：解决现有 KV Cache 压缩方法因永久删除而产生语义跳跃的痛点。
📊 实验结果：在多个数据集上超越现有 SOTA KV Cache 驱逐方法（具体数值见原文）。
🧩 技术分类：**Memory 维度**：工作记忆；**Context 维度**：上下文压缩 / 长窗口扩展
🔗 Memory ↔ Context 关联：KV Cache 本质是 LLM 的短期工作记忆，Meta-Soft 对其动态压缩与语义保全，直接关系到 Agent 在长上下文任务中的记忆保真度。

### 论文 6

📄 **Gated DeltaNet-2：线性注意力中擦除与写入的解耦**（Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention）
🔗 https://arxiv.org/abs/2605.22791
💡 核心贡献：在线性注意力（固定大小循环状态即压缩记忆）架构中，将"擦除"与"写入"由单一标量门扩展为独立的通道级门控（erase gate b_t + write gate w_t），精准控制记忆更新，不扰乱已有关联。
🔧 技术亮点：
- **通道级解耦门控**：erase gate 控制旧内容擦除程度，write gate 控制新内容写入强度，二者相互独立，大幅提升记忆编辑精度。
- **统一泛化框架**：Gated DeltaNet 和 KDA（Kimi Delta Attention）均为本模型在特殊参数下的退化形式，理论上更通用。
- **高效训练算法**：推导出考虑通道级 decay 的分块 WY 算法和门感知反向传播，保留线性训练效率。
📊 实验结果：1.3B 参数 / 100B token 训练，在语言建模、常识推理、检索任务中优于 Mamba-2/3、Gated DeltaNet、KDA；长上下文 RULER needle-in-a-haystack 多键检索提升最显著。代码已开源（NVlabs）。
🧩 技术分类：**Memory 维度**：工作记忆（循环压缩状态）；**Context 维度**：长窗口扩展 / 上下文管理
🔗 Memory ↔ Context 关联：线性注意力的固定大小循环状态即是一种极度压缩的记忆表示，Gated DeltaNet-2 改进该状态的读写机制，等价于改进了模型在长上下文下的记忆精确管理能力。

## 🧠 今日洞察

1. **记忆系统工程化成熟**：VikingMem（VLDB'26 接收）和 xMemory 的出现标志着 Agent 记忆从学术原型走向工程落地——前者基于向量引擎构建企业级内存管理系统，后者提出可迭代更新的层级检索结构，两者均面向真实长期交互场景而非 toy benchmark。

2. **上下文压缩成为核心战场**：Focus（主动自压缩）、ACON（自然语言空间优化 + 蒸馏）、Meta-Soft（动态 Soft Token + 语义迁移）、LaProx（输出感知 KV 驱逐）同期涌现，说明"上下文膨胀"已是 Agent 落地的首要工程瓶颈，研究社区正在从启发式驱逐转向端到端可学习压缩策略。

3. **Memory ↔ Context 协同设计趋势凸显**：本期 6 篇论文无一孤立讨论记忆或上下文——从 VikingMem 的时间加权召回决定上下文填充，到 Focus 的记忆巩固即是上下文压缩，再到 Gated DeltaNet-2 将循环状态视为压缩记忆并优化其读写门控，越来越多的工作将"记忆组织逻辑"与"上下文分配机制"作为同一问题的两个面向统一建模，Memory-Context 协同设计正成为领域共识。
