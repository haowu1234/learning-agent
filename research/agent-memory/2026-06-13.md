### 1

📄 **MemRefine：LLM 引导的长期 Agent 记忆压缩框架**（MemRefine: LLM-Guided Compression for Long-Term Agent Memory）
🔗 https://arxiv.org/abs/2606.13177
💡 核心贡献：提出在固定存储预算约束下，用 LLM 判断器对记忆条目做"删除/合并/保留"三元决策，而非依赖表面语义相似度来管理记忆；解决了长期 Agent 交互中记忆无限膨胀、检索质量下降的问题。
🔧 技术亮点：
- 相似度仅用于召回候选对，实际决策交由 LLM judge 基于**事实内容**判断（避免语义相似≠事实价值的误判）
- 迭代式压缩直至满足预算，兼容任意下游记忆框架（无需重训）
- 在 tight budget 场景下显著优于基于规则的 baseline
📊 实验结果：在多个长期对话基准（LongMemEval 等）上，budgeted 设置下持续超越规则方法，且保留了下游任务性能
🧩 技术分类：Memory维度：记忆检索 / 外部存储
🔗 Memory ↔ Context 关联：通过压缩记忆库控制未来检索时注入上下文的大小，直接影响 Agent 的有效 context 利用效率

---

### 2

📄 **G-Long：图增强的高效长期对话 Agent 记忆管理**（G-Long: Graph-Enhanced Memory Management for Efficient Long-Term Dialogue Agents）
🔗 https://arxiv.org/abs/2606.13115
💡 核心贡献：用轻量 fine-tuned sLM 进行结构化三元组抽取与关联检索，配合 T5 summarizer 的跨注意力信号实现 attention-aware 重要度评分，大幅降低长期对话 Agent 的计算开销。
🔧 技术亮点：
- 引入"关注感知重要度评分"（attention-aware importance scoring），利用 T5 内在 cross-attention 分数识别显著记忆
- 图结构存储支持关联检索，避免孤立记录间的信息孤岛
- 用 sLM 替代 LLM 做三元组抽取，推理成本大幅压缩
📊 实验结果：MSC 数据集上响应质量提升 9.8%，LME 检索召回提升 40.8%，同时显著降低计算开销
🧩 技术分类：Memory维度：情景记忆 / 记忆检索
🔗 Memory ↔ Context 关联：图结构记忆检索直接决定哪些历史事实被注入 context，从而控制上下文内容质量

---

### 3

📄 **认知驱动的多因子记忆价值模型：Agent 学会"记什么"**（Learning What to Remember: A Cognitively Grounded Multi-Factor Value Model for Agentic Memory）
🔗 https://arxiv.org/abs/2606.12945
💡 核心贡献：受认知心理学启发，提出七因子记忆价值函数 V(m)，用梯度无关优化器从下游任务目标中学习各因子权重，单一标量同时控制编码深度、遗忘风险和检索排名。
🔧 技术亮点：
- 七个可解释因子：情感强度、目标相关性、价值对齐、自/用户相关性、任务效用、可靠性、使用历史
- 区分"巩固时刻"（遗忘决策）与"查询时刻"（检索决策），两阶段需求不同→目标相关性在遗忘阶段被正确下调权重
- 全部实验跑在单 CPU 上，无需 API 调用，高度可复现
📊 实验结果：LongMemEval 盲测场景下 gold evidence 保留率 0.770（vs 均匀权重 0.657、最佳单因子 0.518、recency 0.368），所有差异 95% bootstrap CI 均显著
🧩 技术分类：Memory维度：情景记忆 / 语义记忆 / 外部存储
🔗 Memory ↔ Context 关联：记忆价值函数同时决定"深度编码入外部存储"和"检索时注入 context 的优先级"，从记忆管理侧直接优化上下文质量

---

### 4

📄 **HORMA：层级组织与导航的高效 Agent 工作记忆**（Organize then Retrieve: Hierarchical Memory Navigation for Efficient Agents）
🔗 https://arxiv.org/abs/2606.11680
💡 核心贡献：提出 HORMA，将 Agent 经验组织为类文件系统的层级结构（摘要实体→原始轨迹），并用 RL 训练的轻量导航 Agent 进行树状遍历检索，在受限 context 预算下兼顾效率与信息完整性。
🔧 技术亮点：
- 两阶段：结构化记忆构建（区分"缺信息导致的失败" vs "信息过载导致的失败"）+ RL 导航检索
- 导航模块训练用 RL 选取"最小充分上下文"，减少关键路径延迟
- 避免纯 lossy 压缩：摘要节点始终链接到原始细粒度轨迹
📊 实验结果：ALFWorld、LoCoMo、LongMemEval 上，最多仅需 baseline 22.17% token 用量即达到同等或更好性能
🧩 技术分类：Memory维度：工作记忆 / 情景记忆 / 记忆检索；Context维度：上下文管理 / 上下文压缩
🔗 Memory ↔ Context 关联：层级结构让 Agent 按需精准截取上下文片段，将工作记忆的组织方式与 context 窗口的高效利用深度耦合

---

### 5

📄 **EvoMem：补丁式记忆演化追踪，应对动态环境下的 LLM Agent**（EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments）
🔗 https://arxiv.org/abs/2606.13681
💡 核心贡献：提出 EvoArena 基准（覆盖终端/软件/社交三类动态变化场景）和 EvoMem 补丁式记忆范式，将记忆演化记录为结构化的"更新历史"，使 Agent 能够推理环境变化的演进过程。
🔧 技术亮点：
- Patch-based memory：记录记忆的"差分变化"而非覆写快照，保留完整演化轨迹
- 支持链式子任务（chain-level）推理，连续相关演化子任务准确率提升 3.7%
- 提供动态环境评测套件（EvoArena），揭示当前 Agent 在动态场景下仅 39.6% 平均准确率的短板
📊 实验结果：EvoMem 在 EvoArena 上平均提升 1.5%，GAIA 提升 6.1%，LoCoMo 提升 4.8%
🧩 技术分类：Memory维度：情景记忆 / 外部存储
🔗 Memory ↔ Context 关联：EvoMem 的 patch 历史结构化地增量注入上下文，相比全量记忆重载更节省 context 空间

---

### 6

📄 **UMG-RAG：不确定性感知多粒度混合检索**（Uncertainty-Aware Hybrid Retrieval for Long-Document RAG）
🔗 https://arxiv.org/abs/2606.13550
💡 核心贡献：将块粒度（chunk granularity）视为查询专属的可靠性估计问题，通过分布熵衡量各 expert-granularity 对的置信度，免训练地融合密集/稀疏检索器在多粒度上的结果。
🔧 技术亮点：
- 每个 expert-granularity 分数列表转为证据分布，熵越低→可靠性越高→融合权重越大
- UMGP-RAG 变体：细粒度命中定位证据位置，返回非冗余的父级 chunk 保证局部连贯性
- 插件式设计（plug-and-play），无需重训检索器或生成器
📊 实验结果：多个 QA 基准上，不确定性融合+父级提升策略改善生成质量，同时保持轻量检索流水线
🧩 技术分类：Memory维度：记忆检索 / 外部存储；Context维度：上下文管理
🔗 Memory ↔ Context 关联：多粒度检索策略直接决定注入 LLM context 的证据质量与数量，是外部记忆到 context 窗口的"最后一公里"优化

## 🧠 今日洞察

1. **记忆压缩成新共识**：MemRefine、G-Long、HORMA 三篇工作从不同角度（LLM 判断、图结构、层级导航）攻克同一核心挑战——如何在有限 context 预算下保留最高价值记忆，标志着 Agent Memory 研究从"怎么存"全面转向"怎么精"。

2. **认知科学与 AI 记忆的深度融合加速**：多因子记忆价值函数（情感强度、可靠性、目标对齐）借鉴认知心理学的"记忆巩固"模型，将"遗忘时刻决策"与"检索时刻决策"显式解耦，预示 Agent 记忆管理正从工程 heuristic 迈向认知理论驱动的系统设计。

3. **Memory ↔ Context 协同设计趋势明显**：HORMA 的层级树状导航、EvoMem 的补丁式增量更新、UMG-RAG 的多粒度可靠性融合，三项工作的共同逻辑是"记忆的组织方式直接决定上下文的使用效率"——记忆系统与 context 管理的边界正在模糊，协同设计（co-design）成为下一阶段的主旋律。
