📄 **【自进化记忆架构】EvolveMem：基于自动化研究的 LLM Agent 自进化记忆架构**
（EvolveMem: Self-Evolving Memory Architecture via AutoResearch for LLM Agents）
🔗 https://arxiv.org/abs/2605.13941
💡 **核心贡献**
现有记忆系统只更新存储内容，检索机制一旦部署便固化不变；EvolveMem 将检索配置（评分函数、融合策略、生成策略）暴露为结构化动作空间，由 LLM 驱动诊断模块在闭环中自动演化。系统每轮读取问题级失败日志、识别根因、提出配置调整，带自动回滚与探索保护，无需人工调参即实现 AutoResearch 闭环。
🔧 **技术亮点**
- 将记忆检索配置建模为可优化的结构化动作空间，与存储内容协同演化
- 元分析器负责"回退时回滚 + 停滞时探索"，确保安全且可收敛的自进化
- 进化出的配置可跨 benchmark 正向迁移，证明其捕捉到通用检索原则
📊 **实验结果**
LoCoMo 上超越最强 baseline 25.7%（相对提升），相对最小基线提升 78.0%；MemBench 上超越最强 baseline 18.9%（相对提升）
🧩 **技术分类**
Memory维度：记忆检索 / 外部存储
Context维度：上下文管理
🔗 **Memory ↔ Context 关联**
通过让检索配置与上下文注入策略一同自进化，该工作首次实现了"记忆内容与记忆读取路径"的双层联合优化。

📄 **【技能级记忆生命周期】MUSE-Autoskill：通过技能创建、记忆管理与评估实现自进化 Agent**
（MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation）
🔗 https://arxiv.org/abs/2605.27366
💡 **核心贡献**
现有技能创建方法将技能视为孤立静态制品，限制可复用性和长期改进；MUSE-Autoskill 引入技能级记忆，让每个技能跨任务积累经验，在统一生命周期（创建→记忆→管理→评估→精炼）中持续提升任务解决能力。
🔧 **技术亮点**
- 技能级记忆（Skill-Level Memory）：每个技能拥有独立记忆槽，跨任务积累调用经验与失败案例
- 通过单元测试 + 运行时反馈对技能做持续评估与精炼，形成技能"长寿命"管理
- 支持跨 Agent 技能迁移，验证了经验感知技能的泛化能力
📊 **实验结果**
在 SkillsBench 上，生命周期管理的技能在任务成功率、效率、复用率和跨智能体迁移上均有提升（论文在进行中，数值待发布）
🧩 **技术分类**
Memory维度：情景记忆 / 语义记忆 / 外部存储
🔗 **Memory ↔ Context 关联**
技能记忆通过在上下文窗口中高效注入经验摘要（而非完整历史）来压缩任务上下文，是记忆压缩与上下文管理的典型融合。

📄 **【长期个性化基准】VitaBench 2.0：在长期用户交互中评估个性化与主动性 Agent**
（VitaBench 2.0: Evaluating Personalized and Proactive Agents in Long-Term User Interactions）
🔗 https://arxiv.org/abs/2605.27141
💡 **核心贡献**
现有 Agent benchmark 主要评估推理与工具使用，忽视从碎片化日常交互中推断并利用用户偏好的挑战；VitaBench 2.0 构建了时序任务序列，要求 Agent 持续提取、利用、更新用户偏好，并通过主动性任务评估 Agent 的预判能力。
🔧 **技术亮点**
- 任务以时序有序的个人交互序列组织，偏好嵌入在碎片化异构交互中，模拟真实长期记忆场景
- 同时评估个性化（personalization）和主动性（proactivity），填补现有 benchmark 空白
- 多轮任务完成需要持续更新的用户偏好记忆模型，而非静态检索

🔗 **Memory ↔ Context 关联**

📄 **【双图谱 RAG】DualGraph：半结构化问答中的符号查询与语义检索协同框架**
（Query Symbolically or Retrieve Semantically? A Dataset and Method for Semi-Structured Question Answering）
🔗 https://arxiv.org/abs/2605.27164
💡 **核心贡献**
纯语义相似度检索在需要精确过滤、聚合或跨文档结构属性检索的半结构化语料上表现不稳定；DualGraph 将文档表示为文本知识图（语义检索）与符号知识图（精确查询）双视图，并提供多种混合策略。
🔧 **技术亮点**
- 文本知识图（TKG）+ 符号知识图（SKG）双图谱表征同一文档，语义与符号互补
- 提出多种证据选择/融合策略，可根据问题类型动态切换检索路径
- 同步发布 SpecsQA benchmark（商业购物网站半结构化产品文档 + 人工问题标注）
📊 **实验结果**
DualGraph 在开放式和规格导向性问题上，持续超越 SOTA 稠密检索、GraphRAG、符号方法和表格方法基线
🧩 **技术分类**
Memory维度：外部存储 / 记忆检索
Context维度：上下文管理
🔗 **Memory ↔ Context 关联**
通过双图谱选择性注入精确或语义证据，有效压缩进入上下文的检索噪声，提升上下文信噪比。

📄 **【RAG 安全盲点】检测不等于解决：RAG 增强 LLM 中的监控-控制鸿沟**
（Detecting Is Not Resolving: The Monitoring Control Gap in Retrieval Augmented LLMs）
🔗 https://arxiv.org/abs/2605.27157
💡 **核心贡献**
RAG 系统的评估通常假设单轮鲁棒性可预测多轮累积时的鲁棒性，但本文证明这一假设根本错误：模型能感知矛盾证据但行动选择不受约束，形成"监控-控制鸿沟"。
🔧 **技术亮点**
- 多轮文档累积协议（4个模型家族，1.5B–32B，超过 50,000 个轮级评估），系统性揭示单轮诊断过高估计 RAG 安全性
- 隐藏状态探针 + 注意力分析 + 响应策略分类法，定位"危险信息已被内部表征但未约束输出"这一机制缺陷
- 证明矛盾确认与安全解决之间无相关性，且无通用 prompt 修复方案
📊 **实验结果**
跨 1.5B–32B 四个模型家族，单轮安全率系统性高于多轮，人工验证确认该鸿沟非实验噪声
🧩 **技术分类**
Memory维度：记忆检索 / 外部存储
Context维度：上下文管理
🔗 **Memory ↔ Context 关联**
揭示了外部记忆内容注入上下文后，模型如何在注意力层面处理但在行动层面失效——记忆安全不能只靠检索质量保证。

📄 **【主动上下文压缩】Focus Agent：LLM Agent 的自主记忆管理与上下文压缩**
（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 **核心贡献**
LLM Agent 在长时程任务中因交互历史增长出现"上下文膨胀"（Context Bloat），推理能力下降且成本急剧上升；Focus Agent 受黏菌（Physarum polycephalum）生物探索策略启发，让 Agent 自主决定何时将关键学习凝固为持久"Knowledge"块并主动剪枝原始历史。
🔧 **技术亮点**
- 以语义知识块（Knowledge Block）替代原始历史，实现主动式有损压缩而非被动总结
- Agent 自主触发压缩时机，平均每任务完成 6.0 次自主压缩，无需外部调度
- 使用 SWE-bench Lite 长上下文实例评估，实现 22.7% token 减少同时保持相同准确率
📊 **实验结果**
N=5 上下文密集实例（Claude Haiku 4.5），Token 从 14.9M 降至 11.5M（-22.7%），单实例最高节省 57%，准确率维持 60%（3/5）
🧩 **技术分类**
Memory维度：工作记忆 / 记忆检索
Context维度：上下文压缩 / 上下文管理
🔗 **Memory ↔ Context 关联**
将工作记忆的动态管理直接映射为上下文压缩动作，是 Memory 与 Context 协同设计的直接实践范例。

## 🧠 今日洞察

1. **记忆机制从"存储-检索"二元走向"存储-检索-进化"三元**：EvolveMem 和 MUSE-Autoskill 同期出现，标志着 Agent Memory 研究进入自优化范式——记忆系统不仅要存好、取对，还要通过闭环反馈自我改进检索策略和经验积累路径。

2. **Context 压缩正在从被动外挂走向 Agent 主动自决**：Focus Agent（2601.07190）和 ACON（2510.00615）均指向同一趋势：Agent 应具备自主判断"何时压缩、压缩什么"的元认知能力，而非依赖固定规则或外部调度器。

3. **Memory × Context 协同设计的关键挑战从效率延伸到安全**：RAG 安全盲点论文（2605.27157）揭示即使检索正确、模型感知矛盾，行动选择仍可能失控——这意味着外部记忆注入上下文的安全性需要从"检索质量"延伸到"行动约束"的全链路设计，Memory 与 Context 的联合治理已成为不可回避的工程议题。
