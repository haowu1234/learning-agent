### 论文 2

📄 **[Agentic Memory：通过强化学习统一管理长短期记忆]**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885
💡 **核心贡献：** AgeMem 框架将长期记忆（LTM）和短期记忆（STM）管理统一为 Agent 策略的一部分，通过工具调用暴露记忆操作（存储/检索/更新/摘要/遗忘），让 LLM 自主决策。采用三阶段渐进强化学习 + 逐步 GRPO 解决稀疏奖励问题。（阿里巴巴，已有开源代码）

🔧 **技术亮点：**
- 将 LTM/STM 管理统一入 Agent 策略，消除了传统方案中启发式分离控制器的依赖
- 三阶段渐进 RL 训练策略：逐步引入记忆操作复杂度，避免冷启动问题
- 逐步 GRPO（step-wise GRPO）：专为记忆操作导致的稀疏、非连续奖励信号设计

📊 **实验结果：** 在 5 个长程基准任务上一致优于强基线，实现更高任务成功率、更高质量 LTM 以及更高效的上下文使用

🧩 **技术分类：**
- Memory 维度：情景记忆 / 外部存储 / 记忆检索（LTM+STM 统一管理）

🔗 **Memory ↔ Context 关联：** AgeMem 的核心价值之一在于动态决定何时将上下文内容写入 LTM、何时直接在工作记忆（上下文窗口）中保留，实现了记忆与上下文的协同调度。

### 论文 3

📄 **[主动上下文压缩：LLM Agent 的自主记忆管理]**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 **核心贡献：** 提出 Focus 架构，受黏菌（Physarum polycephalum）生物探索策略启发，让 Agent 自主决定何时将当前探索轨迹压缩为持久化「知识块」并主动剪除原始历史，将上下文从单调增长的日志转变为锯齿形「探索-压缩」循环。

🔧 **技术亮点：**
- 引入 `start_focus` / `complete_focus` 两个原语，Agent 完全自主控制压缩时机，无外部定时器或启发式规则
- 「锯齿形」上下文管理：探索阶段积累，压缩阶段清除，持久化 Knowledge 块在顶部保留关键学习
- 激进提示策略（每 10–15 次工具调用强制压缩）是实现实质性节约的关键，被动提示仅节省 6%，激进提示达 22.7%

📊 **实验结果：** SWE-bench Lite（N=5 高难度实例）：总 token 从 14.9M 降至 11.5M（-22.7%），准确率与基线相同（3/5 = 60%）；单实例最高节省 57%（matplotlib-26020）

🧩 **技术分类：**
- Context 维度：上下文压缩 / 上下文管理

🔗 **Memory ↔ Context 关联：** Focus 架构将上下文压缩与工作记忆管理深度耦合——压缩过程同时生成可持久化的语义知识块，是记忆与上下文协同设计的典型案例。
