### 1️⃣

📄 **[Gated DeltaNet-2：线性注意力中擦除与写入的解耦]**（Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention）
🔗 https://arxiv.org/abs/2605.22791

💡 **核心贡献**
线性注意力用固定大小的循环状态替代无界 KV Cache，本文指出现有方法用同一标量门控同时控制"擦除旧内容"和"写入新内容"，两者耦合导致记忆编辑质量受限。Gated DeltaNet-2 将其解耦为独立的通道级擦除门 b_t 和写入门 w_t，显著提升压缩记忆的精细编辑能力。

🔧 **技术亮点**
- 引入通道级 erase gate（b_t）和 write gate（w_t），统一泛化了 Gated DeltaNet 与 KDA 两条技术路线
- 推导出 fast-weight update 视角和 chunkwise WY 算法，保持高效并行训练
- 设计 gate-aware 反向传播，将通道级衰减吸收进不对称擦除因子

📊 **实验结果**
1.3B 参数 / 100B FineWeb-Edu tokens 训练，在长上下文 RULER needle-in-a-haystack 基准上超越 Mamba-2、Gated DeltaNet、KDA、Mamba-3，在多键检索（multi-key retrieval）任务中取得最强成绩。

🧩 **技术分类**
Memory维度：工作记忆（循环状态即压缩的工作记忆）
Context维度：长窗口扩展 / 上下文管理

🔗 **Memory ↔ Context 关联**
固定大小循环状态本质是对历史上下文的压缩记忆，精细化 erase/write 机制直接提升了 Agent 在长上下文中的工作记忆质量。

### 2️⃣

📄 **[Meta-Soft：基于可组合元 Token 的上下文保全 KV Cache 压缩]**（Meta-Soft: Leveraging Composable Meta-Tokens for Context-Preserving KV Cache Compression）
🔗 https://arxiv.org/abs/2605.22337

💡 **核心贡献**
现有 KV Cache 驱逐方法用静态参数集评估 KV pair 重要性，无法动态适配不同输入，且被移除的 KV pair 导致不可逆信息损失。Meta-Soft 通过可学习正交基矩阵和 Gumbel-Softmax 选择器动态合成 Soft Token，并用注意力流集成机制将被驱逐 token 的语义重新分配至保留 token。

🔧 **技术亮点**
- 构建可学习正交基元库（meta-library），结合 Gumbel-Softmax 选择器，为每个输入动态生成最贴切的 Soft Token 探针
- 注意力流集成（attention-flow integration）机制：语义信息从被移除 token 流向保留 token，消除上下文断裂
- 避免了现有方法中固定 Soft Token（如 Judge Q）对输入的不适应性

📊 **实验结果**
在多个数据集上超越现有 SOTA KV Cache 驱逐方法（具体数值见论文）。

🧩 **技术分类**
Memory维度：工作记忆 / 记忆检索
Context维度：上下文压缩

🔗 **Memory ↔ Context 关联**
KV Cache 是 LLM 最核心的短期工作记忆载体，Meta-Soft 的无损压缩思路（被移除内容语义的重分配）为 Agent 长期记忆压缩提供了"整合性遗忘"的新范式。

### 3️⃣

📄 **[LCGuard：多 Agent 系统中 KV 共享的隐私安全防护]**（LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems）
🔗 https://arxiv.org/abs/2605.22786

💡 **核心贡献**
多 Agent LLM 系统通过 KV Cache 共享（latent communication）提效，但 KV Cache 编码了敏感的中间推理状态，造成隐式隐私泄漏。LCGuard 将共享 KV Cache 视为"潜在工作记忆"，通过表征级变换在传输前过滤敏感信息，在保持任务性能的同时降低攻击者重建成功率。

🔧 **技术亮点**
- 正式定义"基于重建的表征级敏感信息泄漏"（reconstruction-based leakage），为记忆安全提供可量化标准
- 对抗训练框架：攻击者学习重建敏感输入，LCGuard 学习在保留任务语义的同时最小化可重建信息
- 跨多个模型家族和多 Agent 基准验证，一致性降低泄漏率和攻击成功率

📊 **实验结果**
在多个模型（跨 model families）和多 Agent 基准上，相比标准 KV 共享基线一致性降低重建攻击成功率，任务性能保持竞争力。

🧩 **技术分类**
Memory维度：工作记忆 / 外部存储（跨 Agent 记忆共享）
Context维度：上下文管理（共享上下文的安全治理）

🔗 **Memory ↔ Context 关联**
将 KV Cache（上下文记忆）从技术效率问题拓展至安全治理维度，建立了多 Agent 记忆共享中 context 与 privacy 之间的安全边界。

### 4️⃣

📄 **[Search-E1：自蒸馏驱动搜索增强推理的自进化]**（Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning）
🔗 https://arxiv.org/abs/2605.22511

💡 **核心贡献**
现有搜索增强推理通常依赖外部监督（更强模型、PRM、树搜索等），引入大量工程负担。Search-E1 仅用 vanilla GRPO + 离线自蒸馏（OFSD）让 Agent 从自身检索经验中自主进化，无需任何外部监督，实现了从 RAG 检索向内部经验积累的范式跃迁。

🔧 **技术亮点**
- 离线自蒸馏（OFSD）：策略在自身训练问题上 rollout，token 级前向 KL 目标对齐推理分布与拥有"特权上下文"（更高效同胞轨迹）时的分布
- GRPO + OFSD 交替迭代，自然产生密集的每步监督信号，无需手工奖励设计
- 不依赖 PRM、树搜索、多阶段 curriculum 或外部评判者，pipeline 极简

📊 **实验结果**
7 个 QA 基准，Qwen2.5-3B 达到 0.440 平均 EM，超越所有同规模开源基线。

🧩 **技术分类**
Memory维度：情景记忆（检索经验的结构化积累）/ 记忆检索
Context维度：In-Context 学习（自蒸馏改进 in-context 推理分布）

🔗 **Memory ↔ Context 关联**
通过自蒸馏将过去检索轨迹（情景记忆）压缩为 in-context 推理策略，实现了"记忆即上下文学习信号"的协同设计。

### 5️⃣

📄 **[AMEL：对话历史累积效应对 LLM 判断的偏置影响]**（AMEL: Accumulated Message Effects on LLM Judgments）
🔗 https://arxiv.org/abs/2605.22714

💡 **核心贡献**
大规模实证研究（75,898 次 API 调用 × 11 个模型）发现：LLM 在多轮对话中维护会话记忆时，对话历史的极性会系统性偏置后续判断，负面历史比正面历史产生 1.62× 更多偏置，且偏置与上下文长度无关（5 轮 ≈ 50 轮）。这是 Agent Memory 系统中的安全隐患，对评估 Pipeline 有直接影响。

🔧 **技术亮点**
- 跨 4 家提供商（OpenAI、Anthropic、Google + 4 个开源模型）的大规模控制实验，效应稳健
- 发现"负偏 > 正偏"（negativity asymmetry，d = -0.34 for high-entropy items）且位置无关（任意位置的 5 轮偏置 = 50 轮末尾 5 轮）
- 提出最简修复方案：评估时每 item 使用独立上下文窗口（fresh context）

📊 **实验结果**
整体偏置效应 d = -0.17（p < 10⁻⁴⁶）；高熵 item 达 d = -0.34；负面历史偏置是正面的 1.62× (t=13.46, p < 10⁻³⁹)；模型规模提升略有改善（GPT-5.2: -0.17 vs Nano: -0.34）但无法根除。

🧩 **技术分类**
Memory维度：情景记忆（对话历史作为情景记忆的偏置效应）
Context维度：上下文管理（对话上下文对推理的系统性干扰）

🔗 **Memory ↔ Context 关联**
揭示了 Agent 将对话历史（情景记忆）保留在上下文窗口时的系统性偏置：记忆越长不等于推理越好，上下文中的历史记忆会"污染"当前判断。

## 🧠 今日洞察

1. **记忆精细化趋势：解耦设计成主流**。从 Gated DeltaNet-2 的 erase/write 门解耦，到 Meta-Soft 的注意力流重分配，再到 LCGuard 的隐私边界形式化——2026 年 Agent Memory 研究正从"粗粒度压缩"走向"精细化、可控、可验证的记忆编辑"，信息丢失不可逆的时代正在结束。

2. **RAG → 经验记忆范式迁移加速**。Search-E1 通过自蒸馏将检索历史内化为策略，MOSS 通过源码级演化突破文本记忆局限——越来越多工作表明：单纯的检索增强（外部 RAG）正让位于结构化的经验积累（内化的情景记忆），Agent 正在学会"记住如何思考"而不仅是"记住什么信息"。

3. **Memory ↔ Context 协同设计的安全盲点浮现**。AMEL 和 LCGuard 揭示了记忆-上下文协同的两类新风险：（a）上下文中的历史记忆会系统性偏置当前判断，且模型规模无法根除；（b）跨 Agent 的 KV Cache 共享（上下文即记忆）存在不可见的隐私泄漏通道。未来 Memory & Context 协同设计必须将安全性（偏置缓解、隐私保护）列为一等公民。
