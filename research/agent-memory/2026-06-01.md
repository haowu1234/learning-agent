📄 **[EGOSTREAM：自我中心视觉中流式情景记忆诊断基准]**（EGOSTREAM: A Diagnostic Benchmark for Streaming Episodic Memory in Egocentric Vision）
🔗 https://arxiv.org/abs/2605.31557
💡 核心贡献：提出 EGOSTREAM 基准，专门评测具身 Agent 在流式视频中的情景记忆能力；引入「答案有效窗口（AVW）」机制，将 2250 道题扩展为 8528 道可控的记忆召回评估实例。
🔧 技术亮点：
- 七维认知记忆分类（细节、空间、时序、事件、社交、因果、前瞻记忆）
- 对比测试 KV-cache 剪枝、token 合并、量化卸载等主流 Memory 管理策略
- 统一 Qwen3-VL 骨干框架，揭示不同机制的「记忆剖面」差异
📊 实验结果：所有机制均低于实时（>1s/帧），最优方法准确率上限约 45%，暴露当前架构的严重不足
🧩 技术分类：Memory维度：**情景记忆** / **记忆检索**；Context维度：**上下文管理**
🔗 Memory ↔ Context 关联：通过 KV-cache 剪枝与量化卸载等机制，直接将情景记忆的长期保留问题转化为上下文窗口内的状态管理策略。

📄 **[LongTraceRL：通过搜索代理轨迹和评分奖励学习长上下文推理]**（LongTraceRL: Learning Long-Context Reasoning from Search Agent Trajectories with Rubric Rewards）
🔗 https://arxiv.org/abs/2605.31584
💡 核心贡献：提出 LongTraceRL 框架，利用搜索 Agent 轨迹构建分层干扰文档（高混淆/低混淆），并设计基于金实体的过程监督奖励信号，显著提升 LLM 在长上下文中的多跳推理能力。
🔧 技术亮点：
- 基于知识图谱随机游走生成多跳问题及真实搜索轨迹
- 「分层干扰器」：将 Agent 读取但未引用的文档作为高混淆负样本
- 「评分奖励（Rubric Reward）」：仅对答案正确的响应施加过程监督，避免奖励黑客问题
📊 实验结果：在 5 个长上下文基准上，4B–30B 规模模型均稳定超越强 baseline；代码/数据集/模型开源（THU-KEG）
🧩 技术分类：Memory维度：**记忆检索**；Context维度：**长窗口扩展** / **In-Context学习**
🔗 Memory ↔ Context 关联：通过搜索 Agent 的外部检索轨迹将记忆检索过程显式纳入上下文训练信号，实现记忆获取与上下文推理的协同优化。

📄 **[技能复用即压缩：Agent强化学习中的记忆编码]**（Skill Reuse as Compression in Agentic RL）
🔗 https://arxiv.org/abs/2605.31509
💡 核心贡献：提出 ReuseRL，将最小描述长度（MDL）原则引入 Agent 强化学习，通过构建可复用的技能词典并对轨迹压缩质量进行正则化，推动 Agent 学习可泛化的抽象行为模式。
🔧 技术亮点：
- 从成功轨迹中提取共享技能词典，作为 Agent 的「程序性记忆库」
- 基于 MDL 的分割代价惩罚特异性行为，鼓励跨任务技能复用
- 证明 PAC-Bayes 泛化界：压缩惩罚直接关联分布外性能提升
📊 实验结果：在 ALFWorld、TextWorld-Cooking、Countdown-Stepwise 三个 benchmark 上，分布内与分布外成功率均优于 vanilla GRPO 和轮次长度基线
🧩 技术分类：Memory维度：**语义记忆**（程序性技能库）；Context维度：**上下文压缩**
🔗 Memory ↔ Context 关联：技能词典作为外部语义记忆，通过 MDL 压缩减少上下文中冗余的行为表示，实现记忆效率与上下文精简的双重优化。

📄 **[多源 RAG 中的事实密度评估：医疗 AI 准确性研究]**（Evaluating Factual Density in Multi-Source RAG: A Study in Medical AI Accuracy）
🔗 https://arxiv.org/abs/2605.31506
💡 核心贡献：识别标准 RAG 流程中的「专家盲目效应」（Expert Blindness Effect）——余弦相似度检索偏向词汇主导文本而非高事实密度内容；引入 FD*（事实密度）信号对检索排序进行重新优化。
🔧 技术亮点：
- FD* = 验证原子主张数 / Token 总数，通过概率事实性分析打分
- Z-score 按文档长度分箱归一化，消除长度偏差（从 R=-0.86 改善到 p=0.07）
- 在 HealthFC 基准（750 条医疗声明）中，FD* 是唯一实现 Top-5 系统综述 100% 饱和的方法
📊 实验结果：FD* 优化检索将 Cochrane 证据从 Top-10 外提升至 Top-5，覆盖 7 条 HealthFC 支持声明的 25 个映射
🧩 技术分类：Memory维度：**外部存储** / **记忆检索**；Context维度：**上下文管理**
🔗 Memory ↔ Context 关联：通过事实密度信号优化外部记忆的检索排序，直接改善注入上下文的知识质量，减少上下文污染。

📄 **[StateKV：线性扩展视频 VLM 实现长视频理解]**（Linear Scaling Video VLMs for Long Video Understanding）
🔗 https://arxiv.org/abs/2605.31598
💡 核心贡献：提出 StateKV，一种无需微调的推理时方法，通过固定容量的基于重要性的循环状态替代标准自注意力，实现视频预填充的线性时间复杂度，同时保留跨帧上下文。
🔧 技术亮点：
- 双缓存设计：循环状态（跨帧上下文记忆）+ 完整逐帧缓存（解码用）
- 基于重要性的状态更新策略，无需训练直接适配预训练模型
- 在固定计算预算下可运行更大模型，提升性能帕累托前沿
📊 实验结果：在 3 个长视频基准和 7 个模型（跨 3 个系列和多种规模）上，StateKV 优于滑动窗口/近因偏置流式近似方法，逼近全自注意力精度
🧩 技术分类：Memory维度：**工作记忆**（循环状态）；Context维度：**长窗口扩展** / **上下文压缩**
🔗 Memory ↔ Context 关联：将长视频帧序列的跨帧工作记忆压缩为固定容量循环状态，是上下文压缩与记忆保持的典型协同设计。

📄 **[LoRA 如何记忆？LLM 微调的参数记忆定律]**（How LoRA Remembers? A Parametric Memory Law for LLM Finetuning）
🔗 https://arxiv.org/abs/2605.30260
💡 核心贡献：首次量化 LLM 参数记忆的容量上限，发现损失降低 ΔL 与有效参数数量和序列长度之间遵循幂律；并在 Token 级别揭示了一个决定性的相变点：预测概率 p>0.5 是逐字召回的充分条件。
🔧 技术亮点：
- LoRA 作为参数记忆容量探针，在潜空间中系统量化精确记忆
- 幂律（Parametric Memory Law）建立参数规模、序列长度与记忆容量的定量关系
- MemFT：根据相变阈值动态重分配训练预算，优先关注低于阈值的 Token
📊 实验结果：MemFT 在多项评估中提升记忆保真度与训练效率；GitHub 开源（zjunlp/ParametricMemoryLaw），30 个 upvotes
🧩 技术分类：Memory维度：**语义记忆**（参数化记忆）；Context维度：**In-Context学习**
🔗 Memory ↔ Context 关联：参数记忆的容量定律直接影响 In-Context 学习中何时依赖上下文提示 vs. 依赖参数化知识，为两者协同设计提供理论依据。
