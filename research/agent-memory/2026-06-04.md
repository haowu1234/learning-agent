### 1️⃣

📄 **[面向持续学习语言 Agent 的严格评估框架 AgentCL]**（Toward Rigorous Evaluation of Continual Learning in Language Agents）
🔗 https://arxiv.org/abs/2606.02461
👥 Yiheng Shu, Bernal Jiménez Gutiérrez 等（Ohio State University）| 2026-06-02

💡 **核心贡献**
- 提出 AgentCL 评估框架，专门评测语言 Agent 在组合式任务流中跨 episode 积累与复用经验的能力。
- 开发 MemProbe 记忆探针方法，存储交互/洞察/技能并在巩固阶段过滤不可靠经验，揭示 naive task stream 无法区分记忆设计优劣的根本缺陷。

🔧 **技术亮点**
- 构建**组合式任务流（compositional streams）**，确保早期子方案、证据和工作流可被后续任务复用
- MemProbe 三层存储结构：interactions（原始交互）→ insights（提炼洞察）→ skills（可执行技能），对应记忆的分层整合
- 对比 naive stream 与 controlled stream 的评估差异，暴露"记忆诱导的性能退化"现象

📊 **实验结果**
- 跨编码/深度调研/语言理解任务实验，controlled stream 下不同记忆设计的可塑性差异显著更清晰；naive 设置下记忆系统往往收益有限甚至负增益。

🧩 **技术分类**
- Memory维度：情景记忆 + 工作记忆 + 记忆检索
- Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
跨 episode 的经验复用本质上是将历史上下文压缩为可检索记忆单元，AgentCL 通过 MemProbe 的三层结构验证了记忆整合（consolidation）对于长期上下文利用效率的关键作用。

### 2️⃣

📄 **[状态外部化工作记忆的强化学习搜索 Agent：Harness-1]**（Reinforcement Learning for Search Agents with State-Externalizing Harnesses）
🔗 https://arxiv.org/abs/2606.02373
👥 Pengcheng Jiang, Zhiyi Shi 等（UIUC，Jiawei Han 组）| 2026-06-02

💡 **核心贡献**
- 提出"状态外部化（state-externalizing）"范式：将搜索 Agent 的工作记忆从策略模型中完全剥离，由环境侧 Harness 组件维护，策略模型只保留语义决策。
- Harness-1（20B 模型）在 8 个检索 benchmark 上达到 0.730 平均召回率，超越最强开源搜索子 Agent +11.4 个百分点。

🔧 **技术亮点**
- Harness 维护 6 类工作记忆结构：候选池、重要性标记精选集、紧凑证据链接、验证记录、压缩去重观察、预算感知上下文渲染
- 策略模型只做四类语义判断：搜什么 / 保留or丢弃哪些文档 / 验证什么 / 何时停止
- RL 训练聚焦于语义决策而非状态记账，泛化能力显著提升（held-out 迁移 benchmark 表现尤其突出）

📊 **实验结果**
- 8 个检索基准（Web/金融/专利/多跳QA）平均 curated recall = **0.730**，+11.4pp vs 最强开源竞品；代码已开源 github.com/pat-jj/harness-1

🧩 **技术分类**
- Memory维度：工作记忆 + 外部存储
- Context维度：上下文压缩 + 上下文管理

🔗 **Memory ↔ Context 关联**
Harness 的"预算感知上下文渲染"直接将工作记忆压缩为符合上下文窗口约束的输入，实现了记忆管理与上下文窗口限制的协同设计。

### 3️⃣

📄 **[追踪适应性 Agent 的行为轨迹：记忆文件演化审计]**（Tracking the Behavioral Trajectories of Adapting Agents）
🔗 https://arxiv.org/abs/2606.02536
👥 Jonah Leshin, Manish Shah, Ian Timmis | 2026-06-02

💡 **核心贡献**
- 提出将 Agent 的"特质（traits）"定义为文本嵌入空间的方向向量，通过追踪 memory/skill 文件的 embedding diff 来审计 Agent 行为演化。
- 构建 Agent-to-Agent 协议，允许一个 Agent 通过可信中介评估另一个 Agent 的 skill file 更新的安全性。

🔧 **技术亮点**
- Trait Vector：在 embedding 空间定义特质方向，线性模型学习投影 skill edit 的 embedding diff 并评分
- 在 68 个标注 skill diff 对上，"倾向获取敏感数据"特质分类准确率达 **91.2%（ρ=0.82）**
- 提供可解释的记忆演化监控手段，支持多 Agent 间的记忆安全性互验

📊 **实验结果**
- 68 个 skill diff 对标注集，敏感特质分类 91.2% 准确率；Spearman ρ=0.82 表明 trait vector 投影与人类判断高度一致。

🧩 **技术分类**
- Memory维度：情景记忆 + 外部存储（skill/memory files）
- Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
通过追踪 memory/skill 文件在 embedding 空间的演化，将外部存储记忆的安全性问题转化为上下文内容审计问题，为记忆-上下文系统的可信性提供了量化工具。

### 4️⃣

📄 **[SIRI：基于技能内化强化学习的 LLM Agent 无库推理]**（SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training）
🔗 https://arxiv.org/abs/2606.02355
👥 Zhongyu He, Yuanfan Li 等 | 2026-06-02

💡 **核心贡献**
- 提出三阶段技能自内化框架：Agent 自主发现→验证→内化技能，推理时无需外部技能库，技能被蒸馏进模型参数。
- 代表"记忆参数化"路线的激进实践：将 procedural memory 从外部存储彻底转移到模型权重，对比 Voyager 式外部技能库提供了反向设计参考。

🔧 **技术亮点**
- **Self-skill mining**：从自身成功轨迹提炼紧凑技能表示，通过配对 rollouts 进行自验证
- 推理时只需原始 prompt，零额外上下文开销——技能已被蒸馏至权重内
- 超越 prompt-based、RL-based 和 memory-augmented（外部存储）等多类 baseline

📊 **实验结果**
- 超越 prompt-based、RL-based 和 memory-augmented baselines（具体数值未在摘要中完整披露，详见论文本体）。

🧩 **技术分类**
- Memory维度：情景记忆（技能提炼来源）+ 语义记忆（内化目标）
- Context维度：In-Context学习（零额外上下文方案的比较基线）

🔗 **Memory ↔ Context 关联**
SIRI 通过将外部 procedural memory 内化为模型权重，将"记忆检索消耗上下文"的问题彻底消除，指出记忆内化是降低上下文占用成本的极端路径。

### 5️⃣

📄 **[RASER：多跳问答的可恢复感知 RAG 路由优化]**（RASER: Recoverability-Aware Selective Escalation Router for Multi-Hop Question Answering）
🔗 https://arxiv.org/abs/2606.02488
👥 Yuyang Li, Zihe Yan, Tobias Käfer | 2026-06-02

💡 **核心贡献**
- 发现大量多跳问题通过单次 RAG 即可正确回答，无需多轮检索；提出基于可恢复性感知的廉价路由器，按需升级至昂贵检索策略。
- 在保持竞争力 F1 的同时，仅消耗 always-prune 方案的 **41-49% token**，显著降低多 Agent RAG 系统的推理成本。

🔧 **技术亮点**
- **可恢复性（Recoverability）**评估：判断当前检索结果是否已足够，或升级才能恢复正确答案
- 路由决策无需额外 LLM 调用，极低延迟开销
- 在 Web/金融/多跳 QA 等多个 benchmark 上验证效率-效果 Pareto 优化

📊 **实验结果**
- Token 消耗降至 41–49%（vs always-prune baseline），F1 仍保持竞争力（具体数值详见论文）。

🧩 **技术分类**
- Memory维度：记忆检索 + 外部存储
- Context维度：上下文压缩（通过路由减少不必要检索内容注入上下文）

🔗 **Memory ↔ Context 关联**
通过判断是否需要多轮检索扩充，RASER 实质上在管理"向上下文注入多少记忆"的成本-收益决策，将记忆检索的粒度控制与上下文 token 预算直接挂钩。

### 6️⃣

📄 **[COMAP：世界模型与 Agent 策略的协同进化框架]**（COMAP: Co-Evolving World Models and Agent Policies for LLM Agents）
🔗 https://arxiv.org/abs/2606.02372
👥 Youwei Liu, Jian Wang 等（PolyU HK）| 2026-06-02

💡 **核心贡献**
- 提出 COMAP 框架：文本世界模型与 Agent 策略通过闭环交互协同进化，世界模型预测候选动作的未来状态，Agent 进行"未来感知反思"以精化行动。
- 世界模型作为 Agent 的压缩经验记忆，通过 self-distillation 不断适应 Agent 的在线策略分布，Qwen3-4B 获得 +16.75% 相对提升。

🔧 **技术亮点**
- **Co-evolution 闭环**：on-policy 轨迹 → self-distillation 更新世界模型 → 更精准的未来预测 → 策略改进
- **未来感知反思（future-aware reflection）**：Agent 估计世界模型反馈可靠性，动态调整行动，不盲目依赖世界模型
- 无需外部奖励或验证器，适用于现实交互环境

📊 **实验结果**
- 具身任务规划 + Web 导航 + 工具使用 benchmark，Qwen3-4B 相对提升 **+16.75%**；代码开源 github.com/loyiv/CoMAP

🧩 **技术分类**
- Memory维度：情景记忆（世界模型存储环境动态经验）+ 语义记忆（self-distillation 压缩知识）
- Context维度：上下文管理（未来感知反思精化在线上下文利用）

🔗 **Memory ↔ Context 关联**
世界模型本质是对 episodic experience 的预测性压缩，COMAP 通过将历史轨迹蒸馏为可预测的世界状态，将"记忆检索回放"升维为"未来状态预测"，在上下文空间内完成记忆的前瞻性激活。

## 🧠 今日洞察

1. **记忆外部化 vs 参数化的分野正在加深**：同一天的 Harness-1（工作记忆外部化）与 SIRI（procedural memory 参数化内化）代表了两条相向而行的路线——前者认为 RL 不应负担状态记账，后者则要求技能从外部库彻底消失；这一分野预示着 2026 下半年 Memory 架构的核心辩题。

2. **记忆评估基础设施急需升级**：AgentCL 揭示 naive task stream 无法区分记忆设计优劣，MemProbe 的三层探针方法（interaction→insight→skill）为记忆系统评估提供了新基准，这标志着 Agent Memory 研究正从"如何设计记忆"进入"如何严格评估记忆"的新阶段。

3. **Memory 与 Context 的协同设计已成主流**：从 RASER 的"按需注入记忆以控制 token 成本"，到 Harness-1 的"预算感知上下文渲染"，再到 COMAP 的"经验记忆压缩为世界模型以前瞻性激活"，本周论文的共同信号是：记忆系统的设计目标已从"存什么、检什么"扩展到"在有限上下文预算内，何时、以何种粒度将记忆投影到上下文空间"。
