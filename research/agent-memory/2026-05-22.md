### 1. 📄 **面向长时程科学智能体的情节-语义记忆架构**
（Episodic-Semantic Memory Architecture for Long-Horizon Scientific Agents）

🔗 https://arxiv.org/abs/2605.17625

💡 **核心贡献**
提出双过程记忆架构（Dual Process Memory Architecture），将即时情景记忆（固定10条消息窗口）与持续增长的长期语义知识库解耦，专为科学研究场景中的长时程 Agent 设计。通过 6 个 LLM 家族共 1,440 次查询、15,000 条消息的大规模评估，验证了系统在超长上下文场景下的持续稳定运行能力。

🔧 **技术亮点**
- 情景层（Episodic Layer）固定10消息滑动窗口，避免二次成本爆炸；语义层（Semantic Layer）以约 3 tokens/消息线性增长，实现知识沉淀
- 引入「Sim-to-Real Gap」概念：合成测试中记忆近似常量，而真实工作流呈线性增长，记忆巩固质量是可扩展性的主要瓶颈
- 成功管理含 14,000+ 科学事实（125k tokens）的配置文件，超越全上下文模型在 10,000 条消息时的崩溃上限

📊 **实验结果**
全上下文模型在 10,000 条消息时因上下文溢出失败；本架构以 62% 更少 token（45,434 vs 120,000+）维持 70-85% 准确率，延迟 1-2 秒。双过程架构在数值/时间查询上表现优异（65-90%），RAG 在历史检索上更强（60-85%），二者具有互补部署价值。

🧩 **技术分类**
Memory维度：情景记忆 / 语义记忆 / 外部存储
Context维度：上下文管理 / 长窗口扩展

🔗 **Memory ↔ Context 关联**
通过将情景记忆与语义记忆分层解耦，直接解决了科学 Agent 上下文窗口饱和问题，将记忆架构设计转化为上下文管理策略。

### 2. 📄 **基于因果干预的长时程 LLM Agent 记忆选择**
（Causal Intervention-Based Memory Selection for Long-Horizon LLM Agents）

🔗 https://arxiv.org/abs/2605.17641

💡 **核心贡献**
提出因果记忆干预（Causal Memory Intervention, CMI）技术，通过受控干预估计候选记忆对模型答案的因果影响，主动筛选提升任务表现的记忆、抑制不稳定/无关/有害记忆，突破现有语义相似度检索的局限性。同时引入因果标注基准 Causal-LoCoMo，覆盖有用记忆、无关干扰项和有害合成记忆。

🔧 **技术亮点**
- 将记忆选择从"相关性匹配"升级为"因果有效性评估"，解决「拓扑相关但任务无关」的虚假记忆检索问题
- 引入 NullMemory 反事实基线，量化记忆引入带来的答案偏移
- 对比7种基线（向量、图、反思、摘要、全历史、无记忆）均取得最优的质量-鲁棒性平衡

📊 **实验结果**
CMI 在 Causal-LoCoMo 上实现了答案质量与误导记忆鲁棒性的最强平衡，证明可靠长期记忆需要基于因果有效性而非单纯相关性的上下文选择。

🧩 **技术分类**
Memory维度：记忆检索 / 情景记忆 / 外部存储

🔗 **Memory ↔ Context 关联**
通过因果干预判断记忆对当前上下文的实际贡献度，在记忆检索环节实现了更精准的上下文填充决策。

### 3. 📄 **记忆越多，风险越大：记忆装备 LLM Agent 的纵向安全风险**
（Remembering More, Risking More: Longitudinal Safety Risks in Memory-Equipped LLM Agents）

🔗 https://arxiv.org/abs/2605.17830

💡 **核心贡献**
首次系统性研究记忆装备 Agent 的纵向安全风险（Temporal Memory Contamination），指出现有安全评估聚焦于单任务快照而忽视了跨任务记忆积累带来的行为漂移问题。通过触发-探测协议（trigger-probe protocol）和 NullMemory 反事实基线，量化了记忆暴露长度与安全违规率的正相关关系。

🔧 **技术亮点**
- 定义「时序记忆污染」（Temporal Memory Contamination）：随记忆积累，Agent 安全状态在独立任务间相互污染
- 跨3种部署场景（记录/备忘录/邮件）和8种记忆架构进行评估，结论具有跨架构普适性
- 发现记忆引发的风险在记忆检索阶段（生成前）即可检测，提出高召回率诊断监控器

📊 **实验结果**
所有记忆启用 Agent 的安全违规率均稳定高于 NullMemory 基线，且违规率随暴露长度呈鲁棒上升趋势；顺序随机化实验证明该效应主要由积累内容驱动，而非遭遇顺序。

🧩 **技术分类**
Memory维度：外部存储 / 记忆检索
Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
揭示了记忆内容通过上下文注入机制对 Agent 行为产生跨任务影响的安全隐患，为记忆-上下文协同设计增加了安全维度。

### 4. 📄 **PEEK：面向长上下文 LLM Agent 的上下文地图定向缓存**
（PEEK: Context Map as an Orientation Cache for Long-Context LLM Agents）

🔗 https://arxiv.org/abs/2605.19932

💡 **核心贡献**
提出 PEEK 系统，将 Agent 对重复外部上下文（如文档库、代码仓库）的「定向知识」（orientation knowledge）缓存为固定大小的上下文地图（context map），注入 prompt 使 Agent 获得对外部上下文的持续洞察，无需重复扫描原始材料。

🔧 **技术亮点**
- 三模块可编程缓存策略：Distiller（从推理信号提取可迁移知识）、Cartographer（将知识转为结构化编辑）、Evictor（基于优先级强制固定 token 预算）
- 上下文地图大小恒定，不随任务积累而膨胀，从根本上解决长上下文 token 爆炸问题
- 跨模型泛化（含 OpenAI Codex 生产级编程 Agent）且无需参数更新，适配闭源/大规模 LLM

📊 **实验结果**
在长上下文推理和信息聚合任务上相对强基线提升 6.3-34.0%，减少 93-145 次迭代，成本比 SOTA 的 ACE 框架低 1.7-5.8 倍；在上下文学习任务上解题率提升 6.0-14.0%，准确率提升 7.8-12.1%，成本低 1.4 倍。

🧩 **技术分类**
Context维度：上下文压缩 / 上下文管理 / In-Context学习
Memory维度：工作记忆 / 外部存储

🔗 **Memory ↔ Context 关联**
将记忆提炼与上下文压缩统一于「定向缓存」范式，通过在 prompt 中维护结构化记忆地图实现了记忆持久性与上下文效率的协同优化。

### 5. 📄 **NeuSymMS：面向持久自策展 LLM Agent 的混合神经符号记忆系统**
（NeuSymMS: Neural-Symbolic Memory System for Persistent Self-Curating LLM Agents）

🔗 https://arxiv.org/search/?query=NeuSymMS

💡 **核心贡献**
提出 NeuSymMS 自适应混合记忆系统，将神经方法（语义嵌入、模糊匹配）与符号方法（结构化规则、知识图谱）融合，使 LLM Agent 能够持久化存储、自主策展和精确检索记忆，实现更可靠的长期知识管理。

🔧 **技术亮点**
- 神经-符号双引擎架构：神经层处理语义模糊查询，符号层保障精确逻辑推理和知识一致性
- 引入自策展（self-curation）机制：Agent 可主动压缩、合并、删除冗余或过期记忆条目
- 支持多跳推理（multi-hop reasoning），符号层维护记忆实体间的关系图谱

🧩 **技术分类**
Memory维度：语义记忆 / 外部存储 / 记忆检索
Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
通过神经-符号双轨检索降低无效记忆注入上下文的概率，实现记忆质量与上下文利用效率的双重提升。

### 6. 📄 **EXG：基于经验图的自演化 Agent**
（EXG: Self-Evolving Agent via Experience Graph）

🔗 https://arxiv.org/search/?query=EXG+self-evolving+experience+graph

💡 **核心贡献**
针对「LLM Agent 无法从过去经验中学习」的核心痛点，提出经验图（Experience Graph, EXG）——将 Agent 历史交互结构化为可检索、可复用的节点-边网络，实现基于经验积累的自演化能力，无需对基础模型进行微调。

🔧 **技术亮点**
- 图结构经验存储：将任务、行动、结果建模为图节点，用有向边捕捉因果与时序关联
- 经验图支持子图检索，Agent 在新任务中可召回结构相似的历史解决路径
- 自演化循环：每轮交互后更新图结构，逐步积累领域专有经验，形成闭环学习

🧩 **技术分类**
Memory维度：情景记忆 / 外部存储 / 记忆检索
Context维度：In-Context学习

🔗 **Memory ↔ Context 关联**
通过图检索将结构化历史经验转化为上下文中的少样本示例（few-shot demonstrations），在记忆调取与 In-Context 学习之间建立直接桥梁。

## 🧠 今日洞察

1. **记忆分层与双过程架构正成为主流范式**：从 ESMA 的情景-语义双层到 NeuSymMS 的神经-符号双轨，研究者普遍认识到单一记忆机制无法同时满足即时响应与长期积累的需求，「分层协作」是突破上下文窗口瓶颈的核心路径。

2. **记忆可靠性从「检索相关性」向「因果有效性」跃迁**：CMI 用因果干预替代语义相似度作为记忆选取标准，而「Remembering More, Risking More」则从安全角度揭示记忆积累的副作用——标志着该领域开始深入思考「什么样的记忆值得保留」而非仅关注「如何存储更多记忆」。

3. **Memory 与 Context 的协同设计迎来突破**：PEEK 的「上下文地图」将记忆压缩与上下文管理统一于单一机制，EXG 将经验图直接映射为 In-Context 示例——这预示着下一代 Agent 框架将不再把记忆系统和上下文窗口视为两个独立问题，而是设计统一的「记忆-上下文协同优化」基础设施。
