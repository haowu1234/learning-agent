### 1️⃣ δ-mem：大语言模型的高效在线记忆机制

**原文标题：** δ-mem: Efficient Online Memory for Large Language Models
🔗 https://arxiv.org/abs/2605.12357
📅 发布：2026-05-12 | 作者：Jingdi Lei et al.

💡 **核心贡献**
在冻结的全注意力骨干模型上叠加一个 8×8 紧凑关联记忆状态矩阵，无需微调即可显著提升记忆密集型任务表现。通过 delta-rule 学习将历史信息压缩为固定大小状态，再以低秩修正方式耦合到注意力计算中，实现"记忆即计算"。

🔧 **技术亮点**
- 仅用 64 个参数（8×8 矩阵）作为在线工作记忆，极端压缩但高度有效
- Delta-rule 持续更新状态矩阵，生成时以低秩修正直接介入注意力权重
- 无需 backbone 替换、上下文扩展或全量微调，plug-and-play 设计

📊 **实验结果**
- MemoryAgentBench：相对冻结 backbone 提升 **1.31×**
- LoCoMo：提升 **1.20×**，通用能力几乎不受影响
- 超越所有非 δ-mem 记忆基线（平均 1.15×）

🧩 **技术分类**
Memory 维度：**工作记忆**（参数化在线关联状态）
Context 维度：**上下文压缩**（历史信息压缩为固定大小状态矩阵）

🔗 **Memory ↔ Context 关联**
δ-mem 本质是将无界上下文历史压缩为固定大小的参数化状态，再通过注意力修正在生成时"调用"，是记忆压缩与上下文利用的深度融合。

### 4️⃣ xMemory：超越 RAG 的层级解耦 Agent 记忆

**原文标题：** Beyond RAG for Agent Memory: Retrieval by Decoupling and Aggregation
🔗 https://arxiv.org/abs/2602.02007
📅 发布：2026-02-02（v4 更新：2026-05-12）| 作者：Zhanghao Hu et al.

💡 **核心贡献**
提出"先解耦后聚合"原则：将交互历史解耦为可复用的记忆组件，再用稀疏-语义保真目标（sparsity-semantic faithfulness）聚合为层级结构，从根本上解决 flat top-k 检索的冗余与摘要层级抹除细节两大痛点。

🔧 **技术亮点**
- 四级层级结构：原始消息 → 片段 → 记忆组件 → 组，增量更新支持记忆进化
- 稀疏-语义保真目标指导高层节点组织，同时保留区分性细节
- 推理时自顶向下检索：先选互补的组/组件，再按读者不确定性决定是否展开到原始片段

📊 **实验结果**
- LoCoMo 和 PerLTQA 上跨多种开源/闭源 LLM 均取得**一致性答案质量提升**
- 冗余度降低、证据密度提升、覆盖率改善（三项分析支持）

🧩 **技术分类**
Memory 维度：**语义记忆 + 情景记忆 + 记忆检索**（层级解耦存储 + 不确定性驱动检索）
Context 维度：**上下文压缩**（只展开必要层级以控制注入 token 数）

🔗 **Memory ↔ Context 关联**
xMemory 通过层级化存储和不确定性扩张策略，动态控制引入上下文的粒度——需要细节时展开，无需时保持高层摘要，实现记忆深度与上下文效率的精准平衡。

### 5️⃣ COMI：基于边际信息增益的粗细粒度上下文压缩（ICLR 2026）

**原文标题：** COMI: Coarse-to-fine Context Compression via Marginal Information Gain
🔗 https://arxiv.org/abs/2602.01719
📅 发布：2026-02-02 | **已收录 ICLR 2026** | 作者：Jiwei Tang et al.（清华大学 & 阿里巴巴未来生活实验室）

💡 **核心贡献**
提出边际信息增益（MIG）指标——衡量一个单元相对于查询的相关性减去与其他已选单元的语义冗余——以此指导压缩过程同时优化相关性与多样性，解决高压缩率下的"信息内卷"问题。

🔧 **技术亮点**
- **粗粒度组重分配**：按组间 MIG 动态分配压缩预算，确保高价值区域获得更多保留 token
- **细粒度 Token 合并**：组内基于 MIG 加权融合 token，保留关键语义同时避免冗余积累
- 两阶段自适应压缩，与骨干模型无关（LLaMA-2-7B、Qwen2-7B 验证）

📊 **实验结果**
- NaturalQuestions（32× 压缩）：EM 提升约 **25 个百分点**（Qwen2-7B）
- 跨 NQ / 2WikiMQA / HotpotQA / NarrativeQA / MultiNews 全面领先基线

🧩 **技术分类**
Context 维度：**上下文压缩**（信息论驱动的自适应双阶段压缩）
Memory 维度：**记忆检索**（MIG 指导的相关性-多样性联合优化，可用于 RAG 证据选择）

🔗 **Memory ↔ Context 关联**
COMI 的 MIG 框架天然适用于 Agent 记忆检索场景：在将历史记忆注入上下文时，可用 MIG 同时保证检索片段的相关性与多样性，避免冗余证据占据宝贵的上下文预算。

### 6️⃣ Gated DeltaNet-2：线性注意力中解耦擦除与写入

🔗 https://arxiv.org/abs/2605.22791

🔧 **技术亮点**
- 通道级擦除门 b_t 与写入门 w_t 完全解耦，分别控制旧内容清除强度和新内容写入量
