### 1️⃣

📄 **[LongMemEval-V2：面向"经验型同事"的智能体长期记忆评测基准]**（LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues）
🔗 https://arxiv.org/abs/2605.12493
📅 发布：2026-05-12 | 作者：Di Wu, Zixiang Ji, Jia-Chen Gu, Nanyun Peng, Kai-Wei Chang 等

💡 **核心贡献**
提出 LongMemEval-V2（LME-V2）基准，专门评测 Web Agent 在特定环境中通过记忆积累"成为专家"的能力。通过 451 道人工标注问题、最多 500 条轨迹（115M tokens）的历史数据，系统测量 Agent 对界面状态、工作流、常见失效模式的记忆内化程度。

🔧 **技术亮点**
- 定义五类核心记忆能力：静态状态召回、动态状态追踪、工作流知识、环境陷阱、前提感知
- 提出 AgentRunbook-R（RAG 知识池方案：原始观察、事件、策略三类记忆）和 AgentRunbook-C（文件级轨迹存储 + 代码 Agent 取证）双方案
- 首次将"上下文聚合"（context gathering）形式化，将记忆输出定义为下游 QA 的压缩证据

📊 **实验结果**
AgentRunbook-C 达到 72.5% 平均准确率，显著超越最强 RAG 基线（48.5%）和开箱即用代码 Agent 基线（69.3%）；但 AgentRunbook-C 存在高延迟代价，准确率-延迟 Pareto 前沿仍有较大提升空间。

🧩 **技术分类**
Memory维度：情景记忆 / 外部存储 / 记忆检索
Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
本文将长期记忆的输出显式设计为"压缩的上下文片段"，直接建立了记忆检索与上下文构建之间的桥梁：好的记忆系统 = 为 Agent 生成高质量的精简上下文。

### 2️⃣

📄 **[MedMemoryBench：个性化医疗场景中的智能体记忆基准测评]**（MedMemoryBench: Benchmarking Agent Memory in Personalized Healthcare）
🔗 https://arxiv.org/abs/2605.11814
📅 发布：2026-05-12 | 作者：Yihao Wang, Haoran Xu, Ke Chen, Lidan Shou 等

💡 **核心贡献**
针对医疗健康场景中部署个性化 Agent 的严苛需求，构建了首个面向临床长期追踪的记忆基准 MedMemoryBench，包含约 2000 session、16000 轮交互的合成医患轨迹数据。首创"边构建边评估"的流式评测协议，精确模拟生产环境中的动态记忆积累过程。

🔧 **技术亮点**
- 基于临床有根据的合成患者原型，通过人机协作流程生成高保真长时程医疗轨迹
- 提出"记忆饱和"（memory saturation）现象的正式定义与系统性研究：持续信息注入会主动降低检索与推理的鲁棒性
- 流式评测协议替代传统静态快照评估，评测粒度更细、更贴近真实部署

📊 **实验结果**
综合评测揭示主流架构在复杂医疗推理和噪声鲁棒性方面存在严重瓶颈，当前最优系统在记忆饱和场景下性能显著下降。

🧩 **技术分类**
Memory维度：情景记忆 / 语义记忆 / 外部存储 / 记忆检索

🔗 **Memory ↔ Context 关联**
记忆饱和问题本质是上下文累积导致的信噪比下降，要求记忆系统具备主动过滤与压缩能力，将记忆质量与上下文管理深度耦合。

### 3️⃣

📄 **[LongSeeker：面向长时程搜索智能体的弹性上下文编排框架]**（LongSeeker: Elastic Context Orchestration for Long-Horizon Search Agents）
🔗 https://arxiv.org/abs/2605.05191
📅 发布：2026-05-06 | 作者：Rui Ye, Yuwen Du, Jiajun Wang, Songhua Liu, Siheng Chen

💡 **核心贡献**
提出 Context-ReAct 框架，将推理、上下文管理与工具调用统一融入一个循环，通过五个原子操作（Skip/Compress/Rollback/Snippet/Delete）让 Agent 能主动弹性地重塑工作上下文。在此基础上训练了 LongSeeker（基于 Qwen3-30B-A3B，使用 1 万条合成轨迹微调）。

🔧 **技术亮点**
- 五个原子上下文操作各有功能保证：Compress 具有表达完备性，其余操作提供效率与保真度双保障
- 根据任务相关性动态维护不同粒度的轨迹，对已解决信息进行摘要、丢弃无效分支
- 理论证明 Compress 算子在合理假设下可还原其他算子，为弹性压缩提供理论基础

📊 **实验结果**
在 BrowseComp 达到 61.5%，BrowseComp-ZH 达到 62.5%，分别超越 Tongyi DeepResearch（43.2% / 46.7%）和 AgentFold（36.2% / 47.3%）。

🧩 **技术分类**
Memory维度：工作记忆
Context维度：上下文压缩 / 上下文管理

🔗 **Memory ↔ Context 关联**
该工作将"工作记忆管理"等同于"上下文弹性压缩"，通过原子操作实现记忆与上下文的共同演化，是 Memory-Context 协同设计的典型范例。

### 4️⃣

📄 **[Experience-RAG Skill：面向异构任务的经验驱动检索策略编排插件]**（An Agent-Oriented Pluggable Experience-RAG Skill for Experience-Driven Retrieval Strategy Orchestration）
🔗 https://arxiv.org/abs/2605.03989
📅 发布：2026-05-05 | 作者：Dutao Zhang 等

💡 **核心贡献**
提出 Experience-RAG Skill，一种可插拔的检索编排层，位于 Agent 与检索器池之间。通过分析当前场景并查询经验记忆（experience memory），为不同类型任务（事实问答、多跳推理、科学验证）动态选择最优检索策略。

🔧 **技术亮点**
- 将检索策略选择封装为可复用的 Agent Skill，而非硬编码在上层工作流中
- 引入"经验记忆"作为策略知识库，通过历史检索经验指导当前决策
- 架构无关（model-agnostic）设计，可无缝插入现有 RAG 管道

📊 **实验结果**
在 BeIR/nq、BeIR/hotpotqa、BeIR/scifact 混合场景下，nDCG@10 达到 0.8924，超越固定单检索器基线，与 Adaptive-RAG 路由方案持平。

🧩 **技术分类**
Memory维度：语义记忆 / 记忆检索
Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
经验记忆充当"元检索知识库"，将 RAG 的上下文构建提升为由历史经验驱动的自适应过程，实现了记忆指导上下文生成的闭环。

### 5️⃣

📄 **[LaProx：重构 KV 缓存驱逐问题的输出感知长上下文高效推理]**（Reformulating KV Cache Eviction Problem for Long-Context LLM Inference）
🔗 https://arxiv.org/abs/2605.07234
📅 发布：2026-05-08 | 作者：Tho Mai 等

💡 **核心贡献**
将 KV Cache 驱逐问题从传统的逐头局部注意力权重平均，重新建模为输出感知、跨层矩阵乘法近似问题。提出 LaProx 驱逐策略，显式建模注意力图与投影 Value 状态的乘积交互以量化 Token 贡献，并实现了首个全局可比的重要性评分统一驱逐框架。

🔧 **技术亮点**
- 突破"逐头决策"局限，建立跨头依赖感知的 Token 重要性度量
- 全局统一评分使模型可做全局 Token 选择，而非局部独立决策
- 仅需 5% KV Cache 即可维持模型性能，极端压缩场景下准确率损失降低至原来的 1/2

📊 **实验结果**
在 LongBench 和 Needle-In-A-Haystack 的 19 个数据集上，5% KV Cache 保留率下性能维持，极端场景下准确率损失对比 SOTA 减少最多 2×，额外开销极小。

🧩 **技术分类**
Context维度：长窗口扩展 / 上下文压缩

🔗 **Memory ↔ Context 关联**
KV Cache 是 Transformer 的"工作记忆"具象化；LaProx 提升了工作记忆的利用效率，通过精准保留高价值 Token 实现"用更少的上下文存储更多有效信息"。

### 6️⃣

📄 **[Focus Agent：LLM 智能体自主上下文压缩与记忆管理架构]**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
📅 发布：2026-01-12 | 作者：Nikhil Verma

💡 **核心贡献**
提出 Focus Agent，一种 Agent 自主决定何时将关键知识固化为持久"Knowledge 块"并主动裁剪原始历史的架构，从"被动保留"转向"主动压缩"，实现 Token 减少与任务性能的双优化。

🔧 **技术亮点**
- 受黏菌（Physarum polycephalum）生物探索策略启发，设计 Agent 自主上下文自我调节机制
- 将交互历史的关键学习提炼写入持久 Knowledge 块，同时物理裁剪原始轨迹
- 实验基于 SWE-bench Lite + Claude Haiku 4.5，每任务平均执行 6.0 次自主压缩

📊 **实验结果**
在 SWE-bench Lite 5 个上下文密集实例上，Token 用量减少 22.7%（14.9M→11.5M），单实例最高节省 57%，任务准确率（60%）与基线完全持平。

🧩 **技术分类**
Memory维度：工作记忆 / 外部存储
Context维度：上下文压缩 / 上下文管理

🔗 **Memory ↔ Context 关联**
该工作直接将"记忆写入"（Knowledge 块）与"上下文压缩"（裁剪历史）统一为一个 Agent 决策动作，是记忆管理与上下文管理协同设计的最直观实现。

## 🧠 今日洞察

1. **记忆评测向"专家化"与"场景化"迈进**：本周出现两篇高质量记忆基准论文（LongMemEval-V2、MedMemoryBench），评测重心从通用对话记忆转向"特定环境经验内化"与"高风险临床长期追踪"，预示 Agent Memory 评测将与领域深度耦合，通用基准不再足够。

2. **上下文主动压缩正成为核心竞争力**：从 Focus Agent 到 LongSeeker，再到 LaProx，三条路线（Agent 自主裁剪、弹性原子操作、KV Cache 全局驱逐）共同指向同一结论——被动保留上下文是性能瓶颈，主动、结构化的上下文压缩才是长时程 Agent 的生命线。

3. **Memory 与 Context 的协同设计从"并行"走向"融合"**：Experience-RAG Skill 的经验记忆驱动检索策略选择、LongSeeker 的工作记忆即上下文操作、LongMemEval-V2 的记忆输出即压缩上下文——这些工作表明，下一代 Agent 架构中记忆系统与上下文管理将不再是两个独立模块，而是一体化设计的两面。
