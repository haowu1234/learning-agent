📄 **AutoSci：以记忆为核心的科研全生命周期 Agent 系统**（AutoSci: A Memory-Centric Agentic System for the Full Scientific Research Lifecycle）
🔗 https://arxiv.org/abs/2605.31468
💡 核心贡献：提出 AutoSci，一个专为科研全生命周期设计的 Agent 系统，其核心模块 SciMem 将长期知识记忆（LTM）与活跃研究记忆（Active Research Memory）显式分离，并通过 SciEvolve 模块将反馈信号转化为对记忆组织的版本化更新。该系统不仅能执行，还能跨项目持续记忆与演化。
🔧 技术亮点：
- **SciMem 分层架构**：schema-governed 结构显式区分可复用的科学知识（LTM）与项目级工件（想法、实验、手稿、评审），解决了现有系统只能捕获记忆碎片的问题
- **SciEvolve 记忆演化**：将用户反馈、实验结果、同行评审等外部信号自动转化为记忆组织、技能库和模板的版本化迭代更新
- **SciDAG 多智能体增强**：针对复杂技能使用 DAG 形状的多 Agent 算子，结合可复用的阶段特定模板实现流程协作
📊 实验结果：支持从文献理解到反驳信的五阶段科研流程，系统可跨研究项目保持持续的结构化状态
🧩 技术分类：Memory维度：**情景记忆 + 语义记忆 + 外部存储**
🔗 Memory ↔ Context 关联：SciMem 通过分层记忆结构动态选择注入 Agent 上下文的知识范围，实现了"按需上下文化"的记忆-上下文协同

📄 **AdaCoM：面向长时序任务的自适应上下文管理**（Learning Agent-Compatible Context Management for Long-Horizon Tasks）
🔗 https://arxiv.org/abs/2605.30785
💡 核心贡献：提出 AdaCoM，一个训练外部 LLM 来管理冻结 Agent 上下文的框架，通过端到端强化学习实现灵活的上下文修改动作，无需修改目标 Agent 本身，对闭源 Agent 友好。揭示了 Fidelity-Reliability Trade-off：高能力 Agent 需要高保真度上下文保留，而低能力 Agent 则需要更激进的压缩策略。
🔧 技术亮点：
- **外部上下文管理器**：用独立的 RL 训练 LLM 管理冻结 Agent 的上下文，无需针对每个 Agent 重新训练，大幅降低适配成本
- **Fidelity-Reliability Trade-off**：系统性发现不同能力 Agent 所需的最优压缩策略不同，为上下文压缩提供了新的理论指引
- **跨 Agent 迁移**：迁移实验表明 AdaCoM 在能力相近的 Agent 间泛化效果最好，暗示了构建通用上下文管理器的可行路径
📊 实验结果：在 web search 和 deep research 基准上跨多样化 Agent 显著提升任务性能，策略学习揭示了压缩与任务约束保留之间的系统性规律
🧩 技术分类：Context维度：**上下文压缩 + 上下文管理**
🔗 Memory ↔ Context 关联：AdaCoM 本质是将 Agent 的工作记忆（working context）外包给一个专用管理 LLM，通过动态裁剪实现长时序任务中的记忆-上下文高效协同

📄 **IndexMem：基于潜在记忆的可学习 KV 缓存淘汰**（IndexMem: Learned KV-Cache Eviction with Latent Memory for Long-Context LLM Inference）
🔗 https://arxiv.org/abs/2605.25475
💡 核心贡献：引入可学习的 KV 重要性预测器（indexer）精准保留关键 token，同时设计轻量化潜在记忆模块（latent memory module）压缩被淘汰 token 为紧凑在线状态，以残差读出补偿注意力损失，彻底解决传统 KV 淘汰导致的不可逆遗忘问题。
🔧 技术亮点：
- **可学习 KV 索引器**：打破启发式淘汰策略的局限，通过学习预测 token 重要性分布，实现依赖输入内容的动态精准淘汰决策
- **在线潜在记忆模块**：将被淘汰的 token 压缩为紧凑的连续状态向量，提供残差注意力补偿，防止长程检索退化
- **预算约束下的稳定推理**：在有界 KV 预算内保持长上下文推理精度，在 Qwen/Mistral/Llama 系列模型上均有提升
📊 实验结果：在 RULER (4K/16K) 上相对 heuristic 基线提升最高 25 分；Needle-in-a-Haystack 检索明显更稳定；LongBench 各指标及压缩曲线均优于现有淘汰策略
🧩 技术分类：Memory维度：**工作记忆**；Context维度：**长窗口扩展 + 上下文压缩**
🔗 Memory ↔ Context 关联：将 KV 缓存显式建模为一种有界"工作记忆"，潜在记忆模块扮演记忆的"压缩留存"角色，直接连接了记忆遗忘与上下文窗口效率的核心矛盾

📄 **AgeMem：通过强化学习统一学习长短期记忆管理**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885
💡 核心贡献：提出 AgeMem，将 LTM 和 STM 管理直接集成进 Agent 策略，将记忆操作（存储、检索、更新、摘要、遗忘）暴露为工具调用动作，通过三阶段渐进式强化学习（Step-wise GRPO）训练 Agent 自主决策记忆行为，彻底摒弃启发式规则与辅助控制器。
🔧 技术亮点：
- **工具化记忆操作**：将 store/retrieve/update/summarize/discard 建模为 Agent 可调用的工具动作，使记忆管理成为端到端可优化的策略组成部分
- **三阶段渐进 RL 训练**：解决记忆操作引发的稀疏与非连续奖励问题，通过 Step-wise GRPO 实现对记忆行为的精细训练信号
- **LTM+STM 统一框架**：打破传统 LTM/STM 分治设计，允许 Agent 根据任务需求动态在长短期记忆间协调分配
📊 实验结果：在五个长时序基准上一致优于强记忆增强基线，多个 LLM backbone 下均实现更高任务成功率、更高质量长期记忆与更高效上下文利用
🧩 技术分类：Memory维度：**情景记忆 + 工作记忆 + 记忆检索**
🔗 Memory ↔ Context 关联：通过工具化记忆操作动态调控哪些历史信息进入上下文窗口，实现了 Memory 与 Context 之间的端到端 RL 协同优化

📄 **xMemory：超越 RAG，基于解耦聚合的 Agent 记忆检索**（Beyond RAG for Agent Memory: Retrieval by Decoupling and Aggregation）
🔗 https://arxiv.org/abs/2602.02007
💡 核心贡献：指出标准 RAG 的 flat top-k 检索不适合 Agent 记忆场景——交互流中存在大量强相关或近重复片段导致冗余。提出"先解耦再聚合"原则：从相似历史中先隔离可复用事实、更新与区分细节，再构建层次记忆结构（消息→片段→记忆组件→组），支持自顶向下的高效增量检索。
🔧 技术亮点：
- **解耦聚合原则**：先从原始交互序列提取细粒度记忆组件，再通过稀疏-语义忠实度目标聚合为高层组，减少冗余同时保留区分性细节
- **可修订层次记忆结构**：支持增量更新，记忆随交互演化自动维护，避免批量重建的开销
- **自顶向下检索策略**：先检索互补的组/组件骨干，再按需展开到片段和原始消息，仅在确有必要时才增加 token 消耗
📊 实验结果：在 LoCoMo 和 PerLTQA 跨开源/闭源 LLM 上一致提升答案质量和推理 token 效率，冗余度分析和证据密度分析均支持方法有效性
🧩 技术分类：Memory维度：**情景记忆 + 记忆检索 + 外部存储**
🔗 Memory ↔ Context 关联：xMemory 通过自顶向下的层次检索精准控制注入上下文的记忆粒度，直接优化了"记忆密度 vs 上下文长度"的权衡

📄 **ACON：面向长时序 LLM Agent 的上下文压缩优化**（ACON: Optimizing Context Compression for Long-horizon LLM Agents）
🔗 https://arxiv.org/abs/2510.00615
💡 核心贡献：提出 Agent Context Optimization (ACON) 统一框架，在自然语言空间中迭代优化上下文压缩准则，通过分析 Agent 失败案例精炼压缩指导原则，无需参数更新即可适配闭源/大规模 LLM，并通过蒸馏小模型降低计算开销。已被 ICML 2026 接收。
🔧 技术亮点：
- **自然语言空间优化**：压缩准则以自然语言形式表达和迭代精炼，基于失败分析反馈，无需模型微调即可持续改进
- **压缩器蒸馏**：将优化后的压缩准则蒸馏进小型 LM 充当轻量压缩器，大幅降低长时序 Agent 的推理开销
- **统一观测+历史压缩**：同时压缩环境观测和交互历史，覆盖上下文增长的两个主要来源
📊 实验结果：在 AppWorld、OfficeBench、Multi-objective QA 上 token 峰值用量减少 26-54%，同时提升任务成功率；小型 LM 作为 Agent 时性能提升最高 46%（ICML 2026）
🧩 技术分类：Context维度：**上下文压缩 + 上下文管理**
🔗 Memory ↔ Context 关联：ACON 通过语言空间的失败反馈将 Agent 的任务记忆（关键状态信息）高效压缩进受限上下文，本质是面向行动的记忆蒸馏

## 🧠 今日洞察

1. **记忆层次化与结构化成为新共识**：从 AutoSci 的 LTM/活跃记忆分离，到 xMemory 的解耦聚合层次结构，再到 AgeMem 的工具化统一框架，今日论文共同指向一个趋势——扁平化、启发式的记忆管理正被结构感知、可演化的层次体系所取代。

2. **上下文压缩从"启发式"走向"可学习"**：ACON 的自然语言空间优化、AdaCoM 的 RL 训练外部管理器、IndexMem 的可学习 KV 索引器，三条并行路线共同推动上下文压缩摆脱脆弱规则，向数据驱动的自适应方向演进，且均注重无需目标模型微调的实用性。

3. **Memory ↔ Context 协同设计正成为核心命题**：AgeMem 通过 RL 端到端优化记忆-上下文决策、AdaCoM 将工作上下文管理外包给专用模型、IndexMem 用潜在记忆补偿 KV 淘汰损失——研究者越来越将"什么进入记忆"与"什么注入上下文"视为一个联合优化问题而非两个独立模块，记忆与上下文的边界正在被重新定义。
