### 1️⃣

📄 **[LongMemEval-V2：面向"经验同事"的长期 Agent 记忆评测基准]**
（LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues）

🔗 https://arxiv.org/abs/2605.12493

💡 **核心贡献**
本文提出 LongMemEval-V2（LME-V2），一个专门评估 Agent 能否将 Web 环境操作经验内化为长期记忆的基准，包含 451 个手工问题，覆盖高达 115M tokens 的交互历史。同时提出两种记忆方法 AgentRunbook-R（RAG 知识池方案）和 AgentRunbook-C（代码 Agent + 沙箱方案），其中 AgentRunbook-C 以 72.5% 准确率大幅超越 RAG 基线（48.5%）。

🔧 **技术亮点**
- 定义五类核心记忆能力：静态状态回溯、动态状态跟踪、工作流知识、环境陷阱识别、前提意识
- AgentRunbook-C 将完整交互轨迹存为文件，调用编码 Agent 在增强沙箱中主动检索证据，超越纯检索方案
- 引入"上下文收集范式"：记忆系统消耗历史轨迹后返回紧凑证据供下游 QA 使用

📊 **实验结果**
- AgentRunbook-C：72.5% 平均准确率（vs RAG 基线 48.5%，off-the-shelf 代码 Agent 69.3%）
- 测试集含最多 500 条轨迹 / 115M tokens，是目前规模最大的 Agent 记忆评测集

🧩 **技术分类**
Memory 维度：情景记忆 / 外部存储 / 记忆检索
Context 维度：上下文管理

🔗 **Memory ↔ Context 关联**
通过将 115M tokens 的历史上下文压缩为结构化知识池，直接打通"长期记忆存储"与"当前上下文利用"的闭环。

### 2️⃣

📄 **[仿人脑记忆架构：面向 LLM Agent 的六机制生物启发系统]**
（Human-Inspired Memory Architecture for LLM Agents）

🔗 https://arxiv.org/abs/2605.08538

💡 **核心贡献**
提出包含六大认知机制的生物接地记忆架构，覆盖睡眠期记忆巩固、干扰遗忘、印记成熟、提取再巩固、实体知识图谱和混合多线索检索，系统性地解决了朴素记忆累积的各类失效模式。在 LongMemEval 个人对话基准上，M 级评估（475 session，540K+ 轮）达到与原始检索相当精度（70.1% vs 71.2%）的同时将存储量减少 58%。

🔧 **技术亮点**
- 睡眠期去重巩固（sleep-phase consolidation）：实现 97.2% 保留精度 + 58% 存储压缩
- 实体知识图谱作为语义记忆层，与情景记忆互补
- 合成校准方法（synthetic calibration）：无需暴露基准数据即可推导流水线阈值，消除评估泄露

📊 **实验结果**
- VSCode issue 跟踪数据集（13K 条/120K 事件）：去重巩固精度 97.2%，存储减少 58%（+21.8pp vs 基线）
- S 级评估（50 sessions）：偏好召回 +13.3pp

🧩 **技术分类**
Memory 维度：情景记忆 / 语义记忆 / 记忆检索 / 外部存储

🔗 **Memory ↔ Context 关联**
通过记忆巩固机制，将历史会话压缩为实体图谱+印记，大幅减少注入当前上下文的 token 量，实现记忆质量与上下文效率的双重提升。

### 3️⃣

📄 **[MemReread：基于记忆引导重读的 Agent 长上下文推理增强]**
（Enhancing Agentic Long-Context Reasoning via Memory-Guided Rereading）

🔗 https://arxiv.org/abs/2605.10268

💡 **核心贡献**
提出 MemReread 框架，解决流式阅读范式中记忆覆写导致的间接证据丢失问题。当最终记忆不足以回答问题时，触发问题分解并重读原始上下文，无需中间检索模块即可恢复被提前丢弃的事实；配合强化学习框架动态决定重读次数，在线性时间复杂度下实现非线性推理。

🔧 **技术亮点**
- 绕过中间检索（circumvents intermediate retrieval），避免无效查询引入的噪声干扰
- 问题分解 + 靶向重读：仅在最终记忆不足时触发，按需控制计算开销
- RL 框架赋能长度外推（length extrapolation），动态调整重读轮次

📊 **实验结果**
- 在多个长上下文推理基准上一致超越基线框架，同时保持线性时间复杂度

🧩 **技术分类**
Memory 维度：工作记忆 / 记忆检索
Context 维度：长窗口扩展 / 上下文管理

🔗 **Memory ↔ Context 关联**
将工作记忆的不足直接映射为上下文重读触发信号，实现记忆状态与原始上下文之间的按需动态桥接。

### 4️⃣

📄 **[第一滴墨水效应：误导性信息对长上下文推理的非线性冲击]**
（The First Drop of Ink: Nonlinear Impact of Misleading Information in Long-Context Reasoning）

🔗 https://arxiv.org/abs/2605.10828

💡 **核心贡献**
在 RAG 与 Agent 场景中系统研究"干扰文档比例"与"推理性能"的定量关系，发现显著的非线性规律：极少量（<5%）的强干扰文档即可造成性能大幅下降，但后续增加干扰的边际损失很小。这一"第一滴墨水效应"为优化检索精度提供了理论依据。

🔧 **技术亮点**
- 基于注意力力学的理论分析：少量干扰文档以不成比例的方式抢占注意力权重
- 发现过滤性能提升主要来自上下文长度压缩而非干扰文档移除本身
- 指出恢复性能需将干扰比例降至接近零，强调上游检索精度的关键性

📊 **实验结果**
- 固定长度上下文下，5% 以下硬干扰导致的性能下跌占全程下跌量的绝大部分
- 上下文过滤的收益主要来自 token 数量减少（信息密度提升）

🧩 **技术分类**
Memory 维度：记忆检索
Context 维度：上下文管理 / 上下文压缩

🔗 **Memory ↔ Context 关联**
揭示检索阶段噪声（记忆维度）如何通过注意力机制污染整个上下文窗口（Context 维度），为"精准检索 → 干净上下文"的协同优化路径提供实证支撑。

### 5️⃣

📄 **[ACON：面向长时程 LLM Agent 的上下文压缩优化框架]**
（ACON: Optimizing Context Compression for Long-Horizon LLM Agents）

🔗 https://arxiv.org/abs/2510.00615

💡 **核心贡献**
ACON（Agent Context Optimization）是一个统一压缩框架，通过自然语言空间中的压缩指南优化（compression guideline optimization），将环境观测和交互历史同时压缩为简洁但信息丰富的凝缩表示；支持将优化后的压缩器蒸馏到更小模型，在减少 26-54% 峰值 token 的同时保持任务性能，并已被 ICML 2026 收录。

🔧 **技术亮点**
- 对比成功/失败轨迹对进行压缩指南优化，形成自适应压缩策略
- 压缩器蒸馏：将大 LLM 压缩器知识迁移到小模型，减少额外模块开销
- 跨环境验证：AppWorld、OfficeBench、Multi-objective QA 三类长时程任务

📊 **实验结果**
- 峰值 token 减少 26-54%，任务性能基本不变
- 蒸馏后小模型保留 >95% 精度；小 LM 作为长时程 Agent 性能提升最高 46%

🧩 **技术分类**
Context 维度：上下文压缩 / 上下文管理

🔗 **Memory ↔ Context 关联**
将 Agent 的动作-观测历史（外部存储）实时压缩为精简上下文，直接连接 Agent 记忆积累与当前上下文窗口预算。

### 6️⃣

📄 **[FRACTAL：用于长序列计算时序分析的分数阶循环架构]**
（SSM with Fractional Recurrent Architecture for Computational Temporal Analysis of Long Sequences）

🔗 https://arxiv.org/abs/2605.08833

💡 **核心贡献**
提出 FRACTAL，将分数阶测度理论引入状态空间模型（SSM）的递归记忆更新机制中，通过可调奇异性指数（singularity index）在保留长程尺度不变记忆的同时增强对近期信号扰动的敏感性，解决了 HiPPO 算子在均匀测度（淡化近期）与指数测度（丢失全局）之间的根本权衡。已被 ICML 2026 收录。

🔧 **技术亮点**
- 分数阶投影算子：同时具备尺度不变谱结构（长程全局记忆）与高奇异性近期敏感度
- 对角化状态空间框架实例化：通过调制输入投影初始化，无需修改整体架构
- 多尺度时序特征的线性复杂度捕获，适合超长序列

📊 **实验结果**
- Long Range Arena 平均 87.11%（ListOps 61.85%），超越 S5 模型
- ICML 2026 正式论文（19 页）

🧩 **技术分类**
Memory 维度：工作记忆
Context 维度：长窗口扩展

🔗 **Memory ↔ Context 关联**
以循环记忆状态替代 Transformer 的显式上下文窗口，通过分数阶记忆更新在线性上下文开销下保留任意长度历史。

## 🧠 今日洞察

1. **生物启发 × 工程落地**：本周最显著趋势是 Memory 设计的"认知科学化"——从睡眠期巩固、印记成熟到再巩固，研究者正系统地将神经科学记忆模型映射到 LLM Agent 架构中，不再满足于简单的向量数据库检索。

2. **评测驱动创新**：LongMemEval-V2 将 Agent 记忆评测推至 115M tokens 规模并引入"环境经验内化"新维度，表明社区正从"能检索"迈向"能像有经验的同事一样工作"——这将倒逼记忆系统从被动存取走向主动学习与经验蒸馏。

3. **Memory ↔ Context 协同设计的最新进展**：ACON 的压缩指南优化与 MemReread 的按需重读，代表两种截然不同的 Memory-Context 协同路径——前者在写入时压缩（减小上下文），后者在读取时扩展（按需回溯原始上下文）；而"第一滴墨水效应"则揭示了检索精度对 Context 质量的非线性影响，提示未来的协同优化应把上游记忆检索精度置于核心位置。
