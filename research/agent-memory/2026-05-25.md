### 1. 经验图驱动的自演化 Agent
**（EXG: Self-Evolving Agents with Experience Graphs）**

🔗 https://arxiv.org/abs/2605.17721
**作者：** Yuxin Jin, Siyuan Zhang, Hanchen Wang 等（2026-05-17）

💡 **核心贡献**
大多数 LLM Agent 在部署后仍是静态的，既有反思机制局限于单任务纠错，也缺乏结构化经验管理。EXG 首次将 Agent 的历史成功/失败经验组织为结构化的关系图（Experience Graph），实现跨任务的在线实时增长与离线复用。

🔧 **技术亮点**
- 双模式图管理：**在线模式**（部署期实时图扩展，即时跨任务复用）＋**离线模式**（会话间持久化图作为外部记忆模块）
- 即插即用设计（plug-and-play），可叠加于现有自演化 Agent 框架之上，无需改动底层策略
- 在代码生成与推理基准上，相比基于反思和基于记忆的基线，实现更优的性能-效率 trade-off

📊 **实验结果**
在代码生成与推理基准上，在线与离线双模式均优于反思类（reflection-based）和记忆类（memory-based）基线；结构化图相比非结构化累积记忆更能提升解决方案质量和资源效率。

🧩 **技术分类**
Memory维度：情景记忆 / 外部存储 / 记忆检索（经验图结构化存储+跨任务检索）

🔗 **Memory ↔ Context 关联**
将碎片化对话上下文外化为结构化经验图，根本解决了上下文窗口无法积累跨会话经验的困境。

### 2. 可执行 Agent 记忆：GUI Agent 的知识图谱规划
**（EAM: Executable Agentic Memory for GUI Agent）**

🔗 https://arxiv.org/abs/2605.12294
**作者：** Zerui Qin, Sheng Yue, Xingyuan Hua, Yongjian Fu, Ju Ren（2026-05-12）

💡 **核心贡献**
传统 GUI Agent 基于"模型中心+逐步决策"范式，在长视界任务中因上下文重复解析而性能脆弱。EAM 将 GUI 规划从自由生成转换为**结构化知识图谱的检索-执行**过程，使经验记忆直接成为可执行策略。

🔧 **技术亮点**
- 状态感知 DFS ＋ action-group mining 构建样本高效的记忆管线，将多步操作压缩为可复用图节点
- 轻量级 Q-function 模型引导 MCTS（蒙特卡洛树搜索）在知识图谱上执行值引导图搜索
- 理论建立 Q-model 的偏差一致性和路径恢复的样本复杂度界（bias-consistency bounds）

📊 **实验结果**
在 AndroidWorld 上比 UI-TARS-7B 提升最高 **19.6%**；相对 GPT-4o token 成本降低 **6×**；平均延迟仅 **2.8s**。

🧩 **技术分类**
Memory维度：外部存储 / 记忆检索（KG 结构化记忆 + MCTS 检索规划）

🔗 **Memory ↔ Context 关联**
以结构化知识图谱替代冗余上下文历史，将"上下文中的操作记录"转化为"图中的可复用知识路径"。

### 3. 目标导向的 RAG 记忆推理框架
**（Goal-Mem: Goal-Oriented Reasoning for RAG-based Memory）**

🔗 https://arxiv.org/abs/2605.12213
**作者：** Jiazhou Liang, Armin Toroghi, Yifan Simon Liu 等（2026-05-12）

💡 **核心贡献**
现有 RAG 记忆系统依赖原始话语的语义相似度检索，缺乏对缺失中间事实的显式推理，常返回不相关或不充分的证据。Goal-Mem 提出**目标导向逆向推理链**：将用户话语作为目标，分解为原子子目标，对每个子目标进行定向记忆检索，并用 Natural Language Logic 形式化整个推理过程。

🔧 **技术亮点**
- **目标分解**：将用户话语目标逆向分解为原子子目标列表，驱动定向检索而非盲目语义匹配
- **Natural Language Logic（NLL）**：结合一阶逻辑（FOL）的可验证性与自然语言的表达力，推理路径可审计
- **迭代缺口识别**：当中间子目标无法从已检索记忆中解决时，触发进一步检索，闭环推进

📊 **实验结果**
在两个对话记忆数据集上对比 9 个强基线，在多跳推理和隐式推断任务上显著领先。

🧩 **技术分类**
Memory维度：记忆检索（目标驱动逆向链式检索）；Context维度：In-Context学习（推理增强的上下文利用）

🔗 **Memory ↔ Context 关联**
通过目标驱动的推理链决定"哪些记忆值得进入上下文"，实现从语义相关性到任务相关性的检索范式升级。

### 4. 混合神经符号记忆系统：可持久、可审计的 LLM Agent 记忆
**（NeuSymMS: A Hybrid Neuro-Symbolic Memory System for Persistent, Self-Curating LLM Agents）**

🔗 https://arxiv.org/abs/2605.17596
**作者：** Mujahid Sultan, Sri Thuraisamy, Daya Rajaratnam（2026-05-17）

💡 **核心贡献**
NeuSymMS 提出混合神经符号架构，使 LLM Agent 能够跨会话持久化存储、自策展（self-curate）和推理记忆，同时避免上下文膨胀（context-window bloat）和跨实体污染。结合神经事实提取（LLM）与符号规则推理（CLIPS 专家系统），实现可信、可审计的生产级记忆。

🔧 **技术亮点**
- 神经路径：LLM 从非结构化对话中提取事实；符号路径：CLIPS 专家系统对事实进行分类、去重、生命周期管理
- 知识以 **subject-relation-value 三元组**存储于关系数据库，支持 user/agent/agent-to-agent 多范围隔离
- 双时域模型（short-term + long-term）：基于访问频率晋升（access-based promotion）和时间剪枝（time-based pruning）

📊 **实验结果**
与日志检索、摘要压缩和 key-value 记忆方案相比，在可持久性、可审计性、跨实体隔离方面均有优势（论文提供定性对比分析）。

🧩 **技术分类**
Memory维度：语义记忆 / 外部存储（三元组知识库 + 双时域管理）

🔗 **Memory ↔ Context 关联**
通过符号规则动态剪枝过期记忆，确保注入上下文的记忆始终精简有效，从源头控制 context-window bloat。

### 5. 轻量级在线状态记忆：无需微调的注意力增强
**（δ-mem: Efficient Online Memory for Large Language Models）**

🔗 https://arxiv.org/abs/2605.12357
**作者：** Jingdi Lei, Di Zhang, Junxian Li 等（2026-05-12）

💡 **核心贡献**
不依赖外部检索，也不扩展上下文窗口，δ-mem 在冻结的全注意力 backbone 上附加一个极紧凑的关联记忆状态矩阵（仅 8×8），通过 delta-rule 学习将历史信息压缩为固定大小状态，并在生成时以低秩修正耦合注意力计算。这是一条无需微调即可为 LLM 注入"工作记忆"的新路线。

🔧 **技术亮点**
- 固定大小 **8×8 在线状态矩阵**，内存开销极小，可插入冻结 backbone 而无需参数更新
- delta-rule 更新规则：每个 token 处持续写入，读出时生成低秩修正向量直接作用于注意力
- 通用能力几乎不受影响（非记忆密集型任务保持稳定），专攻记忆密集型任务提升显著

📊 **实验结果**
MemoryAgentBench：相比 backbone 提升 **1.31×**；LoCoMo：提升 **1.20×**；平均综合提升 **1.10×**（vs 最强非 δ-mem 基线 **1.15×**）

🧩 **技术分类**
Memory维度：工作记忆（参数化在线关联状态，类工作记忆机制）；Context维度：上下文压缩（隐式压缩历史信息为固定状态）

🔗 **Memory ↔ Context 关联**
δ-mem 以参数化状态替代显式上下文历史，将"上下文中的记忆"内化为注意力修正，实现了 Memory 与 Context 的深度融合。

### 6. Agent 上下文优化：长视界任务的统一压缩框架
**（ACON: Optimizing Context Compression for Long-horizon LLM Agents）**

🔗 https://arxiv.org/abs/2510.00615
**作者：** Minki Kang 等（Microsoft，ICML 2026）

💡 **核心贡献**
针对 Agent 在长视界任务中上下文不断膨胀的挑战，ACON 提出统一压缩框架，同时压缩环境观测（observations）和交互历史（histories），并通过自然语言空间中的压缩指导优化（compression guideline optimization）动态调整压缩策略。

🔧 **技术亮点**
- 压缩指导优化（CGO）：给定"完整上下文成功/压缩上下文失败"的对比轨迹，让强 LLM 分析失败原因并更新压缩指导
- 知识蒸馏路径：将优化后的 LLM 压缩器蒸馏为小型模型，降低额外模块开销，小模型保留 **>95%** 准确率
- 不依赖参数更新或特定 backbone，对闭源/大规模 LLM 友好

📊 **实验结果**
AppWorld / OfficeBench / Multi-objective QA 上：内存占用（peak tokens）减少 **26-54%**，任务性能基本保持；小型 LM 在长视界 Agent 任务上性能提升最高 **46%**

🧩 **技术分类**
Context维度：上下文压缩 / 上下文管理（观测+历史双路统一压缩）

🔗 **Memory ↔ Context 关联**
通过动态压缩策略让 Agent 的外部记忆（交互历史）始终维持可用的上下文长度，形成"压缩即记忆管理"的协同设计。

## 🧠 今日洞察

1. **记忆系统正从"检索增强"向"结构化经验"演进**：本周最显眼的趋势是 EXG、EAM 等工作将 Agent 历史经验从扁平向量检索升级为结构化图（关系图/知识图谱），知识图谱已成为 Agent 长期记忆的主流载体，提供了更强的跨任务泛化与可解释性。

2. **Memory 与 Context 的协同设计出现两种范式分化**：一方面是以 δ-mem 为代表的"内化路线"——将历史压缩为参数化状态直接耦合注意力，无需外部存储；另一方面是以 ACON 为代表的"外化压缩路线"——通过主动压缩控制上下文长度，守住外部记忆系统的可用边界。两条路线反映了"记忆住在哪里"这一根本设计决策。

3. **Agent Memory 安全与可审计性成新兴议题**：NeuSymMS 的符号规则记忆管理，以及"Remembering More, Risking More"等论文共同指向一个新关切——随着记忆系统越来越强大，如何在持久化、跨会话记忆的同时，保持可审计性（auditability）、隔离性（scoping）和安全边界，将是下一阶段 Agent Memory 研究的重要方向。
