📄 **PEEK：长上下文 LLM Agent 的方向缓存上下文地图**（Context Map as an Orientation Cache for Long-Context LLM Agents）
🔗 https://arxiv.org/abs/2605.19932
💡 **核心贡献**：提出 PEEK 系统，通过缓存"方向性知识"（orientation knowledge）作为固定大小的上下文地图，使 LLM Agent 在重复操作同一外部上下文时积累可复用的结构化索引。该系统让 Agent 在多次调用中持续 peek 外部上下文，无需每次重新探索，有效压缩上下文使用并提升推理效率。
🔧 **技术亮点**：
- 三级缓存管道：Distiller（提取推理时信号中的可迁移知识） → Cartographer（结构化编辑成上下文地图） → Evictor（基于优先级的 token 预算淘汰）
- 缓存 artifact 大小固定，可无缝嵌入 Agent prompt，兼容多种 LM 和 Agent 架构
- 相比 SOTA 的 prompt-learning 框架 ACE，成本降低 1.7–5.8x，在上下文学习任务上迭代次数减少 93–145 次
📊 **实验结果**：在长上下文推理与信息聚合任务上相比强基线提升 6.3–34.0%；上下文学习任务提升求解率 6.0–14.0%、rubric 准确率 7.8–12.1%；在 OpenAI Codex 等生产级 Agent 上验证有效性
🧩 **技术分类**：
- Memory维度：语义记忆 / 外部存储 / 记忆检索
- Context维度：上下文压缩 / 上下文管理
🔗 **Memory ↔ Context 关联**：将外部上下文中的结构性知识蒸馏为可复用的紧凑缓存，本质上是在 Context 窗口内构建持久化的语义记忆索引，实现"记忆即上下文摘要"。

📄 **ReBel：奖励信念而非行动——长时序 Agent 的一致性引导信用分配**（Rewarding Beliefs, Not Actions: Consistency-Guided Credit Assignment for Long-Horizon Agents）
🔗 https://arxiv.org/abs/2605.20061
💡 **核心贡献**：提出 ReBel 算法，在部分可观测环境中显式建模结构化信念状态（structured belief states）来总结交互历史，将预测信念与实际观测的差异转化为密集的自监督信号，从根本上解决长时序 Agent 的时序信用分配难题。
🔧 **技术亮点**：
- 信念一致性监督（Belief-Consistency Supervision）：无需外部逐步标注，利用"预测信念 vs 实际反馈"的偏差自动生成训练信号
- 信念感知分组（Belief-Aware Grouping）：在相似信念状态下比较轨迹，获得更鲁棒、低方差的优势估计
- 过程级 RL 算法，在 GRPO episode-level baseline 之上引入信念状态作为中间监督层
📊 **实验结果**：在 ALFWorld 和 WebShop 长时序基准上，任务成功率比 GRPO 基线提升最高 20.4 个百分点，样本效率提升 2.1×
🧩 **技术分类**：
- Memory维度：工作记忆 / 情景记忆（信念状态作为压缩的情景记忆表示）
- Context维度：上下文管理 / In-Context学习
🔗 **Memory ↔ Context 关联**：将历史交互的情景记忆压缩为结构化信念状态，作为上下文的精炼替代物注入策略学习，实现"记忆驱动上下文压缩"闭环。

📄 **MINTEval：长时序 Agent 系统的多目标干扰记忆评测基准**（Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems）
🔗 https://arxiv.org/abs/2605.18565
💡 **核心贡献**：提出 MINTEval 基准，填补现有评测只关注静态独立召回的空白，专注于现实世界中"信息频繁更新且相互干扰"的动态长时序场景，系统评估记忆增强 Agent 在干扰密集环境下的表现。
🔧 **技术亮点**：
- 覆盖 4 个领域：状态追踪、多轮对话、Wikipedia 修订、GitHub 提交，评估领域泛化能力
- 两类问题类型：单目标召回（从长上下文检索特定目标）+ 多目标聚合（跨多条证据推理）
- 共 15,600 个 QA 对，平均上下文长度 138,800 tokens，最长可达 1.8M tokens
📊 **实验结果**：评估 7 个代表性系统（含 vanilla 长上下文 LLM、RAG、记忆增强 Agent），平均准确率仅 27.9%；多目标聚合任务表现尤其差；性能瓶颈主要在检索与记忆构建阶段
🧩 **技术分类**：
- Memory维度：情景记忆 / 记忆检索（评测视角）
- Context维度：长窗口扩展 / 上下文管理
🔗 **Memory ↔ Context 关联**：揭示长上下文中"信息干扰"是记忆系统失效的核心原因，即上下文长度扩展与记忆检索精度存在根本性张力。

📄 **KoRe：面向 LLM 的紧凑知识表示**（KoRe: Compact Knowledge Representations for Large Language Models）
🔗 https://arxiv.org/abs/2605.20170
💡 **核心贡献**：提出 KoRe 方法，将知识图谱的 1-hop 子图编码为紧凑离散知识 token 并注入 LLM，无需大规模重训练或 fine-tuning 即可为模型提供可更新的外部知识支撑。
🔧 **技术亮点**：
- 将 KG 1-hop 子图压缩为离散 knowledge token，直接注入 LLM backbone prompt
- token 使用量相比传统文本 KG 注入方式减少最高 10×
- 支持知识的独立更新（修改 KG 而无需重训 LLM），克服参数化知识的不透明性与幻觉问题
📊 **实验结果**：在三个知识密集型 QA 基准上取得与全量 fine-tuning 相当的竞争性性能，同时 token 效率大幅提升
🧩 **技术分类**：
- Memory维度：语义记忆 / 外部存储
- Context维度：上下文压缩
🔗 **Memory ↔ Context 关联**：将外部知识图谱压缩为离散 token 注入上下文，是"外部语义记忆→上下文效率压缩"路径的典型实现。

📄 **BalanceRAG：级联 RAG 的联合风险校准**（BalanceRAG: Joint Risk Calibration for Cascaded Retrieval-Augmented Generation）
🔗 https://arxiv.org/abs/2605.20084
💡 **核心贡献**：为级联 RAG 系统开发 BalanceRAG 框架，通过二维格上的序贯图检验联合校准 LLM-only 与 RAG 两路的不确定性阈值对，实现在目标风险约束下最大化检索效率。
🔧 **技术亮点**：
- 将级联 RAG 的阈值校准问题形式化为二维格上的联合优化，突破逐级校准的保守性
- 序贯图检验（Sequential Graphical Testing）识别安全操作点，控制系统级错误率
- 支持多风险联合校准，同时约束选择条件风险与检索调用频率
📊 **实验结果**：在三个开放域 QA 基准（多 LLM backbone）上，在满足设定风险水平的前提下，覆盖率更高、正确样本保留更多、不必要检索调用更少
🧩 **技术分类**：
- Memory维度：记忆检索（检索决策优化）
- Context维度：上下文管理
🔗 **Memory ↔ Context 关联**：通过智能化的检索决策门控，避免将冗余检索内容注入上下文，实现"按需记忆召回"以节省上下文预算。

📄 **AutoResearchClaw：人机协作的自强化自主研究系统**（AutoResearchClaw: Self-Reinforcing Autonomous Research with Human-AI Collaboration）
🔗 https://arxiv.org/abs/2605.20025
💡 **核心贡献**：提出多 Agent 自主科研管线，核心创新是跨轮演化（cross-run evolution）机制，将过去实验中的错误和经验结构化存储，作为"防错记忆"指导未来的研究行为，实现跨会话的情景记忆积累。
🔧 **技术亮点**：
- Cross-run evolution：将历史错误显式转化为未来运行的"负样本防护知识"，而非依赖 RAG 的语义匹配
- 多 Agent 架构（含 Hypothesis Generator、Experiment Executor、Memory Manager 等专职角色）
- 与人类研究者协作接口，支持人工注入领域先验到记忆系统
📊 **实验结果**：在 ARC-Bench 上比 AI Scientist v2 高出 54.7%，体现了跨轮记忆演化对科学推理任务的显著提升
🧩 **技术分类**：
- Memory维度：情景记忆 / 外部存储（跨会话错误记忆库）
- Context维度：上下文管理
🔗 **Memory ↔ Context 关联**：跨会话积累的错误情景记忆在新轮次中被选择性地注入上下文作为"避坑指引"，是情景记忆→上下文增强的直接应用。

## 🧠 今日洞察

1. **从"存什么"转向"怎么压缩/缓存"**：今日三篇代表作（PEEK、KoRe、BalanceRAG）均聚焦于记忆的效率表示与选择性召回，而非记忆容量的扩充，标志着领域从"记忆覆盖率"向"记忆精准度与成本效率"的范式转移。

2. **信念状态正在成为 Memory 与 Context 的理论桥梁**：ReBel 将情景记忆压缩为结构化信念状态并作为 RL 训练信号，初步验证了"记忆即信念"框架的可行性；这一思路若与 KoRe 的离散 token 表示结合，有望产生可训练的内部化记忆机制。

3. **MINTEval 的低分警示（27.9% 均值）揭示 Memory × Context 协同设计的最大缺口**：现有系统在上下文超长、信息频繁更新时，记忆检索与上下文管理的协同严重失效；这预示着未来 Agent Memory 研究的核心战场将从单一的检索优化转向**干扰感知的记忆重构（interference-aware memory reconstruction）**。
