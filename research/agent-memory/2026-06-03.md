### 1. δ-mem：面向大语言模型的高效在线记忆机制

**（δ-mem: Efficient Online Memory for Large Language Models）**

🔗 https://arxiv.org/abs/2605.12357
📅 2026-05-12 | cs.AI

💡 **核心贡献**
在冻结的全注意力 backbone 上叠加一个极紧凑的关联记忆状态矩阵，通过 delta-rule 学习将历史信息压缩为固定大小状态，并以低秩修正的形式注入注意力计算，无需全量微调或上下文扩展即可实现有效记忆。

🔧 **技术亮点**
- 仅使用 8×8 的在线状态矩阵压缩所有历史信息，显存占用极小
- Delta-rule 学习机制实现流式更新，状态矩阵实时随生成过程演化
- 读出向量生成低秩修正直接作用于注意力权重，与 backbone 紧耦合

📊 **实验结果**
- MemoryAgentBench 上提升 **1.31×**，LoCoMo 上提升 **1.20×**
- 通用能力几乎不受影响（vs. 冻结 baseline 平均 1.10×）
- 显著超越同类非 δ-mem 记忆基线 1.15×

🧩 **技术分类**
Memory维度：工作记忆 / 参数化在线状态记忆

🔗 **Memory ↔ Context 关联**
δ-mem 以极小参数化状态替代上下文扩展，直接将历史信息编码进注意力计算，从"扩展上下文窗口"转向"压缩为记忆状态"，是 Memory 与 Context 协同的创新范式。

### 2. GUI Agent 的可执行 Agentic 记忆（EAM）

**（Executable Agentic Memory for GUI Agent）**

🔗 https://arxiv.org/abs/2605.12294
📅 2026-05-12 | cs.AI

💡 **核心贡献**
将 GUI Agent 的规划从自由文本生成转变为结构化知识图谱（KG）的检索-执行过程，用状态感知 DFS 和 action-group 挖掘构建可执行经验图谱，实现"记忆即程序"的范式创新。

🔧 **技术亮点**
- 状态感知 DFS + 动作组挖掘（action-group mining）构建样本高效的记忆图谱
- 轻量级 Q-function 模型引导 MCTS 在知识图谱上进行值引导搜索
- 理论上证明了 Q-model 的偏差一致性并推导路径恢复的样本复杂度界

📊 **实验结果**
- AndroidWorld 上比 UI-TARS-7B 最高提升 **19.6%**
- Token 成本相较 GPT-4o 降低 **6×**，平均延迟仅 **2.8s**

🧩 **技术分类**
Memory维度：情景记忆 / 外部存储 / 程序性记忆（可执行图谱）

🔗 **Memory ↔ Context 关联**
EAM 将多步历史经验压缩为可执行 KG 节点，彻底绕过上下文长度限制，以结构化外部存储代替冗长交互历史填充上下文窗口。

### 3. 对话式 Agent 系统中 RAG 记忆的目标导向推理（Goal-Mem）

**（Goal-Oriented Reasoning for RAG-based Memory in Conversational Agentic LLM Systems）**

🔗 https://arxiv.org/abs/2605.12213
📅 2026-05-12 | cs.AI

💡 **核心贡献**
提出 Goal-Mem 框架，以用户话语为目标进行显式逆向推理链：将目标分解为原子子目标，对每个子目标定向检索记忆，并迭代识别推理缺口，用自然语言逻辑（Natural Language Logic）融合 FOL 可验证性与自然语言表达力。

🔧 **技术亮点**
- 逆向推理链（backward chaining）：从目标出发分解子目标，而非从上下文出发扩展
- 自然语言逻辑（NLL）：结合一阶逻辑（FOL）的可验证性与自然语言的灵活性
- 迭代缺口识别：当子目标无法被当前检索满足时，自动触发二次检索

📊 **实验结果**
在两个数据集上对比9个强基线，在多跳推理和隐式推断任务上显著领先（具体数值见原文）

🧩 **技术分类**
Memory维度：外部存储 / 记忆检索；Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
Goal-Mem 通过目标驱动的检索策略，将 RAG 外部记忆与推理过程深度融合，减少了冗余检索结果对上下文的污染，实现"精准检索 → 精准上下文注入"的闭环。

### 4. AgeMem：统一长短期记忆管理的 Agentic 记忆框架

**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for LLM Agents）**

🔗 https://arxiv.org/abs/2601.01885
📅 2026-01-05（v2: 2026-04-30）| cs.CL

💡 **核心贡献**
将 LTM（长期记忆）和 STM（短期记忆）的管理统一集成进 Agent 策略本身，通过强化学习端到端训练记忆操作（存储/检索/更新/摘要/丢弃），避免依赖启发式或辅助控制器。

🔧 **技术亮点**
- 将记忆操作暴露为 tool-based actions，Agent 自主决策何时进行何种记忆操作
- 三阶段渐进式 RL 训练策略，解决记忆操作引发的稀疏非连续奖励问题
- 设计 step-wise GRPO 优化器应对不连续奖励信号

📊 **实验结果**
在五个长时序 benchmark 上持续优于强记忆增强基线，任务性能、LTM 质量、上下文使用效率均有提升

🧩 **技术分类**
Memory维度：情景记忆 / 语义记忆 / 工作记忆（统一管理）；Context维度：上下文管理

🔗 **Memory ↔ Context 关联**
AgeMem 通过强化学习训练 Agent 主动管理上下文中的信息保留与外存迁移，实现了 Memory 操作与上下文窗口的动态协同平衡。

### 5. MemoryArena：多会话 Agentic 任务中的 Agent 记忆评测框架

**（MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks）**

🔗 https://arxiv.org/abs/2602.16313
📅 2026-02-18 | cs.AI | ICML 2026 接收

💡 **核心贡献**
构建首个多会话 Memory-Agent-Environment 循环评测框架，任务中记忆与行动紧耦合——Agent 须从早期交互中提炼经验写入记忆，再凭记忆引导后续任务决策，填补了现有 benchmark 将记忆与行动割裂评估的空白。

🔧 **技术亮点**
- 人工精心设计的多会话 Agentic 任务，子任务之间显式相互依赖
- Memory-Agent-Environment 三方循环评估闭环
- 覆盖 Web 导航、偏好约束等多类 Agentic 场景

📊 **实验结果**
揭示当前所有顶级模型在多会话记忆利用上存在显著性能缺口（具体数据见原文）

🧩 **技术分类**
Memory维度：情景记忆 / 记忆检索 / 多会话记忆管理

🔗 **Memory ↔ Context 关联**
MemoryArena 的评测设计迫使 Agent 从有限上下文中提炼跨会话记忆，揭示了上下文窗口限制与长期任务记忆需求之间的深层矛盾。

### 6. 分类器上下文腐蚀：LLM 监控性能随上下文长度下降

**（Classifier Context Rot: Monitor Performance Degrades with Context Length）**

🔗 https://arxiv.org/abs/2605.12366
📅 2026-05-12 | cs.AI

💡 **核心贡献**
首次系统揭示"上下文腐蚀"（Context Rot）现象：当分类任务相关内容出现在超长上下文末尾时，顶级 LLM（Opus 4.6、GPT 5.4、Gemini 3.1）的漏报率相较短上下文提高 2-30 倍，现有评测严重高估长上下文分类能力。

🔧 **技术亮点**
- 在 >800K token 的 Agent 运行日志上系统评测分类性能衰减曲线
- 量化了 Opus 4.6、GPT 5.4、Gemini 3.1 三大前沿模型的"遗忘"程度
- 提出周期性提示（periodic reminders）作为缓解策略，验证 post-training 的改进空间

📊 **实验结果**
800K token 后危险行为漏报率提升 **2-30×**（视模型而异），周期性提示可部分缓解

🧩 **技术分类**
Context维度：长窗口扩展 / 上下文管理；Memory维度：工作记忆可靠性

🔗 **Memory ↔ Context 关联**
该工作从反面论证了"扩展上下文≠有效记忆"——超长上下文中的位置衰减效应直接说明外部记忆系统对长时序 Agent 的不可替代性。

## 🧠 今日洞察

**① 记忆架构正在从"外挂检索"转向"内外协同"：** δ-mem 和 AgeMem 分别从参数化状态记忆和 RL 统一管理两个角度，尝试将记忆操作深度融合进模型推理流程，而非仅依赖外部向量数据库检索，标志着 Agent Memory 从"工具化"向"内化"演进。

**② 检索策略从语义相似度转向目标驱动推理：** Goal-Mem 揭示了 RAG 系统"检索到但不够用"的根本缺陷，逆向推理链 + 自然语言逻辑的组合使记忆检索从被动匹配升级为主动推理，这对下一代对话 Agent 设计具有重要指导意义。

**③ Context Rot 现象为 Memory-Context 协同设计提供了最强理论动机：** 2605.12366 实验数据证明，仅靠扩大上下文窗口无法解决长时序任务的记忆问题；EAM、δ-mem、Goal-Mem 等工作则从不同技术路线给出了"外部结构化记忆 + 精准上下文注入"的协同方案，Memory 与 Context 的协同设计已成为 2026 年 Agent 研究的核心范式。
