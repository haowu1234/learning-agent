### 1️⃣

📄 **[从存储到经验：LLM Agent 记忆机制演化综述]**（From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms）
🔗 https://arxiv.org/abs/2605.06716
💡 **核心贡献**
提出全新三阶段演化框架，将 LLM Agent 记忆机制的发展路径形式化为 Storage（轨迹保存）→ Reflection（轨迹精炼）→ Experience（轨迹抽象）三个阶段，填补了操作系统工程与认知科学之间的理论鸿沟；同时重点探讨了前沿 Experience 阶段中的主动探索（proactive exploration）与跨轨迹抽象（cross-trajectory abstraction）两种变革性机制。
🔧 **技术亮点**
- 三阶段演化路径：Storage → Reflection → Experience，对应记忆从"存什么"到"怎么用"的质变
- 揭示演化的三大驱动力：长程一致性需求、动态环境挑战、持续学习终极目标
- 系统梳理跨轨迹抽象技术，为下一代 Agent 设计提供路线图
📊 **实验结果**（综述论文，无直接实验）
🧩 **技术分类**
Memory维度：情景记忆 / 语义记忆 / 外部存储 / 记忆检索（综合）
🔗 **Memory ↔ Context 关联**
三阶段框架指出 Reflection 阶段的核心是将原始 Context 轨迹精炼为结构化记忆，是 Memory 与 Context 协同设计的理论锚点。
*(ACL 2026 Findings 录用)*

### 2️⃣

📄 **[xMemory：超越 RAG 的 Agent 记忆——解耦与聚合式检索]**（Beyond RAG for Agent Memory: Retrieval by Decoupling and Aggregation）
🔗 https://arxiv.org/abs/2602.02007
💡 **核心贡献**
指出标准 RAG 与 Agent 记忆存在根本性不匹配——Agent 记忆是有界且相关性极高的交互流，而非大规模异质语料库；提出 xMemory 框架，通过"解耦优先于聚合"原则，构建可修订的层级记忆结构，实现高效且精准的 top-down 检索。
🔧 **技术亮点**
- 稀疏-语义忠实性目标（sparsity-semantics faithfulness objective）指导高层节点组织，避免语义漂移
- 四层层级结构：原始消息 → 片段 → 记忆组件 → 记忆群组，支持增量维护
- 推理时 top-down 检索，仅在读者不确定性下降时才展开至原始消息，大幅提升 token 效率
📊 **实验结果**
在 LoCoMo 和 PerLTQA 基准上，xMemory 的 F1 达到 **97.10%**，大幅领先标准 RAG（80.16%）和混合 RAG（87.24%）；推理 token 效率同步提升。
🧩 **技术分类**
Memory维度：情景记忆 / 外部存储 / 记忆检索
Context维度：上下文压缩
🔗 **Memory ↔ Context 关联**
xMemory 通过层级解耦将长期记忆存储与检索时上下文窗口用量解绑，使 Agent 能在有限 Context 内访问精确记忆。

### 3️⃣

📄 **[LongSeeker：面向长时程搜索 Agent 的弹性上下文编排]**（LongSeeker: Elastic Context Orchestration for Long-Horizon Search Agents）
🔗 https://arxiv.org/abs/2605.05191
💡 **核心贡献**
提出 Context-ReAct 范式，将推理、上下文管理与工具调用统一在一个循环中；通过五个原子操作（Skip / Compress / Rollback / Snippet / Delete）赋予 Agent 自主塑造工作记忆的能力，使长时程任务中的上下文始终保持高密度相关性。
🔧 **技术亮点**
- Compress 算子在理论上具备表达完备性（expressively complete），可等价替换其余算子
- Rollback/Delete 允许 Agent 主动剪除无效分支，防止"Context Poisoning"
- LongSeeker 在 Qwen3-30B-A3B 基础上用 1 万条合成轨迹微调，5 个基准全面超越 DeepResearch
📊 **实验结果**
BrowseComp: **61.5%**（vs Tongyi DeepResearch 43.2%，AgentFold 36.2%）；BrowseComp-ZH: **62.5%**（vs 46.7%，47.3%）
🧩 **技术分类**
Context维度：上下文压缩 / 上下文管理
Memory维度：工作记忆
🔗 **Memory ↔ Context 关联**
Context-ReAct 通过 Compress 操作将交互历史动态压缩为精炼的工作记忆块，直接在 Context 层实现了短期 Memory 的自主管理。

### 4️⃣

📄 **[Focus Agent：受黏菌启发的主动上下文压缩 Agent 架构]**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 **核心贡献**
提出 Focus Agent 架构，受黏菌（Physarum polycephalum）生物探索策略启发，赋予 Agent 在单次任务轨迹内自主决定何时压缩、何时裁剪历史的能力，将关键学习内容固化到持久化"Knowledge"块，实现轨迹内（intra-trajectory）压缩而非任务间处理。
🔧 **技术亮点**
- `start_focus` / `complete_focus` 两个工具原语，Agent 完全自主调用无外部启发式干预
- 知识块（Knowledge Block）持久化设计：精炼学习内容存储，原始历史日志主动删除
- 对标 SWE-bench Lite，平均每任务自主压缩 6.0 次，在不损失准确率的前提下最多节省 57% token
📊 **实验结果**
N=5 context-intensive 实例：token 消耗从 14.9M 降至 11.5M（**减少 22.7%**），准确率保持 3/5=60% 不变；单实例最高节省 **57%** token。
🧩 **技术分类**
Context维度：上下文压缩 / 上下文管理
Memory维度：工作记忆 / 情景记忆
🔗 **Memory ↔ Context 关联**
Focus Agent 将 Context（历史轨迹）显式转化为结构化 Memory（Knowledge 块），以压缩 Context 换取持久化语义记忆。

### 5️⃣

📄 **[记忆诅咒：扩展历史如何侵蚀 LLM Agent 的合作意图]**（The Memory Curse: How Expanded Recall Erodes Cooperative Intent in LLM Agents）
🔗 https://arxiv.org/abs/2605.08060
💡 **核心贡献**
首次系统揭示"记忆诅咒"现象：在多 Agent 社会困境中，扩展可访问历史在 28 种模型-游戏设置的 18 种中降低了合作率；通过词法分析、LoRA 探针微调与记忆卫生（memory sanitization）三重方法定位根因为前瞻性意图（forward-looking intent）的侵蚀，而非偏执或上下文长度本身。
🔧 **技术亮点**
- 37.8 万条推理痕迹词法分析，精确区分"偏执增加"vs"前瞻意图下降"两种假说
- LoRA 适配器仅在前瞻性轨迹上训练，能零样本迁移缓解不同游戏中的合作衰减
- 记忆卫生实验（合成合作历史替换真实历史）恢复合作，证明触发因素是记忆内容而非长度
📊 **实验结果**
7 个 LLM × 4 种博弈 × 500 轮：**18/28** 设置合作率随历史扩展而下降；LoRA 探针有效缓解衰减并零样本迁移。
🧩 **技术分类**
Memory维度：情景记忆 / 记忆检索
Context维度：上下文管理 / In-Context学习
🔗 **Memory ↔ Context 关联**
该工作揭示了记忆内容（历史 Context）对多 Agent 推理行为的因果影响，表明 Memory 管理策略（如选择性遗忘）是 Context 设计中不可忽视的行为对齐维度。

## 🧠 今日洞察

1. **Memory 机制正走向"主动自治"**：从 LongSeeker 的弹性上下文编排到 Focus Agent 的轨迹内压缩，研究焦点从"存什么记忆"转向"Agent 如何自主管理自己的记忆与上下文"，主动性（proactive）是2026年的核心关键词。

2. **记忆质量 > 记忆数量**：xMemory 以高精度层级检索击败 RAG，Memory Curse 揭示扩展历史的负面效应——两项研究从不同角度证明，无节制堆积记忆有害，精炼与选择性遗忘才是设计重点。

3. **Memory ↔ Context 协同设计走向统一**：Context-ReAct 范式（LongSeeker）与 ACL 2026 录用的三阶段演化综述（Storage→Reflection→Experience）共同指向同一趋势：Memory 层与 Context 层的边界正在模糊，未来高效 Agent 将需要跨层联合优化——压缩、检索、遗忘、重构将在一个统一控制循环中完成。
