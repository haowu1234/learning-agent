📄 **[LatentRAG：潜在空间推理与检索的高效 Agentic RAG 框架]**（LatentRAG: Latent Reasoning and Retrieval for Efficient Agentic RAG）
🔗 https://arxiv.org/abs/2605.06285
💡 **核心贡献**：提出 LatentRAG，将 Agentic RAG 的推理与检索过程从离散语言空间迁移至连续潜在空间，通过单次前向传播直接生成潜在子查询 token，解决多步 Agentic RAG 的高延迟瓶颈。在保持与显式 Agentic RAG 相当性能的同时，推理延迟降低约 **90%**。
🔧 **技术亮点**：
- 在潜在空间中对齐 LLM 与稠密检索模型，支持基于潜在子查询 token 直接检索，实现端到端联合优化
- 引入并行潜在解码机制（Parallel Latent Decoding），将潜在 token 反向翻译为自然语言，增强透明性与语义可解释性
- 一次前向传播同时生成 thoughts 与 subqueries，彻底消除逐 token 自回归生成的串行延迟
📊 **实验结果**：在 7 个基准数据集上性能与显式 Agentic RAG 相当，推理延迟降低约 90%，大幅缩小与传统单步 RAG 的延迟差距
🧩 **技术分类**：
- Memory 维度：记忆检索（潜在空间检索）
- Context 维度：上下文压缩（潜在 token 替代显式子查询链路）
🔗 **Memory ↔ Context 关联**：将外部知识库的检索记忆过程压缩进潜在空间，使检索信息以极小 token 代价融入上下文，是 Memory 检索与 Context 效率协同优化的典型工作。

📄 **[AgeMem：统一长短期记忆管理的 Agent 记忆框架]**（Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents）
🔗 https://arxiv.org/abs/2601.01885
💡 **核心贡献**：提出 AgeMem，首个将长期记忆（LTM）与短期记忆（STM）管理统一集成进 Agent 策略的框架，通过工具调用形式暴露记忆操作（存储、检索、更新、摘要、丢弃），使 Agent 自主决策记忆生命周期。
🔧 **技术亮点**：
- 将记忆操作建模为可学习的 tool-based actions，LLM 自主决定"何时存、存什么、何时遗忘"，彻底告别启发式控制器依赖
- 设计三阶段渐进式强化学习训练策略（Progressive RL），循序培养记忆管理的复杂行为
- 提出 step-wise GRPO 算法，专门应对记忆操作引发的稀疏、非连续奖励信号
📊 **实验结果**：在 5 个长时域基准测试上持续优于强基线，任务性能提升、长期记忆质量更高、上下文使用更高效
🧩 **技术分类**：
- Memory 维度：工作记忆 + 情景记忆（统一 LTM/STM）
- Context 维度：上下文管理（动态 context 使用优化）
🔗 **Memory ↔ Context 关联**：通过 RL 训练 Agent 学会自主压缩/清理上下文，使长短期记忆在有限 context window 内高效共存，直接建立了记忆策略与上下文效率的闭环。

📄 **[E-mem：基于多智能体的情景上下文重建记忆框架]**（E-mem: Multi-agent based Episodic Context Reconstruction for LLM Agent Memory）
🔗 https://arxiv.org/abs/2601.21714
💡 **核心贡献**：针对传统 RAG 和长文本系统中"破坏性去上下文化"问题，提出从"记忆预处理"范式转向"情景上下文重建"范式，通过多智能体异构层级架构保留原始上下文的完整推理链路。**已被 ICML 2026 接收**。
🔧 **技术亮点**：
- 异构层级架构：多个 assistant agent 各自维护未压缩的情景记忆上下文，master agent 负责全局规划，分工协作
- 非被动检索：assistant agent 在本地激活的记忆片段内进行实际推理，提取上下文感知证据后再聚合给 master，保留推理完整性
- 受生物 engram（记忆印迹）启发，以序列依赖关系的完整保留代替传统 embedding 压缩
📊 **实验结果**：LoCoMo 基准 F1 超过 54%，超越 SOTA GAM 7.75%，同时 token 成本降低 70% 以上
🧩 **技术分类**：
- Memory 维度：情景记忆（Episodic Context Reconstruction）
- Context 维度：上下文管理（分布式情景上下文维护）
🔗 **Memory ↔ Context 关联**：以多 agent 分布式持有完整 context 代替单点压缩，让情景记忆的丰富性与 context window 限制之间找到新的平衡点。

📄 **[REMem：面向语言 Agent 的情景记忆推理框架]**（REMem: Reasoning with Episodic Memory in Language Agent）
🔗 https://arxiv.org/abs/2602.13530
💡 **核心贡献**：识别并形式化了语言 Agent 情景记忆的核心挑战——现有系统忽视情景性、缺乏显式事件建模、过度依赖简单检索而非复杂推理——并提出两阶段情景记忆框架 REMem，显著提升情景回溯与推理能力。**已被 ICLR 2026 接收**。
🔧 **技术亮点**：
- 离线索引阶段构建混合记忆图（Hybrid Memory Graph），灵活连接时间感知的 gist 节点与事实三元组节点，同时保留时序与语义双维结构
- 在线推理阶段采用配备精心设计工具集的 agentic retriever，在记忆图上执行迭代检索，支持复杂多跳推理
- 对不可回答问题展现出更鲁棒的拒答行为，降低幻觉风险
📊 **实验结果**：在 4 个情景记忆基准上显著优于 Mem0、HippoRAG 2 等 SOTA，情景回溯提升 3.4%、情景推理提升 13.4%（绝对值）
🧩 **技术分类**：
- Memory 维度：情景记忆 + 记忆检索（混合记忆图 + 迭代检索）
🔗 **Memory ↔ Context 关联**：混合记忆图将情景历史结构化外置，通过迭代检索按需注入上下文，实现情景记忆与 context 窗口的精准解耦。

📄 **[Focus：LLM Agent 的主动上下文压缩与自主记忆管理]**（Active Context Compression: Autonomous Memory Management in LLM Agents）
🔗 https://arxiv.org/abs/2601.07190
💡 **核心贡献**：提出 Focus Agent，一种受黏菌（Physarum polycephalum）生物探索策略启发的以 Agent 为中心的上下文压缩架构，Agent 可自主决定何时将关键学习内容巩固进持久"知识块"并主动裁剪原始交互历史，解决软件工程长时域任务中的"Context Bloat"问题。
🔧 **技术亮点**：
- Agent 自主触发压缩：平均每任务执行 6.0 次自主压缩，单任务最高节省 57% tokens，打破"被动外部摘要"的传统依赖
- 持久"Knowledge"块机制：将关键洞察和学习成果结构化写入独立知识块，在裁剪交互历史的同时保留核心知识
- 评估基于工业最佳实践脚手架（持久 bash + 字符串替换编辑器），与真实软件工程场景对齐
📊 **实验结果**：SWE-bench Lite 5 个上下文密集实例：激进压缩模式下整体 token 减少 22.7%（14.9M→11.5M），准确率维持不变（3/5=60%）
🧩 **技术分类**：
- Memory 维度：工作记忆（主动记忆巩固与裁剪）
- Context 维度：上下文压缩（自主 Context Compression）
🔗 **Memory ↔ Context 关联**：通过将交互历史中有价值的部分提炼为持久记忆块、丢弃冗余上下文，直接在 Memory 写入与 Context 管理之间建立实时动态平衡。

📄 **[面向自主 LLM Agent 的记忆机制综述：机制、评测与新前沿]**（Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers）
🔗 https://arxiv.org/abs/2603.07670
💡 **核心贡献**：首篇系统覆盖 2022-2026 年初 LLM Agent 记忆设计、实现与评测全貌的综述，形式化 write-manage-read 记忆循环，构建三维分类体系（时间范围 × 表示基底 × 控制策略），并系统梳理五大记忆机制家族与新兴挑战。
🔧 **技术亮点**：
- 三维分类体系：时间范围（短期/长期）× 表示基底（文本/向量/图/参数）× 控制策略（被动/主动/策略学习）
- 深入剖析五大记忆机制：上下文内压缩（Context-resident compression）、检索增强存储（RAG stores）、反思自改进（Reflective self-improvement）、层级虚拟上下文（Hierarchical virtual context）、策略学习管理（Policy-learned management）
- 系统追踪评测范式演变：从静态回溯基准转向多会话 Agentic 测试，分析四个揭示持久性能差距的近期基准
📊 **实验结果**：N/A（综述论文，不含原始实验）
🧩 **技术分类**：
- Memory 维度：全维度（情景记忆 / 语义记忆 / 工作记忆 / 外部存储 / 记忆检索）综述
- Context 维度：上下文压缩 / 上下文管理（综合覆盖）
🔗 **Memory ↔ Context 关联**：显式将记忆架构与 context window 约束并置分析，指出 context-resident 压缩是连接两者的关键机制，为协同设计提供理论框架。

## 🧠 今日洞察

1. **从被动检索到主动自治**：今日研究趋势明显转向 Agent 对记忆的主动管理——无论是 AgeMem 的 RL 驱动自主记忆决策、Focus 的自主上下文压缩，还是 E-mem 的多智能体情景重建，均表明"让 Agent 学会管理自己的记忆"已成为主流范式，硬编码的被动摘要机制正在被取代。

2. **情景记忆成为研究焦点**：REMem（ICLR 2026）和 E-mem（ICML 2026）双双聚焦情景记忆的深度重建与推理，说明学界认识到当前语言 Agent 的记忆能力仍停留在语义层面，缺乏时序完整性与事件推理能力，情景记忆的形式化表示（混合图、engram 架构）是破局方向。

3. **Memory × Context 协同设计进入系统化阶段**：LatentRAG 的潜在空间检索、AgeMem 的 context 使用优化、Focus 的 Knowledge 块机制，都体现出 Memory 机制设计必须与 Context 效率共同考量的新趋势；2603.07670 综述的发布标志着该领域正从零散探索走向系统化理论框架构建阶段，write-manage-read 循环的形式化为 Memory ↔ Context 协同设计提供了统一语言。
